1.2 연구 목표 (Research Objective)

단일 로봇 사회적 항해(social navigation)에서 강화학습(RL)은 인간과 공유하는 제약 환경에서 빠르고 확장 가능한 결정을 내리는 유력한 패러다임이 되었다. 그러나 이 성공을 다중 로봇(multi-robot) 환경으로 그대로 확장하면 안전성과 효율이 동시에 무너진다. 핵심 원인은 두 가지다.

  1. 상호 가림(occlusion): 로봇 A의 시야를 로봇 B·보행자가 가로막아, A 혼자서는 사각지대에 들어올 보행자/로봇을 관측할 수 없다. 단일 로봇 정책을 독립적으로 복제하면 각 로봇이 자기 센서만 믿고 움직여 사각지대 충돌이 급증한다.

  2. 분포 이동(distribution shift, OOD): 학습 시 보지 못한 레이아웃·보행자 밀도·돌진(rushing) 행동이 배치 시점에 나타나면, 미래 예측(forecast)이 체계적으로 빗나가고 정책이 과신(overconfident)하여 위험 영역으로 진입한다.

CoopUQ는 이 두 문제를 "불확실성 인지 협력 점유 예측(uncertainty-aware cooperative occupancy forecasting)" 과 "강건 의사결정(robust decision making)" 을 다리 놓아(bridge) 해결한다. 구체적으로:

  • 여러 로봇의 시공간 특징을 교차 로봇 융합(cross-robot spatiotemporal feature fusion) 하여 미래 점유 격자지도(Occupancy Grid Map, OGM) 를 예측한다 — 가림 영역을 이웃 로봇의 관측으로 메운다.
  • 예측 OGM의 불확실성(uncertainty) 을 정량화하여, "점유될 것으로 예측된 영역" 뿐 아니라 "높은 불확실성 영역" 까지 회피하도록 제약 다중에이전트 RL(constrained multi-agent RL, CMARL) 의 비용(cost)으로 주입한다.
  • 이 설계 덕분에 정책은 분포 이동 하에서 위험 민감도(risk sensitivity)를 적응적으로 조정한다 — OOD에서 예측이 흐릿해지면(불확실성↑) 자동으로 더 보수적으로 움직인다.

즉 이 논문의 기여는 (예측·불확실성) → (제약 비용) → (정책) 이라는 폐루프를, 다중 로봇의 협력 관측과 결합해 "강건한 사회적 항해"로 완성한 데 있다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

C1. 단일→다중 로봇 확장의 비자명성. 단일 로봇 사회적 항해(SA-RL 계열)는 자기 관측만으로 보행자 의도를 추정하고 회피한다. 로봇이 여럿이면 (a) 서로가 서로의 동적 장애물이 되고, (b) 서로가 서로의 시야를 가린다. 독립 정책 복제는 비협력적(non-cooperative) 평형으로 수렴해 교착·충돌을 유발한다.

C2. 가림 하의 관측 불완전성. 밀집 군중에서 각 로봇의 2D LiDAR/점유 관측은 심하게 가려진다. 사각지대로 진입할 보행자를 "보이지 않으니 없다"고 가정하면 충돌한다. 그러나 이웃 로봇은 그 보행자를 보고 있을 수 있다 — 협력 관측이 가림을 메운다.

C3. OOD에서의 예측 붕괴와 과신. 미래 OGM 예측기는 학습 분포(특정 레이아웃·밀도·속도)에서만 신뢰할 수 있다. 배치 시 밀도가 올라가거나 보행자가 돌진하면 예측 오차가 급증하는데, 이를 "확정된 미래"로 취급하면 정책이 위험하게 행동한다. 예측이 틀릴 수 있다는 사실(불확실성)을 정책이 알아야 한다.

C4. 안전과 효율의 상충을 명시적으로 다루기. 조밀 보상(dense reward)에 안전·효율·진행을 모두 섞으면 가중치 튜닝이 불투명하고, 분포 이동마다 재학습이 필요하다. 안전을 제약(constraint) 으로 분리하면 임계값에 해석 가능한 의미를 부여하고 위험 민감도를 조정 가능하게 만들 수 있다.

2.2 핵심 해결책

CoopUQ는 두 모듈을 폐루프로 연결한다.

  1. 협력 점유 예측기 (Cooperative Occupancy Forecasting) — 각 로봇의 OGM 이력을 ConvLSTM으로 인코딩하고, 중간 융합(Middle Fusion) 으로 이웃 로봇의 공간 정렬된 특징을 편차 유도 어텐션 게이트(deviation-guided attention gate) 로 선택적으로 통합한 뒤, 확률적 VAE 디코더로 비자기회귀(non-autoregressive) 미래 OGM 시퀀스를 생성한다. M=8개 샘플로 미래 OGM의 픽셀별 정규화 섀넌 엔트로피 를 불확실성 맵으로 뽑는다.

  2. 제약 다중에이전트 RL (Constrained MARL) — 미래 점유맵과 불확실성 맵을 관측에 넣고, 비용 함수가 "점유 예측 영역 OR 고불확실성 영역"으로의 진입을 거리 가중 페널티로 처벌 하는 제약 마르코프 게임(Constrained Markov Game)을 MAPPO-Lagrangian 으로 푼다. 비용 한도 ϵ이 위험 허용치의 해석 가능한 손잡이가 된다.

3. 핵심 방법론 (Core Methods)

3.1 협력 점유 예측기 — 인코더 (ConvLSTM Spatiotemporal Encoder)

각 로봇 i는 자기중심 OGM 이력 O^i_{t-τ:t} (τ=5, 64×64 셀, 0.1m 해상도)을 유지한다. 먼저 자기운동 보상(ego-motion compensation) 으로 과거 OGM들을 현재 로봇 프레임으로 정렬한 뒤, ConvLSTM으로 시공간 특징 F^i_t 를 뽑는다.

F^i_t = ConvLSTM(EgoComp(O^i_{t-τ:t}))      # 시공간 특징 (C×H×W)

ConvLSTM은 셀 상태에 공간 구조(격자)를 보존하므로, 보행자의 "이동 방향·속도"가 특징맵의 국소 활성 패턴으로 암묵 인코딩된다. 자기운동 보상이 없으면 로봇 자신의 회전·병진이 "배경 흐름"으로 섞여 예측을 오염시킨다.

3.2 교차 로봇 시공간 융합 (Cross-Robot Fusion, Middle Fusion)

CoopUQ의 핵심 설계 결정은 "언제·어떻게 이웃 로봇 정보를 합치는가" 이다. 논문은 세 가지 융합 시점을 비교한다.

Early Fusion   : 원시 OGM을 먼저 합친 뒤 인코딩   → 정렬 오차·가림 상호 전파
Late Fusion    : 각자 예측한 뒤 결과를 합침        → 가림 영역은 이미 비어 복원 불가
Middle Fusion  : 중간 특징 F를 공간 정렬 후 융합   → 본 논문 채택 (최고 성능)

① 공간 정렬(spatial alignment). 이웃 로봇 k의 특징 F^k_t 를 로봇 i의 프레임으로 학습 가능한 변환 Γ_F 로 옮긴다. 상대 포즈 p^i_t, p^k_t 를 입력받아 특징맵을 재샘플링한다.

F̂^{k→i}_t = Γ_F(F^k_t, p^i_t, p^k_t)        # k의 특징을 i 프레임으로 정렬

② 편차 유도 어텐션 게이트(deviation-guided attention gate). 모든 이웃 정보를 똑같이 믿으면, 포즈 오차나 중복 관측이 노이즈를 주입한다. CoopUQ는 자기 특징 F^i_t 과 정렬된 이웃 특징 F̂^{k→i}_t 사이의 공간적 불일치(disagreement) 로부터 게이트 G^i_t 를 계산해, "자기가 이미 잘 보는 영역"은 이웃 기여를 낮추고 "자기 사각지대(불일치가 큰 영역)"는 이웃 기여를 높인다.

G^i_t = Gate( Disagree(F^i_t, {F̂^{k→i}_t}_{k≠i}) )     # 사각지대일수록 게이트 개방
F^cross_i = Attn_cross( F^i_t, {F̂^{k→i}_t}_{k≠i} ; G^i_t )

이 게이트가 CoopUQ의 "협력이 도움될 때만 협력" 철학의 수학적 구현이다. 가림이 심한 픽셀 영역에서만 이웃 관측을 적극 끌어온다.

③ 윈도우 MHSA + FFN. 융합된 특징을 윈도우 기반 멀티헤드 자기어텐션(window MHSA)과 FFN으로 정제한다.

F^fuse_i = FFN( MHSA(F^cross_i) )

3.3 확률적 VAE 디코더 (Stochastic Future Decoding)

미래는 다봉(multi-modal)이다 — 보행자가 좌/우/정지 중 어디로 갈지 불확실하다. CoopUQ는 확률적 VAE 로 이 다봉성을 포착한다.

  • 인코더가 대각 가우시안 잠재분포의 평균 μ, 표준편차 σ 를 산출.
  • 재매개화 트릭(reparameterization): z = μ + σ ⊙ ε, ε ~ N(0,I). 미래 스텝마다 별도 잠재변수를 둬 스텝별 다양성 확보.
  • 스킵 연결 디코더가 현재 OGM 기하를 보존하면서 h=5 스텝 미래 OGM을 비자기회귀(non-autoregressive) 로 한 번에 디코딩 → 자기회귀 오차 누적 회피.
학습 손실:  L = L_recon(m̂, m_gt) + β · D_KL( q(z|·) ‖ N(0,I) ),   β = 0.01

3.4 불확실성 정량화 (Uncertainty Quantification)

CoopUQ의 불확실성은 생성 앙상블(generative ensemble) 에서 나온다 — 드롭아웃이나 컨포멀 예측이 아니라, VAE 디코더에서 M=8개 샘플 을 뽑아 분산을 측정한다.

{ m̂^{(1)}, ..., m̂^{(M)} } = VAE_decode(z^{(1..M)}),   M = 8

예측 OGM :  m^i_{t+1:t+h}(x,y) = (1/M) Σ_s m̂^{(s)}(x,y)          # 픽셀 평균
불확실성맵:  u^i_{t+1:t+h}(x,y) = 정규화 섀넌 엔트로피_s[ m̂^{(s)}(x,y) ]  # 픽셀별

직관: 8개 샘플이 어떤 픽셀에서 "점유/비점유"로 갈리면 엔트로피가 높다 — 그 픽셀은 미래가 불확실하다. OOD(밀집·돌진)에서는 샘플 간 불일치가 커져 불확실성 맵이 전역적으로 밝아지고, 이것이 곧바로 정책을 보수화시킨다. 이 "불확실성→보수화" 연결이 분포 이동 강건성의 핵심 메커니즘이다.

3.5 제약 다중에이전트 RL (Constrained MARL)

항해를 제약 마르코프 게임(Constrained Markov Game) 으로 정식화한다.

max_{πθ}  J^R(πθ) = E_{πθ}[ Σ_t γ^t R(s_t, a_t) ]
   s.t.   J^C(πθ) = E_{πθ}[ Σ_t γ^t C(s_t, a_t) ] ≤ ϵ

비용 함수(per-robot). CoopUQ 기여의 수학적 심장. 미래 지평 전체에서 "점유 예측 영역" 또는 "고불확실성 영역"에 진입하면 거리 가중 페널티 를 부과한다.

C^i(s_t,a_t) = Δt · [
    max_{ℓ∈{0..h}, (x,y)∈B^i_occ}  λ_occ · 𝕀( m^i_{t+ℓ}(x,y) > φ_occ ) · w_d(x,y)
  + max_{ℓ∈{0..h}, (x,y)∈B^i_unc}  λ_unc · 𝕀( u^i_{t+ℓ}(x,y) > φ_unc ) · w_d(x,y)
]

w_d(x,y) = max(0, r_safe − d(x,y))      # 로봇에 가까운 위험일수록 큰 페널티
  • 첫 항: 점유 예측 임계 φ_occ=0.5 초과 셀 진입 처벌.
  • 둘째 항: 불확실성 임계 φ_unc=0.3 초과 셀 진입 처벌 — "안 보이는 미래"를 명시적으로 기피.
  • max_ℓ: 미래 h 스텝 중 가장 위험한 순간을 집계(worst-case).
  • w_d: 안전 반경 r_safe=5셀 내에서 로봇에 가까울수록 선형 가중.
  • λ_occ=λ_unc=0.5: 두 위험을 동등 가중.

보상 함수.

도달 +10 / 정적충돌 −10 / 로봇충돌 −15 / 인간충돌 −20
진행 보상 r_dis = Δd·f + r_time   (f=5, r_time=−0.1)   # 목표 접근 장려 + 시간 페널티

인간 충돌(−20)을 로봇 충돌(−15)·정적 충돌(−10)보다 무겁게 둬 사회적 안전 우선순위를 명시한다.

MAPPO-Lagrangian. 제약을 라그랑주 쌍대로 완화한다.

max_{πθ} min_{η≥0}  L(πθ, η) = J^R(πθ) − η·( J^C(πθ) − ϵ )
  • 보상 크리틱·비용 크리틱 두 개를 분리 운영.
  • 라그랑주 승수 η 초기값 0.1, 학습률 0.003, [0,5] 로 클리핑 — 비용이 한도 ϵ을 넘으면 η가 커져 정책을 보수화, 여유가 생기면 η가 작아져 효율 추구.
  • 비용 한도 ϵ=0.10 이 위험 허용치의 해석 가능한 단일 손잡이. OOD에서 예측이 흐려져 불확실성 비용이 늘면, 같은 ϵ 아래에서 정책이 자동으로 더 조심하게 된다 — 재학습 없이 위험 민감도가 적응한다.

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 (Datasets / Environments)

  • Unity3D 기반 시뮬레이션 다중 환경: 다양한 레이아웃, 보행자 밀도, 돌진 행동.
  • In-Distribution(ID) 과 Out-of-Distribution(OOD) 설정 분리 평가.
  • OOD 축: (a) 미관측 레이아웃, (b) 더 밀집한 군중(12–15명), (c) 돌진 보행자(최대 2 m/s).
  • 예측기 학습: OGM 64×64@0.1m, 이력 τ=5, 지평 h=5(5Hz에서 1초), M=8, 20 에폭, Adam(lr=1e-4, wd=1e-3).
  • 정책 학습: 환경당 3로봇, 총 1e6 스텝, 8 병렬 롤아웃, γ=0.99, GAE λ=0.95, Adam lr=5e-4(선형 감쇠).

6. 핵심 기여점 (Key Contributions)

  1. 불확실성 인지 협력 예측 → 강건 의사결정의 폐루프 통합. 다중 로봇의 교차 시공간 융합으로 미래 OGM을 예측하고, 그 예측과 불확실성을 CMARL 비용으로 되먹여 정책을 보수화한다. "예측·불확실성·정책"을 하나의 학습 가능한 폐루프로 묶은 최초의 다중 로봇 사회적 항해 프레임워크.

  2. 편차 유도 게이트 기반 중간 융합. 이웃 특징을 공간 정렬하되, 자기-이웃 불일치(=사각지대)에서만 게이트를 열어 선택적으로 통합. 조기/후기 융합 대비 IoU·SSIM·WMSE 전부 우위(표 1).

  3. 점유 ∪ 불확실성 거리 가중 비용. 비용이 "점유 예측 영역"뿐 아니라 "고불확실성 영역"까지 처벌(λ_occ=λ_unc=0.5, φ_occ=0.5, φ_unc=0.3). 이것이 분포 이동 시 재학습 없는 위험 민감도 적응을 가능케 함.

  4. 해석 가능한 단일 안전 손잡이 ϵ. MAPPO-Lagrangian의 비용 한도 ϵ=0.10이 위험 허용치를 명시. 라그랑주 승수 η가 실시간으로 안전↔효율 균형을 조정.

  5. ID·OOD·실기체 전면 검증. Unity3D ID/OOD(밀도·돌진·레이아웃)에서 예측·안전 모두 베이스라인 상회, 2대 ROSMASTER X3 zero-shot 전이로 실세계 강건성 입증. 코드·체크포인트 공개(predictor/·onpolicy/·simulator/).

정책(policy)

  • 환경당 3로봇, 총 1e6 스텝, 8 병렬 롤아웃 스레드.
  • γ=0.99, GAE λ=0.95, Adam lr=5e-4(선형 감쇠).
  • GRU 순환 정책 + 64유닛 MLP.
  • 라그랑주 승수 η: 초기 0.1, lr 0.003, 클립 [0,5].

비용/보상 상수

  • ϵ=0.10, φ_occ=0.5, φ_unc=0.3, λ_occ=λ_unc=0.5, r_safe=5셀, Δt=0.2s.
  • 보상: 도달 +10 / 정적 −10 / 로봇 −15 / 인간 −20 / 진행 f=5, r_time=−0.1.

실기체

  • ROSMASTER X3 ×2, UWB+KF 측위, RPLIDAR-A1(~6Hz), Unity→실기체 zero-shot.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

학습은 3로봇으로 수행했으나, 교차 로봇 어텐션은 가변 이웃 수를 수용하도록 설계되어 있다. 다만 전역 특징 공유의 통신 대역폭·동기화 지연이 로봇 수에 따라 어떻게 늘어나는지는 본문에서 정량화되지 않았다(실기체는 2대). 대규모 군집(수십 대)으로의 확장성은 열린 문제.

8.2 한계점 (Limitations)

  • 통신 가정. 교차 로봇 융합은 이웃의 중간 특징과 상대 포즈를 실시간 공유한다고 가정. 실기체는 UWB로 상대 포즈를 얻지만, 특징 공유의 대역폭·지연·패킷 손실 강건성은 미평가.
  • 불확실성의 성격. 섀넌 엔트로피 기반 불확실성은 VAE 샘플 분산(aleatoric+부분적 epistemic 혼합)이며, 컨포멀 예측처럼 통계적 커버리지 보장은 없다. OOD 커버리지가 "경험적으로" 개선될 뿐 이론 보장은 아니다(CoSMO·ProximitySafetyBalance의 ACI/DtACI 대비 약점).
  • 2D·실내. OGM이 2D 점유라 3D 장애물(테이블 밑·계단)·실외 비정형 지형은 범위 밖. 실기체도 실내 4장면.
  • 보행자 모델 의존. Unity 보행자 행동(돌진 포함)이 실제 인간 다양성을 얼마나 대표하는지는 시뮬 한계.

8.3 향후 방향 (Future Directions)

  • 통신 제약(대역폭·지연·간헐 연결)을 명시 모델링한 융합 — "언제 공유할지"까지 학습(Cooperative VLN hindsight gating 선례와 접점).
  • 컨포멀/분포 강건 최적화로 불확실성에 커버리지 보장 부여(CoSMO의 ACI 결합).
  • 로봇 수 확장성 실증(수십 대), 실외·3D 지형, 이기종 로봇팀.

9.1 기존 리뷰 논문과의 비교

9.2 장단점 분석

장점.

  • 다중 로봇 가림 문제를 협력 예측으로 정면 해결 — 중간 융합이 조기/후기보다 IoU에서 명확히 우위(표 1).
  • 불확실성을 비용에 넣어 OOD에서 재학습 없이 보수화 — 하락폭이 SCOPE의 절반(밀집 −11.1% vs −22.4%).
  • ProximitySafetyBalance의 "제약 RL" 철학을 다중 로봇으로 확장하면서, 상태 기반 비용을 예측맵 기반 비용으로 승격 — 미래 위험을 선제적으로 회피.
  • 실기체 zero-shot 전이로 sim-to-real 간극 실증.

단점.

  • 불확실성에 통계적 보장이 없다 — CoSMO(ACI)·ProximitySafetyBalance(DtACI)가 커버리지를 보장하는 데 반해, CoopUQ는 경험적 개선만. OOD 극단에서 보장이 필요한 안전 임무엔 약점.
  • 교차 로봇 특징 공유의 통신 비용·강건성 미평가(실기체 2대).
  • 2D·실내 한정, 보행자 모델의 현실성 의존.

9.3 실적용 가능성 평가

실내 다중 서비스 로봇(병원·공항·창고)에서 여러 로봇이 같은 공간을 공유할 때 직접 유용하다. 코드·체크포인트·Unity 시뮬이 공개되어 재현·확장 가능. zero-shot 실기체 전이가 배치 장벽을 낮춘다. 다만 (a) 특징 공유 통신 인프라(저지연·동기), (b) 안전 보장 필요 시 컨포멀 결합, (c) 로봇 수 확장 실증이 실배치 전 과제.

9.4 연구 방향성 평가

CoopUQ는 "협력 지각 + 불확실성 인지 제약 RL"이라는 조합을 다중 로봇 사회적 항해에 성립시킨 참신한 통합이다. 개별 구성요소(ConvLSTM 예측, VAE 다봉, Lagrangian 제약 RL)는 선행에 존재하나, 교차 로봇 중간 융합 게이트 + 점유∪불확실성 비용의 결합은 새롭다. ProximitySafetyBalance(동일 계보)의 자연스러운 다중 로봇 후속이자, CoSMO(컨포멀 의미 안전)와 상보적(CoSMO=단일 로봇 의미 커버리지 보장 vs CoopUQ=다중 로봇 기하 협력 예측) — 둘을 합치면 "보장된 불확실성 + 협력 예측"이 가능. 중복이 아닌 누적·결합 가능한 확장이다.

11. 결론 (Conclusion)

CoopUQ는 다중 로봇 사회적 항해의 두 고질병 — 상호 가림과 분포 이동 하 과신 — 을, 교차 로봇 협력 점유 예측과 불확실성 인지 제약 RL을 폐루프로 묶어 동시에 해결한다. 중간 융합의 편차 유도 게이트는 "사각지대일 때만 협력"을 구현해 예측 정확도를 끌어올리고(IoU 0.57→0.72), VAE 섀넌 엔트로피 불확실성을 거리 가중 비용으로 되먹여 OOD에서 하락폭을 절반으로 억제한다(밀집 −11.1% vs −22.4%). MAPPO-Lagrangian의 단일 비용 한도 ϵ이 안전↔효율을 해석 가능하게 조율하며, 2대 ROSMASTER X3 zero-shot 전이가 실세계 강건성을 입증한다.

혁신성은 개별 블록의 신규성보다 "협력 지각 → 불확실성 → 제약 정책"의 통합 설계에 있다. 실용적 의의는 공개 코드·시뮬·체크포인트와 zero-shot 전이로 즉시 재현·확장 가능하다는 점이다. 한계는 불확실성의 통계적 보장 부재와 통신·확장성 미평가로, 향후 컨포멀 결합(CoSMO 접목)·통신 제약 모델링·대규모 군집 실증이 자연스러운 다음 단계다. 동일 계보 ProximitySafetyBalance의 단일 로봇 제약 RL을 다중 로봇·예측맵 비용으로 승격한 일관된 연구 궤적의 확장으로서, 사회적 항해 Planner 연구에 견고한 기여를 더한다.
