1.2 연구 목표 (Research Objective)

UGE-MPC는 샘플링 기반 궤적 최적화의 근본적 한계를 해결한다. MPPI(Model Predictive Path Integral Control)는 로봇 경로 계획에서 가장 널리 사용되는 샘플링 기반 최적화 방법이지만, 초기 솔루션에 과도하게 민감하고 복잡한 환경에서 로컬 미니마에 빠지는 심각한 문제가 있다.

핵심 질문: "샘플링 기반 MPC가 어떻게 더 다양하고 탐색적인 궤적 후보들을 생성할 수 있는가?"

기존 방법들의 접근:

  1. MPPI: 단일 가우시안 분포에서 샘플링 → 행동 공간에서만 다양성 확보 시도
  2. MoG-MPPI: 혼합 가우시안(Mixture of Gaussians) 사용 → 다중 모드 탐색 가능하지만 동역학 무시
  3. SV-MPC: Stein Variational Gradient Descent → 입자 반발로 다양성 강제하지만 계산 비용 高

DeCoNav의 핵심 통찰: 궤적 다양성은 행동 공간이 아닌 구성 공간(configuration space)에서 측정되어야 한다. 로봇의 동역학이 동일한 행동 변화라도 완전히 다른 궤적을 만들 수 있기 때문에, 행동 공간에서의 다양성 측정은 실제 궤적 다양성을 정확히 반영하지 못한다.

UGE-TO는 궤적을 불확실성 타원체(Uncertainty Ellipsoids)로 유도된 확률 분포로 표현하고, 이들 사이의 헬링거 거리(Hellinger Distance)를 최대화하여 구성 공간에서의 진정한 다양성을 달성한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. MPPI의 근본적 한계: 로컬 미니마 수렴

MPPI 동작 원리와 한계:

입력: 명목 제어 시퀀스 Ū = [u_0, ..., u_{T-1}]
      + 노이즈 분산 Sigma_u

프로세스:
  1. L개 랜덤 섭동 생성: U^(l) = Ū + eta^(l), eta^(l) ~ N(0, Sigma_u)
  2. 각 섭동에 대해 비용 J(U^(l)) 평가
  3. 중요도 가중치: w^(l) = exp(-J(U^(l)) / lambda)
  4. 가중 합산으로 Ū 업데이트

핵심 문제:
  - Ū 주변 가우시안에서만 샘플링 → 좁은 탐색 범위
  - Ū이 나쁜 로컬 미니마에 있으면 탈출 불가
  - 행동 공간 섭동 ≠ 궤적 공간 다양성 (동역학 무시)

구체적 실패 시나리오:

좁은 통로 (concave obstacle) 상황:

        목표
         |
    ┌────┴────┐
    │  장애물  │
    └─────────┘
         ↑
       ┌─┴─┐
       │   │
       └─┬─┘
       로봇

MPPI: Ū이 장애물 정면을 향하면, 모든 샘플이 같은 방향으로 편중됨
      → 장애물을 우회하는 경로를 발견하지 못함
      → 결과: 정지 또는 무한 진동

UGE-MPC: 불확실성 타원체로 표현된 궤적들이
          Hellinger 거리 최대화로 강제 분리됨
          → 좌측 우회 + 우측 우회 경로 자연 발생
          → 더 나은 명목 솔루션 선택

B. 기존 다양성 강화 방법들의 한계

방법 비교:

MoG-MPPI (Mixture of Gaussians):
  ✅ 다중 모드 샘플링 가능
  ❌ 행동 공간에서만 다양성 측정
  ❌ 동역학이 행동 → 궤적 매핑에 미치는 영향 무시
  ❌ 모드 수 사전 결정 필요

SV-MPC (Stein Variational):
  ✅ 입자 반발로 강제 다양성
  ❌ 그래디언트 계산 필요 → 블랙박스 동역학 불가
  ❌ 수렴 보장 약함
  ❌ 계산 비용 높음 (MPPI 대비 3-5배)

UGE-TO의 해결:
  ✅ 구성 공간(configuration space)에서 다양성 측정
  ✅ 동역학 전파 통해 행동→궤적 매핑 반영
  ✅ Hellinger 거리 → [0,1] 범위, 안정적 최적화
  ✅ 그래디언트 불필요 (순수 샘플링 기반)

C. 동역학 인식 다양성의 필요성

예시: 동일한 행동 섭동, 다른 궤적

시스템: 자전거 모델 (Bicycle Model)
        x_{t+1} = f(x_t, u_t) (비선형)

섭동: delta_u = [0.1, 0.1]  (가속도, 조향각 변화)

위치 A (직선 도로):
  delta_u → 궤적 변화: ~0.3m 이탈 (소폭)

위치 B (급커브):
  delta_u → 궤적 변화: ~2.5m 이탈 (대폭)
  (곡률 증폭 효과)

→ 같은 행동 섭동이라도 동역학에 따라 궤적 다양성이 크게 다름
→ 행동 공간에서만 다양성을 측정하면 실제 탐색 효과 과대/과소 평가

2.2 핵심 해결책

UGE-TO의 3단계 해결 전략:

해결 전략:

1. 불확실성 타원체 표현:
   → 각 제어 시퀀스에 대해 선형화된 동역학으로 
     공분산(covariance)을 앞방향으로 전파
   → 궤적 = 평균 경로 + 불확실성 타원체 (확률 분포)

2. Hellinger 거리 기반 분리:
   → 서로 다른 궤적 분포들 사이의 Hellinger 거리 최대화
   → [0,1]로 정규화된 안정적 거리 메트릭 활용

3. UGE-MPC 통합:
   → UGE-TO로 다양한 명목 궤적 생성 (글로벌 탐색)
   → MPPI로 최선의 명목 궤적 주변 정밀 최적화 (로컬 수렴)
   → 글로벌 다양성 + 로컬 수렴의 시너지

3. 핵심 방법론 (Core Methods)

3.1 시스템 동역학 모델 (System Dynamics Model)

UGE-TO는 다음 확률론적 동역학 시스템에 적용된다:

상태 전이 방정식 (Eq. 1):
  x_{t+1} = f(x_t, u_t) + epsilon_t

  여기서:
    x_t in R^n    : 상태 벡터 (시간 t)
    u_t in R^m    : 제어 입력
    epsilon_t ~ N(0, Q) : 프로세스 노이즈

확률론적 최적 제어 목적함수 (Eq. 2):
  min_U  J(U) = E[ phi_T(x_T) + sum_{t=0}^{T-1} c(x_t, u_t) ]

  제약조건:
    x_0 ~ N(x̄_0, Q)    : 초기 상태 불확실성
    u_t in U             : 제어 입력 제약
    x_t in X             : 상태 공간 제약

제어 섭동 (Eq. 3):
  U^(i) = Ū + eta^(i),   eta^(i) ~ N(0, Sigma_u)

실제 구현에서의 동역학 모델 (실험 설정):

자전거 모델 (Bicycle Kinematic Model):
  상태: x = [px, py, theta]  (위치 x, 위치 y, 방향각)
  제어: u = [v, delta]  (속도, 조향각)

  상태 전이:
    px_{t+1}    = px_t + v_t * cos(theta_t) * dt
    py_{t+1}    = py_t + v_t * sin(theta_t) * dt
    theta_{t+1} = theta_t + v_t * tan(delta_t) / L * dt

  파라미터:
    v = 0.5 m/s (고정 속도)
    L = 1.0m (축간 거리)
    dt = 0.05s
    T = 4s 예측 호라이즌

3.2 불확실성 타원체 기반 궤적 표현 (Uncertainty Ellipsoid Representation)

UGE-TO의 핵심 아이디어: 각 제어 시퀀스 U^(i)를 확률 분포 T^(i)로 표현

3.2.1 공분산 전파 (Covariance Propagation)

비선형 동역학을 현재 궤적 주변에서 선형화:

공분산 전파 방정식 (Eq. 5):
  Sigma_{t+1}^(i) = A_t^(i) * Sigma_t^(i) * (A_t^(i))^T + Q

  여기서:
    A_t^(i) = df/dx|_{x_t^(i), u_t^(i)}  : 자코비안 행렬
    Sigma_t^(i)                            : 시간 t에서의 공분산
    Q                                       : 프로세스 노이즈 공분산

초기 조건:
  Sigma_0^(i) = Q  (초기 상태 불확실성)

이 전파는 제어 입력의 동역학적 효과를 공분산에 반영한다. 같은 크기의 행동 섭동이라도 동역학 자코비안 A_t에 따라 공분산이 다르게 증폭/감쇠된다.

3.2.2 궤적 분포 정의

전체 궤적을 하나의 가우시안 분포로 표현 (Eq. 6):

T^(i) = N(mu^(i), Sigma^(i))

mu^(i)    = [x_0^(i)^T, x_1^(i)^T, ..., x_T^(i)^T]^T
              (예측된 평균 궤적의 상태 시퀀스 연결)

Sigma^(i) = blockdiag(Sigma_0^(i), Sigma_1^(i), ..., Sigma_T^(i))
              (시간축 공분산 블록 대각 행렬)

이 표현의 핵심 특성:

  • 동역학 인식: 공분산이 동역학 자코비안으로 전파되므로 동역학 특성 반영
  • 비용 효율적: 블록 대각 구조로 고차원에서도 계산 효율적
  • 물리적 의미: 타원체 크기가 각 시간 스텝에서의 궤적 불확실성을 나타냄
시각화 예시:

시간 t=0: 작은 원 (초기 불확실성 = Q)
시간 t=2: 중간 타원 (동역학으로 전파된 불확실성)
시간 t=4: 큰 타원 (누적 불확실성, 급격한 동역학에서 더 크게 성장)

         t=0    t=2     t=4
          ○      ○       ○
궤적 A: ──●──────●───────●──→
          ↕      ↕↕      ↕↕↕  (불확실성 타원체 크기)
궤적 B: ──●────────●─────●──→

3.3 Hellinger 거리 기반 다양성 강화

두 궤적 분포 간의 거리를 Hellinger 거리로 측정:

3.3.1 헬링거 거리 정의

두 가우시안 분포 사이의 제곱 Hellinger 거리 (Eq. 8):

H²(T^(i), T^(j)) = 1 - |Sigma^(i)|^{1/4} * |Sigma^(j)|^{1/4}
                       ─────────────────────────────────────────
                              |Sigma_bar_{ij}|^{1/2}
                   * exp( -1/8 * Delta_mu^T * Sigma_bar_{ij}^{-1} * Delta_mu )

여기서:
  Delta_mu   = mu^(i) - mu^(j)   (평균 궤적 차이)
  Sigma_bar_{ij} = 1/2 * (Sigma^(i) + Sigma^(j))  (평균 공분산)

Hellinger 거리를 선택한 이유 (KL divergence 대비):

특성 KL Divergence Hellinger Distance
범위 [0, ∞) (무한대 가능) [0, 1] (유계)
대칭성 ❌ 비대칭 ✅ 대칭
안정성 분포 비겹침 시 폭발 안정적 계산
기울기 안정성 불안정할 수 있음 안정적
수렴 보장 약함 강함 
수식적 비교:

KL(P||Q) = integral [ p(x) log(p(x)/q(x)) ]
           → q(x)≈0인 영역에서 log(p/q) → ∞ → 수치 불안정

H²(P,Q) = 1 - integral [sqrt(p(x)*q(x))]
          → 항상 [0,1] → 안정적 최적화

3.3.2 분리 점수 및 최선 후보 선택

각 궤적 i에 대해 M개의 대안 후보를 생성하고, 현재 다른 궤적들로부터 가장 멀리 떨어진 후보 선택:

누적 분리 점수 (Eq. 9):
  h^(i,m) = sum_{j ≠ i}  H²(T^(i,m), T^(j))

  여기서:
    T^(i,m) : 궤적 i의 m번째 대안 후보
    j ≠ i   : 다른 모든 궤적들과의 Hellinger 거리 합산

최선 후보 선택 (Eq. 10):
  m* = argmax_m  h^(i,m)
  U^(i) ← U^(i, m*)

의미: 다른 모든 궤적들과 가장 멀리 떨어진 대안을 선택
      → 구성 공간에서 최대 커버리지 달성

3.4 UGE-TO 알고리즘 (Algorithm 1)

알고리즘: UGE-TO (Uncertainty Guided Exploratory Trajectory Optimization)

입력: 명목 제어 Ū, 호라이즌 T, N 궤적, M 후보/궤적,
      공분산 Sigma_u, Q, K 반복 횟수

초기화:
  U^(i) = Ū + eta^(i), eta^(i) ~ N(0, Sigma_u), i=1,...,N
  
각 궤적 i에 대해: 동역학 전파 (Eq. 5)로 Sigma^(i) 계산
각 궤적 i에 대해: T^(i) = N(mu^(i), Sigma^(i)) 구성

for k = 1 to K:
  for i = 2 to N:  (첫 번째 궤적 고정)
    
    # M개 대안 후보 생성
    for m = 1 to M:
      eta^(i,m) ~ N(0, Sigma_u)
      U^(i,m) = Ū + eta^(i,m)  (명목 기준 새 섭동)
      동역학 전파: Sigma^(i,m) 계산
      T^(i,m) = N(mu^(i,m), Sigma^(i,m))
    
    # 최선 후보 선택 (Hellinger 거리 기반)
    m* = argmax_m  sum_{j≠i} H²(T^(i,m), T^(j))
    U^(i) ← U^(i,m*)  # 궤적 업데이트
    T^(i) ← T^(i,m*)  # 분포 업데이트

출력: N개 다양화된 제어 시퀀스 {U^(1), ..., U^(N)}

시간 복잡도 분석:

루프당 계산:
  - M개 후보 생성: O(M * T * n²)  [공분산 전파]
  - Hellinger 거리 계산: O(N * T * n³)  [행렬식, 역행렬]
  - N개 궤적, K 반복: O(K * N * M * T * n³)

실제 파라미터:
  K=8, N=6 (UGE-TO 단계), M=128 후보
  → 총 샘플 수: 8 × 6 × 128 ≈ 6,144 (명목 포함)
  → 실제 비용 계산 횟수: 6 × 8 = 48 (선택된 후보만)
  → 계산 효율적: M × N × K 생성, 그러나 N × K만 비용 평가

3.5 UGE-MPC: 통합 모델 예측 제어 (Algorithm 2)

UGE-TO를 샘플링 기반 MPC에 통합하여 되풀이 지평선(receding horizon) 제어 실현:

알고리즘: UGE-MPC

입력: 명목 Ū, 호라이즌 T, 정제 파라미터 (N, M),
      MPPI 샘플 예산 L, 공분산, 온도 lambda

[단계 1: 글로벌 탐색 - UGE-TO]
  UGE-TO 실행 → N개 다양한 제어 시퀀스

[단계 2: 최선 명목 선택]
  비용 평가: J(U^(i)) for i=1,...,N
  i* = argmin_i J(U^(i))
  Ū ← U^(i*)  (최선 후보를 새 명목으로 설정)

[단계 3: 로컬 정밀 최적화 - MPPI]
  L개 추가 섭동 생성: eta^(l) ~ N(0, Sigma_u)
  U^(l) = Ū + eta^(l), l=1,...,L
  비용 평가: J(U^(l)) for l=1,...,L

[단계 4: MPPI 가중 업데이트 (Eq. 13)]
  w^(l) = exp(-J(U^(l)) / lambda)   (Eq. 12)
  Ū ← Ū + sum_l [w^(l) * eta^(l)] / sum_l w^(l)

[단계 5: 되풀이 지평선]
  u_0 실행 (첫 번째 제어 적용)
  지평선 이동: Ū ← shift(Ū)
  다음 스텝으로 반복

출력: 연속적인 제어 입력 (실시간 MPC)

UGE-MPC의 두 단계 역할 분리:

글로벌-로컬 분리:
┌─────────────────────────────────────────────┐
│ UGE-TO (글로벌 탐색)                         │
│  - N개 다양화된 명목 궤적 생성                │
│  - Hellinger 거리로 구성 공간 커버            │
│  - 서로 다른 로컬 미니마 주변 탐색            │
│  - 최선 명목 선택 → 더 나은 시작점           │
└──────────────────┬──────────────────────────┘
                   │ 더 나은 명목 Ū 전달
┌──────────────────▼──────────────────────────┐
│ MPPI (로컬 정밀 최적화)                       │
│  - 선택된 명목 주변 L개 샘플                  │
│  - 중요도 가중으로 세밀한 업데이트            │

└─────────────────────────────────────────────┘

3.6 비용 함수 설계 (Cost Function)

비용 함수 (Eq. 14):
  J(tau, U) = phi(x_T) + sum_{t=0}^{T-1} [ lambda_u * C_u(u_t) + C_state(x_t, x_G) ]

구성:
  phi(x_T)         : 최종 상태 비용 (목표까지 거리)
  C_u(u_t)         : 제어 입력 비용 (부드러움 유지)
  C_state(x_t, x_G): 상태-목표 비용 (거리 최소화)
  lambda_u         : 제어 비용 가중치

장애물 비용:
  C_obs(x_t) = lambda_obs * exp(-d(x_t, obstacles) / sigma)
  
  d(x_t, obstacles): 로봇과 가장 가까운 장애물까지의 거리

하이퍼파라미터 (실험별):
  궤적 최적화: lambda_obs=50, lambda_dist=10
  혼잡 MPC:   lambda_obs=1000

6. 핵심 기여점 (Key Contributions)

6.1 구성 공간에서의 궤적 다양성 정의

기여 1: 행동 공간이 아닌 구성 공간에서 궤적 다양성을 측정하는 최초의 방법

기존 방법들(MoG-MPPI, SV-MPC)은 행동 공간에서 다양성을 확보하려 했지만, 동역학이 행동을 궤적으로 변환하는 과정에서 다양성이 손실되거나 왜곡된다. UGE-TO는 불확실성 타원체를 통해 동역학의 영향을 직접 궤적 표현에 반영한다.

6.2 Hellinger 거리의 최적 선택

기여 2: 궤적 분포 비교에 Hellinger 거리를 도입하여 KL 발산의 불안정성 극복

Hellinger 거리의 [0,1] 유계성은 최적화 안정성을 보장하며, 대칭성은 공정한 비교를 가능하게 한다. 가우시안 분포에 대한 닫힌 형식(closed-form) 해가 존재하여 계산 효율적이다.

6.3 2단계 글로벌-로컬 최적화

기여 3: UGE-TO(글로벌 탐색)와 MPPI(로컬 정제)의 시너지적 결합

UGE-TO가 로컬 미니마에서 벗어난 더 나은 명목 궤적을 제공하면, MPPI는 그 주변에서 효율적으로 정밀 최적화를 수행한다. 이는 기존 방법들의 "전적으로 글로벌" 또는 "전적으로 로컬"의 한계를 극복한다.

6.4 동일 샘플 예산에서의 성능 향상

기여 4: 총 샘플 예산을 증가시키지 않고도 탐색 효율을 72.1% 향상

같은 계산 예산(2048 샘플) 내에서 UGE-TO의 선택적 비용 평가(전체 생성 후 최선만 평가)로 실제 비용 계산 횟수를 최소화하면서 탐색 커버리지를 극대화한다.

8. 고급 주제 (Advanced Topics)

8.1 UGE-TO의 이론적 특성

수렴 보장

UGE-TO는 명시적인 수렴 보장을 제공하지는 않지만,
다음 특성이 실용적 수렴을 뒷받침한다:

1. 단조 개선 (Monotonic Improvement):
   각 반복에서 h^(i,m*)가 현재 h^(i)보다 항상 ≥
   → 분리 점수가 감소하지 않음

2. 유한 수렴:
   H²(T^(i), T^(j)) ∈ [0,1]로 유계
   → 무한 발산 불가능

3. 탐색 완전성:
   M개 후보가 충분히 크면, 전체 구성 공간 커버 가능
   → M = 128이 실험적으로 충분함을 확인

Hellinger 거리의 기하학적 해석

Hellinger 거리의 기하학적 의미:

두 가우시안 T^(i) = N(mu^i, Sigma^i), T^(j) = N(mu^j, Sigma^j):

H²(T^i, T^j) = 1 - sqrt(Bhattacharyya 계수)

Bhattacharyya 계수 = exp(-Bhattacharyya 거리)

Bhattacharyya 거리:
  D_B = 1/8 * (mu^i - mu^j)^T * Sigma_bar^{-1} * (mu^i - mu^j)  (마할라노비스 거리)
       + 1/2 * ln(|Sigma_bar| / sqrt(|Sigma^i| * |Sigma^j|))      (분산 차이)

→ H²가 클수록 궤적 분포가 더 멀리 떨어짐
  (평균 차이 + 분산 구조 차이 모두 반영)
→ 동역학으로 인해 분산이 커지는 방향에서 자동으로 더 큰 분리 달성

8.2 한계점

한계 1: 선형화 가정

공분산 전파에 자코비안 선형화를 사용하므로, 강한 비선형 동역학(드론의 대각도 기동 등)에서는 부정확할 수 있다. 실제 공분산과 선형화된 공분산 사이의 차이가 클 경우 Hellinger 거리 계산이 부정확해진다.

한계 2: 저차원 동역학

자전거 모델(3차원 상태)은 비교적 단순하다. 고차원 동역학(6-DOF 드론: 12차원, 휴머노이드: 수십 차원)에서의 성능은 검증되지 않았다. 자코비안 계산과 행렬식 계산이 차원에 따라 빠르게 비싸진다.

한계 3: 정적 장애물 환경

실험이 정적 장애물 환경에 한정되었다. 동적 장애물(보행자, 다른 로봇)이 있는 환경에서의 성능 검증이 필요하다.

한계 4: 온라인 계산 비용

M=128 후보 × N=6 궤적 × K=8 반복 = 6,144 후보 생성이 10 Hz 실시간 제어에서 계산 가능한지, 더 강한 동역학 모델에서도 가능한지 검증이 필요하다.

  1. 고차원 동역학(드론, 휴머노이드) 적용 검증

12.1 Hellinger 거리 유도 과정

두 다변량 가우시안 사이의 Hellinger 거리의 닫힌 형식 유도:

일반 Hellinger 거리 정의:
  H²(P, Q) = 1 - ∫ sqrt(p(x) * q(x)) dx
           = 1 - BC(P, Q)   [BC: Bhattacharyya 계수]

가우시안 P = N(mu_1, Sigma_1), Q = N(mu_2, Sigma_2):

BC(P, Q) = ∫ N(x; mu_1, Sigma_1)^{1/2} * N(x; mu_2, Sigma_2)^{1/2} dx

정규 분포 밀도 함수:
  N(x; mu, Sigma) = (2π)^{-n/2} |Sigma|^{-1/2} exp(-1/2 (x-mu)^T Sigma^{-1} (x-mu))

두 가우시안의 기하 평균:
  sqrt(N(x; mu_1, Sigma_1) * N(x; mu_2, Sigma_2))
  = (2π)^{-n/2} |Sigma_1|^{-1/4} |Sigma_2|^{-1/4}
    * exp(-1/4 * (x-mu_1)^T Sigma_1^{-1} (x-mu_1) - 1/4 * (x-mu_2)^T Sigma_2^{-1} (x-mu_2))

지수 부분 완전 제곱식으로 변환:
  -1/4 (x-mu_1)^T Sigma_1^{-1} (x-mu_1) - 1/4 (x-mu_2)^T Sigma_2^{-1} (x-mu_2)
  = -1/2 (x-mu_bar)^T Sigma_bar^{-1} (x-mu_bar) - 1/8 (mu_1-mu_2)^T Sigma_bar^{-1} (mu_1-mu_2)
  
  여기서:
    Sigma_bar = 2 * (Sigma_1^{-1}/2 + Sigma_2^{-1}/2)^{-1}
              = (Sigma_1^{-1} + Sigma_2^{-1})^{-1} * 2
    (단순 경우: 같은 분산 구조면 Sigma_bar = (Sigma_1 + Sigma_2) / 2)

적분 계산:
  BC(P, Q) = |Sigma_1|^{-1/4} |Sigma_2|^{-1/4} / |Sigma_bar/2|^{-1/2} * (상수)
           = |Sigma_1|^{1/4} |Sigma_2|^{1/4} / |Sigma_bar|^{1/2}
             * exp(-1/8 * Delta_mu^T * Sigma_bar^{-1} * Delta_mu)

최종 Hellinger 거리 (본 논문 Eq. 8):
  H²(T^(i), T^(j)) = 1 - |Sigma^(i)|^{1/4} |Sigma^(j)|^{1/4} / |Sigma_bar|^{1/2}
                       * exp(-1/8 * (mu^i - mu^j)^T Sigma_bar^{-1} (mu^i - mu^j))

12.2 공분산 전파의 수치 안정성

공분산 전파에서의 수치 안정성 문제와 해결:

문제 1: 행렬 폭발 (Matrix Blowup)
  A_t^T * Sigma_t * A_t 반복 계산 시 고유값 폭발 가능
  
  완화책:
    - Q 추가 (Q = 0.1*I): 각 단계에서 최소 분산 유지
    - 수치 클리핑: Sigma_t의 고유값을 [eps, max_sigma]로 클리핑

문제 2: 블록 대각 행렬의 역행렬 비용
  Sigma = blockdiag(Sigma_0, ..., Sigma_T)의 역행렬
  → 블록별 역행렬 계산 가능: O(T * n^3)
  → T=80, n=3이면: 80 * 27 = 2,160 연산 (매우 효율적)

문제 3: 행렬식 계산
  |Sigma| = product of |Sigma_t| (블록 대각 성질)
  → 개별 블록의 행렬식 곱 = 매우 효율적

실제 구현 팁:
  - Cholesky 분해로 |Sigma_t| 계산 (수치 안정적)
  - 로그 행렬식: log|Sigma| = sum log|Sigma_t| (오버플로우 방지)
  - 역행렬: Sigma_bar^{-1} ← Cholesky 풀기

12.3 UGE-TO vs. 기존 방법 계산 비교

동일 샘플 예산 2048에서 계산 비용 비교:

MPPI:
  - 샘플 생성: 2048 × O(T*n) = 2048 × 240 ≈ 490K 연산
  - 비용 평가: 2048 × O(T) = 2048 × 80 ≈ 164K 연산
  - 총 계산: ~654K 연산

MoG-MPPI (K=4 컴포넌트):
  - E단계: 2048 × 4 × O(n²) ≈ 590K
  - M단계: 4 × O(n²) ≈ 36
  - 총: ~600K + MPPI 비용

SV-MPC (N=16 입자):
  - 그래디언트 계산: 16 × O(T*n²) ≈ 46K
  - 커널 행렬: O(N² * n²) = 16² * 9 = 2.3K
  - 총: ~630K

UGE-MPC (N=16, M=128, K=8):
  - UGE-TO 후보 생성: N*M*K * O(T*n²) = 16*128*8 * 720 = 1.18B
  - UGE-TO 분포 비교: N*K * O(N * T*n³) = 128 * 16*80*27 = 4.4M
  - MPPI: 2016 * O(T) = 161K
  - 총 계산: ~1.18B (생성) + 4.4M (비교) + 0.16M (MPPI)

주의: "생성"은 단순 가우시안 샘플 + 동역학 전파 (저비용)
     "비교"는 Hellinger 계산 (중간 비용)
     실제 비용 평가 (환경 충돌 검사)는 48+126 = 174회만 수행

실제 병목: 환경 충돌 검사 (비용 함수 평가)
  → UGE-MPC: 174회 (vs. MPPI 2048회)
  → 충돌 검사 비용이 지배적인 환경에서 UGE-MPC가 실제로 더 빠를 수 있음

12.4 ROSborg 통합 예시 (개념적 코드)

# UGE-MPC 개념적 구현 (Python/NumPy)
import numpy as np

class UGETO:
    def __init__(self, dynamics_fn, jacobian_fn, N=16, M=128, K=8, Q=None, Sigma_u=None):
        self.f = dynamics_fn      # x_{t+1} = f(x_t, u_t)
        self.J = jacobian_fn      # A_t = df/dx at (x_t, u_t)
        self.N, self.M, self.K = N, M, K
        self.Q = Q or np.eye(3) * 0.1
        self.Sigma_u = Sigma_u or np.eye(2) * 0.1

    def propagate_covariance(self, x_traj, u_seq, T):
        """불확실성 타원체 전파 (Eq. 5)"""
        n = len(x_traj[0])
        Sigmas = [self.Q.copy()]  # Sigma_0 = Q
        for t in range(T):
            A = self.J(x_traj[t], u_seq[t])  # 자코비안
            Sigma_next = A @ Sigmas[t] @ A.T + self.Q
            Sigmas.append(Sigma_next)
        return Sigmas

    def hellinger_distance(self, mu_i, Sigmas_i, mu_j, Sigmas_j):
        """Hellinger 거리 계산 (Eq. 8) - 블록 대각 구조 활용"""
        T = len(mu_i)
        log_bc = 0.0
        for t in range(T):
            S_i, S_j = Sigmas_i[t], Sigmas_j[t]
            S_bar = 0.5 * (S_i + S_j)
            delta = mu_i[t] - mu_j[t]
            
            # Bhattacharyya 거리 = 마할라노비스 + 행렬식 항
            mah = 0.125 * delta @ np.linalg.solve(S_bar, delta)
            det_term = 0.5 * np.log(np.linalg.det(S_bar)) \
                     - 0.25 * np.log(np.linalg.det(S_i)) \
                     - 0.25 * np.log(np.linalg.det(S_j))
            log_bc -= mah + det_term
        
        BC = np.exp(log_bc)
        return 1.0 - BC  # H² ∈ [0, 1]

    def optimize(self, U_init, x0, T):
        """UGE-TO 메인 루프"""
        # N개 초기 섭동 생성
        trajectories = []
        for i in range(self.N):
            eta = np.random.multivariate_normal(np.zeros(T), self.Sigma_u, T)
            U_i = U_init + eta
            x_traj = self._rollout(x0, U_i, T)
            Sigmas_i = self.propagate_covariance(x_traj, U_i, T)
            trajectories.append({'U': U_i, 'x': x_traj, 'Sigma': Sigmas_i})
        
        # K 반복
        for k in range(self.K):
            for i in range(1, self.N):  # 첫 번째 궤적 고정
                best_h, best_m = -np.inf, 0
                
                # M개 대안 후보
                for m in range(self.M):
                    eta_m = np.random.multivariate_normal(np.zeros(T), self.Sigma_u, T)
                    U_cand = U_init + eta_m
                    x_cand = self._rollout(x0, U_cand, T)
                    S_cand = self.propagate_covariance(x_cand, U_cand, T)
                    
                    # 다른 모든 궤적과의 Hellinger 거리 합
                    h = sum(self.hellinger_distance(
                        x_cand, S_cand, trajectories[j]['x'], trajectories[j]['Sigma']
                    ) for j in range(self.N) if j != i)
                    
                    if h > best_h:
                        best_h, best_m = h, m
                        best_U, best_x, best_S = U_cand, x_cand, S_cand
                
                trajectories[i] = {'U': best_U, 'x': best_x, 'Sigma': best_S}
        
        return [t['U'] for t in trajectories]  # N개 다양화된 궤적
