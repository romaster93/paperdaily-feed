1.2 연구 목표 (Research Objective)

고밀도 동적 군중 환경에서의 자율 이동 로봇 내비게이션은 자율주행, 서비스 로봇, 물류 로봇 등 다양한 응용 분야에서 핵심적인 기술이다. 특히 40-60명 이상의 동적 보행자가 밀집한 환경에서 순수 반응적 계획(reactive planning) 방법은 근본적인 한계를 보인다:

  • MPPI(Model Predictive Path Integral): 단기 예측 지평선으로 인해 복잡한 군중 상황에서 국소 최솟값(local minima)에 갇힘
  • DWA, ORCA 등: 반응적 회피는 가능하지만, 장기적 탈출 경로를 계획하지 못함

RAY-TOLD는 이 문제를 학습된 잠재 동역학 모델(Learned Latent Dynamics)과 물리 기반 MPPI 제어의 하이브리드 결합으로 해결한다. 핵심 기여는:

  1. LiDAR 레이 기반 컴팩트 상태 표현
  2. TDMPC2 프레임워크 기반 잠재 동역학 모델 학습
  3. 정책 혼합 샘플링 전략으로 MPPI의 국소 최솟값 탈출 능력 부여

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 고밀도 동적 군중에서의 MPPI 실패

MPPI는 강력한 샘플링 기반 최적 제어 방법이지만, 고밀도 동적 군중에서 구조적 한계를 보인다:

MPPI의 기본 작동 원리:
┌─────────────────────────────────────────────────────────┐
│  K개의 랜덤 궤적 후보 샘플링                              │
│  각 후보를 물리 모델로 전방 시뮬레이션 (H 스텝)            │
│  각 후보의 누적 보상 계산                                 │
│  소프트맥스 가중치로 최적 궤적 추출                        │
└─────────────────────────────────────────────────────────┘

고밀도 군중에서의 실패 패턴:

시나리오 1: 수렴하는 장애물 경로
    장애물 1 → ↘
                    ← (에고 차량 이동 경로)
    장애물 2 → ↗

    문제: H 스텝 단기 예측으로는 수렴 패턴 미리 파악 불가
    결과: 예측 지평선 너머에서 발생하는 충돌을 피하지 못함

시나리오 2: 갇힘 현상 (Local Minima)
    장애물들이 에고 차량 주변 360°를 둘러싼 상황
    
    순수 MPPI: 모든 샘플 궤적이 높은 비용 → 수렴 실패
    결과: 제자리에서 진동, 전진 불가, 충돌 발생

시나리오 3: 좁은 통로
    두 장애물 그룹 사이 좁은 경로만 존재
    
    K=256 랜덤 샘플: 좁은 통로를 우연히 통과하는 샘플 극소수
    결과: 올바른 경로를 찾지 못하고 충돌

B. 학습 기반 방법과 물리 기반 방법의 트레이드오프

순수 학습 기반 방법 (End-to-End RL):
  장점: 장기 계획, 복잡한 패턴 학습
  단점: 물리적 실현 가능성 보장 불가
         새로운 환경 일반화 어려움
         안전 제약 위반 가능

순수 물리 기반 방법 (MPPI, MPC):
  장점: 물리적 실현 가능, 즉각적 반응
  단점: 단기 예측 지평선 제한
         학습 없는 미래 예측 불가
         국소 최솟값 탈출 어려움

RAY-TOLD: 두 접근의 장점 결합
  - 물리 기반 MPPI로 운동학적 실현 가능성 보장
  - 잠재 동역학으로 장기 가치 추정
  - 정책 사전으로 목표 지향적 안내

C. 고차원 LiDAR 데이터 처리

LiDAR 센서 데이터의 처리 과제:
  원시 포인트 클라우드: 수만 개의 3D 점 → 고차원, 처리 비용 높음
  
  가능한 표현 방법:
  1. 원시 포인트 클라우드: 완전한 정보, 처리 비용 매우 높음
  2. 점유 격자(Occupancy Grid): 이산화 손실, 동적 정보 제한
  3. 레이 기반 표현: 컴팩트, 해석 가능, 동적 정보 포함 가능
  4. 딥러닝 인코더(PointNet 등): 강력하지만 실시간 어려울 수 있음

RAY-TOLD: 레이 기반 표현 선택
  이유: 계산 효율성 + 폐색(occlusion) 처리 + 장애물 속도 포함

2.2 핵심 해결책

RAY-TOLD의 핵심 통찰:

"LiDAR 레이 측정값을 컴팩트한 잠재 공간으로 인코딩하고, 잠재 공간에서 동역학 모델을 학습한다. MPPI 샘플링 시 학습된 정책 사전을 혼합하여 물리 기반 탐색과 학습 기반 안내를 결합하면, 고밀도 동적 군중에서의 국소 최솟값 탈출이 가능하다."

구체적으로:

  • 레이 기반 상태 표현: 60개 LiDAR 레이 + 속도 → 186차원 입력 벡터
  • 잠재 인코더: 186차원 → 128차원 잠재 상태
  • 잠재 동역학 모델: 잠재 공간에서 상태 전이 예측 (물리 엔진 불필요)
  • 가치 함수: 잠재 상태에서 무한 지평선 할인 누적 보상 추정
  • 정책 혼합 샘플링: α * 정책 안내 + (1-α) * 확률적 탐색

3. 핵심 방법론 (Core Methods)

3.1 레이 기반 상태 표현 (Ray-Based State Representation)

입력 벡터 구성

RAY-TOLD의 상태 표현은 세 가지 구성 요소로 이루어진 186차원 벡터이다:

상태 벡터 s ∈ R^186 구성:

[1] 차량 운동학 상태 (Kinematic State):
    - 위치: (x, y)
    - 속도: (v_x, v_y)
    - 방향: (heading θ)
    - 차량 모델: 운동학적 자전거 모델 (wheelbase = 2.5m, length = 2.5m)
    차원: ~6

[2] 목표 정보 (Goal Information):
    - 상대 목표 위치: (Δx_goal, Δy_goal) (에고 차량 기준 상대 좌표)
    차원: ~2

[3] LiDAR 레이 측정 (Ray Measurements):
    - 범위: 360° 완전 커버리지
    - 레이 수: 60개 (균등 간격 6°)
    - 각 레이: {거리 d_i, 장애물 속도 (v_x_i, v_y_i)}
    - 폐색 인식 절단(Occlusion-Aware Truncation): 장애물 뒤 레이는 절단 처리
    차원: 60 * 3 = 180

총 입력 차원: 6 + 2 + 180 ≈ 186

레이 기반 표현의 장점

기존 접근 대비 장점:

1. 계산 효율성 비교:
   원시 포인트 클라우드: O(N^2) 처리 비용 (N: 포인트 수)
   레이 기반 표현:     O(60) = 상수 복잡도
   → 실시간 처리에 적합

2. 폐색 처리 (Occlusion Handling):
   포인트 클라우드: 폐색된 영역 명시적 표현 어려움
   레이 기반:      폐색 레이는 절단 → 미지 영역을 자연스럽게 표현

3. 동적 정보 내포:
   정적 거리 + 장애물 속도(v_x_i, v_y_i) 동시 인코딩
   → 장애물의 이동 방향과 속도를 즉각 파악

4. 해석 가능성:
   레이 = 실제 LiDAR 센서 동작 모방
   잠재 공간의 의미가 명확 (충돌 위험 ↔ 레이 단거리)

5. 환경 이식성:
   레이 수(60개)를 조정하면 다양한 LiDAR 센서 호환
   포인트 클라우드와 달리 밀도 변화에 무관

3.2 TDMPC2 기반 잠재 동역학 모델 (Latent Dynamics Model)

TDMPC2(Task-oriented Latent Dynamics Model Predictive Control 2)는 제어 태스크를 위한 잠재 공간 세계 모델 프레임워크이다. RAY-TOLD는 이를 자율 이동 로봇의 고밀도 동적 장애물 회피에 적용한다.

모델 구성 요소

구성 요소 1: 상태 인코더 (State Encoder) h_θ

h_θ: R^186 → R^128

입력: 186차원 상태 벡터 s_t
       (차량 운동학 + 목표 정보 + 60 LiDAR 레이 + 속도)
출력: 128차원 잠재 상태 z_t

특징:
  - 비선형 신경망 (구체적 레이어 구조 미공개)
  - 원시 관측에서 계획에 유용한 피처 추출
  - 잠재 공간에서 물리적 의미 있는 군집화 (t-SNE 분석 확인)

잠재 공간 해석 (t-SNE 시각화 결과):
  - 위험 상태 (충돌 근접): 잠재 공간에서 별도 군집 형성
  - 안전 상태 (열린 공간): 독립적인 군집
  - 전이 부드러운 연속성 (물리적 의미 있는 내삽 가능)
  → 단순 센서 메모리가 아닌 실제 충돌 위험 기하학 학습

구성 요소 2: 잠재 동역학 모델 (Latent Dynamics) d_φ

d_φ: (R^128, R^a) → R^128

입력: 현재 잠재 상태 z_t, 행동 a_t
출력: 예측 다음 잠재 상태 z_{t+1}

수학적 표현:
  z_{t+1} = d_φ(z_t, a_t)

핵심 특징:
  - 잠재 공간 내에서 완전히 동작 (물리 엔진 불필요)
  - 멀티-스텝 상상 롤아웃(imagined rollout) 수행 가능:
    z_{t+1} = d_φ(z_t, a_t)
    z_{t+2} = d_φ(z_{t+1}, a_{t+1})
    ...
    z_{t+H} = d_φ(z_{t+H-1}, a_{t+H-1})
  - MPPI 계획 중 각 후보 궤적의 빠른 평가 가능

장점 vs. 물리 엔진:
  물리 엔진:  정확하지만 느림, 동적 장애물 예측 어려움
  잠재 동역학: 학습된 근사지만 빠름, 장애물 패턴 암묵적 학습

구성 요소 3: 보상 예측기 (Reward Predictor) R_ψ

R_ψ: (R^128, R^a) → R

입력: 잠재 상태 z_t, 행동 a_t
출력: 즉각 보상 예측값 r_t

보상 함수 구성 (6가지 가중 구성 요소):
  R_total = λ_1 * R_goal + λ_2 * R_collision + λ_3 * R_safety
            + λ_4 * R_velocity + λ_5 * R_progress + λ_6 * R_sparse

  1. 목표 거리 보상 (R_goal): 목표에 가까워질수록 정(+) 보상
  2. 충돌 페널티 (R_collision): 장애물과 충돌 시 강한 부(-) 보상
  3. 안전 여유 인센티브 (R_safety): 장애물 근처에서 완만한 부 보상
  4. 속도 인센티브 (R_velocity): 목표 속도 유지 시 정 보상
  5. 진행도 정렬 (R_progress): 목표 방향으로 이동 시 정 보상
  6. 희소 목표 보상 (R_sparse): 목표 지점 도달 시 큰 정 보상
  
  할인율: γ = 0.99

구성 요소 4: 가치 함수 (Value Function / Q-Function) C_ω

C_ω: (R^128, R^a) → R

입력: 잠재 상태-행동 쌍 (z_t, a_t)
출력: 무한 지평선 할인 누적 보상 추정 Q(z_t, a_t)

수학적 표현:
  Q(z_t, a_t) = E[Σ_{k=0}^{∞} γ^k * r_{t+k}]
  
  실제 계산 (유한 지평선 + 터미널 가치):
  Q(z_t, a_t) ≈ Σ_{k=0}^{H-1} γ^k * R_ψ(z_{t+k}, a_{t+k}) 
                + γ^H * C_ω(z_{t+H}, π_ξ(z_{t+H}))

핵심 역할: MPPI 계획 지평선(H 스텝) 너머의 가치를 추정
→ H 스텝 이후의 충돌 위험을 미리 고려 가능
→ 단기 계획의 근시안적 한계 극복

구성 요소 5: 정책 사전 네트워크 (Policy Prior) π_ξ

π_ξ: R^128 → R^a

입력: 잠재 상태 z_t
출력: 목표 지향적 행동 a_t

작동 방식:
  - 잠재 공간에서 재귀적으로 펼쳐짐 (recursive unrolling)
  - 잠재 동역학 d_φ와 연계하여 H-스텝 행동 시퀀스 생성
  - 학습을 통해 일반적으로 "좋은" 행동을 사전으로 학습

MPPI에서의 역할:
  - 정책 사전이 생성한 행동 시퀀스를 MPPI 후보군에 혼합
  - 순수 무작위 샘플 + 정책 안내 샘플의 혼합

아키텍처 요약 다이어그램

RAY-TOLD 모델 아키텍처:

입력: s_t = [차량 운동학 | 목표 | 60 LiDAR 레이 + 속도] ∈ R^186
                            │
                    ┌───────▼───────┐
                    │ 인코더 h_θ    │
                    │ 186 → 128    │
                    └───────┬───────┘
                            │ z_t ∈ R^128
              ┌─────────────┼─────────────┐
              │             │             │
      ┌───────▼──────┐ ┌───▼──────┐ ┌───▼──────┐
      │ 동역학 d_φ   │ │ 보상 R_ψ │ │ 가치 C_ω │
      │ z,a → z'    │ │ z,a → r  │ │ z,a → Q  │
      └───────┬──────┘ └──────────┘ └──────────┘
              │ z_{t+1}
      ┌───────▼──────┐
      │ 정책 π_ξ     │
      │ z → a        │
      └──────────────┘
구성 요소 입력 차원 출력 차원 역할
인코더 h_θ 186 128 원시 관측 → 잠재 상태
동역학 d_φ 128+a 128 잠재 상태 전이 예측
보상 예측기 R_ψ 128+a 1 즉각 보상 추정
가치 함수 C_ω 128+a 1 무한 지평선 Q값
정책 사전 π_ξ 128 a 목표 지향적 행동 생성

3.3 정책 혼합 MPPI 샘플링 (Policy Mixture MPPI)

RAY-TOLD의 가장 핵심적인 기여는 정책 혼합 샘플링 전략(Policy Mixture Sampling Strategy)이다.

표준 MPPI의 한계

표준 MPPI 계획 절차:
  1. 이전 솔루션 이동(warm-start): Ū_{1:H} (이전 최적 행동 시퀀스)
  2. K개 노이즈 샘플 생성: ε^(k) ~ N(0, Σ_u), k=1,...,K
  3. K개 후보 궤적: U^(k) = Ū + ε^(k)
  4. 각 후보를 물리 모델로 시뮬레이션
  5. 비용/보상 계산
  6. 소프트맥스 가중치로 최적 행동 추출

문제: 모든 샘플이 Ū 주변 가우시안에서 생성
→ Ū이 나쁜 국소 최솟값에 있으면 모든 샘플도 나쁜 영역
→ 복잡한 장애물 상황에서 탈출 불가

RAY-TOLD의 정책 혼합 샘플링

RAY-TOLD 계획 알고리즘 (Algorithm 1):

입력:
  - 현재 잠재 상태 z_t
  - 이전 솔루션 Ū (warm-start)
  - 혼합 비율 α ∈ [0, 1]

1단계: 후보 집합 분할
  K_policy = floor(α * K) 개: 정책 안내 후보
  K_random = K - K_policy 개: 표준 MPPI 확률 후보

2단계: 정책 안내 후보 생성 (K_policy개)
  For i in 1..K_policy:
    z_0 = z_t  (현재 잠재 상태)
    For h in 0..H-1:
      a_h^(i) = π_ξ(z_h) + noise  (정책 + 소량 노이즈)
      z_{h+1} = d_φ(z_h, a_h^(i))  (잠재 동역학으로 전이)
    궤적: {a_0^(i), a_1^(i), ..., a_{H-1}^(i)}

3단계: 확률적 후보 생성 (K_random개)
  표준 MPPI와 동일: 가우시안 노이즈로 Ū 주변 샘플링

4단계: 모든 K개 후보 평가
  For each candidate k:
    물리 모델(운동학적 자전거 모델)로 실제 궤적 계산
    비용 J^(k) = Σ_{h=0}^{H-1} γ^h * R_ψ(z_h^(k), a_h^(k))
               + γ^H * C_ω(z_H^(k), π_ξ(z_H^(k)))  ← 터미널 가치

5단계: 가중치 계산 및 최적 행동 추출
  w^(k) = exp(-J^(k) / λ)  (소프트맥스, λ: 온도 파라미터)
  U* = Σ_k w^(k) * U^(k)  (가중 평균)

6단계: 첫 번째 행동 실행, 계획 반복

핵심: α=0이면 순수 MPPI, α=1이면 순수 정책
      α=0.1이 최적: 90% 확률적 탐색 + 10% 정책 안내

터미널 가치의 역할 (Terminal Value Estimation)

일반 MPPI: 유한 H 스텝 내에서만 비용 평가
  비용 = Σ_{h=0}^{H-1} r_h  (H 스텝 이후 고려 없음)

RAY-TOLD: 가치 함수로 H 스텝 이후 비용 추정
  비용 = Σ_{h=0}^{H-1} γ^h * r_h + γ^H * Q(z_H, a_H)
                                     └── 무한 지평선 추정

효과:
  H=30 스텝 (실제 계획 지평선)이지만
  가치 함수 C_ω가 무한 지평선을 근사
  → 30 스텝 너머에서 발생할 충돌도 현재 계획에 반영
  → 장기 안전 경로 선택 가능

3.4 학습 절차 (Training Procedure)

학습 목적 함수

TDMPC2 프레임워크를 기반으로 네 가지 손실 함수를 동시에 최소화한다:

총 손실 함수:
L = λ₁ * L_reward + λ₂ * L_value + λ₃ * L_policy + λ₄ * L_latent

각 손실의 역할:

1. L_reward (보상 예측 손실):
   L_reward = ||R_ψ(z_t, a_t) - r_t||²
   
   역할: 실제 보상과 예측 보상의 차이 최소화
   훈련: 지도 학습 (실제 환경 상호작용에서 r_t 수집)

2. L_value (가치 함수 손실, TD 학습):
   L_value = ||C_ω(z_t, a_t) - [r_t + γ * C_ω(z_{t+1}, π_ξ(z_{t+1}))]||²
   
   역할: 시간차(TD) 학습으로 Q함수 학습
   핵심: Bellman 방정식의 근사 오차 최소화

3. L_policy (정책 손실):
   L_policy = -E[C_ω(z_t, π_ξ(z_t))]
   
   역할: 정책이 높은 Q값을 가진 행동을 생성하도록 최적화
   방법: Q값 극대화 (Actor-Critic 스타일)

4. L_latent (잠재 일관성 손실):
   L_latent = ||h_θ(s_{t+1}) - d_φ(h_θ(s_t), a_t)||²
   
   역할: 잠재 동역학 모델이 실제 상태 전이를 정확히 예측하도록
   효과: 잠재 공간의 물리적 일관성 보장

학습 설정

하이퍼파라미터:
  - 배치 크기: 256
  - 학습률: 1×10⁻⁴ (Adam optimizer)
  - 리플레이 버퍼: 50,000개 전이 경험
  - 할인율: γ = 0.99
  - TDMPC2 프레임워크 기반

학습 과정:
  1. 환경에서 탐색하며 경험 수집 (리플레이 버퍼 채움)
  2. 미니배치로 L_reward, L_value, L_policy, L_latent 동시 최소화
  3. 정책이 개선됨에 따라 리플레이 버퍼 데이터 품질 향상
  4. 수렴까지 반복

학습 환경:
  - 20m × 10m 시뮬레이션 아레나
  - 40-60개 동적 장애물 (에피소드마다 완전 랜덤화)
  - 시작 위치: (1, 0), 목표 위치: (19, 0)
  - 장애물 모델: 수정된 Social Force Model (SFM)

5.2 평가 지표 (Evaluation Metrics)

1. 성공률 (Success Rate, SR):
   - 정의: 충돌 없이 목표 (19, 0) 도달한 에피소드 비율
   - 공식: SR = |{에피소드 | 충돌 없이 목표 도달}| / 100
   - 범위: 0~1 (높을수록 좋음)

2. 충돌률 (Collision Rate, CR):
   - 정의: 동적 장애물과 충돌한 에피소드 비율
   - 관계: CR ≈ 1 - SR (충돌 없이 목표 미달 에피소드도 존재)
   - 범위: 0~1 (낮을수록 좋음)

3. 안전 여유 (Safety Margin):
   - 정의: 에피소드 중 에고 차량과 장애물 간 최소 거리의 평균
   - 단위: 미터
   - 높을수록 더 안전한 경로 선택

5.3 정량적 결과 (Quantitative Results)

주요 성능 비교 (100개 테스트 에피소드)

방법 성공률 ↑ MPPI 대비 개선 충돌률 ↓ MPPI 대비 감소 안전 여유 ↑

RAY-TOLD (α=0) 89.0% ±0% 11.0% ±0% 0.17m

핵심 분석:

1. α=0 (정책 혼합 없음):
   - MPPI와 동일한 성능 → 정책 혼합 없이는 개선 없음
   - 잠재 동역학의 터미널 가치만으로는 충분하지 않음
   - 정책 혼합 샘플링이 성능 향상의 핵심임을 확인

2. α=0.1 (최적):
   - 충돌률 11% → 6% (45.45% 상대 감소)
   - 성공률 89% → 94% (+5%p, +5.62% 상대 향상)
   - K=256 중 K_policy=25개, K_random=231개

3. α=0.2 (과도한 정책 의존):
   - α=0.1보다 성능 하락 (SR 94% → 91%)
   - 고확률적 환경에서 정책 안내가 너무 많으면 탐색 다양성 감소
   - SFM 기반 장애물의 불규칙한 행동에 정책이 과적합될 위험

4. 안전 여유:
   - 세 방법 모두 비슷한 안전 여유 (~0.17-0.19m)
   - 충돌 감소가 여유 증가보다 더 의미 있는 개선

6. 핵심 기여점 (Key Contributions)

6.1 하이브리드 LiDAR-Latent MPPI 아키텍처

내용: LiDAR 레이 기반 컴팩트 상태 표현 + 잠재 동역학 모델 + MPPI를 결합한 하이브리드 아키텍처

의의:

  • 물리 기반 MPPI의 운동학적 실현 가능성 보장
  • 잠재 동역학으로 동적 장애물 패턴 학습
  • 레이 기반 표현으로 계산 효율성과 해석 가능성 동시 확보

6.2 정책 혼합 샘플링 전략 (Policy Mixture Sampling)

내용: MPPI 후보 집합에 학습된 정책 사전 궤적을 혼합하는 새로운 샘플링 전략

의의:

  • 수작업 휴리스틱(handcrafted heuristics) 없이 MPPI의 국소 최솟값 탈출
  • 혼합 비율 α로 탐색(exploration)과 활용(exploitation) 균형 제어
  • α=0.1에서 최적: 충돌률 45.45% 감소 달성

6.3 학습된 터미널 가치 추정 (Learned Terminal Value Estimation)

내용: 가치 함수 C_ω가 MPPI 계획 지평선 너머의 장기 보상을 추정

의의:

  • 유효 예측 지평선을 물리 롤아웃 H 스텝에서 실질적으로 무한으로 확장
  • 단기 계획의 근시안적 한계 극복
  • 30 스텝 너머에서 발생할 충돌도 현재 계획에 반영

7.2 TDMPC2 프레임워크 기반

RAY-TOLD의 구현 기반: TD-MPC2 (Hansen et al., 2023)

TD-MPC2 원래 목적: 연속 제어(continuous control) 태스크 (MuJoCo 등)
RAY-TOLD의 확장: 자율 이동 로봇의 고밀도 동적 장애물 회피

주요 변경/적응:
  1. 입력 도메인: MuJoCo 관절 상태 → LiDAR 레이 + 운동학 상태
  2. 보상 함수: 관절 제어 보상 → 내비게이션 6요소 보상
  3. 환경: 완전 결정론적 MuJoCo → 확률적 SFM 기반 동적 군중
  4. 새로운 기여: 정책 혼합 샘플링 (α-mixture sampling)

7.3 운동학적 자전거 모델 (Kinematic Bicycle Model)

상태 방정식:
  x_{t+1} = x_t + v * cos(θ) * dt
  y_{t+1} = y_t + v * sin(θ) * dt
  θ_{t+1} = θ_t + (v/L) * tan(δ) * dt

여기서:
  (x, y): 차량 위치
  θ: 방향각
  v: 종방향 속도
  L = 2.5m: 휠베이스
  δ: 앞바퀴 조향각 (행동 a_t = [v, δ])
  dt: 타임스텝

MPPI에서의 역할:
  - 각 후보 궤적의 물리적 실현 가능성 보장
  - 잠재 동역학 d_φ와는 별도로 실제 물리 시뮬레이션에 사용
  - 잠재 공간 롤아웃은 근사, 물리 평가는 정확

8. 고급 주제 (Advanced Topics)

8.1 잠재 동역학과 물리 동역학의 이중 구조

RAY-TOLD에서 흥미로운 이중 구조가 존재한다:

이중 동역학 구조:

1. 잠재 동역학 d_φ (학습된 근사):
   - 용도: 정책 안내 후보 생성 (π_ξ + d_φ 롤아웃)
   - 특징: 빠름, 장애물 패턴 암묵적 학습, 근사적 정확도
   - 역할: 좋은 행동 시퀀스 방향 안내

2. 운동학적 자전거 모델 (물리 기반 정확한 모델):
   - 용도: 모든 K개 후보 궤적의 실제 물리 시뮬레이션
   - 특징: 정확함, 하지만 장애물 미래 위치 미고려
   - 역할: 물리적 실현 가능성 보장

두 동역학의 역할 분리:
  잠재 d_φ: "어느 방향으로 가야 좋을까?" (장기 안내)
  자전거 모델: "실제로 그 방향으로 갈 수 있나?" (운동학 검증)

8.2 혼합 비율 α의 민감도

α 민감도 분석:

α=0.0: 순수 MPPI
  성공률: 89%, 충돌률: 11%
  → 기준선, 개선 없음

α=0.1: 최적
  성공률: 94%, 충돌률: 6%
  → 최적 균형: 충분한 탐색 다양성 + 학습 안내

α=0.2: 과도한 정책 의존
  성공률: 91%, 충돌률: 9%
  → 확률적 환경에서 과도한 정책 의존의 위험:
     정책이 학습한 패턴과 다른 장애물 행동에 취약

이론적 해석:
  α 너무 작: 정책 안내 효과 미미 → MPPI 한계 유지
  α 최적: 정책이 좋은 영역을 안내, MPPI가 세부 최적화
  α 너무 큼: 정책에 과의존 → SFM 장애물의 무작위성에 취약

8.3 확장성 및 한계점

현재 한계:
  1. 비교 기준선 부족
     - 오직 MPPI 변형들과 비교
     - DWA, TEB, RVO, ORCA, CROWD-NAV, SARL, LSTM-RL 등과 비교 없음
     - 더 강한 학습 기반 방법(DR-MPC, SANDO 등)과 비교 필요

  2. 단순화된 환경
     - 2D 평면 시뮬레이션만
     - 실제 로봇: 3D 환경, 불규칙 지형, 센서 노이즈
     - SFM 모델은 실제 보행자 행동을 과도하게 단순화

  3. 코드 미공개
     - 재현 어려움
     - 상세 아키텍처 미공개 (레이어 수, 활성화 함수 등)

  4. 계산 비용 미보고
     - MPPI 대비 추가 계산 비용 미측정
     - 실시간 실행 가능 여부 불명

확장 가능한 방향:
  1. 더 강한 기준선과 비교 (CrowdNav, SANDO 등)
  2. 3D 환경 확장 (UAV 장애물 회피)
  3. 실제 로봇 배포 (TurtleBot, Unitree 등)
  4. 코드 공개로 재현성 확보
  5. 아키텍처 세부사항 공개 (레이어 구조, 활성화 함수)

8.4 MPPI-RL 하이브리드의 관련 연구 위치

MPPI + 학습 기반 방법의 연구 계보:

1. PRM-RL (확률적 로드맵 + RL):
   - RL이 장기 계획, 단기는 물리 기반
   - RAY-TOLD: 유사한 아이디어를 MPPI에 적용

2. AC-MPC (미분가능 MPC + RL):
   - RL Actor가 MPC를 통해 동작
   - RAY-TOLD: 직접 샘플 혼합 방식 (미분 불필요)

3. DR-MPC (잔차 RL + MPC):
   - RL이 MPC의 잔차 보정
   - RAY-TOLD: 별도 잔차 대신 혼합 샘플링

4. DreamerNav (잠재 동역학 + 내비게이션):
   - 깊이/점유 맵 기반
   - RAY-TOLD: LiDAR 레이 기반 (더 컴팩트)

RAY-TOLD의 차별점:
  → 정책 안내를 MPPI 제안 분포에 직접 주입
  → 모든 행동이 물리 모델(자전거)로 검증됨
  → 수작업 휴리스틱 없이 학습으로 방향 안내

11. 결론 (Conclusion)

혁신성 평가

RAY-TOLD는 고밀도 동적 군중 환경에서의 자율 이동 로봇 내비게이션이라는 중요하면서도 충분히 연구되지 않은 문제를 다룬다. 핵심 기여인 정책 혼합 샘플링 전략은 수작업 휴리스틱 없이 MPPI의 국소 최솟값 탈출 문제를 학습 기반으로 해결한다는 점에서 독창적이다.

특히 α=0.1에서 충돌률을 11%에서 6%로 45.45% 감소시킨 결과는 의미 있는 성과이다. 잠재 공간의 t-SNE 분석을 통해 인코더가 실제 위험 기하학을 학습했음을 보여주는 정성적 분석도 방법론의 타당성을 뒷받침한다.

실용적 의의

Hanyang University, KAIST, Samsung Research의 공동 연구로서, 산업 응용(물류 로봇, 서비스 로봇)에 대한 잠재적 관심을 반영한다. TDMPC2 프레임워크를 자율 이동 로봇에 적용한 선도적 사례로서, 잠재 동역학 기반 로봇 계획 연구의 방향을 제시한다.

향후 연구 방향

현 논문이 해결하지 못한 가장 중요한 과제는 실세계 검증이다. SFM 기반 시뮬레이션에서의 성공을 실제 보행자 환경에서 재현하는 것이 다음 핵심 단계이다. 또한 코드 공개와 더 다양한 기준선과의 비교가 이루어진다면, 이 연구가 실제로 SOTA를 달성하는지 명확히 확인할 수 있을 것이다.

장기적으로 RAY-TOLD의 정책 혼합 샘플링 아이디어를 SANDO 방식의 수학적 안전 보장과 결합하는 연구, 그리고 IRRL처럼 온라인 실세계 적응 능력을 추가하는 연구가 자연스러운 확장 방향이다.
