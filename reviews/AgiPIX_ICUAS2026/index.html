1.2 연구 목표 (Research Objective)

AgiPIX는 실내 항공 자율 비행 및 산업 시설 점검이라는 두 가지 실용적 목표를 위한 공개 하드웨어-소프트웨어 통합 플랫폼을 제안한다. 핵심 연구 질문은:

"어떻게 하면 연구실에서 개발한 자율 비행 알고리즘을 실제 산업 환경의 UAV에 제로샷(zero-shot)으로 전이할 수 있는가?"

이 문제는 실내 항공 자율화 연구의 근본적 병목이다. 연구자들은 시뮬레이터에서 알고리즘을 개발하지만, 현실 UAV에 배포할 때마다:

현재 문제:
  1. 하드웨어 플랫폼마다 ROS 인터페이스 재작성 필요
  2. 물리 엔진 차이로 인한 훈련-배포 성능 격차
  3. 고품질 산업 시설 디지털 트윈 부재
  4. 재현 불가능한 플랫폼 설정 (논문마다 다른 센서 조합)

AgiPIX는 이를 컨테이너화된 ROS 2 자율화 스택 + 포토리얼리스틱 디지털 트윈 + 표준화된 하드웨어 플랫폼으로 해결한다. 특히 ENRICH 2025 유럽 로보틱스 해커톤(오스트리아 핵발전소 Zwentendorf)에서 실제 방사선 점검 임무를 수행하며 현실 검증을 달성한 점이 중요한 기여다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 실내 항공 자율화의 독특한 제약

실내 환경은 실외 드론과 다른 근본적 제약을 가진다:

실외 UAV:
  ✓ GPS 활용 가능 (절대 위치 파악)
  ✓ 광활한 공간 (충돌 여유)
  ✓ 표준화된 공역 규정

실내 UAV:
  ✗ GPS 불가 (실내 신호 차단)
  ✗ 좁은 공간, 빈번한 충돌 위험
  ✗ 복잡한 구조물 (배관, 기둥, 설비)
  ✗ 산업 시설의 열/전자기 잡음

실내 항공 자율화를 위해서는 SLAM(동시 위치추정 및 지도작성), 충돌 회피 경로 계획, 정밀 자세 제어가 모두 온보드 컴퓨팅으로 처리되어야 한다.

B. 시뮬레이션-현실 갭 (Sim-to-Real Gap)

문제의 깊이:
  물리 엔진 차이:
    - 시뮬레이터 공기 저항 모델 ≠ 실제 공기 역학
    - 로터 워시 효과 시뮬레이션 부정확
    - 센서 노이즈 모델 (LiDAR 반사율, IMU 드리프트) 불완전

  비주얼 갭:
    - Matterport/Habitat의 사진 현실감 ≠ 산업 시설 재질
    - 형광등 조명의 스펙트럼 특성 미재현
    - 금속 표면 반사/간섭 패턴 부재

  동역학 갭:
    - 시뮬레이터의 이상화된 모터 응답
    - 배터리 소모에 따른 성능 저하 미고려
    - 열 영향에 의한 IMU 편차 누적

기존 연구들은 이 갭을 도메인 적응, 시스템 ID, 또는 광범위한 도메인 랜덤화로 해결하려 했으나, AgiPIX는 컨테이너화된 자율화 스택의 직접 이식으로 접근한다.

C. 재현 불가능한 연구 플랫폼

현재 실내 항공 연구의 재현성 문제:
  - 각 연구실마다 독자적 하드웨어 조합
  - 소프트웨어 의존성 충돌 (ROS1 vs ROS2, Python 버전 등)
  - 독점적 시뮬레이터 사용 (라이선스 제한)
  - 클로즈드 소스 펌웨어 (상용 드론 플랫폼)
  
결과:
  - 다른 연구실에서 알고리즘 재현 시 3-6개월 소요
  - 하드웨어 획득 비용 ($5K-$50K)
  - 안전 인증 취득 비용 추가

AgiPIX는 모든 하드웨어 설계, 시뮬레이션 자산, 소프트웨어를 오픈소스로 공개하여 이 재현성 위기를 해결한다.

2.2 핵심 해결책

AgiPIX의 세 가지 핵심 기여:

1. AgiREAL 플랫폼:
   - 표준화된 오픈 하드웨어 UAV 설계

   - ROS 2 기반 컨테이너화 모듈
   - 시뮬-현실 제로샷 이식 가능

핵심 하드웨어 구성 요소

1. Livox MID-360 LiDAR (능동 감지)

특성:
  - 비균일 스캔 패턴 (꽃잎 형태)
  - 근거리 밀집 포인트 클라우드 생성

  - 정밀도: ±2cm @ 20m
  - 무게: 265g (소형 UAV에 적합)

왜 Livox MID-360인가:
  - 기존 회전식 LiDAR (Velodyne 등) 대비 소형/경량
  - 실내 좁은 공간에서의 밀집 포인트 클라우드
  - 금속 인프라의 반사율 처리 능력
  - HEATS SLAM과의 통합 최적화

2. NVIDIA Jetson Orin NX (온보드 컴퓨팅)

사양:
  - CPU: 8코어 ARM Cortex-A78AE
  - GPU: 1024 CUDA 코어 (Ampere)
  - 메모리: 16GB LPDDR5
  - 전력: 10-25W (동적 조절)
  - 무게: 45g (모듈 단독)

성능:
  - 추론 지연: 120ms (FAINT 내비게이션 정책)
  - CPU 부하: 41% 평균 (자율화 스택 가동 중)
  - GPU 부하: 37% 평균
  - 실시간 SLAM + 경로 계획 + 학습 정책 동시 실행

3. 하드웨어 타임스탬프 동기화

# 동기화 메커니즘 (개념 코드)
class HardwareSyncManager:
    """
    LiDAR와 IMU의 하드웨어 수준 타임스탬프 동기화
    소프트웨어 동기화 대비 지연 분산 99% 감소
    """
    def sync_lidar_imu(self, lidar_packet, imu_packet):
        # 하드웨어 트리거 신호로 동기화 (PPS)
        # 타임스탬프 편차 < 1μs
        aligned_packet = TimestampAligner(
            ref=lidar_packet.hardware_timestamp,
            target=imu_packet.hardware_timestamp
        )
        return aligned_packet

    def publish_synced_pointcloud(self, synced_data):
        # 동기화된 LiDAR + IMU 데이터 → HEATS SLAM 입력
        self.slam_input_pub.publish(synced_data)

소프트웨어 동기화 대비 하드웨어 동기화의 장점:

  • 운영 체제 스케줄링 지연으로 인한 타임스탬프 편차 제거
  • LiDAR-IMU 정합(calibration) 품질 향상
  • 고속 비행 중 동적 환경에서의 SLAM 정확도 향상

시뮬레이터 설계 철학

기존 시뮬레이터의 한계:

  AgiREAL 정밀 모사:
    - 로터 워시 물리 시뮬레이션
    - Livox MID-360 센서 모델 (비균일 스캔 패턴)

디지털 트윈 구축 파이프라인

1. 3D 재구성 (포토그래메트리/LiDAR):
   실제 산업 시설 → 구조형 광/LiDAR 스캔 → 고밀도 포인트 클라우드
   
2. 메시 처리:
   포인트 클라우드 → Reality Capture / Metashape → 텍스처드 메시

3. UE5 임포트:
   메시 → Nanite 최적화 → PBR 재질 적용 → 조명 베이킹

4. 센서 통합:
   AgiREAL 센서 파라미터 → UE5 센서 플러그인 설정
   (FOV, 노이즈 모델, 타임스탬프 에뮬레이션)

5. ROS 2 브리지:
   UE5 ↔ ROS 2 topic (AgiSTACK과 동일한 인터페이스)

점유 지도 정확도 평가:

결과: IoU = 0.96 (96% 정합도)

물리적 의미:

  - 경로 계획 알고리즘이 시뮬 환경에서 학습한 내용이

HEATS 기반 SLAM 및 ESDF 생성

HEATS (HEATs spatial mapping framework):
  입력: Livox MID-360 포인트 클라우드 + IMU
  출력: 
    - 3D 점유 맵 (Occupied/Free/Unknown)
    - ESDF (Euclidean Signed Distance Field)

ESDF 활용:
  D(p) = signed distance to nearest obstacle surface
  D(p) > 0: 자유 공간 (양수 = 장애물에서 떨어짐)
  D(p) < 0: 점유 공간 (음수 = 장애물 내부)
  D(p) = 0: 장애물 경계면

경로 계획에서의 ESDF 사용:
  비용 함수: c(p) = λ_esdf * f(D(p)) + λ_dist * dist_to_goal
  
  f(D(p)) = {
    0             if D(p) > d_safe (안전 거리)
    1/D(p)        if 0 < D(p) ≤ d_safe
    ∞             if D(p) ≤ 0 (장애물 내부)
  }
  
  d_safe = 0.5m (실내 환경 기준)

학습 기반 내비게이션 (FAINT Policy)

# FAINT (학습된 내비게이션 정책) 배포 흐름
class FAINTPolicy:
    """
    학습된 UAV 내비게이션 정책
    입력: 센서 관측 → 출력: 속도 명령
    """
    def __init__(self, model_path: str):
        # TensorRT 최적화된 모델 (Jetson GPU 실행)
        self.model = TRTModel(model_path)
        self.inference_time = 120  # ms (Jetson Orin NX 기준)
    
    def predict(self, obs: dict) -> VelocityCommand:
        """
        obs = {
            'lidar': np.array,       # 포인트 클라우드
            'pose': SE3,             # 현재 자세 (SLAM 출력)
            'goal': np.array,        # 목표 위치
            'esdf': np.array,        # ESDF 맵
        }
        """
        # 센서 융합 → 상태 표현
        state = self.encode_state(obs)
        
        # TensorRT 추론 (GPU 가속)
        with torch.cuda.stream(self.cuda_stream):
            velocity_cmd = self.model(state)
        
        return velocity_cmd  # (vx, vy, vz, yaw_rate)

    def encode_state(self, obs):
        # LiDAR 포인트 클라우드 → 주변 밀도 특징
        lidar_feat = self.lidar_encoder(obs['lidar'])
        # 목표 방향 벡터
        goal_vec = obs['goal'] - obs['pose'].translation()
        # 상태 연결
        return torch.cat([lidar_feat, goal_vec, obs['esdf']])

일반 궤적 추적 RMSE: 1.07m
챌린지 궤적 추적 RMSE: 1.42m
추론 지연: 120ms (실시간 비행 제어 가능 수준)

3.4 RRT* 기반 경로 계획

AgiSTACK의 전역 경로 계획기로 ESDF 인식 RRT*를 사용:

알고리즘: ESDF-aware RRT* (Rapidly-exploring Random Tree Star)

입력:
  - 현재 UAV 위치 p_start ∈ R^3
  - 목표 위치 p_goal ∈ R^3
  - ESDF 맵 D(·)

RRT* 핵심 절차:
  1. 랜덤 샘플링: p_rand ~ Uniform(MapBounds)
  2. 최근접 노드: p_near = NearestNode(tree, p_rand)
  3. 조종: p_new = Steer(p_near, p_rand, δ=0.5m)
  4. 충돌 검사: IsCollisionFree(p_near, p_new, D) using ESDF
     - 경로 상 모든 점에서 D(p) > d_safe
  5. 비용 재배선: 부모 노드 최적화 (최소 누적 비용)
  6. 비용 전파: 자손 노드 비용 업데이트

비용 함수:
  cost(p_near → p_new) = ||p_new - p_near|| * (1 + α/D(p_new))
  여기서 α: 장애물 근접 페널티 가중치 (α=2.0)

목표 편향 샘플링:
  p_rand = p_goal   with probability 0.1 (수렴 가속)
  p_rand ~ Uniform  with probability 0.9

출력:
  - 경유점 시퀀스: [p_0, p_1, ..., p_K] (충돌 없는 경로)
  - 각 경유점은 FAINT 로컬 정책의 목표로 사용

실험적 경로 계획 성능:

궤적 추적 ATE RMSE (Absolute Trajectory Error):
                | Simulation | Real-World |
Lemniscate      |  0.0637m   |  0.1404m   |
Up-Down Spiral  |  0.0368m   |  0.1049m   |

시뮬-현실 갭:
  Lemniscate:    0.0637 → 0.1404m (+120% 오차)
  Up-Down Spiral: 0.0368 → 0.1049m (+185% 오차)
  
  갭 분석:
    - 실제 기류 효과 (로터 워시, 주변 바람)
    - 배관/금속 구조물 근처의 LiDAR 간섭
    - IMU 열 드리프트 누적
    - 모터 토크 비선형성

3.5 탐색 정책 (Exploration Policy)

실내 미지 환경에서의 자율 탐색을 위한 프론티어 기반 탐색:

Frontier-based Exploration:
  1. HEATS SLAM으로 3D 점유 맵 실시간 구축
  2. Frontier 감지: Known Free ↔ Unknown 경계 추출
  3. Frontier 선택: 정보 이득 기반 (탐색 미지 영역 최대화)
  4. 경로 계획: RRT*로 선택된 Frontier까지 경로 생성
  5. 탐색 완료: Frontier 없을 때 (맵 완성)

정보 이득 추정:
  IG(f) = |UnknownVoxels(f, r_sensor)| 
  # f: 프론티어 위치, r_sensor: 센서 범위

8.2 한계점 (Limitations)

A. 배터리 제한

현재: ~15분 비행 시간 (소형 LiPo 배터리)
대형 산업 시설 점검: 수십 분~수 시간 필요

해결 방안:
  1. 교체식 배터리 모듈 (착륙 스테이션)
  2. 케이블 급전 (특정 구역 집중 점검)
  3. 연료 전지 통합 (고에너지 밀도)

B. LiDAR 간섭

금속 표면, 유리, 투명 물체:
  - Livox MID-360이 ENRICH에서 경험한 반사 간섭
  - 특히 스테인리스 배관, 금속 저장 탱크에서 발생
  - 포인트 클라우드 오염 → SLAM 품질 저하

해결 방안:
  1. 강도(intensity) 기반 이상치 제거 필터
  2. 다중 반사 모델링 (GPU 가속)
  3. 보조 RGB-D 카메라 통합

C. 좁은 공간 기동성

현재 축간거리: 250mm
좁은 배관 통로 (직경 < 500mm):
  - 로터 워시로 인한 자세 불안정
  - 최소 안전 거리 제약 (d_safe=0.5m)
  - 실제 핵발전소 일부 구역 진입 불가

해결 방안:
  1. 더 소형 플랫폼 (150mm급, 터널 드론)
  2. 변형 구조 (접이식 암)
  3. 뱀 형태 로봇으로 대체 (좁은 공간)

9.2 장단점 분석

장점 (Strengths)

1. 재현성의 혁명적 향상

기존 Planner 논문들이 알고리즘만 공개하는 것과 달리, AgiPIX는 하드웨어 설계까지 포함한 완전한 시스템을 공개한다:

재현 비용 비교:
  기존 실내 UAV 연구 재현:
    - 하드웨어 구입: $10K-$30K (상용 연구용 드론)
    - 소프트웨어 통합: 2-6개월
    - 전문 인력 필요: 임베디드 + ROS + 항공 엔지니어

  AgiPIX 복제:
    - 하드웨어 부품: ~$800-1500 (BOM 공개)
    - 소프트웨어 설치: 1-2주 (Docker 기반)
    - 문서화된 절차: 단계별 가이드

2. 실제 산업 환경 검증의 희소성

SANDO(UAV 실험 있음)도 실외 열린 공간에서 테스트한 반면, AgiPIX는 실제 핵발전소 내부에서 테스트했다:

SANDO 실험: 옥외 환경 (GPS 보조 가능, 열린 공간)
AgiPIX 실험: 핵발전소 실내 (GPS 없음, 복잡한 금속 구조물)

난이도 차이:
  - 비구조화된 금속 인프라 → LiDAR 반사 어려움
  - GPS 불가 → 순수 LiDAR SLAM으로 자기 위치 추정
  - 방사선 환경 → 전자 기기 내방사선 요구
  - 좁은 통로 → 정밀 비행 제어 필수

3. 제로샷 전이의 실용적 가치

GRATE(미지 환경 탐색)가 알고리즘 수준에서만 다뤘다면, AgiPIX는 시스템 수준에서 제로샷 전이를 구현하고 검증했다.

단점 (Weaknesses)

1. 경로 계획 알고리즘의 참신성 부족

사용된 계획 알고리즘:
  RRT*: 1998년 제안 (Lavalle), 2011년 점근 최적성 증명
  ESDF: 2017년 EDF, 2019년 ESDF-based 계획 대중화
  Frontier 탐색: 1997년 Yamauchi

AgiPIX의 기여: 이 알고리즘들의 통합 + 플랫폼
→ 알고리즘 자체의 혁신이 아닌 시스템 통합 기여

플래닝 알고리즘 측면에서 TRG-Planner(방향별 위험도 그래프), GPU-SLS(GPU 가속 비선형 MPC), SANDO(MIQP + STSFC) 등에 비해 알고리즘적 혁신성은 낮다.

2. ICUAS 수준의 학회

투고 학회: ICUAS 2026 (International Conference on Unmanned Aircraft Systems)
임팩트: ICRA, IROS, RA-L 대비 낮음

플래너 트랙 기존 리뷰:
  TRG-Planner: RA-L (탑 저널)
  HEIGHT: T-ASE (탑 저널)
  SANDO: arXiv (강력한 MIT ACL 연구실)
  
AgiPIX: ICUAS (상대적으로 낮은 임팩트)
→ 논문의 학술적 기여보다 오픈소스 기여가 더 큼

3. 단일 환경 유형 특화

현재 AgiPIX는 실내 산업 시설에 특화되어 있어, 다음 환경으로의 일반화가 미검증:

  • 연기/연무가 있는 화재 현장
  • 수중 환경 (해양 시설 점검)
  • 반지하 환경 (지하철 터널)

9.3 실적용 가능성 평가

핵발전소/원자력 시설 점검:
  적합도: ★★★★★ (5/5) ← ENRICH 2025에서 이미 검증
  이유: 실제 핵발전소 환경 테스트 완료
  필요 추가 작업: 방사선 센서 통합, 장시간 운영

화학 공장/정유 시설:
  적합도: ★★★★☆ (4/5)
  이유: 유사한 금속 인프라 환경
  필요 추가 작업: ATEX 방폭 인증, 가스 감지 통합

창고/물류 센터:
  적합도: ★★★★★ (5/5)
  이유: 환경이 단순하고 목표 명확 (재고 확인)
  필요 추가 작업: 카메라 기반 인식 통합

건축 현장 점검:
  적합도: ★★★☆☆ (3/5)
  이유: 야외+실내 하이브리드, GPS 필요
  필요 추가 작업: GPS/LiDAR 융합

연구용 플랫폼:
  적합도: ★★★★★ (5/5)
  이유: 완전 오픈소스, 낮은 복제 비용, 풍부한 문서

9.4 연구 방향성 평가

AgiPIX가 제시하는 "재현 가능한 오픈 플랫폼" 연구 방향은 로보틱스 분야의 중요한 공백을 채운다. 알고리즘 논문이 넘쳐나는 반면, 다른 연구자가 실제로 사용할 수 있는 플랫폼 논문은 드물다.

기존 리뷰 논문들이 알고리즘 혁신에 집중한 것과 달리, AgiPIX는 플랫폼 생태계 구축이라는 다른 차원의 기여를 한다. 이는 OpenAI Gym이 RL 연구를 민주화했듯, AgiPIX가 실내 항공 자율화 연구를 민주화할 수 있는 잠재력을 가진다.

단, 알고리즘적 참신성이 낮고 ICUAS라는 상대적으로 낮은 임팩트 학회를 대상으로 한다는 점에서, 순수 알고리즘 기여를 중시하는 관점에서는 한계가 있다.

11. 결론 (Conclusion)

혁신성 평가

AgiPIX의 혁신성은 알고리즘보다 시스템 통합과 오픈소스 생태계에 있다. RRT*, ESDF, Frontier 탐색이라는 검증된 알고리즘들을 재현 가능한 하드웨어 + 컨테이너화된 소프트웨어 + 포토리얼리스틱 시뮬레이터로 통합하여, 실내 항공 자율화 연구의 진입 장벽을 획기적으로 낮춘다.

특히 ENRICH 2025 핵발전소 현장 실험은 논문의 실용적 가치를 크게 높인다. 대부분의 Planner 논문이 시뮬레이션이나 연구실 환경에 머무는 반면, AgiPIX는 실제 산업 현장에서 자율 비행을 검증했다.

실용적 의의

AgiPIX는 다음 실용적 응용 분야에서 즉각적인 활용 가능성을 가진다:

  1. 산업 시설 정기 점검: 핵발전소, 정유 시설, 화학 공장
  2. 재난 현장 탐색: 건물 붕괴, 화재 현장의 사전 정찰
  3. 창고/물류 센터 재고 관리: 자동화된 재고 스캐닝
  4. 연구 플랫폼: 실내 항공 자율화 알고리즘 개발의 표준 테스트베드

향후 연구 방향

가장 시급한 개선은 (1) 더 긴 비행 시간(케이블 급전 또는 교체 배터리), (2) 강화된 금속 환경 LiDAR 처리, (3) 다중 UAV 협력 탐색이다. 장기적으로 AgiPIX가 실내 항공 자율화 연구의 표준 플랫폼으로 자리잡는다면, 이는 학계와 산업계 모두에 큰 기여가 될 것이다.

현재 존재하는 알고리즘-플랫폼 갭(뛰어난 알고리즘 논문은 많지만 실제 사용 가능한 시스템은 드문)을 메우려는 AgiPIX의 시도는 올바른 방향이다. ENRICH 2025의 현실 검증이 이를 뒷받침한다.
