1.2 연구 목표 (Research Objective)

실세계 혼잡 환경에서 이동 로봇의 연속적으로 충돌 없는(continuously collision-free) 내비게이션을 달성하는 것이 핵심 목표다. 기존 볼록 자유 영역(convex free-region) 기반 방법들이 갖는 두 가지 근본 한계를 해결한다:

  1. 방향 무관성(Direction-Agnosticism): 기존 방법들은 장애물 형상만으로 영역을 확장하여, 좁은 통로에서 이동 가능한 방향을 보존하는 영역을 생성하지 못한다.
  2. 이산적 안전 검증(Discrete Safety Verification): 이산 샘플 지점에서만 안전성을 확인하므로, 샘플 사이에서 충돌이 발생할 수 있다.

FRGraph는 이 두 문제를 각각 방향 인식 QP 기반 영역 생성과 립시츠 연속 안전 인증(Lipschitz-based continuous safety certification)으로 해결하고, 이를 영역 기반 내비게이션 그래프(region-based navigation graph)로 통합하여 점진적 계획을 가능하게 한다.

핵심 혁신: 볼록 자유 영역을 생성할 때 원하는 이동 방향 벡터 e를 편향 행렬 Q = ee^T + λ(I - ee^T)로 인코딩하여, 이동 방향으로 더 넓고 통과 가능한 영역을 생성한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 볼록 자유 영역 기반 내비게이션의 기본 원리

볼록 자유 영역(Convex Free Region, CFR)은 로봇의 충돌 없는 공간을 볼록 다면체로 표현한다:

볼록 자유 영역 P:
P = {p ∈ R^d | Ap ≤ b}

여기서:
- 각 행 a_i^T·p ≤ b_i 는 하나의 분리 초평면
- 볼록 다면체는 최적화(MPC, QP)에서 효율적으로 처리 가능
- 로봇이 P 내에 있으면 장애물과 충돌하지 않음

장점:
- 최적화 친화적: LP/QP 제약으로 직접 사용
- 볼록 궤적 계획: 볼록 집합 내 베지어 곡선 생성
- 수학적 보장: 볼록성으로 인한 전역 최솟값 보장

B. 도전 1: 방향 무관 영역 생성의 협소 통로 문제

기존 방법(RILS, FRTree, FIRI)은 현재 위치 주변의 장애물 기하학적 형상만으로 CFR을 구성한다:

기존 방향 무관 방법의 실패 시나리오:

환경 (협소 통로):
    ████████████████████████
    ██ (벽)     ██ (벽)  ██
    ██          ██       ██
    ██   로봇→  ████     ██
    ██          ██  출구 ██
    ██          ████     ██
    ██          ██       ██
    ████████████████████████

문제:
기존 CFR 생성: 로봇 중심에서 등방성으로 확장
→ 상하 방향으로 벽에 막혀 생성된 영역이 얇은 수평 띠 형태
→ 로봇 크기를 수용하면서 전방 통과 경로를 포함하는 영역 생성 실패
→ 내비게이션 불가능 판단 (실제로는 통과 가능)

FRGraph의 방향 인식 생성:
이동 방향 e = (1, 0) (전방)로 QP 편향
→ 전방 방향으로 최대화된 영역 생성
→ 통로를 포함하는 충분한 폭의 영역 확보
→ 성공적 내비게이션

정량적 영향 (Table IV 소거 실험):

  • 장애물 밀도 1.0/m²: 방향 무관 시 완주율 80%, FRGraph 100%
  • 장애물 밀도 1.2/m²: 방향 무관 시 완주율 75%, FRGraph 100%

C. 도전 2: 이산 샘플 안전성의 충돌 간격 문제

연속 궤적의 안전성을 유한 샘플로만 확인하면 반드시 간격이 존재한다:

이산 안전 검증의 충돌 간격 문제:

궤적 p(t), t ∈ [0,1]:
이산 검증 시:  p(0), p(0.1), p(0.2), ..., p(1.0) 에서만 안전성 확인

실제 문제:
                    p(0.15)  ← 이 지점에서 충돌!
                  /
 p(0.1) ── 장애물 ── p(0.2)
   (안전)   (통과)    (안전)

이산 샘플 p(0.1), p(0.2) 모두 안전하지만
샘플 사이 p(0.15)에서 로봇이 장애물과 교차

중요성:
- 고속 이동 시 더 심각 (샘플 간격이 더 큼)
- 비볼록 형상의 로봇 바디에서 더 자주 발생
- 볼록 자유 영역 내에서도 발생: 영역 경계 근처 궤적에서 양 끝점은 안전하나 중간 경로가 경계를 살짝 벗어날 수 있음

정량적 영향: 연속 안전 검증 없이는 장애물 밀도 1.2/m²에서 완주율 70%, 충돌 없는 완주율 85%. FRGraph 전체는 100%/100%.

3. 핵심 방법론 (Core Methods)

3.1 내비게이션 방향 추출 (Gap Extractor)

LiDAR 기반 구형 범위 맵

LiDAR 포인트 클라우드 처리:
1. 크롭: 3m 반경 구 내부 포인트만 사용
2. odom 좌표계로 변환
3. 구형 투영: (az, el) 각도 쌍으로 매핑

2D 설정:
  범위 맵 크기: 1600 × 1 픽셀
  방위각(azimuth): 전체 360° 표현

3D 설정:
  범위 맵 크기: 1600 × 32 픽셀
  방위각 × 고도각 격자

갭 감지 및 방향 추출

갭(Gap) 유형 정의:

개방 갭 (Open Gap):
- 2D: 최소 10픽셀 폭, 방위각 범위 ≥ 45°
- 3D: 최소 20픽셀 폭, 방위각 ≥ 45°, 고도각 ≥ 30°
- 특성: 확실히 통과 가능한 넓은 개구부

제한 갭 (Limited Gap):
- 2D: 최소 2픽셀, 방위각 ≥ 30°
- 3D: 최소 48픽셀, 방위각 ≥ 30°, 고도각 ≥ 30°
- 보정: 방위각 ±10°, 고도각 ±10° 편향 적용
- 특성: 좁은 통로, 조심스럽게 탐색 필요

방향 벡터 추출:
e_k = d_k / ||d_k||  (갭 중심 방향의 단위 벡터)

3.2 방향 인식 볼록 자유 영역 생성 (Direction-Aware CFRG)

핵심 수학: 방향 편향 행렬

이동 방향 e에 의한 편향 행렬:
Q = ee^T + λ(I - ee^T)

기하학적 해석:
- ee^T: e 방향 투영 행렬 (e 방향에 단위 가중치)
- I - ee^T: e에 수직인 방향 투영 행렬 (e에 수직 방향에 λ 가중치, 0 < λ < 1)

결과:
- e 방향: Q에 의해 가중치 1 (최대 중요도)
- e 수직 방향: Q에 의해 가중치 λ < 1 (감소된 중요도)

물리적 의미:
QP가 n^T·Q·n을 최소화 → n이 e 방향에 직교하는 초평면 법선 선호
→ 초평면이 e 방향에 수직 → 영역이 e 방향으로 넓게 확장

λ 파라미터 역할:

λ → 0: 완전 방향 편향 (e 방향으로 최대 확장, 수직 방향 거의 무시)
λ → 1: 방향 무관 (등방성 확장, Q = I)
λ = 0.3 (실험적 최적값): 방향성과 수직 보호의 균형

QP 기반 분리 초평면 생성

개별 초평면을 하나의 장애물 포인트 o_i에 대해 QP로 최적화:

최적화 문제 (식 1):
minimize    n^T · Q · n

subject to:
  (v_j - o_i)^T · n ≤ -ε         ∀ 로봇 꼭짓점 v_j  (로봇이 안전 측에 있음)
  (p_1 - o_i)^T · n = -1          (정규화 / 스케일링)

변수: 초평면 법선 n ∈ R^d

여기서:
  v_j: 로봇 바디의 꼭짓점 (2D: 4개, 3D: 8개)
  o_i: 선택된 장애물 포인트
  p_1: 로봇 중심 (영역 내부에 있어야 함)
  ε > 0: 안전 마진

이 QP의 해 n*는 로봇이 o_i와 확실히 분리되는 초평면의 법선이며, 동시에 이동 방향 e와 수직에 가깝도록 최적화된다.

반복적 영역 구성 알고리즘

알고리즘: 방향 인식 CFR 생성

입력: 장애물 포인트 집합 O, 로봇 꼭짓점 V, 이동 방향 e, 현재 포즈 p_1

초기화:
  active_obstacles = O

반복 (active_obstacles가 빌 때까지):
  1. 장애물 포인트 선택 전략:
     우선: active_obstacles 중 방향 e 전방 반공간에서 방향 레이에 가장 가까운 포인트
     대체: 전방 후보 없으면 로봇 중심에서 가장 가까운 포인트 선택
  
  2. QP 풀기:
     선택된 o_i에 대해 분리 초평면 법선 n 계산
     (위 QP 공식 사용)
  
  3. 영역 업데이트:
     새 반공간 추가: {p | n^T·p ≤ n^T·o_i - ε}
     새 제약에 의해 제거되는 포인트를 active_obstacles에서 삭제
  
출력: 볼록 다면체 P = {p | Ap ≤ b}
      (모든 반공간의 교집합)

기존 방법 비교 (Table I):

방법 방향 인식 로봇 형상 포함

FIRI (2025) ✗ ✓

3.3 연속 안전 궤적 생성 (Continuous-Safe Trajectory Generation)

3.3.1 목표 포즈 선택

볼록 자유 영역 P 내에서 최대 전진 진행 방향의 도달 가능한 목표 포즈를 선택:

포즈 샘플링:
- 2D: 18개 요(yaw) 방향 샘플 (0°, 20°, 40°, ..., 340°)
- 3D: 18(yaw) × 5(roll) × 5(pitch) = 450개 방향 조합
  - 롤/피치 범위: ±30° (0.5236 라디안)

각 방향 R에 대해 LP로 최대 전진 거리 계산:
maximize    e^T · p       (이동 방향으로 최대 전진)
subject to  Ap ≤ b        (볼록 자유 영역 P 내)
            R(p - p_start) ∈ robot_footprint  (로봇 형상 포함)

상위 K=3 요 방향 선택 후 ±20°(요), ±10°(롤/피치) 범위 세밀 탐색
→ 최종 목표 포즈 p_target 선택

3.3.2 5차 베지어 궤적 파라미터화

5차 베지어 곡선 (Degree-5 Bézier):
p(t) = Σ_{i=0}^{5} B_i^5(t) · P_i,    t ∈ [0,1]

B_i^5(t) = C(5,i) · t^i · (1-t)^{5-i}  (번스타인 기저 함수)

제어점:
P[0] = p_start (시작 포즈, 고정)
P[1..4] = 자유 변수 (내부 제어점)
P[5] = p_target (목표 포즈, 고정)

방향(각도) 커브:
theta(t) = Σ_{i=0}^{5} B_i^5(t) · Theta_i

2D (BezierSE2): Theta_i = [yaw_i] ∈ R
3D (BezierSE3): Theta_i = [roll_i, pitch_i, yaw_i] ∈ R³

초기화: 제어점을 시작-끝 직선 보간 (최단 각도 보간)

5차 베지어 곡선을 선택한 이유:

  • 낮은 차수(1,2,3차): 복잡한 장애물 회피에 유연성 부족
  • 매우 높은 차수: 진동(Runge 현상) 위험, 최적화 복잡도 증가
  • 5차: 6개 제어점으로 충분한 자유도, 안정적 최적화

3.3.3 립시츠 연속 안전 인증 (Lipschitz-Based Continuous Safety Certification)

이것이 FRGraph의 핵심 기여 중 하나다. 각 분리 초평면 a^T·x ≤ b에 대해 로봇의 연속적 안전 함수를 정의:

연속 안전 함수:
g(t) = a^T·p(t) + max_j [a^T · (R(t) · v_j)] - b

여기서:
- a^T·p(t): 로봇 중심의 초평면 값
- max_j [a^T · (R(t) · v_j)]: 현재 방향에서의 로봇 최대 돌출
- b: 초평면 경계값

안전 조건: g(t) ≤ 0,    ∀ t ∈ [0,1]
(궤적 전 구간에서 로봇 모든 꼭짓점이 초평면 안쪽)

g(t)의 립시츠 상수 L 계산 (2D):

g(t)의 시간 미분 상한:
|g'(t)| ≤ ||a||₂ · (||p'(t)||₂ + r_max · |θ'(t)|)

여기서:
- r_max: 로봇 최대 반경 (중심에서 꼭짓점까지 최대 거리)
- p'(t): 위치 속도 (4차 베지어 미분으로 계산)
- θ'(t): 각속도

5차 베지어 미분 (4차 베지어):
Qi = 5 · (P[i+1] - P[i]),  i = 0,...,4

립시츠 상수 (2D):
L = a_max · (dp_max_norm + r_max · dth_max_abs)

where:
a_max = max(||a||₂)       (초평면 법선 최대 노름)
dp_max_norm = max_{t} ||p'(t)||₂
dth_max_abs = max_{t} |θ'(t)|

3D 설정에서의 각속도 처리:

3D 각속도 상한:
omega_max = sqrt(3) · drpy_max_norm  (롤-피치-요 합성)

립시츠 상수 (3D):
L = a_max · (dp_max_norm + r_max · omega_max)

3.3.4 적응형 구간 세분화 (립시츠 분기한정법)

립시츠 상수를 이용한 연속 안전성의 효율적 검증:

구간 [t_L, t_R]에서 g의 상한 U:
U(t_L, t_R) = g(t_c) + L · (t_R - t_L) / 2
where t_c = (t_L + t_R) / 2  (구간 중점)

알고리즘: 분기한정법 (Branch-and-Bound)

우선순위 큐 (최대 힙, U 기준 정렬):
  초기: [0, 1] 구간 하나

반복:
  1. 가장 높은 U를 가진 구간 추출
  2. U ≤ 0이면: 이 구간 전체 안전 보장 → 폐기
  3. U > 0이면: 충돌 위험 → 구간을 [t_L, t_c], [t_c, t_R]로 분할
  4. 최소 구간 크기 min_dt=1e-4 도달: 실제 충돌로 판정
  5. 최대 노드 수 max_nodes=5000 도달: 타임아웃

출력: 안전 (모든 구간이 U≤0로 폐기) 또는 불안전 (충돌 위치 t* 포함)

립시츠 분기한정법의 핵심 장점:

  • 이산 샘플 검증 대비 수학적 보장: U ≤ 0이면 구간 전체 안전 증명
  • 적응형 집중: 위험한 구간에만 재귀적으로 세분화
  • 단순 균일 샘플링보다 훨씬 효율적: 대부분 구간에서 빠른 종료

3.3.5 국소 QP 수정 (Local Trajectory Refinement)

충돌이 발견된 경우(g(t*) > 0), 위반된 초평면에 대해 제어점을 국소 수정:

QP 수정 문제 (식 2):
minimize    ||δx_p||²_{W_p} + ||δx_θ||²_{W_θ} + w_s · s²

subject to:
  ∇g_ℓ(t*)^T · δx - s ≤ -g_ℓ(t*) - m    (위반 초평면 ℓ에 대해)
  δx ∈ B                                   (신뢰 영역 박스)
  s ≥ 0                                    (슬랙 변수)

여기서:
  δx = [δP_x, δP_y, δYaw, ...]  (자유 제어점 변위)
  δx_p = 위치 변위 성분
  δx_θ = 방향 변위 성분
  W_p, W_θ = 가중치 행렬
  w_s = 슬랙 페널티
  m = 안전 마진

솔버: PIQP (Proximal Interior Point QP)
영향 제어점 선택: t*에서 번스타인 가중치 최대인 제어점 (최대 K_cp=4개)
라인 서치: α=0.8에서 시작, 조건 불만족 시 절반으로 축소, 최대 6회
수정 루프: 최대 30회 반복

안전 수정이 성공하면 립시츠 검증 재시도. 30회 후에도 실패하면 해당 방향 불가 판정.

3.4 영역 기반 내비게이션 그래프 (Region-Based Navigation Graph, FRGraph)

그래프 자료구조

GraphNode (노드):
  state_pos_: Eigen::Vector3d  (위치)
  polys_: Polyhedron3D          (3D 볼록 자유 영역)
  polys_2d_: Polyhedron2D       (2D 투영)
  parent_id_: NodeId
  edge_ids_: vector<EdgeId>
  deadend_: bool                (막힌 길 플래그)

GraphEdge (엣지):
  from_, to_: NodeId            (시작, 종료 노드)
  goal_: Direction3D            (목표 방향)
  trajectory: BezierTrajectory  (검증된 안전 궤적)
  valid_: bool                  (유효 플래그)

그래프 탐색 전략

FRGraph 내비게이션 알고리즘:

1. 초기화:
   루트 노드 = 시작 위치
   
2. 현재 노드에서 계획 (Plan from Current Node):
   a. LiDAR에서 갭 방향 추출: {e_1, ..., e_k}
   b. 각 방향 e_i에 대해:
      - 방향 인식 CFR 생성 → P_i
      - 목표 포즈 선택 → p_target_i
      - 5차 베지어 궤적 생성 + 립시츠 검증 → τ_i
      - 성공하면 그래프에 엣지 추가
   
3. 목표 지향 엣지 선택:
   현재 전역 목표 g에 가장 가까운 p_target_i를 가진 엣지 선택
   
4. 궤적 실행:
   선택된 τ_i 실행 (트래킹 컨트롤러에 전달)
   실행 중 연속 안전 모니터링
   
5. 도착 후:
   upsertNode(새 위치): 기존 노드와 merge_radius_ 내이면 합병
   그래프에 새 노드 추가
   
6. 실패 처리:
   궤적 안전 실패 → 해당 엣지 invalid 처리
   다음 최선 엣지 선택 시도
   모든 엣지 소진 → deadend_ = true, 백트래킹
   
7. 막힌 길 복구 (Backtracking):
   부모 노드 방향으로 역행
   유효 엣지 있는 이전 노드로 복귀
   새로운 방향 탐색

점진적 탐색의 장점

비교: 반응형(Reactive) vs FRGraph 점진적 계획

반응형 (매 스텝 재계획):
  단점: 이전 탐색 경험 폐기
        같은 막힌 길을 반복 탐색
        그래프 지식 없는 비효율 순환

FRGraph 점진적:
  장점: 탐색한 영역의 그래프 누적 유지
        막힌 길을 명시적으로 기록 (deadend 플래그)
        백트래킹으로 이전 분기점 재방문 가능
        동일 영역 재방문 최소화 (upsertNode 병합)

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 및 환경 (Experimental Setup)

2D 시뮬레이션 환경:

  • 공간: 5m × 5m 작업 공간
  • 장애물: 원통형 (반경 r=0.3m)
  • 장애물 밀도: 0.6, 0.8, 1.0, 1.2 개/m²
  • 각 조건: 5가지 시나리오 × 4회 = 20회 실험

비교 대상 방법:

  • DDR-OPT: 2-원판 로봇 모델 기반 직접 최적화
  • FASTER: 암묵적 장애물 안전 기반 빠른 궤적 계획기
  • FRTree: 겹치는 팽창으로 볼록 자유 영역을 생성하되 이산 안전 검증

5.2 평가 지표 (Evaluation Metrics)

  • 경로 길이 스케일: 실제 경로 길이 / 직선 거리 (1에 가까울수록 효율적)
  • 완주율 (Complete Rate): 목표 도달 성공 비율 [0,1]
  • 충돌 없는 완주율 (Collision-Free Rate): 충돌 없이 목표 도달 비율 [0,1]
  • 모듈별 실행 시간: 각 처리 단계 평균 시간 [ms]

→ 이산 검증만으로는 고밀도 환경에서 안전 보장 불충분

6. 핵심 기여점 (Key Contributions)

기여 1: 방향 인식 볼록 자유 영역 생성 (Direction-Aware CFRG)

문제: 기존 방법(RILS, FRTree, FIRI)은 모두 방향 무관으로 협소 통로에서 실패.

해결: 편향 행렬 Q = ee^T + λ(I - ee^T)를 QP 목적함수에 통합하여 이동 방향을 인식하는 볼록 자유 영역 생성. 로봇 형상(꼭짓점 포함 조건)을 QP 제약에 명시적으로 통합.

효과: 모든 기존 방법 대비 협소 통로에서 더 높은 완주율 달성. 특히 고밀도 환경(1.2/m²)에서 75-90%인 기존 방법 대비 100% 완주율.

기여 2: 립시츠 연속 안전 인증 (Lipschitz Continuous Safety Certification)

문제: FRTree를 포함한 기존 방법들은 이산 샘플에서만 안전 확인, 샘플 간 충돌 발생.

해결: 5차 베지어 궤적의 립시츠 상수를 해석적으로 계산하고, 분기한정법으로 모든 t ∈ [0,1]에서 안전성을 수학적으로 인증. PIQP 기반 국소 수정으로 위반 시 궤적 복구.

효과: FRTree 대비 충돌 없는 완주율 0.40 → 1.00 (밀도 1.2). 이산 검증 대비 수학적 보장 제공.

기여 3: 영역 기반 점진적 내비게이션 그래프 (FRGraph)

문제: 반응형 재계획은 이전 탐색 경험을 버려 막힌 길 재탐색, 비효율.

해결: 탐색한 모든 볼록 자유 영역과 검증 궤적을 그래프로 유지. 목표 지향 탐색 + 막힌 길 백트래킹으로 효율적 내비게이션.

효과: 단순 반응형 대비 반복 탐색 감소, 막힌 길에서의 빠른 회복.

8. 고급 주제 (Advanced Topics)

8.1 이론적 완전성과 현실적 한계

완전성의 조건부 보장:

FRGraph는 수학적 완전성(completeness)을 직접 보장하지 않는다. 구체적 한계:

완전성 실패 시나리오:

시나리오 1: 극도로 좁은 통로
  로봇 크기 포함 조건으로 인해 생성 가능한 볼록 영역이 없음
  → CFR 생성 실패
  → FRGraph가 통과 불가로 판단
  → 실제로는 통과 가능할 수 있음 (ε 마진이 너무 큼)
  완화: λ 값 또는 ε 감소로 더 공격적인 영역 생성 시도

시나리오 2: 5차 베지어 표현력 한계
  극단적으로 구불구불한 협소 경로는 5차 베지어로 표현 불가
  → 안전 인증 30회 실패
  → 해당 방향 불가로 판단
  완화: 제어점 수 증가 (계산 비용 증가)

시나리오 3: LiDAR 인식 한계
  센서 노이즈, 반사, 투명 장애물 등으로 갭 감지 실패
  → 존재하는 통로를 인식하지 못함

8.2 동적 장애물 처리

현재 FRGraph는 정적 미지 환경을 가정한다. 동적 장애물(이동하는 사람, 다른 로봇)은 처리하지 않는다. SANDO와 같이 시공간 안전 비행 경로 코리도(Spatiotemporal SFC)를 결합하면 이 한계를 극복할 수 있다.

8.3 확장성

더 큰 환경:

  • 현재 3m 반경 내 LiDAR만 처리 → 큰 실내/야외 환경에서는 전역 경로 계획기 필요
  • FRGraph를 로컬 플래너로, A* 또는 Dijkstra를 전역 플래너로 결합하는 계층적 아키텍처 자연스럽게 확장 가능

다른 로봇 플랫폼:

  • 로봇 형상만 변경(꼭짓점 정의)하면 다른 로봇 형태에 즉시 적용
  • 선박(보트 풋프린트), 지게차(직사각형 + 포크), 인형 로봇(다각형) 등

9.2 장단점 분석

FRGraph의 장점:

  1. 협소 통로에서의 방향 인식: 편향 행렬 Q를 통한 방향 인식 영역 생성은 기존 모든 방법에서 처리하지 않은 새로운 기여. SANDO의 STSFC조차 장애물 형상 기반이므로 협소 통로에서 유사한 한계 가능성.

  2. 수학적 연속 안전 보장: 립시츠 분기한정법은 유한 샘플 기반 검증 대비 엄격한 수학적 보장. FRTree처럼 이산 검증만 하는 방법들과 명확히 차별화.

  3. 이기종 플랫폼: 2D 지상 로봇 + 3D UAV 모두 동일 프레임워크로 지원. 이는 ViLiNT(지상만), TRG-Planner(지상 비정형)와 대비.

  4. 실시간 성능: 2D 4.4ms, 3D 22.3ms는 실세계 로봇에서 즉시 활용 가능한 수준.

  5. 공개 코드: GitHub에서 공개, ROS 통합 완료로 즉시 재현 및 확장 가능.

FRGraph의 단점:

  1. 동적 장애물 처리 미흡: SANDO는 동적 장애물을 명시적으로 처리하지만 FRGraph는 정적 환경만 가정. 실제 인간 공존 환경(창고, 병원 복도)에서 한계.

  2. 전역 경로 계획 없음: 지역 플래너만 존재. 복잡한 대형 환경에서는 FRGraph가 미로에 빠질 수 있음. SANDO, TRG-Planner는 전역 계획기를 포함.

  3. 모달 센서 단일: LiDAR만 사용. ViLiNT처럼 RGB+LiDAR 융합으로 의미론적 장애물 회피(사람 인식 등) 불가.

  4. 학습 없는 방법의 적응성: 환경 지식을 학습하지 않으므로 구조적 패턴(복도 배치, 문 위치 등) 활용 불가. ViLiNT나 TRG-Planner(지형 위험 학습)는 이를 활용.

9.4 연구 방향성 평가

FRGraph는 볼록 자유 영역 기반 경로 계획의 두 가지 핵심 한계—방향 무관성과 이산 안전 검증—를 각각 독립적이고 체계적인 방법으로 해결했다는 점에서 연구 방향성이 타당하다.

특히 방향 인식 편향 행렬 아이디어는 간단하지만 효과적이며, 기존 볼록 자유 영역 문헌에서 간과된 실용적 문제를 해결한다. 립시츠 연속 안전 인증도 다른 궤적 최적화 문제에 일반화할 수 있는 잠재력이 있다.

동적 장애물 처리와 전역 계획기 통합이 향후 자연스러운 확장 방향이다.

11. 결론 (Conclusion)

혁신성 평가

FRGraph는 볼록 자유 영역 기반 내비게이션이라는 잘 정립된 분야에서 두 가지 명확하고 실용적인 한계를 체계적으로 해결했다는 점에서 혁신적이다.

특히 방향 인식 편향 행렬 Q = ee^T + λ(I - ee^T)는 아이디어는 단순하지만:

  • 기존 방법 어디에서도 제안되지 않은 접근
  • 수학적으로 QP 목적함수에 우아하게 통합
  • 협소 통로라는 실용적으로 중요한 시나리오에서 극적 성능 향상 달성

립시츠 연속 안전 인증은:

  • 수학적으로 엄격한 연속 충돌 없음 보장
  • 이산 샘플 검증 대비 이론적으로 명확한 우위
  • 분기한정법으로 계산 효율 확보

실용적 의의

  1. 창고 자동화, 좁은 복도 환경: 가장 즉각적인 적용처. 물류 로봇이 좁은 통로를 안전하게 통과하는 핵심 문제 해결.
  2. 실세계 검증의 신뢰성: Unitree Go2(사족 로봇)와 UAV 모두에서 검증, 시뮬레이션에만 의존하지 않음.
  3. 공개 코드: GitHub의 C++/ROS 구현으로 즉각적인 재사용 가능성.

향후 연구 방향

  1. 동적 장애물 통합: SANDO의 STSFC 아이디어를 FRGraph의 방향 인식 영역 생성에 통합하여 이동하는 사람/로봇 처리
  2. 전역-지역 계획기 결합: Topo-metric 맵과 결합하여 대형 미지 환경 탐색
  3. 의미론적 갭 탐지: RGB-D 또는 멀티모달 센서로 갭의 종류(문, 복도 출구, 기계 사이 간격) 분류하여 의미 인식 내비게이션 확장
  4. 학습 기반 λ 적응: 환경 유형에 따라 λ를 동적으로 조정하는 메타러닝 접근
  5. 다중 로봇 확장: FRGraph를 공유하여 다중 로봇 협력 내비게이션에 적용
