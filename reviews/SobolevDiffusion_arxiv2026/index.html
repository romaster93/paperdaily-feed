1.2 연구 목표 (Research Objective)

이 논문은 학습 기반 워밍스타트(warm-start)를 통해 경사 기반 궤적 최적화(TO)의 수렴 속도와 해 품질을 동시에 개선하는 방법을 제안한다.

경사 기반 궤적 최적화(iLQR, DDP, ProxDDP)는 로봇의 최적 제어에서 강력한 도구지만 한계가 있다:

  1. 인스턴스 독립성: 매 새로운 문제(초기 위치, 목표)마다 처음부터 반복 수렴 → 이전 문제 해결 경험 미활용
  2. 초기값 민감성: 나쁜 초기 궤적에서 시작하면 지역 최솟값(local minimum)에 수렴 → 해 품질 저하
  3. 복잡한 제약 처리: 접촉-풍부(contact-rich) 시나리오나 다중 장애물에서 수렴이 느림 또는 실패

OLAhGP 방법으로 이를 해결하려면 학습된 정책이 각 문제에 대한 좋은 초기 궤적 추정값을 제공해야 한다. 그러나 TO 솔버가 생성한 데이터(로컬 최적 궤적)로 정책을 학습하면 복합 오차(compounding errors) 문제가 발생한다: 작은 궤적 이탈이 학습 데이터에 없던 상태로 정책을 이끌고, 이로부터 회복 불가한 오차가 연쇄 증폭된다.

핵심 기여: Sobolev 학습(Sobolev learning)을 확산 정책(diffusion policy)에 적용하여, 궤적 데이터와 함께 1차 정보(피드백 게인, feedback gains)를 학습에 통합한다. 1차 정보는 TO 솔버의 역방향 패스에서 추가 계산 없이 무료로 얻을 수 있으며, 이를 통해 510배 적은 궤적 데이터로 효과적인 워밍스타트를 달성하고 TO 수렴을 2×20× 가속한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 인스턴스별 독립 해결(Per-Instance Solving)의 비효율성

경사 기반 TO 솔버(iLQR, DDP, ProxDDP)의 구조적 한계:

TO 솔버의 인스턴스 독립성 문제:

문제 인스턴스 ξ₁ (초기상태 x̂₁, 목표 x_goal1)
  → 직선 보간 초기값
  → TO 수렴: 1,000회 반복, 4.1초 소요
  → 최적 궤적 τ₁*

문제 인스턴스 ξ₂ (초기상태 x̂₂, 목표 x_goal2)  ← τ₁*에서 배운 것 없음
  → 직선 보간 초기값
  → TO 수렴: 900회 반복, 3.8초 소요
  → 최적 궤적 τ₂*

...반복...

비효율: 유사한 문제들이 독립적으로 해결됨
        이전 경험이 초기값 품질 개선에 활용되지 않음

양적 규모: 로봇팔(UR5), 이중 진자, 사족 드론 실험에서 TO 단독으로는 평균 400900회 반복, 416초 소요. 실시간 모션 계획에는 너무 느리다.

B. 복합 오차(Compounding Errors) 문제 - TO 기반 데이터의 역설

TO 솔버가 생성한 학습 데이터의 특수성이 오히려 독이 된다:

TO 생성 데이터의 로컬 최적성 역설:

TO 솔버:
  초기값 → 반복 → 로컬 최적 궤적 τ*
  특성: τ* 상의 모든 상태는 토크 제약 만족, 목표 도달
        τ* 주변에서 "미끄러짐(misstep)" 없음

학습 데이터: D = {τ₁*, τ₂*, ...}
  → 모든 궤적이 로컬 최솟값 주변의 완벽한 경로
  → 경로를 벗어난 상태 (out-of-distribution, OOD) 데이터 없음

정책 롤아웃 시:
  소규모 예측 오차 → OOD 상태 s_OOD 진입
  정책은 s_OOD에서 어떻게 해야 할지 학습 안 됨
  → 오차 증폭: δ₁ → δ₂ → ... → 완전한 실패

비교: 인간 시연 데이터는 자연스럽게 불완전 → 소규모 이탈 경험 포함

실제 규모: DiffuSolve(Li et al., 2024)는 이 문제를 해결하기 위해 200,000개 궤적(200 CPU 코어, 20시간 계산)이 필요했다. 이 논문의 Sobolev 접근법은 수백 개 궤적으로 동등한 성능을 달성한다.

C. 확산 정책의 MLP 대비 장점과 한계

확산 정책의 장점:

  • 복잡한 다중 모달(multi-modal) 분포 표현 가능
  • 표현력(expressiveness)이 MLP 직접 정책보다 훨씬 강력
  • 장기 수평선(long horizon) 궤적에서 일관된 동작 생성

확산 정책의 현재 한계:

  • 학습에 많은 데이터 필요 → 로컬 최적 데이터에서 복합 오차에 더 취약
  • 추론 시 여러 확산 단계 필요 → 지연 시간(latency) 발생
  • 기존 Sobolev 학습 방법은 MLP 직접 정책에만 적용 (Le Lidec et al., 2023)

이 논문의 핵심 질문: 확산 정책에 Sobolev 학습을 적용하여 복합 오차 문제를 해결하면서도 표현력의 장점을 유지할 수 있는가?

2.2 핵심 해결책

Sobolev-trained Diffusion Policy는 두 가지 아이디어로 위 문제를 해결한다:

  1. Sobolev 1차 손실: 궤적 데이터(τ₀)와 함께 TO 솔버의 피드백 게인(∂u/∂x)을 사용하여 정책이 궤적 주변의 국소 동특성(local dynamics)을 학습 → 복합 오차 저항성 향상
  2. 교번 알고리즘: 궤적 수집과 정책 학습을 반복하여 점진적으로 어려운 문제에 도전 → TO 솔버가 해결 못한 문제도 정책의 워밍스타트로 해결

3. 핵심 방법론 (Core Methods)

3.1 확산 정책(Diffusion Policy) 배경

3.1.1 DDPM (Denoising Diffusion Probabilistic Models)

Ho et al. (2020)의 DDPM은 정방향 노이즈 추가와 역방향 노이즈 제거 과정을 통해 데이터 분포를 학습한다:

DDPM 정방향 프로세스 (노이즈 추가):
p_D(τ_k | τ_{k-1}) := N(τ_k; √(1-β_k) τ_{k-1}, β_k I)

직접 샘플링 (Eq. 3):
τ_k = √(ᾱ_k) τ_0 + √(1-ᾱ_k) ε,   ε ~ N(0, I)
ᾱ_k = ∏_{s=1}^k (1-β_s)

여기서:
  k = 1, ..., K: 노이즈 단계 (K = 5 고정)
  τ_0: 깨끗한 궤적 (학습 목표)
  τ_k: k 단계 노이즈가 추가된 궤적
  β_k: 노이즈 스케줄 (square cosine)

역방향 프로세스 (denoising):
p_θ(τ_{k-1} | τ_k) = N(τ_{k-1}; μ_θ(τ_k, k), β̃_k I)
β̃_k = [(1-ᾱ_{k-1})/(1-ᾱ_k)] β_k

신경망 τ_θ: τ_k, k, 조건(ξ, 관측 이력)을 입력받아 깨끗한 τ_0를 예측

τ_0 파라미터화 선택: 이 논문은 ε 예측 대신 τ_0 직접 예측을 선택. 실험적으로 더 나은 성능.

3.1.2 인페인팅(Inpainting) 기법

조건화를 위해 각 역방향 단계에서 과거 행동을 τ_k에 직접 삽입:

인페인팅 (관측 이력 조건화):
각 k 단계에서: τ_k[1:T_o] ← a_hist  (과거 T_o개 행동으로 고정)
선택적으로:   τ_k[T_h] ← x_target   (목표 상태로 고정)

T_o = 1: 관측 이력 길이
T_h = 32: 예측 수평선
T_a = T_h - T_o = 31: 실행 행동 길이 (재계획 전)

3.1.3 표준 DDPM 학습 손실

기본 확산 정책 학습(Diff):

L^Diff = E_{(ξ, τ_0, o_hist), ε, k} [||τ_0 - τ_θ(τ_k, k, ξ, o_hist)||²]

여기서:
  ξ: 문제 파라미터 (초기 위치, 목표)
  τ_0: TO 솔버가 생성한 최적 궤적
  k ~ U(1, K): 무작위 노이즈 단계
  τ_k = √(ᾱ_k) τ_0 + √(1-ᾱ_k) ε: k 단계 노이즈 궤적

이 손실로 학습한 정책(Diff)이 복합 오차 문제로 어려움을 겪는 것이 핵심 동기다.

3.2 Sobolev 학습 이론 (Sobolev Learning Theory)

3.2.1 Sobolev 학습의 기본 원리

Czarnecki et al. (2017, NeurIPS) "Sobolev Training for Neural Networks"는 신경망 학습 시 함수값(0차)과 함께 도함수(1차 이상)를 손실에 포함하는 방법을 제안했다:

일반 Sobolev 손실 (Eq. 8):
L^Sobolev = E_x [||f_θ(x) - y||² + α_Sob ||∂f_θ(x)/∂x - ∂y/∂x||²_F]

여기서:
  f_θ(x): 신경망 예측값
  y: 레이블 (목표값)
  ∂y/∂x: 레이블의 x에 대한 도함수 (외부 제공 필요)
  α_Sob: Sobolev 손실 가중치 (α_Sob = 1.0 기본)

Sobolev 학습의 이점:

  • 함수값뿐 아니라 함수의 국소 동특성(local behavior)까지 정확히 모사
  • 레이블 근방에서 더 견고한 예측 → 작은 이탈에도 올바른 방향 안내
  • 데이터 효율성: 각 데이터 포인트에서 추가 정보를 추출 → 더 적은 샘플로 동등한 성능

3.2.2 TO 피드백 게인에서의 1차 정보

경사 기반 TO 솔버(ProxDDP)의 역방향 패스는 피드백 게인을 자연스럽게 생성한다:

최적 제어 피드백 게인 (Riccati 방정식의 부산물):
∂u_t/∂x_t: t 시점에서 상태 x_t에 대한 제어 u_t의 민감도

연쇄 법칙에 의한 상태 전이 미분 (Eq. 2):
∂x_{t+1}/∂x_t = ∂f/∂x_t(x_t, u_t) + ∂f/∂u_t(x_t, u_t) · ∂u_t/∂x_t

다단계 미분 전파 (Eq. 7):
∂a_{t+h}/∂x_{t+o} = [∂x_{t+o+1}/∂x_{t+o}] · [∂x_{t+o+2}/∂x_{t+o+1}] · ... · [∂a_{t+h}/∂x_{t+h}]
for 0 ≤ o ≤ h < T_h

결과: ∂τ_0/∂x_hist = ∂a_{t1:t1+T_h-1}/∂x_{t1:t1+T_o-1}
     (전체 예측 궤적의 관측 이력에 대한 야코비안)

핵심 통찰: TO 솔버의 피드백 게인은 솔버가 수렴한 후 역방향 패스에서 추가 계산 없이 무료로 얻을 수 있다. 이는 정책 학습에 귀중한 1차 정보를 비용 없이 제공한다.

물리적 해석: ∂u_t/∂x_t는 현재 상태에서 약간 이탈했을 때 제어 입력을 어떻게 조정해야 하는지를 나타낸다. 이를 정책이 학습하면, 롤아웃 중 작은 이탈이 발생해도 올바른 복구 방향을 알 수 있다.

3.2.3 확률적 Sobolev 학습 (Stochastic Sobolev, Eq. 9)

야코비안 전체를 계산하는 것은 비용이 크다. 확률적 투영(stochastic projection)으로 근사:

확률적 Sobolev 손실 (Eq. 9):
L^Sobolev_Stochastic = E_x [||f_θ(x) - y||²
                           + (α_Sob/n_proj) Σᵢ ||vᵢᵀ · ∂y/∂x - ∂/∂x(vᵢᵀ · f_θ(x,ξ))||²]

여기서:
  vᵢ: 단위 구면에서 무작위 샘플링한 투영 벡터
  n_proj: 투영 수 (n_proj = 1로 충분함을 실험으로 확인)

계산 비용: Sob+Diff 학습이 Diff 대비 에포크당 ~2배 느림
           → 하지만 필요한 에포크 수가 훨씬 적으므로 전체 비용은 비슷하거나 낮음

3.3 확산 정책에 Sobolev 학습 적용

3.3.1 실패한 나이브 접근법 (Eq. 10)

처음의 직관적 시도: 전체 확산 프로세스 출력에 Sobolev 손실 적용:

나이브 Sobolev+Diffusion 손실 (실패):
L^Sob+Diff_full = E_{(ξ, τ_0, ∂τ_0/∂x_hist), τ_K} [
    ||τ_0 - τ̄_0^θ||²
  + α_Sob ||∂τ_0/∂x_hist - ∂τ̄_0^θ/∂x_hist||²
]

여기서 τ̄_0^θ: K번의 역방향 단계를 모두 거친 최종 출력

문제: "This opposes how diffusion models are typically trained,
       and it did not work in practice."
  → 전체 확산 체인의 야코비안 계산이 극도로 복잡하고 불안정
  → 그래디언트 소실/폭발 발생

3.3.2 핵심 기여: 단계별 Sobolev 손실 (Eq. 11)

해결책: 최종 출력이 아닌 각 노이즈 단계 k에서의 단일 스텝 예측에 Sobolev 손실 적용:

제안 Sobolev+Diffusion 손실 (핵심 기여, Eq. 11):
L^Sob+Diff = E_{(ξ, τ_0, ∂τ_0/∂x_hist), ε, k} [
    ||τ_0 - τ_0^{θ,k}||²                                          (0차 항)
  + (α_Sob/n_proj) Σᵢ ||vᵢᵀ·∂τ_0/∂x_hist - ∂/∂x_hist(vᵢᵀ·τ_0^{θ,k})||²  (1차 항)
]

여기서:
  τ_0^{θ,k} = τ_θ(τ_k, k, ξ, o_hist): k번째 노이즈에서의 단일 스텝 τ_0 예측
  ∂τ_0^{θ,k}/∂x_hist: 이 단일 스텝 예측의 관측 이력에 대한 미분

핵심 구분:
  τ_0^{θ,k} (사용): k 단계에서의 단일 스텝 네트워크 예측
  τ̄_0^θ (미사용): K번 역방향 패스를 거친 최종 출력

왜 이 방식이 작동하는가?

직관적 설명:

표준 DDPM 학습의 핵심:
  "모든 노이즈 수준 k에서 τ_0를 예측하도록 학습"
  → 단일 네트워크 τ_θ가 모든 k에서 일관된 예측 제공

단계별 Sobolev는 이 원칙과 완벽히 호환:
  "모든 노이즈 수준 k에서 τ_0의 도함수까지 예측하도록 학습"
  → 각 노이즈 단계에서의 국소 동특성을 학습
  → 완전한 확산 체인 없이 단일 네트워크 평가로 미분 계산
  → 복잡한 그래디언트 역전파 불필요

vs 나이브 접근법의 실패 이유:
  "K번의 역방향 패스를 거친 최종 출력의 도함수"
  → K개 네트워크 평가를 통한 역전파 → 그래디언트 소실
  → 확산 훈련 원리와 상충 → 학습 불안정

α_Sob 가중치 설계:

고정 가중치 (최종 선택):
  α_Sob = 1.0: 대부분의 태스크
  α_Sob = 10⁻³: 쿼드로터 태스크 (물리적 스케일 차이가 큼)

시간 의존 가중치 (실험 후 폐기):
  α_Sob · k/K (k가 클수록 증가): 0차/1차 항이 서로 상쇄
  α_Sob · (K-k)/K (k가 클수록 감소): 마찬가지 문제
  → 고정 가중치보다 성능 열등 → 폐기

3.4 교번 학습 알고리즘 (Alternating Loop, Algorithm 1)

3.4.1 알고리즘 구조

Sob+Diff 교번 알고리즘 (Algorithm 1):

초기화: 확산 정책 네트워크 τ_θ; 버퍼 D = ∅

for n_algo 반복:
  ┌─────────────────────────────────────────────────────────┐
  │  [궤적 수집 단계]                                        │
  │  D ← ∅  (버퍼 리셋)                                     │
  │                                                         │
  │  for n_traj 개 궤적:                                     │
  │    ξ ~ P  (태스크 파라미터 샘플링)                        │
  │    X₀, U₀ ← Interpolate(x_0, x_target)  (기본 초기값)   │
  │    X_π, U_π ← PolicyRollout(τ_θ, ξ, T_a, K)  (정책 초기값) │
  │                                                         │
  │    [두 초기값 모두로 TO 실행, 더 나은 것 선택]             │
  │    X, U, ∂u_t/∂x_t, ∂x_{t+1}/∂x_t ← ArgminCost(       │
  │        TO(X₀, U₀, ξ), TO(X_π, U_π, ξ))                 │
  │                                                         │
  │    if 둘 다 n_max = 1,000회 내 미수렴: 거부, 재시도        │
  │    else: D ← D ∪ {(X, U, ∂u_t/∂x_t, ∂x_{t+1}/∂x_t)}  │
  └─────────────────────────────────────────────────────────┘
  
  ┌─────────────────────────────────────────────────────────┐
  │  [정책 학습 단계]                                        │
  │                                                         │
  │  for n_pl 에포크:                                        │
  │    D에서 (ξ, τ_0, x_hist, o_hist, 도함수) 샘플링         │
  │    ∂τ_0/∂x_hist ← ChainRule(∂x_{t+1}/∂x_t, ∂u_t/∂x_t) │
  │    k ~ U(1, K), ε ~ N(0, I)                             │
  │    τ_k = √(ᾱ_k) τ_0 + √(1-ᾱ_k) ε                      │
  │    τ_k[1:T_o] ← a_hist  (인페인팅)                      │
  │    τ_0^{θ,k} = τ_θ(τ_k, k, ξ, o_hist)                 │
  │    n_proj개 투영 벡터 vᵢ 샘플링                           │
  │    ∇_θ L^Sob+Diff 계산 후 그래디언트 스텝                  │
  └─────────────────────────────────────────────────────────┘

3.4.2 세 가지 핵심 알고리즘 선택

선택 1: ArgminCost — 두 초기값 경쟁

목적: 정책 워밍스타트 + TO 솔버의 시너지 극대화

구현:
  TO(직선 보간 초기값, ξ) → 궤적 A, 비용 J_A
  TO(정책 롤아웃 초기값, ξ) → 궤적 B, 비용 J_B
  선택: min(J_A, J_B)

효과:
  - 정책이 나쁜 초기값을 줘도 안전장치 존재
  - 정책이 새로운 로컬 미니마 발견 가능 → D에 더 다양한 궤적 추가
  - D의 품질 점진적 향상

선택 2: 수렴 기준 n_max = 1,000회

목적: D에 미수렴(품질 나쁜) 궤적이 들어가는 것 방지

거부 조건: 두 TO 시작점 모두 1,000회 이내에 수렴 실패
  → 해당 ξ 폐기, 새 ξ 샘플링
  
효과: 낮은 품질 지역 자동 배제, 점진적 어려움 증가에 자연스럽게 대응

선택 3: 매 반복마다 D 리셋

목적: 오래된(과거 정책 초기값으로 생성된) 궤적이 현재 학습을 방해하지 않도록

구현: 매 n_algo 반복 시작 시 D = ∅
      n_traj개 새 궤적을 현재 정책으로 생성

효과: 정책 발전에 따른 데이터 분포 이동 자동 처리
      (DAgger 알고리즘과 유사한 on-policy 특성)

3.4.3 정책 롤아웃 (Algorithm 2)

PolicyRollout(τ_θ, ξ, T_a, K_rollout):

초기화: t = 0, 관측 이력 o_hist, 행동 이력 a_hist

while t < T:
  τ_K ~ N(0, I)  (순수 노이즈에서 시작)
  
  for k = K_rollout 내려가며 1까지:
    τ_k[1:T_o] ← a_hist    (인페인팅으로 과거 행동 고정)
    τ_0^{θ,k} = τ_θ(τ_k, k, ξ, o_hist)
    τ_{k-1} ~ N(μ̃_k(τ_k, τ_0^{θ,k}), β̃_k I)  (DDPM 역방향 스텝)
  
  for s = 1 to T_a:
    if t+s > T: break
    if a가 제어 u: u_{t+s-1} = τ_0[s]
    if a가 상태 x: u_{t+s-1} = PD제어/RNEA(x_{t+s-1}, τ_0[s])
    x_{t+s} = f(x_{t+s-1}, u_{t+s-1})
  
  o_hist, a_hist 업데이트
  t ← t + T_a
  
return X, U

6. 핵심 기여점 (Key Contributions)

6.1 확산 정책에 대한 1차 Sobolev 손실 (핵심 기여)

기존 Sobolev 학습(Le Lidec et al., 2023)은 MLP 직접 정책에만 적용되었다. 이 논문은 확산 정책의 각 노이즈 단계에서의 단일 스텝 예측에 Sobolev 손실을 적용하여 표현력 높은 확산 정책과 복합 오차 저항성을 동시에 달성하는 최초의 방법을 제시한다.

핵심 아이디어인 "단계별 적용 vs 전체 체인 적용"의 차이는 단순해 보이지만, 실제로 확산 모델의 훈련 원리(각 노이즈 단계에서 독립적으로 τ_0 예측 학습)와 Sobolev 손실(예측의 입력 미분까지 일치)이 자연스럽게 결합되는 지점을 정확히 포착했다.

6.2 데이터 효율성 향상 (5~10×)

DiffuSolve(200,000개 궤적, 20시간, 200 CPU)와 비교하여 수백 개 궤적, 단일 노트북에서 동등하거나 우수한 성능을 달성한다. 이는 데이터 수집 비용이 높은 실제 로봇 환경에서 특히 중요하다.

6.3 TO 수렴 가속 (2×~20×)

태스크 가속비 비고
이중 역진자 (T_a=9) ~2.6× 전체 시간 기준
이중 역진자 (T_a=1, 솔버만) ~20× 솔버 시간만 기준
쿼드로터 9 장애물 ~2.1× 전체 시간 기준

단순 속도 향상뿐 아니라 TO 단독으로는 해결 불가한 어려운 태스크를 해결 가능하게 만드는 질적 도약도 달성한다(이중 역진자: TO 80% 실패 → Sob+Diff 워밍스타트로 수렴).

6.4 교번 알고리즘으로 어려운 태스크 점진적 해결

DAgger와 유사하지만 중요한 차이: TO 솔버가 정책 워밍스타트를 받아 이전에 실패했던 태스크를 해결하고, 그 궤적이 다시 정책 학습에 활용된다. 이 양방향 부트스트래핑으로 어려운 태스크에서 점진적 수렴이 가능하다.

7. 구현 상세 (Implementation Details)

7.1 U-Net 아키텍처 상세

조건부 U-Net 구조 (Janner 2022, Chi 2023과 동일):

입력:
  - τ_k: 노이즈 궤적 [T_h × a_dim]
  - k: 노이즈 단계 (정수 → 임베딩)
  - ξ: 태스크 파라미터 (초기 위치, 목표)
  - o_hist: 관측 이력 [T_o × x_dim]

U-Net 구조:
  다운샘플링: [24, 24, 32, 32] 채널 (stride 2 컨볼루션)
  업샘플링: 대응하는 스킵 연결
  조건화: k와 ξ를 Feature-wise Linear Modulation (FiLM)으로 주입

파라미터: ~300k (경량 설계)

출력: τ_0^{θ,k} ∈ R^{T_h × a_dim}
      (노이즈 없는 궤적 예측)

7.2 ProxDDP 솔버 특성

ProxDDP (Proximal Differential Dynamic Programming):
  - Jallet et al. (IEEE Trans. on Robotics, 2025)의 최신 DDP 변형
  - 등식/부등식 제약 처리 (ProxALM 기반)
  - 역방향 패스: 2차 근사 + 피드백 게인 자동 계산
  - 핫스타팅: 이전 솔루션에서 따뜻하게 시작

피드백 게인 계산:
  DDP 역방향 패스의 부산물로 자동 생성
  추가 계산 없이 ∂u_t/∂x_t 획득
  → Sobolev 학습에 추가 비용 없이 활용

7.3 에포크 크기 정의

에포크 크기 (데이터 규모 정규화):

MLP 기반 (직접 정책):
  E = |D| × T: 전체 상태-행동 쌍 수
  
확산 기반 (청크 예측):
  E = |D| × (T - T_h) / T_h: 예측 청크 수
  
이유: 확산 정책은 T_h 길이 청크를 예측하므로
     실제 학습 샘플 수는 T_h배 적음
     → 비교를 위해 정규화 필요

8. 고급 주제 (Advanced Topics)

8.1 Sobolev 학습의 이론적 기반

Pfrommer et al. (2022, NeurIPS) "TaSIL"은 모방 학습에서 Sobolev 도함수 일치의 이론적 기반을 제공한다:

  • k차 Sobolev 손실을 사용하면 모방 오차가 O(T^{2k+1})로 감소 (T: 수평선)
  • 1차 도함수만으로도 컴파운딩 오차의 지수적 증폭을 다항식으로 감소
  • 이론: DAgger 같은 추가 데이터 없이도 복합 오차 저항성 달성 가능
오차 증폭 모델 (단순화):
표준 BC: ||x_t - x_t*|| ≤ C · t · ||π - π*||_{0}  (선형 증폭)
Sobolev: ||x_t - x_t*|| ≤ C · t^{1/2} · ||π - π*||_{1}  (완화된 증폭)

여기서 ||π - π*||_{k}: k차 Sobolev 노름에서의 정책 오차

8.2 확장 가능성

향후 연구 방향:

1. 접촉-풍부 시나리오 (Contact-Rich Scenarios)
   현재: 마찰, 접촉 이벤트 없는 단순 연속 동역학
   향후: 물체 조작, 보행에서의 접촉 처리
   도전: 접촉 역학의 불연속성 → ProxDDP 확장 필요

2. 가변 장애물 수 (Variable Obstacle Count)
   현재: 장애물 수 고정 (9개 쿼드로터)
   향후: 트랜스포머 or 순환 정책으로 가변 입력 처리

3. 오프라인 RL과의 결합
   ArgminCost로 좋은 궤적만 선택하지만 더 세련된 필터링 가능
   → 오프라인 RL 크리틱으로 낮은 품질 로컬 미니마 식별/거부

4. 커리큘럼 학습 (Curriculum Learning)
   현재: 균일 태스크 샘플링 ξ ~ P
   향후: 정책 능력에 맞는 점진적 난이도 조절

5. 실로봇 검증
   현재: 시뮬레이션 전용
   향후: UR5, 쿼드로터 실하드웨어 적용 필요

8.3 한계점 (Limitations)

주요 한계:

1. 시뮬레이션 전용 검증
   실세계 로봇 실험 없음
   Sim-to-real 전이 성능 미검증

2. 경사 기반 TO 의존성
   ProxDDP의 피드백 게인이 핵심 → 다른 TO 솔버에는 재설계 필요
   접촉 불연속 동역학에서 DDP 자체가 어려움

3. 단일 노트북 실험 범위
   더 복잡한 로봇 시스템(휴머노이드, 발 로봇)에서의 확장성 미검증

4. 코드 미공개
   논문 승인 후 공개 예정이지만 현재는 재현 불가

5. 가변 장애물 처리 불가
   쿼드로터에서 장애물 수가 달라지면 정책 재학습 필요

9.4 장단점 분석

Sob+Diff의 강점:

  1. TO와의 시너지: 기존 리뷰 논문들은 TO와 독립적으로 작동한다. Sob+Diff는 TO를 대체하지 않고 TO를 더 효율적으로 만드는 보완재다. 이는 TO의 안전성(constraint satisfaction)과 학습의 효율성을 모두 취하는 최선의 접근이다.

  2. 데이터 효율성의 혁신: 3개 궤적으로 시작할 수 있다는 것은 실제 로봇에서 데이터 수집이 비용이 큰 경우(안전 제약, 마모, 시간) 매우 중요하다.

  3. 이론적 기반: Sobolev 학습의 이론적 근거(TaSIL, Czarnecki 2017)가 명확하고, DDP의 피드백 게인 활용이 수학적으로 자연스럽다.

Sob+Diff의 약점:

  1. 실세계 실험 부재: SANDO, UGE-MPC, DreamFlow, ViLiNT는 모두 실제 로봇 실험을 포함한다. Sob+Diff의 시뮬레이션 전용 검증은 실용성에 물음표를 남긴다.

  2. ProxDDP 의존성: 피드백 게인이 필요하므로 역방향 패스가 있는 경사 기반 TO 솔버에 제한된다. Sampling-based MPC(MPPI 등)와는 직접 결합 불가.

  3. 협소한 적용 범위 검증: 3개 태스크(역진자, UR5, 쿼드로터)는 모두 시뮬레이션 기반이고 단순한 연속 동역학이다. 보행, 접촉 조작 같은 복잡한 시나리오로의 확장은 미검증이다.

9.5 실적용 가능성 평가

실적용 시나리오별 평가:

시나리오 1: 산업 로봇팔 반복 작업 (적합)
  - 동일/유사한 초기 설정에서 다양한 목표로 이동
  - UR5 실험과 직접 일치
  - 사이클 시간 단축이 핵심 가치

시나리오 2: 고속 드론 내비게이션 (부분 적합)
  - 쿼드로터 실험에서 2× 가속 확인
  - 그러나 장애물 수 변화에 대응 어려움
  - 고정 환경에서는 강한 후보

시나리오 3: 접촉 풍부 조작 (부적합, 향후 과제)
  - 파지, 슬라이딩 접촉 등 불연속 동역학
  - DDP/ProxDDP 자체의 어려움
  - 현재 미검증, 향후 연구 과제

시나리오 4: 빠른 재계획 필요 시나리오 (적합)
  - 2~20× 속도 향상이 실시간 제어 가능성 제공
  - MPC 주기를 유지하면서 더 복잡한 솔버 사용 가능

9.6 연구 방향성 평가

Sob+Diff는 학습-최적화 하이브리드(learning-to-optimize) 패러다임의 중요한 진전을 대표한다. 기존 Planner 트랙 리뷰 논문들이 주로 경로 계획이나 내비게이션에 집중한 것과 달리, Sob+Diff는 일반 궤적 최적화 문제의 솔버 가속이라는 더 근본적인 문제를 다룬다.

TO의 장점(제약 만족, 안전성, 지역 최적)을 유지하면서 학습의 장점(경험 재활용, 빠른 추론)을 결합하는 이 방향은 실시간 로봇 제어의 핵심 병목 중 하나를 해결한다. 향후 실세계 검증과 접촉 동역학으로의 확장이 이루어진다면 상당한 실용적 가치를 가질 것이다.

11. 결론 (Conclusion)

Sobolev-trained Diffusion Policy(Sob+Diff)는 경사 기반 궤적 최적화(TO)와 확산 정책의 시너지를 1차 피드백 게인 정보로 극대화하는 혁신적 접근법이다.

핵심 통찰은 세 가지다:

1. 피드백 게인은 무료 정보다: TO 솔버의 역방향 패스에서 추가 계산 없이 얻는 ∂u/∂x는 로컬 동특성을 완전히 기술한다. 이 정보를 정책 학습에 통합하면 복합 오차를 방지할 수 있다.

2. 단계별 Sobolev 적용이 핵심이다: 전체 확산 체인에 Sobolev를 적용하면 실패한다. 각 노이즈 단계에서의 단일 스텝 예측에 적용하는 것이 확산 모델의 훈련 원리와 Sobolev 학습을 자연스럽게 결합하는 유일한 방법이다.

3. 교번 알고리즘으로 어려운 태스크를 부트스트랩한다: TO 단독으로는 80% 실패하는 이중 역진자를 Sob+Diff 워밍스타트로 해결하고, 그 궤적으로 더 나은 정책을 훈련하는 양방향 강화 루프가 핵심이다.

기존 Planner 트랙 리뷰 논문들(SANDO, DreamFlow, ViLiNT, UGE-MPC)이 경로 계획·내비게이션에 집중한 것과 달리, Sob+Diff는 최적 제어 솔버 자체를 가속하는 더 근본적인 문제를 다룬다. 실세계 검증과 접촉 동역학으로의 확장이 이루어진다면, 산업 로봇팔 사이클 타임 단축, 실시간 드론 제어, 자유도 높은 물체 조작 등에서 실질적 영향을 미칠 수 있는 연구 방향이다.
