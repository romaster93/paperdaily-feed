1.2 연구 목표 (Research Objective)

TRG-planner는 산악·동굴·재난 현장 같은 비정형 지형(unstructured terrain)에서 지상 로봇(특히 사족보행 로봇)이 안전하면서도 거리 효율적인 전역 경로를 실시간으로 계획하는 문제를 다룬다. 핵심 통찰은 "지형의 횡단성(traversability)을 그래프의 노드 유효성과 방향성 엣지 위험도(directional edge traversal risk) 로 동시에 인코딩한다"는 것이다.

기존 비정형 지형 플래너는 두 갈래로 나뉜다. 한쪽은 grid/voxel 위에 traversability cost를 깔고 그 위에서 탐색하는 방식으로, 해상도를 올릴수록 메모리·연산이 폭증하고 대규모 환경에서 실시간성이 무너진다. 다른 쪽은 PRM*/RRT* 같은 샘플링 그래프지만, 엣지에 지형 위험도를 충분히 반영하지 못해 "통과 가능 여부"는 알아도 "어느 방향으로 들어가야 안전한가"를 표현하지 못한다.

TRG-planner는 이 둘의 간극을 메운다. 핵심 질문은:

  • 지형 위험도를 이동 방향(종방향 lon / 횡방향 lat)으로 분해하여 그래프 엣지에 직접 실으면, 같은 경사면이라도 진입 방향에 따라 다른 위험도를 부여할 수 있는가?
  • 전역 그리드를 다 채우지 않고 wavefront 전파로 "갈 수 있는 영역만" 점진적으로 그래프화하면, 대규모 환경에서도 ms 단위 실시간 계획이 가능한가?
  • 안전 계수 Γ 하나로 "최단 경로 ↔ 최대 안전"의 트레이드오프를 직관적으로 조절하면서, 실제 사족보행 로봇(Unitree Go1)으로 전이되는가?

논문은 이 셋 모두에 긍정으로 답하며, 그 정점으로 ICRA 2023 Quadruped Robot Challenge(QRC) 우승 팀(DreamSTEP)의 전역 경로 계획기로 채택된 실증을 든다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

(C1) 해상도-연산량 트레이드오프 (Grid 기반의 근본 한계). 2.5D elevation map이나 3D voxel 위에 traversability를 계산하면, 안전한 계획을 위해 고해상도가 필요하지만 해상도를 올릴수록 셀 수가 제곱/세제곱으로 늘어 탐색 비용이 폭증한다. 83m×151m급 산악 환경을 0.05m 해상도로 풀 그리드 A*로 풀면 수 초~수십 초가 걸려 실시간 재계획 루프에 들어갈 수 없다(논문 Table 3에서 Vanilla A*가 Long 시나리오 2980ms를 기록).

(C2) 방향 무관 위험도 (Direction-agnostic traversability). 대부분의 traversability 맵은 각 셀에 스칼라 위험도(경사·거칠기 등)를 부여한다. 그러나 실제 사족보행 로봇은 경사면을 정면으로 오를 때는 안정적이지만, 옆구리로(횡방향) 가로지르면 전복(roll-over) 위험이 급증한다. 동일 지형이라도 진입 방향에 따라 위험도가 달라지는데, 스칼라 셀 비용은 이를 표현하지 못한다.

(C3) 도달 가능성과 안정성의 분리 평가. "로봇이 서 있을 수 있는 안정적 지점(stability)"과 "현재 위치에서 실제로 갈 수 있는 지점(reachability)"은 다른 개념이다. 안정적이어도 고립된 섬(island)이면 무의미하다. 기존 방법은 이 둘을 통합 평가하지 못해, 도달 불가능한 영역을 경로 후보로 잘못 포함하는 사고가 생긴다.

(C4) 대규모 환경의 실시간 갱신. 로봇이 이동하며 새 센서 데이터로 지형을 갱신할 때, 전역 그래프를 매번 재구성하면 비용이 감당 불가다. 로컬 변화만 효율적으로 반영해 전역 그래프에 통합하는 계층적 관리(hierarchical management) 가 필요하다.

(C5) 안전-효율 트레이드오프의 직관적 제어. "얼마나 보수적으로 안전을 우선할 것인가"는 응용마다 다르다(정찰 vs 구조). 이 트레이드오프를 단일하고 해석 가능한 파라미터 로 노출해야 현장 적용성이 높아진다.

2.2 핵심 해결책

TRG-planner의 해법은 "방향성 위험 그래프(TRG) + wavefront 구성 + 계층적 관리 + 위험 인지 A*" 의 4중 결합이다:

  • 방향성 위험 엣지(C2 해결): PCA로 엣지 영역을 타원 평면으로 근사하고, 종/횡 고유벡터와 중력벡터의 내적으로 방향별 위험도를 산출 → 같은 경사라도 진입 방향에 따라 비대칭 위험 부여.
  • stability ∧ reachability 노드(C3 해결): 두 이진 조건을 동시 만족할 때만 노드 valid.
  • wavefront 구성(C1 해결): 전역 그리드 대신 로봇 주변에서 파면처럼 확장 → 탐색 가능 영역만 그래프화하여 ms 단위 계획.
  • 계층적 관리(C4 해결): 로컬 그래프 갱신 → 전역 그래프 통합.
  • 안전 계수 Γ(C5 해결): Γ=1(낙관)/3(균형)/10(보수)으로 단일 파라미터 트레이드오프.

3. 핵심 방법론 (Core Methods)

3.1 TRG 노드 정의 — 안정성과 도달 가능성

TRG의 각 노드 v_i = (p_i, s_i, E_i) 는 로봇이 발을 디딜 수 있는 지형 영역을 나타낸다. p_i는 3D 위치, s_i는 상태(valid/invalid), E_i는 연결된 엣지 집합이다. 노드의 유효성은 두 이진 지표의 논리곱으로 판정된다.

기하 안정성 (Geometric Stability)

노드 중심 c_i 주변(로봇 내접원 반경 r_robot 내) elevation map 높이들이 중앙값 h_mid로부터 임계값 h_max 이내에 머무는지 확인:

g(c_i) = 𝟙{ ∀ h(x_k, y_k) ∈ N(c_i) :  | h(x_k, y_k) − h_mid | < h_max }
  • 𝟙{·}: 지시함수(indicator) — 조건 만족 시 1, 아니면 0.
  • 직관: 로봇 발판 영역의 높이 변동(거칠기·단차)이 h_max(=0.16m, 로봇이 극복 가능한 최대 높이)를 넘으면 그 지점은 불안정 → 노드 무효.

도달 가능성 (Reachability)

r(E_i) = 𝟙{ n(E_i) > 0 }
  • n(E_i): 노드 i에 연결된 유효 엣지 의 개수.
  • 직관: 안정적이어도 어떤 valid 엣지로도 닿을 수 없으면(고립 섬) 도달 불가 → 노드 무효. 이것이 stability만으로는 잡지 못하는 "갈 수 있는가"를 보장한다.

노드 상태 분류

s_i = { valid,    if g(c_i) ∧ r(E_i)
      { invalid,  otherwise

이 이중 게이팅(stability ∧ reachability) 이 C3을 해결한다. "안전하게 설 수 있고(stability) + 실제로 닿을 수 있는(reachability)" 지점만 경로 후보가 된다.

        │ 높이 편차 검사 (|h − h_mid| < h_max ?)

3.2 방향성 엣지 위험도 — PCA 타원 평면과 중력 내적

TRG의 가장 핵심적인 기여는 엣지 위험도를 이동 방향으로 분해 하는 것이다. 두 노드 i, j를 잇는 엣지 영역(elevation map 상의 직사각형 띠)을 PCA로 타원 평면 ξ 에 근사한다.

PCA 타원 평면 근사

엣지 영역 내 elevation 포인트들의 공분산을 PCA로 분해하면, 그 영역의 지배적 기하 방향을 주는 고유벡터들이 나온다. 정규화된 두 주방향:

  • ê^ξ_lon: 종방향(longitudinal) 단위 고유벡터 — 엣지를 따라 이동하는 방향.
  • ê^ξ_lat: 횡방향(lateral) 단위 고유벡터 — 이동 방향에 직교 하는 방향.

방향별 위험도 (중력 내적)

위험도는 각 주방향 고유벡터와 중력 벡터 g = [0, 0, −1] 의 음의 내적으로 정의된다:

R^ξ_dir = − ê^ξ_dir · g ,     dir ∈ { lon, lat }
  • 직관(기하적 의미): 고유벡터가 수평 이면(평지) ê·g ≈ 0 → 위험도 ≈ 0. 고유벡터가 기울어질수록 중력 성분이 커져 위험도가 커진다. 즉 R_dir는 해당 방향의 경사 가파름을 직접 정량화한다.
  • "기운 경로일수록 로봇이 넘어질 가능성이 크다"는 물리 직관을 내적 한 번으로 인코딩.

결합 엣지 가중치

w_ij = γ · R^ξ_lon + (1 − γ) · R^ξ_lat ,     γ ∈ [0, 1]
  • γ = 0.2 (논문 Table 1): 종방향에 0.2, 횡방향에 0.8 가중. 이는 "횡방향 경사가 종방향보다 훨씬 위험하다"는 사족보행 로봇의 물리적 현실을 반영한다. 로봇이 경사를 정면으로 오를 땐 안정적이지만, 옆으로 가로지르면 전복 위험이 크기 때문이다.
  • 이 비대칭이 바로 C2의 해법이다: 동일 지형이라도 진입 방향(엣지 방향)에 따라 R_lon/R_lat 비율이 달라져 방향 의존적 위험도 가 나온다.

엣지 유효 조건

엣지가 그래프에 추가되려면 세 조건을 모두 만족해야 한다:

  1. 엣지 영역 내 elevation 포인트 ≥ 3개 (PCA 평면 정의 최소 조건),
  2. 모든 높이 편차 < h_max,
  3. 경사각 제약:
tan⁻¹( | p_i(z) − p_j(z) | / ‖ p_i(x,y) − p_j(x,y) ‖ )  <  tan⁻¹( h_max / r_robot )

즉 두 노드를 잇는 직선의 경사가, 로봇이 극복 가능한 한계 경사(h_max를 내접원 반경 r_robot에 걸쳐 올라가는 각도) 미만일 때만 엣지가 유효하다.

3.3 Wavefront Propagation — "갈 수 있는 영역만" 점진 구성

전역 그리드를 다 채우는 대신, TRG는 파면(wavefront)이 퍼지듯 로봇 현재 위치에서 바깥으로 노드를 점진 샘플링한다. 이것이 C1(해상도-연산량 폭증)의 해법이다.

ASCII: Wavefront 전파
   기준노드 v_ref 중심, 반경 r_exp 원 위에 균일 샘플
        v_ref ──● ──● ──●   (반경 r_exp = 0.6m)
              ●        ●
              ● ──● ──●
   각 샘플 처리:
     ┌─ stability/traversability 실패 → 폐기(discard)
     ├─ 기존 노드와 r_robot 이내 → 병합(merge)
     └─ 통과 → 그래프·확장큐에 추가(add) + r_exp 내 엣지 연결
   확장큐의 프론티어 노드를 새 v_ref로 → 큐가 빌 때까지 반복

각 샘플 노드에 대해 세 가지 결과가 발생한다:

  1. 폐기(Discard): 안정성/횡단성 검사 실패 시.
  2. 병합(Merge): 기존 노드의 r_robot 반경 내면 중복으로 보고 병합(노드 밀도 제어).
  3. 추가(Add): 통과 시 그래프와 확장 큐에 추가하고, r_exp 내 인접 노드들과 엣지를 연결.

이 과정은 프론티어 노드를 새 기준점 v_ref로 삼아 큐가 빌 때까지 반복된다. 결과적으로 로봇이 실제로 도달 가능한 영역만 그래프에 포함 되어, 전역 그리드 대비 노드 수가 극적으로 줄고 ms 단위 계획이 가능해진다(Table 3의 ~1000배 속도 우위의 근원).

3.4 계층적 관리 (Hierarchical Local-Global Management)

대규모 환경에서 매 갱신마다 전역 그래프를 재구성하면 비용이 감당 불가다(C4). TRG는 로컬 갱신 → 전역 통합 의 계층 구조로 이를 해결한다.

로컬 그래프 추출과 프론티어 식별

로봇 위치 주변에서 전역 그래프 G의 부분집합 V_l(로컬 노드)을 추출한다. 그중 프론티어 노드(아직 탐색 안 된 경계) 를 식별:

V_f = ⋃_{v_i ∈ V_l} { v_i  |  s_i = valid  ∧  u_i ∉ Q_G }

여기서  u_i = p_i + 2·r_robot · (p_i − p_cur) / ‖ p_i − p_cur ‖
  • u_i: 노드 i에서 로봇 반대 방향으로 2·r_robot 만큼 뻗은 확장점.
  • Q_G: 이미 탐색된 전역 영역(점유 셀 집합).
  • 직관: 확장점 u_i가 아직 탐색되지 않은 영역(∉ Q_G)에 떨어지면, 그 노드는 탐색 경계 = 프론티어 → 추가 확장 필요.

전역 통합

로컬에서 갱신된 노드·엣지를 전역 그래프에 병합:

V ← V ∪ V_l
E ← E ∪ { e_ij | v_i, v_j ∈ V_l }

이로써 로봇이 이동하며 새로 관측한 지형만 점진적으로 전역 그래프에 누적되어, 재구성 없이 증분(incremental) 확장 이 이뤄진다. 경로가 무효화되면(예: 이전에 valid였던 엣지가 새 관측으로 invalid가 됨) 재계획이 트리거된다.

3.5 Risk-Aware A* — 안전 계수 Γ로 트레이드오프 제어

구성된 TRG 위에서 위험 인지 비용함수를 가진 수정 A* 로 경로를 탐색한다. 누적 비용과 평가함수:

C(v_{i+1}) = C(v_i) + d_{i+1,i} · ( Γ · w_{i+1,i} + 1 )
J(v_{i+1}) = C(v_{i+1}) + ‖ p_{i+1} − p_goal ‖
  • C(v): 시작부터 누적된 g-cost.
  • d_{i+1,i}: 노드 간 거리.
  • w_{i+1,i}: 엣지 횡단 위험도(3.2).
  • Γ (safety factor, ≥0): 안전과 거리 효율의 트레이드오프를 조절하는 단일 파라미터 (C5 해법).
  • ‖p_{i+1} − p_goal‖: 목표까지 유클리드 거리 휴리스틱.

Γ·w + 1 항의 의미: 위험도가 0이면 비용 = 거리(d·1)로 순수 최단경로. Γ가 클수록 위험한 엣지(w 큼)의 비용이 부풀려져 우회를 유도한다.

Γ = 1.0  (Optimistic, 낙관)   → 위험을 거의 무시, 최단 경로 선호, 낮은 주행 안전
Γ = 3.0  (Balanced,  균형)    → 안전과 거리의 최적 균형 (논문 권장값)
Γ = 10.0 (Conservative, 보수) → 안전 최우선, 과도한 우회 감수

A* admissibility 고찰

휴리스틱이 유클리드 거리이고 모든 엣지 비용이 d·(Γw+1) ≥ d ≥ 직선거리 이므로, 휴리스틱은 admissible(과대평가하지 않음) → 최적성 보장. 단, Γ가 커지면 실제 비용과 휴리스틱의 격차(heuristic gap)가 벌어져 탐색 노드가 늘어나는 효율 저하가 있다(보수적일수록 탐색이 무거워짐).

목표 도달 불가 시 sub-goal

목표가 현재 그래프로 도달 불가하면, 목표에 가장 가까운 프론티어 노드를 sub-goal로 설정 하여 그쪽으로 먼저 이동하면서 그래프를 확장한다. 이 메커니즘이 미탐색 환경에서의 점진 탐사를 가능케 한다.

3.6 PCA 위험도 모델의 작동 원리 (심화)

TRG가 스칼라 traversability를 이기는 근본 이유는 PCA가 엣지 영역의 기하를 방향 분해 하기 때문이다. 엣지 띠 안의 elevation 포인트 집합 {(x_k, y_k, z_k)}의 3×3 공분산 행렬을 고유분해하면, 가장 큰 고유값의 고유벡터가 그 영역에서 점들이 가장 많이 퍼진 방향(=지배적 경사 방향)을 준다. 이를 이동 좌표계(엣지 방향)에 투영해 ê_lon, ê_lat을 얻는다.

여기서 R_dir = −ê_dir · g 는 단순하지만 강력하다. 고유벡터가 수평이면 중력(연직)과 직교해 내적 0(평지, 무위험), 연직에 가까울수록 내적이 커져(가파른 경사) 위험 증가. 즉 방향별 경사를 중력과의 정렬도로 환산 한다.

이 모델의 미묘함:

  • 장점: 계산이 가볍고(공분산 + 고유분해), 방향 분해가 자연스럽다. 스칼라 셀 비용이 못 잡는 진입 방향 의존성을 잡아낸다.
  • 한계(8장에서 상술): PCA는 영역 분산을 단일 평면 으로 근사하므로, 비볼록 지형(V자 도랑, 돌출 바위)이나 bimodal 높이 분포에서는 평면 근사가 실제 위험을 과소/과대평가할 수 있다. 또한 설명된 분산비(explained variance ratio)가 낮을 때(평면 근사가 나쁠 때)에 대한 신뢰도 가중이 없다.

4. 시스템 아키텍처 (System Architecture)

전체 파이프라인은 지각(perception) → TRG 구성 → 계획 → 추종 의 4단으로 흐른다:

[센서: LiDAR + 포즈추정]
        │
        ▼
[Elevation Map 구축]  ρ_map = 0.05m 해상도 2.5D 높이맵
        │
        ▼
┌──────────────────────────────────────────────────┐
│ TRG 구성 (3.1~3.4)                                 │
│  (1) wavefront 노드 샘플링 (r_exp=0.6m 원)        │
│  (2) stability g(c) ∧ reachability r(E) 평가      │
│  (3) PCA 타원평면 → R_lon, R_lat → w_ij           │
│  (4) 계층 관리: 로컬 V_l 갱신 → 전역 G 통합       │
└──────────────────────────────────────────────────┘
        │   (경로 무효화 감지 시 재계획 트리거)
        ▼
┌──────────────────────────────────────────────────┐
│ Risk-Aware A* (3.5)                                │
│  C(v) = C + d·(Γ·w + 1),  J = C + ‖p − p_goal‖    │
│  도달불가 시 → 최근접 프론티어 sub-goal           │
└──────────────────────────────────────────────────┘
        │
        ▼
[Pure Pursuit 경로 추종]  →  Unitree Go1 (DreamWaQ 보행제어)
        │
        ▼
[로봇 이동] → 새 관측 → Elevation Map 갱신 (루프)

데이터 흐름의 핵심: 시스템은 2Hz로 동작하며(Intel Core i7-11700K), 로봇이 이동할 때마다 (i) elevation map이 갱신되고, (ii) 로컬 TRG가 재평가되어 전역 그래프에 통합되며, (iii) 경로가 무효화되면 risk-aware A*가 재실행된다. wavefront + 계층 관리 덕에 이 전체 루프가 ms 단위로 끝나, 대규모 산악 환경에서도 실시간 재계획이 유지된다.

모듈 책임 분리: 지형 표현(TRG)과 탐색(A*)이 깔끔히 분리되어 있다. TRG는 "어디가 안전하고 닿을 수 있는가"를 그래프로 제공하고, A*는 그 위에서 Γ로 조절되는 비용 최소 경로를 찾는다. 이 분리 덕에 동일 TRG 위에서 Γ만 바꿔 낙관/균형/보수 전략을 즉시 전환할 수 있다.

5.4 리얼월드 실험 (Real-world Experiments)

(1) 산악 환경 (83m × 151m × 38.3m):

  • 경사·계단·좁은 통로가 섞인 복합 비정형 지형에서 245m 장거리 경로를 성공적으로 계획·주행.
  • 로봇이 자율적으로 험한 경사 지형을 통과. 대규모 환경에서 계층적 관리 + wavefront 구성의 실시간성이 실증된 핵심 결과.

(2) 둔덕(Mound) 실험 (15°/25°/35° 방향성 경사):

  • 둔덕은 면마다 경사가 다르다(가장 완만 15°, 가장 가파른 35°).
  • TRG-planner가 가장 완만한 15° 면을 자동 식별하여 등반 경로로 선택 하고, 가파른 25°/35° 면은 회피. 로봇이 자율적으로 둔덕을 오르내림.
  • 이것이 방향성 위험도(3.2)의 직접 증거 — 같은 둔덕이라도 어느 방향으로 진입하는가 에 따라 R_lat이 달라지고, A*가 저위험 방향을 선택. 스칼라 traversability로는 불가능한 거동.

(3) ICRA 2023 QRC 우승 (실전 대회 검증):

  • TRG-planner가 DreamSTEP 팀 자율 내비게이션 프레임워크의 전역 경로 계획기 로 채택.
  • 램프·연질 바닥·파이프 계단·K-rail·상자 모사 지형 등 5개 구간(최대 15° 경사 교차로 포함)을 통과.
  • ICRA 2023 Quadruped Robot Challenge 우승. 통제된 실험을 넘어 경쟁적 실전 대회 에서 전역 플래너로 검증된 점이 본 연구의 실용성을 가장 강하게 뒷받침한다.

6. 핵심 기여점 (Key Contributions)

  1. 방향성 횡단 위험 그래프(TRG) 표현. PCA 타원 평면 + 중력 내적으로 엣지 위험을 종/횡방향(R_lon, R_lat)으로 분해하고 w_ij = γR_lon + (1−γ)R_lat로 결합(γ=0.2). 같은 지형이라도 진입 방향에 따라 비대칭 위험 을 부여 — 스칼라 traversability 맵이 못 잡는 방향 의존성을 그래프 엣지에 직접 인코딩한다.

  2. stability ∧ reachability 이중 노드 게이팅. 안정성(g(c))과 도달 가능성(r(E))을 동시 만족할 때만 노드 valid. "안전하게 설 수 있고 + 실제로 닿을 수 있는" 지점만 경로 후보가 되어, 고립 영역을 자연히 배제.

  3. Wavefront 기반 희소 그래프 구성 + 계층적 관리. 전역 그리드 대신 파면 전파로 "갈 수 있는 영역만" 점진 구성하고, 로컬 갱신→전역 통합으로 대규모 환경에서 ms 단위 실시간 계획(초기화 4.01s, 탐색 0.43~3.00ms).

  4. 단일 안전 계수 Γ에 의한 트레이드오프 제어. C = C + d·(Γw+1) 의 Γ 하나로 낙관(1)/균형(3)/보수(10) 전략을 즉시 전환. 동일 그래프 위에서 응용별 안전성을 직관적으로 조절.

  5. 사족보행 실로봇 + 실전 대회 검증. Unitree Go1로 245m 산악 주행, 둔덕 안전 진입 방향 자동 선택, 그리고 ICRA 2023 QRC 우승 팀의 전역 플래너 로 실증.

추가 의의

  • RA-L 2025 게재(탑티어) + 실전 대회 우승이라는 학술·실전 양면 검증 을 동시 충족. 다만 코드 미공개(1.1 참조)로 재현성 측면에서는 코퍼스 내 코드 공개 논문(예: BOWConnect, NeuPAN) 대비 한 칸 낮다.

7.2 구현상의 미묘함

  • γ=0.2의 물리적 근거: 횡방향(전복) 위험이 종방향(슬립)보다 사족보행 로봇에 더 치명적이라는 가정. 이는 단단한 지형에서는 타당하나, 모래/자갈에서는 종방향 슬립이 지배적일 수 있어 지형별 적응 γ 가 물리적으로 더 정확할 여지가 있다(8.2 한계).
  • wavefront r_exp=0.6m vs r_robot=0.3m: 확장 반경이 로봇 반경의 2배 → 노드 간격이 로봇 크기보다 커 그래프가 희소해지고(빠름), 병합 반경 r_robot=0.3m로 중복을 억제. 이 두 반경의 비율이 그래프 밀도-속도 트레이드오프를 결정.
  • 계산 주파수 2Hz: 0.5s 주기 재계획. 탐색 자체는 ms급이므로, 주기 대부분은 elevation map 갱신·로컬 TRG 재평가에 쓰인다.
  • Pure Pursuit 추종: 계획된 전역 경로를 단순 기하 추종기로 따라간다. 전역 안전성은 TRG가, 국소 추종은 Pure Pursuit가 담당하는 책임 분리.

7.3 실배치 엔지니어링 고려

  • elevation map 의존성: 성능이 입력 2.5D 높이맵 품질에 크게 의존. LiDAR 노이즈·동적 객체·초목(tall grass) 등은 높이맵을 오염시켜 위험도 오판을 유발할 수 있다.
  • 2.5D 표현의 한계: 동굴·다층 구조(오버행, 터널) 같은 진정한 3D 환경은 단일 높이맵으로 표현 불가 — 평면 위 지형에 국한.
  • DreamWaQ 보행제어 결합: TRG는 전역 경로 만 제공하고, 실제 발 디딤·균형은 별도 보행 제어기(DreamWaQ)가 담당. 즉 TRG의 "안전 경로"는 보행기가 따라갈 수 있다는 전제 하에 유효.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

TRG의 확장성은 wavefront 희소성 + 계층적 증분 갱신 에서 나온다. 전역 그리드 A*가 환경 면적에 비례(또는 제곱)해 비용이 증가하는 반면, TRG는 "갈 수 있는 영역의 노드 수"에만 비례한다. 83m×151m 산악 환경에서도 ms 단위 탐색이 유지된 것이 그 증거다. 다만:

  • 그래프 초기화 4.01s는 첫 진입 시 일회성 비용이며, 이후 계층적 증분 갱신으로 상환(amortize)된다. 그러나 환경이 극단적으로 커지면(수 km²) 초기화·메모리가 선형 증가하므로 전역 그래프를 무한정 보유하는 것은 한계가 있다 — 슬라이딩 윈도우/계층 LOD 같은 추가 기법이 필요할 수 있다.
  • GPU 미활용: 현재 CPU 단일 구현. wavefront 노드 평가·PCA는 병렬화 여지가 크나 본 논문은 탐구하지 않았다.

8.2 한계점 (Limitations) — 구체적 실패 시나리오 동반

  • (L1) PCA 평면 근사의 정보 손실. 엣지 영역을 단일 타원 평면 으로 근사하므로, 비볼록 지형(V자 도랑, 돌출 바위), bimodal 높이 분포에서는 평면이 실제 기하를 못 담아 위험을 과소/과대평가한다. 예: 좁은 도랑을 가로지르는 엣지에서 PCA가 양 둑의 평균 경사를 잡으면, 도랑 바닥의 실제 위험이 희석될 수 있다. 설명된 분산비(평면 근사 신뢰도)가 위험도에 반영되지 않는다.
  • (L2) 기하적 위험 ≠ 물리적 안정성. R_dir = −ê·g는 경사 가파름 만 본다. 실제 전복/슬립은 ZMP(Zero-Moment Point), Coulomb 마찰계수, 무게중심 높이에 의존하는데 이는 미반영. 같은 15° 경사라도 빙판(저마찰)과 바위(고마찰)의 실제 위험은 다른데 TRG는 동일 R을 준다.
  • (L3) 정적 환경 가정. 동적 장애물(이동 인간/차량)은 미고려. 현재는 정적 elevation map 기반이라 움직이는 객체는 표현·회피 불가.
  • (L4) 파라미터 수동 튜닝. γ, Γ, h_max, r_exp 등이 수동 설정. 특히 γ=0.2(횡방향 80%)는 단단한 지형 가정이라, 모래/자갈처럼 종방향 슬립이 지배적인 지형에선 부정확. 지형별 적응 γ가 필요.
  • (L5) 2.5D 표현 한계. 단일 높이맵이라 오버행·터널·다층 구조 표현 불가 — 평면 위 지형에 국한.
  • (L6) 주행 성공률 80%의 실패 분석 부재. S_trav 79.883.8%는 5분의 1이 실패 한다는 뜻인데, 어떤 지형/방향에서 실패했는지 체계적 failure-mode 분석이 없다. 서비스/구조 로봇이 요구하는 99%+ 신뢰도와는 격차.

8.3 향후 방향

  • 학습 기반 traversability 통합: WayFAST/BADGR류의 외관 기반 학습 비용을 TRG 위험 모델에 융합하면, 기하만으로 못 잡는 재질(빙판 vs 풀)을 반영 가능.
  • 물리 모델 결합: ZMP·마찰을 R에 통합해 기하적 위험을 물리적 안정성으로 격상.
  • 적응적 γ/Γ: 지형 분류에 따라 종/횡 가중과 안전 계수를 자동 조절.
  • 동적 환경 확장: 이동 객체 예측 + 재계획 루프 통합.
  • GPU 병렬 + 3D 표현: wavefront 노드 평가 병렬화, 다층 구조용 3D TRG.

8.5 재현성 평가

  • 코드 ❌ 미공개(1.1에서 검증): 프로젝트 페이지·url-kaist 조직 어디에도 TRG-planner 소스 저장소가 없다(저자 프로필 링크만 존재). 따라서 정확 재현은 어렵고, 본 리뷰의 분석은 논문 본문 수식·실험표에 근거한다.
  • 개념 재현성은 양호: 노드 게이팅·PCA 위험·wavefront·risk-aware A*가 명확히 기술되어 원리 재구현 은 가능하나, 파라미터 일부(엣지 영역 띠 폭, PCA 분산비 처리 등)와 elevation mapping 파이프라인 세부는 본문만으로 정확 복제하기 어렵다.
  • 데이터 재현성: 시뮬 산악맵·실세계 환경이 비공개라 동일 벤치마크 재현 불가.

8.6 비교 누락 — D* Lite / Field D* / 학습 traversability

논문 비교군(A*, PRM*, T-Hybrid)은 합리적이나, incremental replanning 계열(D* Lite, Field D*) 과의 비교가 빠졌다. 이들은 환경 변화 시 부분 재계획 으로 유사 속도를 낼 수 있어, TRG의 계층적 증분 갱신과 직접 경쟁 관계다. 또한 학습 기반 traversability(WayFAST, ViKiNG) 와의 비교도 없어, 기하 위험 모델의 상대적 강약(외관 정보 부재)이 정량적으로 드러나지 않는다. 이 두 축의 비교가 추가되면 TRG의 위치가 더 선명해질 것이다.

8.7 이론적 위치짓기

TRG-planner는 "지형 표현(terrain representation)과 그래프 탐색을 통합한 traversability-aware 전역 플래너" 계열에 속한다. 전통적으로 traversability 분석(셀별 비용)과 경로 탐색(A*/RRT)은 분리된 단계였다. TRG의 기여는 이 둘을 방향성 그래프 라는 단일 구조로 융합한 것 — 노드가 stability/reachability를, 엣지가 방향성 위험을 담아, 탐색기가 곧바로 "안전 경로"를 찾게 한다. 이는 cost-map 위 탐색(분리형)과 샘플링 그래프(위험 표현력 부족)의 중간 지점을 차지 하는 하이브리드다.

9.2 장단점 분석

TRG-planner의 강점:

  1. 방향성 위험 인코딩의 독창성 — SCAN-Planner도 사족보행 험지 주행이지만 충돌 회피(지면추종) 에 집중하는 로컬 플래너로, "어느 방향으로 경사를 진입해야 안전한가"를 전역 경로 수준 에서 결정하지 못한다. TRG는 PCA 방향위험으로 둔덕 실험처럼 전역적으로 안전 진입 방향 을 선택한다 — 이는 스칼라 비용 기반 플래너(FPAS 포함)가 못 하는 거동.
  2. 실전 대회 검증 — FPAS는 시뮬만, HEIGHT는 학습+시뮬 위주인데, TRG는 ICRA 2023 QRC 우승 이라는 경쟁 실전 검증을 보유. 통제 실험을 넘어선 강한 실용성 증거.
  3. 단일 Γ 트레이드오프 — FPAS의 거리/시간 지표나 SCAN의 스플라인 최적화보다, 하나의 해석 가능한 파라미터로 안전성을 조절하는 인터페이스가 현장 적용에 직관적.
  4. wavefront 희소성 — FPAS의 개방도 적응과 철학은 유사하나(필요한 곳만 촘촘), TRG는 지형 위험 을 직접 기준으로 삼아 험지 특화.

TRG-planner의 약점:

  1. 기하 위험의 물리적 충실도 부족 — SCAN-Planner의 풋프린트 2점 충돌질의는 실제 기하 충돌 을 직접 보는 반면, TRG의 R=−ê·g는 경사 가파름만 본다(마찰·ZMP 미반영, 8.2 L2). 저마찰 경사에서 TRG가 안전하다고 판단한 경로가 실제로는 미끄러질 수 있다.
  2. 2.5D 한계 — SCAN-Planner는 명시적으로 3D 다층(계단·터널) 을 다루지만, TRG는 단일 높이맵이라 오버행/다층 표현 불가(8.2 L5). 동굴 같은 진짜 3D 비정형은 SCAN이 유리.
  3. 코드 미공개 — SCAN(예정)·TRG(미공개) 모두 즉시 재현 불가지만, 코퍼스의 코드 공개 논문(BOWConnect, NeuPAN) 대비 재현성에서 뒤진다. RA-L 게재에도 불구하고 소스가 없는 점은 아쉽다.
  4. ~80% 주행 성공률 — HEIGHT/FPAS의 평지·군중 시나리오 대비 험지라 절대 비교는 어렵지만, 서비스 로봇 신뢰도(99%+)와는 거리. 실패 모드 분석 부재(8.2 L6)와 결합돼 신뢰성 입증이 약하다.

9.3 실적용 가능성 평가

  • TRG-planner: 사족보행 로봇의 옥외 험지(산악·재난·정찰) 전역 계획에 강력. 단일 Γ로 임무별 안전성을 조절하고, 실전 대회 검증까지 있어 연구-필드 전이가 즉시 가능 한 후보다. 단 (i) 코드 미공개로 재구현 비용이 들고, (ii) 저마찰·동적·다층 환경은 보완 필요. 실내 평탄/서비스 로봇에는 과한 도구(평지에선 단순 cost-map A*로 충분).
  • SCAN-Planner: 국소 지면추종·다층 횡단에 강점. TRG의 전역 안전 경로 위에 SCAN을 로컬 추종기로 얹는 전역(TRG)+로컬(SCAN) 결합 이 자연스럽다.
  • FPAS: 대규모 미지 환경 탐사(광역 매핑)에 강하나, 험지 위험 모델·실로봇은 비대상.
  • HEIGHT: 동적 군중 회피에 특화(직교 문제). TRG와는 적용 영역이 거의 겹치지 않는다(정적 험지 vs 동적 군중).

9.4 연구 방향성 평가

TRG-planner는 모션 플래닝의 무게중심을 "스칼라 traversability cost-map → 방향성 위험 그래프" 로 옮긴다. 이는 FPAS(샘플 밀도 측 적응)·SCAN(로컬 충돌 측 정밀화)과 직교 하는 축이다. 따라서 결합이 자연스럽다:

  • TRG ⊕ SCAN: TRG가 전역 안전 경로(방향위험 최소)를, SCAN이 로컬 지면추종 충돌회피를 담당하는 2계층. TRG의 ~80% 주행 성공률 중 일부 실패는 로컬 추종 한계일 수 있어, 정밀 로컬 플래너 결합이 보완책.
  • TRG ⊕ 학습 traversability: PCA 기하 위험에 외관 학습 비용(빙판/풀 구분)을 더해 8.2 L2를 메움.
  • TRG ⊕ FPAS 개방도: wavefront 노드 밀도를 위험 뿐 아니라 개방도 로도 조절해 평지-험지 혼합 환경에서 효율 향상.

9.5 일반화 가능성

TRG의 "PCA 방향분해 + 중력 내적 방향위험"은 사족보행에 국한되지 않는다. 방향 의존적 안정성을 갖는 모든 지상 플랫폼(험지 차륜 로버, 추적식 UGV, 행성 탐사 로버)에 이식 가능하다. 핵심 레시피 — "엣지 영역을 PCA로 방향 분해하고, 진입 방향별 위험을 그래프 가중에 직접 싣는다" — 는 traversability-aware 전역 계획의 일반 패턴으로 재사용될 수 있다. 다만 플랫폼별로 종/횡 위험 비대칭(γ)과 한계 경사(h_max)는 재보정이 필요하다.

11. 결론 (Conclusion)

혁신성

TRG-planner의 핵심 혁신은 지형 횡단성을 "방향성 위험 그래프(TRG)"라는 단일 구조로 통합 한 것이다. 노드는 stability(g(c))와 reachability(r(E))의 논리곱으로, 엣지는 PCA 타원 평면의 종/횡 고유벡터와 중력 내적(R=−ê·g)으로 방향별 위험을 인코딩하고, w_ij=γR_lon+(1−γ)R_lat(γ=0.2)로 결합한다. 여기에 wavefront 희소 구성과 계층적 증분 갱신을 결합해 대규모 비정형 환경에서 ms 단위 실시간 계획을 달성하며, risk-aware A*의 단일 안전 계수 Γ로 안전-효율 트레이드오프를 직관적으로 제어한다. "같은 지형이라도 진입 방향에 따라 위험이 다르다" 는 물리 직관을 그래프 엣지에 직접 실은 것이 본질적 기여다.

실용적 의의

시뮬레이션에서 Balanced(Γ=3.0)가 주행 성공률·경로 편차 모두 최적을 보였고(Long 시나리오 S_trav 79.8%, T 0.048), 계획 시간은 풀 그리드 A* 대비 1000배 빠르다(0.433.00ms, 탐색 공간 축소 효과). 무엇보다 Unitree Go1로 245m 산악 주행, 둔덕 안전 진입 방향 자동 선택, 그리고 ICRA 2023 QRC 우승 팀의 전역 플래너 라는 실전 검증을 보유해, 사족보행 옥외 험지 내비게이션에 즉시 투입 가능한 강한 후보다.

향후 연구 방향

한계는 (i) PCA 단일 평면 근사의 비볼록 지형 정보 손실(L1), (ii) 기하 위험과 실제 물리 안정성(마찰·ZMP)의 괴리(L2), (iii) 정적·2.5D 표현 한계(L3·L5), (iv) 고정 γ의 지형 비적응성(L4), (v) ~80% 주행 성공률의 실패 모드 분석 부재(L6)에 있다. 따라서 학습 기반 traversability 융합(외관 정보로 마찰·재질 반영), 물리 모델 결합(ZMP·마찰을 R에 통합), 적응적 γ/Γ, 3D TRG·GPU 병렬화, 동적 환경 확장 이 자연스러운 다음 단계다. 코퍼스 관점에서는 SCAN-Planner(로컬 지면추종)를 로컬 추종기로 결합한 전역(TRG)+로컬(SCAN) 2계층 이 ~80% 성공률을 끌어올릴 유망한 경로다.

종합 평가

TRG-planner는 비정형 지형 전역 계획의 오랜 난제 — "스칼라 traversability cost-map은 진입 방향 의존 위험을 표현하지 못한다" — 를, PCA 방향분해 + 중력 내적 이라는 가볍고 명료한 모델로 정면 돌파한다. 둔덕 실험에서 전역적으로 안전한 진입 방향을 자동 선택 한 거동은 이 방향성 위험 모델의 가치를 가장 선명히 보여준다. 평가 측면에서도 시뮬레이션 정량 비교(Table 2~4)에 그치지 않고 사족보행 실로봇 + 경쟁 실전 대회(ICRA QRC) 우승 이라는 이중 검증을 충족해, RA-L 2025 탑티어 게재에 걸맞은 완성도를 갖췄다. 다만 (i) 코드 미공개로 재현성이 코퍼스의 오픈소스 논문 대비 낮고, (ii) 위험 모델이 기하에 머물러 저마찰·동적·다층 환경에서의 물리적 충실도가 입증되지 않았으며, (iii) ~80% 주행 성공률의 실패 분석이 빠진 점은 후속 연구가 메워야 할 빈칸이다. 그럼에도 "방향성 위험을 그래프 엣지에 직접 싣는다"는 명료한 레시피와 실전 우승 검증은, 본 논문을 사족보행 험지 내비게이션 흐름에서 주목할 가치가 높은 결과로 만든다.
