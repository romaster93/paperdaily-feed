1.2 연구 목표 (Research Objective)

이 논문은 부족구동(underactuated) 비선형 시스템(제어 입력 차원 nu가 상태 차원 nx보다 작은 시스템 — 카트폴, 애크로봇, 두빈스 차량 등)에 대한 빠르고 안전한 모션 플래닝을 목표로 한다. 핵심 착안은 다음 한 문장으로 요약된다:

"부족구동 시스템의 동역학적으로 실현 가능한 운동들은 함수공간(function space) 상의 궤적 다양체(manifold of trajectories) 위에 놓여 있어, 볼록(convex) 모션 플래닝을 직접 적용하기 어렵다."

전통적 방법론은 두 갈래로 나뉜다. (1) 유한차원 궤적 매개화(다항식·B-스플라인 계수) — 매개화가 동역학 실현가능성을 보장하지 못해, 실제로 추종 불가능한 궤적을 생성하거나 강한 제약을 걸어야 한다. (2) 예측 지평(prediction horizon)을 늘리는 방식(kinodynamic RRT, MPPI, NLP) — 지평이 길어질수록 계산비용이 급증하며, 특히 다중로봇/군집 시나리오에서 폭발한다.

본 논문은 명목 궤적(nominal trajectory) 주변에서 국소 유한차원 "행동 좌표(action coordinates)" 를 구성하여, 그 좌표계 안에서 충돌·제어 제약이 선형(linear) 이 되도록 만들고, 동역학 위반을 정량화하는 신뢰영역(trust region) 안에서 IRIS-류 팽창으로 볼록 내부근사(convex inner approximation) 를 뽑아낸다. 이 볼록 집합이 곧 신뢰 다면체 행동집합(trusted Polytopic Action Set, PAS) 이며, 여러 PAS를 선형계획(LP) 으로 합성(compose)하여 다중 세그먼트 계획을 수행한다. 저자들은 이 방식이 kinodynamic RRT 대비 14–78배 빠르고, 샘플링/NLP 베이스라인 대비 종단 오차를 26–86% 낮춘다고 보고한다.

한 마디로: "단일 상태(state)를 노드로 하는 트리"가 아니라 "합성된 도달가능 집합(reachable set)을 노드로 하는 트리" 를 성장시키는 것이 이 논문의 정체성이다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

부족구동 비선형 시스템의 모션 플래닝은 다음의 근본적 난점을 안고 있다.

  1. 동역학 실현가능성과 볼록성의 충돌: ẋ = f(x,u) 가 비선형이면, 실현가능한 궤적들의 집합은 일반적으로 비볼록(nonconvex)이다. 볼록 최적화(LP/QP)의 속도 이점을 얻으려면 이 비볼록 집합을 어떻게든 볼록화해야 하는데, 순진한 선형화는 원래 동역학에서 멀어질수록 오차가 커진다.

  2. 유한차원 매개화의 한계: 다항식/스플라인 계수로 궤적을 매개화하면 최적화 변수는 유한하지만, 그 계수 조합이 실제 동역학을 만족한다는 보장이 없다. 부족구동에서는 "원하는 상태 궤적"을 임의로 그릴 수 없다(예: 카트폴은 진자를 직접 밀 수 없고 카트를 통해 간접 구동).

  3. 지평 확장의 계산 폭발: kinodynamic RRT는 상태공간을 단일 점 단위로 탐색하며, 매 확장마다 짧은 시뮬레이션 롤아웃과 충돌검사를 반복한다. 좁은 통로·버그트랩(U자 장애물)에서 확장 횟수가 급증하고, 다중로봇에서는 조합 폭발이 일어난다.

  4. 질의(query) 능력의 부재: NLP 기반 궤적최적화는 단 하나의 궤적점만 반환한다. "이 계획 세그먼트가 목표를 포함하는가?", "목표에 가장 가까운 도달점은?" 같은 질의를 값싸게 반복할 수 없다. 반면 도달가능 집합을 명시적으로 들고 있으면 이런 질의가 LP 한 번으로 끝난다.

2.2 핵심 해결책

본 논문의 해결책은 3단 파이프라인으로 구성된다.

[1] 명목 궤적 주변 국소 선형화 → 아핀 궤적 사상(affine trajectory map)
       x(t;γ) = x*(t) + R(t)γ,  u(t;γ) = u*(t) + U(t)γ
       → 충돌·제어 제약이 γ에 대해 선형
[2] 동역학 위반 척도 ζ(γ)로 신뢰영역 정의 + IRIS-류 팽창으로 볼록 내부근사
       Ω_trust = A_lin ∩ R_trust(ζ_max)   ← 이것이 PAS
[3] 여러 PAS를 연속성 제약(선형)으로 합성 → PAS-RRT 트리
       노드 = 합성된 도달가능 집합, 확장 = LP 투영 + 새 PAS 부착

핵심은 "동역학을 선형화하되, 선형화가 믿을 만한 영역만 볼록집합으로 인증" 한다는 점이다. 신뢰영역 밖으로 나가면 선형 모델이 실제 동역학과 벌어지므로, 위반 척도 ζ(γ)가 그 경계를 정의하고 IRIS-ZO(zeroth-order) 팽창이 ζ ≤ ζ_max를 만족하는 볼록 내부근사를 잘라낸다.

3. 핵심 방법론 (Core Methods)

3.1 아핀 궤적 사상 (Affine Trajectory Map)

출발점은 부족구동 연속시간 비선형 시스템이다.

ẋ(t) = f(x(t), u(t)),   nx > nu   (부족구동)

명목 궤적 (x*(t), u*(t)) 주변에서 1차 선형화하여 선형 시변(LTV) 시스템을 얻는다.

δẋ(t) = A(t) δx(t) + B(t) δu(t)
   A(t) = ∂f/∂x |(x*,u*),   B(t) = ∂f/∂u |(x*,u*)

상태편차를 상태천이행렬 Φ(t,s)로 적분하면:

δx(t) = Φ(t,0) δx₀ + ∫₀ᵗ Φ(t,s) B(s) δu(s) ds

여기서 결정적 단계 — 제어 편차를 정적 계수벡터로 매개화한다. L(t)를 기저행렬(예: M개 노트를 가진 조각별 선형 PWL), η ∈ ℝ^{nη}를 정적 계수로 두면:

δu(t) = L(t) η

이를 대입하면 상태편차가 입력-상태 사상 K(t)를 통해 정적 매개변수의 선형 함수가 된다.

δx(t) = Φ(t,0) δx₀ + K(t) η
   K(t) := ∫₀ᵗ Φ(t,s) B(s) L(s) ds     (input-to-state map)

복합 매개변수 γ와 기저행렬을 정의한다.

γ := [δx₀ ; η] ∈ ℝ^{nγ},   nγ = nx + nη
R(t) := [ Φ(t,0) | K(t) ]     (상태 기저)
U(t) := [   0    | L(t) ]     (제어 기저)

그러면 아핀 궤적 사상 (식 1) 이 완성된다.

─────────────────────────────────────────
  x(t; γ) = x*(t) + R(t) γ      ← 상태 궤적
  u(t; γ) = u*(t) + U(t) γ      ← 제어 궤적
─────────────────────────────────────────

핵심 성질: γ = 0이면 명목 궤적을 정확히 복원한다. 그리고 상태·제어가 γ에 아핀(affine) 이므로, 종단 제약·충돌회피·제어한계가 전부 γ에 대한 선형 부등식으로 표현된다. 이것이 이후 모든 볼록성의 원천이다.

한 PAS 𝒜(= γ의 다면체)가 주어지면, 시각 t의 도달가능 상태집합은 다면체의 선형상(linear image)으로, 그 자체가 다면체 (식 2) 이다.

𝒳(t) := { x*(t) + R(t) γ | γ ∈ 𝒜 }     ← 다면체

따라서 "목표 포함(goal containment)" 또는 "최근접점(closest-point)" 질의가 γ에 대한 선형 실현가능성/최적화 문제로 환원된다. 이것이 NLP가 못 하는 값싼 반복 질의를 가능케 한다.

3.2 충돌회피의 선형화 (Linear Collision Constraints)

인덱스 k의 샘플된 금지점(forbidden point) p ∈ P_k에 대해, 여유(margin) 0 < ε_{p,k} < ‖p - x*_k‖² 를 두고 다음 분리 초평면(separating hyperplane, 식 9) 을 세운다.

( R_kᵀ (p - x*_k) )ᵀ γ  ≤  ‖p - x*_k‖² - ε_{p,k}

이 부등식은 "상태를 점 p에 놓으려는 임의의 γ"를 위반하게 만든다. 모든 샘플 장애물에 대해 쌓으면:

A_col γ ≤ b_col     (충돌회피, 선형)
A_u   γ ≤ b_u       (제어한계,   선형)

이 둘의 교집합이 선형 행동집합 (식 12) 이다.

𝒜_lin := { γ | A_col γ ≤ b_col,  A_u γ ≤ b_u }

주의할 점: 충돌검사는 이산 시각 k ∈ 𝒦_obs에서만 이뤄지며(샘플 기반, 보수적), 연속시간 안전 인증은 아니다. 저자들도 §한계에서 "더 조밀한 연속시간 안전 인증"을 향후 과제로 명시한다.

3.3 동역학 신뢰영역 (Dynamics Trust Region)

선형화는 명목에서 멀어질수록 실제 동역학과 벌어진다. 이를 정량화하기 위해 1스텝 이산화 결함(defect, 식 13) 을 정의한다.

ζ(γ) := Σ_{k=0}^{N-1} ‖ x_{k+1}(γ) - x_k(γ) - Δt·f(x_k(γ), u_k(γ)) ‖₂²

구성상 ζ(0) = 0(명목 궤적은 결함 0)이고, γ가 커져 선형근사가 벌어질수록 ζ가 증가한다. 사용자 지정 허용치 ζ_max로 신뢰영역 (식 14) 을 정한다.

ℛ_trust(ζ_max) := { γ ∈ ℝ^{nγ} | ζ(γ) ≤ ζ_max }

ζ_max가 작으면 모델 충실도가 높지만 도달범위가 좁고, 크면 도달범위가 넓지만 근사오차가 커진다 — 탐색-충실도 트레이드오프의 명시적 손잡이다.

문제는 ℛ_trust가 일반적으로 비볼록이라는 것. 여기서 IRIS(Iterative Regional Inflation by Semidefinite programming)에서 영감받은 팽창 의 zeroth-order 변형(IRIS-ZO)을 써서, 선형 제약집합 𝒜_lin과 교차시키며 볼록 내부근사를 잘라낸다 (식 15).

─────────────────────────────────────────────
  Ω_trust := 𝒜_lin ∩ ℛ_trust(ζ_max)      ← 이것이 PAS
─────────────────────────────────────────────

IRIS-ZO는 매 라운드 256개 배치 샘플을 행동공간에서 뽑고, 신뢰영역을 위반하는 샘플에 대해 12회 이분탐색(bisection) 으로 경계를 국소화한 뒤 절단 초평면을 추가한다(M_iter 라운드 반복). LTI(이중적분기)처럼 선형화가 정확한 경우 M_iter = 0(팽창 불필요), 카트폴 같은 비선형은 M_iter = 1~5.

3.4 PAS의 합성 (Composition of Polytopic Action Sets)

두 연속 세그먼트의 PAS를 이으려면, 앞 세그먼트의 종단 상태와 뒤 세그먼트의 시작 상태가 일치해야 한다. 궤적 사상이 아핀이므로 이 연속성 제약도 선형 이며, 합성집합 (식 3) 은 볼록 다면체다.

𝒞 := { (γ₁, γ₂) | γⱼ ∈ 𝒜ⱼ,  x_{1,N}(γ₁) = x_{2,0}(γ₂) }

ℓ개의 PAS를 합성하면 연속 다중 세그먼트 궤적을 인코딩하는 다면체가 되고, 그 위에서의 사후 궤적최적화(예: 제어노력 최소화)는 단일 볼록 프로그램(QP) 으로 풀린다. 즉 계획(feasibility)과 최적화(effort)가 분리되어, 먼저 도달가능성을 LP로 확보한 뒤 매끄러운 궤적을 QP로 추출한다.

3.5 PAS-RRT: 집합을 노드로 하는 트리 (Set-Valued Tree Growth)

전체 플래너는 RRT의 뼈대를 따르되, 노드가 단일 상태가 아니라 "합성된 도달가능 집합" 이다.

절차 (Section IV-B):

① 노드 선택 — 무작위 목표 x_rand에 대해, 가중 마스크 W(대각행렬)로 특성상태 x̂_v가 가장 가까운 노드를 고른다.

v* = argmin_v ‖ W ( x̂_v - x_rand ) ‖₂

② 도달집합으로 투영 (식 22) — 선택된 노드의 합성집합 𝒞_{v*} 안에서 x_rand에 가장 가까운 도달점을 LP로 찾는다.

min_{Γ_{v*}, r}  r
   s.t.  Γ_{v*} ∈ 𝒞_{v*},
         ‖ W ( x_{v*}^T(Γ_{v*}) - x_rand ) ‖_∞ ≤ r

해로 얻은 x_seed가 새 PAS의 씨앗이 된다. (가중 L∞ 투영 → LP)

③ 조향 및 새 PAS 구성 — 샘플 기반 조향으로 x_seed에서 x_rand를 향한 명목 궤적을 만들고, §3의 구성으로 신뢰 PAS 𝒜_new를 생성한다. 그리고 이전 세그먼트 집합과 합성 (식 23) 하여 자식 노드를 만든다.

𝒞_{v+} := { (Γ_{v*}, γ_new) |
            Γ_{v*} ∈ 𝒞_{v*},  A_new γ_new ≤ b_new,
            x_{v*}^T(Γ_{v*}) = x_{new,0}(γ_new) }

④ 목표 검사 — LP 실현가능성으로 x_goal ∈ 𝒳_{v+}^T 인지 검사. 성공하면 계획을 추출·반환, 실패하면 최근접 도달점을 캐시하고 ①로 돌아간다.

   │  집합 𝒞_{v*}   │ ────────► │  새 PAS 𝒜_new │
   │ (도달가능 다면체)│          └──────┬───────┘
   └───────────────┘                 │ 합성(연속성 선형제약)
           │                         ▼
           │                 ┌────────────────┐
           └────── 부모 ──────│ 자식 v+  𝒞_{v+} │
                             │ (합성 도달집합)  │
                             └────────────────┘
                                     │ ④ 목표 포함? (LP feasibility)
                                     ▼   yes → 계획 추출

기존 kinodynamic RRT가 매 노드에서 하나의 궤적을 붙이는 반면, PAS-RRT는 매 노드에서 연속체(polytope of trajectories) 를 붙인다. 따라서 목표가 어떤 노드의 도달집합에 "들어오기만 하면" 즉시 성공 판정되고, 정밀한 종단맞춤은 QP가 담당한다 — 이것이 확장 횟수를 크게 줄이는 원천이다.

3.6 IRIS-ZO 팽창의 상세 (Zeroth-Order Regional Inflation)

원래 IRIS는 반정정계획(SDP)으로 자유공간에 최대 볼록영역을 팽창시키지만, 신뢰영역 ℛ_trust의 경계는 ζ(γ)=ζ_max라는 비선형 등위면이라 SDP로 직접 다루기 어렵다. PAAMP는 이를 영차(zeroth-order, 그래디언트 불요) 샘플링으로 우회한다.

알고리즘: IRIS-ZO(𝒜_lin, ζ_max, 라운드 M_iter)
  Ω ← 𝒜_lin                       # 선형제약(충돌+제어)으로 초기화
  repeat M_iter 회:
    S ← Ω 안에서 256개 γ 배치 샘플      # GPU 병렬
    V ← { γ ∈ S | ζ(γ) > ζ_max }      # 신뢰영역 위반 샘플
    for each γ_v in V:
       # 명목점(중심)과 γ_v 사이를 12회 이분탐색으로
       # ζ(γ)=ζ_max 경계 γ_b 국소화
       γ_b ← Bisect(center, γ_v, ζ_max, 12)
       # γ_b에서 접평면(절단 초평면)을 Ω에 추가
       Ω ← Ω ∩ { γ | aᵀ(γ - γ_b) ≤ 0 }
  return Ω                          # 볼록 다면체 (PAS)

핵심 성질:

  • 그래디언트 불요: ζ(γ) 값만 평가하면 되므로, 미분 불가능하거나 접촉이 있는 동역학에도 적용 가능. 256 배치 평가는 GPU 롤아웃으로 병렬화.
  • 내부근사 보장: 각 절단이 위반영역을 배제하는 방향이므로, 결과 Ω는 ℛ_trust ∩ 𝒜_lin의 내부근사(안전측). 즉 PAS 안의 모든 γ는 ζ ≤ ζ_max를 (샘플 해상도 한도 내에서) 만족.
  • LTI 특례: 이중적분기처럼 f가 선형이면 선형화가 정확하여 ζ(γ)=0 ∀γ, 팽창이 불필요(M_iter=0)하고 Ω = 𝒜_lin 그대로. 이때 PAAMP는 정확한 도달집합을 다루므로 Table I의 100% 성공이 자연스럽다.
  • 비선형(카트폴): M_iter=1~5, ζ_max=0.05. 팽창 라운드가 늘수록 PAS는 조금씩 축소되며 모델 충실도↑.

3.7 계획의 볼록 구조 요약 (Why Everything Stays Convex)

전체 파이프라인이 볼록성을 유지하는 이유를 한 표로 정리한다.

구성요소 수학적 형태 볼록 프로그램
아핀 궤적 사상 x=x*+Rγ (아핀) —
충돌회피 (식 9) A_col γ ≤ b_col (선형) LP/QP 제약
제어한계 A_u γ ≤ b_u (선형) LP/QP 제약
신뢰영역 볼록화 IRIS-ZO 절단 (선형) LP/QP 제약
세그먼트 합성 (식 3) 종단=시작 등식 (선형) LP/QP 제약
트리 투영 (식 22) W-L∞ 최소화 LP
목표 포함 검사 실현가능성 LP
사후 궤적 평활 제어노력 최소화 QP

즉 원래의 비볼록·부족구동 궤적생성이, 국소 아핀화 한 겹과 신뢰영역 볼록화 덕분에 LP+QP의 연쇄로 환원된다. 이 환원이 14–78배 가속의 근본 원인이다.

6. 핵심 기여점 (Key Contributions)

  1. 신뢰 다면체 행동집합(Trusted PAS) 개념: 명목 궤적 주변 국소 아핀 좌표에서 충돌·제어 제약을 선형화하고, 동역학 위반 척도 ζ(γ)로 신뢰영역을 정의하여 IRIS-ZO 팽창으로 볼록 내부근사를 인증. 비선형 부족구동 동역학을 값싼 볼록 질의로 다루는 다리를 놓았다.

  2. 집합-값 트리(set-valued tree)로의 RRT 재정의: 노드가 단일 상태가 아니라 "합성된 도달가능 집합"인 PAS-RRT. 목표가 도달집합에 포함되기만 하면 즉시 성공 판정되어, kinodynamic RRT 대비 확장 횟수·런타임을 크게 줄인다(14–78배 가속).

  3. 계획과 최적화의 볼록 분리: 도달가능성(LP feasibility)을 먼저 확보하고, 매끄러운 궤적(제어노력 최소화)을 사후 QP로 추출. 다중 세그먼트 합성이 선형 연속성 제약으로 유지되어 전체가 볼록.

  4. 질의 가능한 계획 표현: NLP가 단일 점만 반환하는 것과 달리, 도달가능 집합을 명시적으로 들고 있어 "목표 포함?", "최근접 도달점?" 같은 질의를 LP 한 번으로 반복 수행.

  5. 완전 공개 재현 구현(MIT): C++/CUDA/Python 실저장소. 4종 동역학(DoubleIntegrator/Cartpole/Acrobot/Dubins), pybind11 바인딩, GoogleTest/pytest 테스트, 벤치마크 스크립트, LP=HiGHS·QP=OSQP 통합, GPU 롤아웃+CPU 폴백. 순수 Python으로 paamp.System 서브클래싱하여 새 동역학 확장 가능.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

  • 지평-확장의 역설: 긴 지평이 오히려 확장 횟수를 줄인다(카트폴 T=3–4 s에서 1–2회 확장). 한 PAS의 도달집합이 넓어져 목표 포함이 빨라지기 때문. 이는 "지평↑ → 비용↑"의 통념을 뒤집는 PAS 고유의 특성.
  • 다중로봇/군집: 논문 서두에서 다중로봇 시 계산폭발을 문제로 지목. PAS의 볼록 합성이 조합 복잡도를 완화할 잠재력이 있으나, 본 논문은 단일 시스템 검증에 그침(향후 과제).
  • GPU 가속: 롤아웃·실현가능성 배치 평가를 GPU로 처리, 256 배치 샘플을 병렬 평가. CPU 폴백으로 이식성 확보.

8.2 한계점 (Limitations)

  1. 보수적 이산 안전: 충돌검사가 이산 시각에서만 이뤄져 연속시간 안전 인증이 아님. "여유(margin)보다 좁은 통로"에서 성능 저하.
  2. 명목 롤아웃 품질 의존: 나쁜 명목 궤적이 나오면 성능이 급락. PAS 생성과 조향의 결합이 느슨함(향후 "더 긴밀한 결합" 명시).
  3. 실기체 검증 부재: 전부 시뮬레이션. sim-to-real 갭·센서잡음·모델오차에서의 신뢰영역 유효성 미검증.
  4. 인증의 근사성: PAS는 신뢰영역의 볼록 내부근사이므로, ζ_max 선택이 도달성-안전성을 좌우하는 튜닝 손잡이로 남음.

8.3 향후 방향 (Future Directions)

  • 연속시간 안전 인증(예: 배리어/튜브 결합)으로 이산 보수성 해소
  • PAS 생성 ↔ 조향의 긴밀 결합(공동 최적화)
  • 실기체 배치 및 sim-to-real
  • 다중로봇 합성으로 군집 계획 확장

9.2 장단점 분석

PAAMP의 강점

  • 부족구동 비선형을 볼록으로: CMG-RRT(준정적 조립)·VisualRRT(기구학)는 동역학을 다루지 않고, TubeRRT는 특정 강체 페이로드 동역학에 특화된다. PAAMP는 일반 부족구동 ẋ=f(x,u) 를 국소선형화+신뢰영역으로 볼록화하는 원리적 다리를 놓는다.
  • 집합-값 노드의 확장 효율: 세 비교군은 모두 단일 상태/경로점을 노드로 하지만, PAAMP는 도달가능 집합을 노드로 두어 목표 포함을 LP로 즉시 판정 — 긴 지평에서 확장 1–2회라는 극적 효율.
  • 질의 가능성: NLP·순수 그래디언트(VisualRRT)가 단일 해만 주는 데 반해, 명시적 다면체로 반복 질의가 값싸다.
  • 재현성 우위: TubeRRT(미공개)·VisualRRT(placeholder)와 달리 실동작 MIT 저장소 — CMG-RRT와 함께 코드 공개 그룹.

PAAMP의 약점

  • 실기체 부재: CMG-RRT(UR5e)·VisualRRT(Fetch 80%)는 sim-to-real을 보였으나 PAAMP는 시뮬만.
  • 이산 안전의 보수성: TubeRRT의 튜브는 연속 안전여유를 명시적으로 다루는 반면, PAAMP의 이산 충돌검사는 좁은 통로에서 보수적.
  • 명목 롤아웃 의존: 나쁜 명목 궤적에서 성능 급락 — CMG-RRT의 다양체 안내처럼 구조적 가이드가 아직 약함.

9.3 실적용 가능성 평가

  • 강한 후보 도메인: 카트폴·애크로봇류 부족구동 로봇, 곡예형 드론·다관절 시스템의 온보드 실시간 계획(볼록 LP/QP는 임베디드 친화적). 14–78배 가속과 GPU 배치는 자원제약 플랫폼에 유리.
  • 선결 과제: 실기체 검증과 연속시간 안전이 없어, 현 단계에서는 시뮬/HIL 파이프라인이나 상위계획-하위추종 스택의 상위 궤적생성기로 통합하는 것이 현실적. TubeRRT식 튜브를 PAS에 결합하면 안전여유를 명시화할 수 있다.
  • 통합 시너지: PAAMP(부족구동 볼록 궤적생성) + iCrowdNav/ProximitySafetyBalance류(사회적 로컬계획)처럼 동역학 계층과 의사결정 계층의 조합이 유망.

9.4 연구 방향성 평가

PAAMP는 "부족구동 동역학을 볼록 최적화의 언어로 번역"하는 원리적 기여로, CMG-RRT(기하 구조)·VisualRRT(지각-계획 융합)와는 직교(orthogonal) 하다. 세 방향은 경쟁이 아니라 결합 가능하다: PAS의 볼록 도달집합을 CMG-RRT의 다양체 안내와 결합하면 부족구동 좁은통로 문제를, VisualRRT의 미분가능 렌더와 결합하면 시각목표 부족구동 계획을 열 수 있다. 특히 집합-값 트리 라는 자료구조 자체가 다중로봇 합성·재계획 캐싱 등으로 확장될 여지가 크다.

11. 결론 (Conclusion)

Trusted Polytopic Action Sets (PAAMP) 는 부족구동 비선형 시스템의 모션 플래닝에서 오래된 딜레마 — "동역학 실현가능성 vs 볼록 최적화의 속도" — 를 명목 궤적 주변의 국소 아핀 좌표계 + 동역학 위반 신뢰영역 + IRIS-ZO 볼록 내부근사 로 정면 돌파한다. 핵심 혁신은 두 가지다. 첫째, 충돌·제어 제약을 γ에 대한 선형 부등식으로 만들어 PAS(신뢰 다면체 행동집합) 라는 볼록 인증 궤적족을 얻고, 이를 선형 연속성으로 합성한다. 둘째, RRT의 노드를 단일 상태에서 "합성된 도달가능 집합" 으로 재정의하여, 목표 포함을 LP로 즉시 판정하는 집합-값 트리(PAS-RRT) 를 구성한다.

성과는 명확하다: kinodynamic RRT 대비 14–78배 가속, 샘플링/NLP 대비 종단오차 26–86% 감소, 좁은통로·버그트랩 100% 성공, 그리고 긴 지평이 오히려 확장을 줄이는 반직관적 효율. 무엇보다 실동작 MIT 저장소(C++/CUDA/Python, 4종 동역학, LP=HiGHS·QP=OSQP)로 재현성을 확보해, 코드 미공개(TubeRRT)·placeholder(VisualRRT) 대비 실용적 우위를 갖는다.

한계는 실기체 검증 부재와 이산 충돌검사의 보수성, 명목 롤아웃 품질 의존이다. 그러나 이는 L-CSS 레터의 범위 안에서 자연스러운 후속 과제이며, 저자들도 연속시간 안전 인증·PAS↔조향 긴밀결합·실기체 배치·다중로봇 합성을 향후 방향으로 제시한다. 종합하면 PAAMP는 부족구동 로봇의 실시간 볼록 궤적생성을 위한 원리적이고 재현가능한 토대로, CMG-RRT(기하 다양체)·VisualRRT(지각-계획 융합)와 직교하며 결합 가능한 유망한 연구 축을 연다.
