1.2 연구 목표 (Research Objective)

이 논문은 "제한된 시야각(FOV)과 센싱 거리를 가진 온보드 센서만으로, 사전 지도 없이(prior-map-free) 미지의 복잡한 3D 환경을 UAV가 안전하면서도 효율적으로 비행할 수 있는가" 라는 문제를 푼다.

UAV가 좁은 통로, 머리 위 장애물, U자형 미로 같은 복잡한 3차원 공간을 빠르게 통과하려면, "앞으로 갈 곳을 미리 봐야(perceive)" 한다. 그런데 실제 온보드 센서(LiDAR·깊이 카메라)는 시야각과 거리 범위가 제한적이라, 단순히 목표를 향해 직진하면 장애물이 시야에 들어오기 전에 이미 충돌 거리 안에 들어와 버리는 상황(지각 지연으로 인한 충돌)이 발생한다. 기존 방법은 이를 회피하려고:

  • 미탐사 공간에 대한 단순 가정(전부 자유공간 / 전부 점유)을 두거나,
  • 보수적 휴리스틱(속도 상한, 고정된 시선 패턴)을 사용하거나,
  • 지각 인식 경로 생성(perception-aware path generation) 을 프론트엔드에서 무겁게 수행한다.

이들은 효율을 떨어뜨리고, 센서 종류(시야각·거리)가 바뀌면 일반화가 잘 안 된다.

FLAP의 핵심 아이디어는 "능동 지각(active perception)을 별도 모듈이 아니라 궤적 최적화(trajectory optimization)의 미분가능 제약·페널티 안으로 직접 통합" 하는 것이다. 구체적으로:

  1. 센서 좌표계에서의 FOV 기하 제약: 수직/수평 FOV, 센싱 거리(d_min~d_max), 시야각(viewing angle)을 센서 프레임에서 정확히 표현해 "이 점을 지금 보고 있는가"를 미분가능하게 평가.
  2. 속도-트리거 활성화(velocity-triggered activation): 긴급 제동 능력에 기반한 안전 기준으로 지각 페널티를 필요할 때만 켠다(불필요한 시선 낭비 방지 → 효율).
  3. 능동 지각 서브-궤적 + 파라메트릭 시작시간 최적화: "어디서부터 미리 봐야 하는가(start time)"를 자유 변수로 두어 지각 지연으로 인한 충돌 위험을 완화.
  4. MINCO 궤적 표현: 미분 평탄성(differential flatness)을 활용한 다항식 궤적으로 위 제약들을 하나의 미분가능 최적화로 융합. 무거운 지각-인식 경로 생성 없이 단순 프론트엔드 전역 경로 하나만 있으면 된다.

결과적으로 수직 FOV가 90°에서 0.2°까지 극단적으로 줄어드는 가혹한 조건에서도, 기존 MINCO 플래너(FM)와 고속 플래너(SUPER) 대비 성공률·강건성을 유지하며, 다양한 센서 구성(LiDAR/깊이 카메라)에 일반화되고, 실제 UAV 비행으로 검증된다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

C1. 제한된 FOV·센싱 거리로 인한 지각 지연 충돌. 온보드 센서의 시야각·거리 범위가 좁으면, 장애물이 측정되기 전에 이미 회피 불가능한 거리에 진입할 수 있다. 특히 고속 비행에서 치명적이다.

C2. 미지(prior-map-free) 환경의 미탐사 공간 처리. 사전 지도가 없으므로, 아직 관측하지 않은 공간을 어떻게 다룰지가 안전과 효율을 가른다. "전부 자유" 가정은 위험하고, "전부 점유" 가정은 경로를 막는다.

C3. 지각(perception)과 운동(motion) 효율의 trade-off. 충돌을 막으려고 끊임없이 전방을 응시하면(yaw를 계속 돌리면) 비행이 느려지고 부자연스럽다. 반대로 운동 효율만 추구하면 못 보고 부딪힌다. 둘의 균형을 상황에 맞게 잡아야 한다.

C4. 센서 이질성(heterogeneity)에 대한 일반화. LiDAR(넓은 수평·좁은 수직)와 깊이 카메라(직사각형 FOV·짧은 거리)는 기하가 완전히 다르다. 휴리스틱이 특정 센서에 맞춰져 있으면 다른 센서에서 깨진다.

C5. 실시간·미분가능 최적화. 온보드 실시간 재계획을 위해, FOV 가시성/안전 제약이 궤적 변수에 대해 미분가능해야(그래디언트 기반 최적화) 한다. 임의의 비매끄러운(non-smooth) 제약이면 느리거나 수렴이 불안정하다.

2.2 핵심 해결책

  • C1 → 능동 지각 서브-궤적 구간 + 파라메트릭 시작시간 최적화로 "지연으로 인한 충돌"을 사전에 방지.
  • C2 → 지각 인식 경로를 무겁게 생성하지 않고, 단순 전역 경로 + 온라인 FOV 제약으로 미탐사 위험 영역을 회피.
  • C3 → 속도-트리거 활성화: 긴급 제동 가능성이 위협받을 때만 지각 페널티를 켜서 운동 효율 보존.
  • C4 → 모든 가시성 제약을 센서 좌표계의 일반 기하 파라미터(α_min/max, β_min/max, d_min/max, θ) 로 표현 → 센서별로 파라미터만 갈아끼우면 됨.
  • C5 → MINCO 다항식 궤적 + 미분 평탄성 위에 모든 제약을 매끄러운 페널티로 얹은 단일 미분가능 최적화.

3. 핵심 방법론 (Core Methods)

표기 (Notation)
  o(t) = [p(t)^T, ψ(t)]^T : 미분평탄 출력 (위치 p∈R^3, yaw ψ)
  o_i(t) ∈ R^4           : i번째 구간의 다항식(시스템 차수 h=3 → 차수 2h-1=5)
  p_v, p_v^S             : 관심점 v의 월드/센서 좌표
  α_v, β_v               : 센서 프레임에서 v의 수직/수평 각도
  [α_min,α_max]          : 수직 FOV 한계
  [β_min,β_max]          : 수평 FOV 한계
  [d_min,d_max]          : 센싱 거리(근/원) 한계
  θ_v                    : 시야각(viewing angle)
  L_a(·)                 : 속도-트리거 활성화 함수
  T_s, T_p               : 전체 시간, 능동지각 서브세그먼트 길이
  t_as = ρ(T_s - T_p)    : 능동지각 서브세그먼트 시작시간, ρ∈(0,1)
  ϱ                      : ρ의 비제약 재파라미터화 변수(로지스틱 변환)

3.1 MINCO 궤적 표현과 미분 평탄성 (Trajectory Representation)

FLAP은 쿼드로터의 미분 평탄(differentially-flat) 출력 o = [p^T, ψ]^T (위치 + yaw)를 시간 다항식으로 표현한다. 각 구간 o_i(t) ∈ R^4는 시스템 차수 h=3(저크/스냅 수준 제어)에 대응하는 차수 2h-1 = 5의 다항식이다. 이는 Fei Gao 그룹의 MINCO(Minimum Control Input, GCOPTER/MINCO 계열) 파라미터화로, 구간 경계의 중간점(intermediate waypoint)과 구간 시간만으로 전체 다항식을 폐형으로 복원하면서, 목적함수의 그래디언트를 중간점·시간에 대해 효율적으로 역전파할 수 있다.

   전역 단순 경로(front-end)         MINCO 백엔드 최적화
   ●──●──●──●──●  (직선 세그먼트)  →  매끄러운 5차 다항식 궤적 o(t)
   (지각-인식 아님, 단순/저비용)        + FOV·안전·동역학 제약을 페널티로

핵심 설계 선택: 무거운 "지각 인식 경로 생성(perception-aware path generation)"을 프론트엔드에서 하지 않는다. 단순한 전역 경로 하나만 주면, 능동 지각의 모든 부담을 백엔드 궤적 최적화의 미분가능 페널티가 담당한다(C5). 이는 계산을 크게 줄이는 동시에, 센서 기하를 바꿔도 같은 백엔드가 작동하게 한다(C4).

3.2 센서 좌표계 FOV 가시성 제약 (FOV-Constrained Visibility)

"지금 이 위험 지점 v를 센서가 보고 있는가"를, 센서 프레임에서의 네 가지 미분가능 부등식으로 표현한다(논문 본문 가시성 기준):

(1) 수직 FOV:   ( α_v − (α_min+α_max)/2 )^2 − ( (α_max−α_min)/2 )^2  ≤ 0
(2) 수평 FOV:   ( β_v − (β_min+β_max)/2 )^2 − ( (β_max−β_min)/2 )^2  ≤ 0
(3) 센싱 거리:  || p_v^S ||_2 − d_max ≤ 0    그리고    d_min − || p_v^S ||_2 ≤ 0
(4) 시야각:     || p_S − p_v ||_2 · sin(θ_v) − ( dis(B, p_S) + d_Bs^max ) ≤ 0

직관:

  • (1),(2)는 점 v의 센서 프레임 각도 α_v, β_v가 FOV 중심 ±절반 범위 안에 있도록 강제하는 "이차식 박스 제약" 이다. 중심에서 벗어날수록 좌변이 커져 페널티가 증가한다. 매끈한 이차식이라 미분가능(C5).
  • (3)은 v가 센서의 근/원 거리 범위 안에 들어오게 한다. 너무 가까우면(d_min 위반) 이미 충돌 임박, 너무 멀면(d_max 위반) 신뢰 못 할 측정.
  • (4)는 장애물 경계 박스 B와의 기하를 고려한 시야각 가림(occlusion) 회피 제약으로, 비스듬한 각도에서 표면이 가려지는 상황을 억제한다.

이 네 제약을 합치면 "위험 가능성이 있는 전방 영역을 실제로 센서 시야에 담도록" 궤적(특히 yaw ψ와 위치 p)을 형성하게 된다. 모두 센서 프레임의 일반 파라미터로 쓰였기 때문에, LiDAR든 깊이 카메라든 (α,β,d) 값만 바꾸면 동일 정식화가 성립한다(C4 해소).

            센서 프레임 FOV 콘(cone)
                   ┌───────────┐  ← 수평 FOV [β_min,β_max]
       d_min ▒▒▒▒▒▒│           │
   ────────►│      │   • v ✅  │   d_max
   센서 원점 │      │           │
             └───────────┘  ← 수직 FOV [α_min,α_max]
   v가 (1)(2)(3)(4) 모두 만족 ⟺ "지금 보고 있음" → 페널티 0

3.3 속도-트리거 활성화 (Velocity-Triggered Activation)

지각 페널티를 항상 켜면, UAV가 끊임없이 위험 방향을 응시하느라 비행이 느려지고 부자연스럽다(C3). FLAP은 긴급 제동(emergency braking) 가능성에 기반한 안전 기준으로 페널티를 필요할 때만 활성화한다:

활성화 조건 (안전 임계):
   || v ||_2^2 / (2 a_max)  +  d_m  −  || p − p_u ||  ≤ 0
   └─ 제동거리 ─┘   └마진┘     └ 미관측 위험점까지 거리 ┘

활성화 페널티:
   P_ap = L_a(x) · (FOV 가시성 위반항)
   L_a(x) : 위 안전 기준이 위협받을 때 1에 가까워지는 게이팅 함수

직관: 현재 속도에서 최대 감속으로 멈출 수 있는 거리(||v||²/(2a_max)) 에 안전 마진 d_m을 더한 값이, 미관측 위험점 p_u까지의 거리보다 크면(즉 "지금 못 보면 못 멈춘다") 지각 페널티를 켜서 그 방향을 보도록 궤적을 유도한다. 반대로 충분히 느리거나 위험점이 멀면 페널티를 꺼서 운동 효율을 보존한다. 속도가 빠를수록 제동거리가 길어져 더 일찍/넓게 봐야 하므로, 활성화가 자연스럽게 속도에 비례해 강해진다 — 보수적 "속도 상한" 휴리스틱을 매끄러운 최적화 항으로 대체한 셈이다.

3.4 능동 지각 서브-궤적 + 파라메트릭 시작시간 (Parametric Start-Time)

"전방을 언제부터 미리 봐야 하는가"는 충돌 회피의 핵심 자유도다. FLAP은 전체 궤적 안에 능동 지각 서브-세그먼트(길이 T_p 고정)를 두고, 그 시작 시간을 최적화 변수로 만든다:

   t_as = ρ · (T_s − T_p),     ρ ∈ (0, 1)
   ρ = σ(ϱ) = 1/(1+e^{−ϱ})     # 로지스틱 변환으로 비제약 변수 ϱ 도입
  • ρ를 직접 (0,1) 제약으로 다루는 대신 로지스틱(시그모이드) 재파라미터화로 비제약 변수 ϱ를 두어, 경계 제약 없는 매끄러운 그래디언트 최적화를 가능케 한다(C5).
  • 시작 시간을 앞당기면(작은 ρ) 더 일찍 미리 보기 → 지연 충돌 위험↓, 운동 효율↓.
  • 늦추면(큰 ρ) 효율↑, 위험↑. 최적화가 환경·속도에 맞춰 자동으로 균형점을 찾는다(C1·C3 동시 해소).
   t=0 ───────────────────────── t=T_s
        │◄── t_as ──►│◄ T_p ►│
        (일반 비행)   (능동지각 구간: 위험방향 응시·감속 여유 확보)
        t_as 를 ρ로 최적화 → "언제부터 미리 볼지" 학습

3.5 통합 최적화 문제 (Unified Optimization)

위 요소를 하나의 미분가능 목적함수로 융합한다(개념적 정식화):

min_{q, T, ϱ}   J = w_e·J_energy(o)            # 제어 입력(스냅) 에너지 = 매끄러움
                  + w_t·J_time(T)              # 총 시간 = 공격성/효율
                  + w_o·J_obs(o)               # 장애물 안전(충돌 회피)
                  + w_d·J_dyn(o)               # 동역학 한계(속도/가속/추력)
                  + w_p·Σ P_ap(o, ϱ)           # 속도-트리거 능동지각 FOV 페널티
   변수: q(중간점), T(구간 시간), ϱ(지각 시작시간 재파라미터화)

q, T, ϱ에 대한 그래디언트를 MINCO 폐형으로 효율적으로 계산해 L-BFGS류 무제약 최적화로 푼다. 핵심: 능동 지각이 별도의 시선 계획 모듈이 아니라, 궤적의 모양·타이밍·yaw를 결정하는 목적함수의 한 항으로 들어가 있다는 점이 FLAP의 구조적 차별성이다.

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 / 시뮬레이션 환경 (Datasets & Sim Setups)

논문은 다양한 시야각·기하 조건을 의도적으로 설계한 시뮬레이션 시나리오로 능동 지각의 효과를 분리 검증한다:

  • 수평 좁은 공간(horizontal narrow-space): 수직 FOV를 90° / 30° / 10° / 0.2° 로 줄여가며 강건성 측정.
  • 머리 위 장애물(overhead-obstacle): H자형 구조물(위쪽에서 내려오는 장애물).
  • U자형 미로(U-shaped maze): 복잡한 3D 장애물 배치.
  • 수직 파이프라인(vertical pipeline): 카메라 센서 기반 수직 통과.

5.2 평가 지표 (Evaluation Metrics)

  • 성공률(Success rate): 충돌 없이 목표 도달한 시도/총 시도(예: 10회 중).
  • 소요 시간(duration, s) 과 평균 속도(mean velocity, m/s): 효율.
  • 실행 가능성(feasibility): 극한 FOV에서 해를 찾는지.

5.4 리얼월드 실험 (Real-world Experiments)

논문은 "extensive simulations and real-world experiments"를 명시한다. 발췌된 센서 사양:

6. 핵심 기여점 (Key Contributions)

  1. 능동 지각의 궤적 최적화 내재화. 시선/지각 계획을 별도 모듈로 분리하지 않고, FOV 가시성·안전을 미분가능 페널티로 MINCO 백엔드에 직접 통합. 무거운 지각-인식 경로 생성이 불필요.
  2. 센서 프레임 FOV 기하 정식화. 수직/수평 FOV, 센싱 거리, 시야각을 센서 좌표계의 이차식/거리 제약으로 표현 → 센서 이질성(LiDAR↔카메라)에 파라미터 교체만으로 일반화.
  3. 속도-트리거 활성화. 긴급 제동 기준(||v||²/(2a_max)+d_m−||p−p_u||≤0)으로 지각 페널티를 필요할 때만 켜 운동 효율과 안전을 동시에 달성. 보수적 속도-상한 휴리스틱을 매끈한 최적화로 대체.
  4. 파라메트릭 시작시간 최적화. "언제부터 미리 볼지"를 로지스틱 재파라미터화된 자유 변수 ϱ로 두어 지각 지연 충돌을 사전 방지.
  5. 극한 FOV 강건성 + 실증. 수직 FOV 0.2°에서도 해를 찾고(FM은 infeasible), 동급 성공률에서 더 빠름. 실제 UAV·이종 센서로 검증.

8. 고급 주제 (Advanced Topics)

8.1 왜 "능동 지각을 최적화 안으로" 넣는가 — 설계 철학

전통적 파이프라인은 (a) 지각-인식 경로 생성(프론트엔드) → (b) 궤적 최적화(백엔드)로 단계를 분리한다. 이때 (a)가 무겁고, 센서 기하가 바뀌면 (a)를 다시 설계해야 한다. FLAP은 (a)를 단순화하고, 지각의 책임을 전부 (b)의 미분가능 항으로 옮긴다. 이로써 ① 계산 절감, ② 센서 일반화, ③ 효율-안전의 연속적 균형(이산 휴리스틱이 아닌 그래디언트 기반)을 얻는다. 이는 Fei Gao 그룹의 "perception-aware planning(RAPTOR/FUEL/Bubble/SUPER 계열)" 전통을, FOV 기하를 센서 프레임에서 명시적으로 제약화하고 시작시간까지 변수화하는 방향으로 확장한 것이다.

8.2 한계점 (Limitations)

  • 코드 미공개: 재현성이 제한된다. 가중치·a_max·T_p 등 핵심 상수가 본문 표에 의존.
  • 극한 FOV(0.2°)에서 성공률 6/10: 능동 지각으로 실행 가능성은 살리지만 완전 신뢰성은 미달 — 센싱이 거의 0에 수렴하면 근본적 한계.
  • 동적 장애물: 발췌 범위에서 정적 미지 환경 중심. 빠른 동적 장애물에 대한 능동 지각(예측 포함)은 별도 과제.
  • 단일 기체·단일 에이전트: 다중 UAV 협응·통신 제약 하의 능동 지각은 미포함.

8.3 향후 방향

  • 동적 장애물 예측을 능동 지각 항에 결합(예측-인식 시선 계획).
  • 학습 기반 활성화/시작시간 사전(prior)으로 최적화 초기화 가속.
  • 다중 센서 융합(LiDAR+카메라 동시) 시 FOV 제약의 합집합 최적화.

9.2 장단점 분석

  • 장점: ① 지각을 별도 모듈이 아닌 최적화 항으로 통합한 구조적 우아함 → 계산↓·센서 일반화↑. ② 속도-트리거·파라메트릭 시작시간으로 효율과 안전을 연속적으로 trade-off(ASIP의 휴리스틱 뷰앵글 적응, 보수적 속도상한과 대비되는 정량적 강점). ③ 극한 FOV(0.2°)에서 FM이 infeasible인데 FLAP은 해를 찾음 → 정량적 우위가 명확.
  • 단점: ① 코드 미공개로 재현성 제약(세 비교 논문도 동일하나, FLAP은 상수 의존도가 높음). ② 정적 미지환경 중심 — ReliaDiffNav의 "지각 신뢰도(유리·거울 등 센서가 보긴 하나 못 믿는 영역)"는 다루지 않음. FLAP의 지각은 "보이느냐(FOV)"에 집중, ReliaDiffNav는 "믿을 수 있느냐(reliability)"에 집중 — 상호 보완적. ③ 다중 로봇(GATP)·통신 제약은 범위 밖.

9.3 실적용 가능성 평가

  • 강점: 온보드 실시간(미분가능 최적화), 이종 센서 일반화, 단순 프론트엔드로 통합 부담↓ → 실 UAV 배포 친화적. Fei Gao 그룹의 MINCO/EGO-Planner 생태계와 호환되어 기존 스택에 얹기 쉽다.
  • 제약: 코드 미공개로 즉시 재현 불가. 극한 FOV 신뢰성·동적 장애물 대응이 실외 고속 배포의 관건.

9.4 연구 방향성 평가

FLAP은 "perception-aware planning"을 FOV 기하의 명시적 제약화 + 시선 타이밍 변수화로 한 단계 정밀화했다. ReliaDiffNav의 지각 신뢰도와 FLAP의 지각 가시성(FOV) 을 결합하면("볼 수 있고 + 믿을 수 있는" 영역으로 능동 유도) 차세대 UAV 안전 비행의 자연스러운 통합점이 된다. ASIP의 커버리지 시선 계획과도 결합 여지가 크다.

11. 결론 (Conclusion)

FLAP은 "능동 지각을 궤적 최적화 안으로 가져온다" 는 한 문장의 아이디어를, FOV 기하의 센서 프레임 제약화·속도 트리거 활성화·파라메트릭 시작시간이라는 세 장치로 구체화한 자원·시야 제약 UAV 항법 프레임워크다. 무거운 지각-인식 경로 생성 없이 단순 전역 경로 + 미분가능 백엔드만으로, 극한 FOV(0.2°)에서 기존 MINCO 플래너가 풀지 못하는 문제를 풀고, 동급 성공률에서 더 빠르며, LiDAR·깊이 카메라 양쪽에 일반화된다.

혁신성: 지각을 별도 모듈이 아닌 최적화 항으로 내재화하고, 특히 "언제부터 미리 볼지"를 변수화한 점이 perception-aware planning 계보에서 신선하다. 실용적 의의: Fei Gao 그룹 MINCO 생태계와 호환되어 실 UAV 스택에 통합 친화적이며, 이종 센서를 파라미터 교체로 흡수한다. 한계: 코드 미공개로 재현성이 제약되고, 극한 FOV 신뢰성(6/10)과 동적 장애물 대응이 후속 과제다. 향후: ReliaDiffNav류 지각 신뢰도와 결합한 "보이고+믿을 수 있는" 능동 지각, 동적 장애물 예측 통합, 다중 UAV 협응 능동 지각이 자연스러운 확장 방향이다.

부록 A. 능동 지각 항(P_ap) 의사코드

def active_perception_penalty(traj, sensor_params, a_max, d_m):
    """FLAP 능동 지각 페널티 (개념적 의사코드)"""
    alpha_min, alpha_max, beta_min, beta_max, d_min, d_max = sensor_params
    P = 0.0
    for t in sample_times(traj):
        p, v, R_sensor = traj.pos(t), traj.vel(t), traj.sensor_frame(t)
        p_u = nearest_unobserved_risk_point(p, R_sensor)   # 미관측 위험점
        # 1) 속도-트리거 게이팅: 못 보면 못 멈추나?
        braking = norm(v)**2 / (2*a_max)
        gate = smooth_activation(braking + d_m - norm(p - p_u))  # ≤0이면 위험 → gate↑
        if gate < 1e-6:
            continue   # 충분히 안전 → 페널티 끔(효율 보존)
        # 2) 위험점을 센서 FOV 안에 담도록 가시성 위반 측정
        p_s = R_sensor.T @ (p_u - p)                  # 센서 프레임 좌표
        alpha, beta = elevation(p_s), azimuth(p_s)
        viol  = relu((alpha-(alpha_min+alpha_max)/2)**2 - ((alpha_max-alpha_min)/2)**2)  # 수직
        viol += relu((beta -(beta_min +beta_max )/2)**2 - ((beta_max -beta_min )/2)**2)  # 수평
        viol += relu(norm(p_s) - d_max) + relu(d_min - norm(p_s))                        # 거리
        P += gate * viol
    return P

부록 B. 파라메트릭 시작시간 재파라미터화

# ρ ∈ (0,1) 제약을 비제약 변수 ϱ 로 변환 → 매끄러운 무제약 최적화
def rho_from_varrho(varrho):           # σ(ϱ)
    return 1.0 / (1.0 + exp(-varrho))

def start_time(varrho, T_s, T_p):
    rho = rho_from_varrho(varrho)
    return rho * (T_s - T_p)            # t_as

부록 F. 긴급 제동 기준의 유도 (Emergency-Braking Criterion)

물리 직관: 등가속 감속 모델
  현재 속력 ||v||, 최대 감속 a_max 로 정지까지 필요한 거리
       d_brake = ||v||^2 / (2 a_max)            (운동학: v^2 = 2 a d)

안전 조건(충돌 회피):
  "지금 못 본 위험점 p_u 까지의 거리"가 "제동거리 + 안전마진" 이상이어야 함
       || p − p_u ||  ≥  d_brake + d_m
   ⟺  d_brake + d_m − || p − p_u ||  ≤  0
   ⟺  ||v||^2/(2 a_max) + d_m − ||p − p_u||  ≤  0     (위반 시 → 능동지각 ON)

해석:
  - 속력↑ → d_brake가 2차로 증가 → 더 일찍/멀리 봐야 함(활성화 강해짐)
  - 위험점이 가까울수록(||p−p_u||↓) 좌변↑ → 활성화
  - d_m(안전마진)은 측정/추종 지연·모델 오차에 대한 버퍼
이 기준을 매끄러운 게이팅 L_a(·)로 감싸 미분가능 페널티에 곱한다.

이 유도가 보여주는 핵심은, FLAP의 능동 지각이 임의의 휴리스틱이 아니라 "정지할 수 있는가"라는 물리적 안전 여유에 직접 정박(anchor) 되어 있다는 점이다. 속도 상한을 고정값으로 두는 보수적 접근과 달리, 같은 한 개의 부등식이 저속에서는 거의 항상 만족(페널티 꺼짐, 효율 보존)되고 고속·근접 상황에서만 발동(안전 확보)되어, 효율-안전의 자기조정(self-regulating) trade-off를 만든다.

부록 G. MINCO 그래디언트 흐름과 시작시간 변수의 결합

목적함수 J(q, T, ϱ) 의 그래디언트 경로
  q (중간점)  ──► MINCO 폐형 c=M(q,T)^{-1} b  ──► o(t)=poly(c) ──► J
  T (구간시간)──►            ▲                                    │
  ϱ (시작시간)──► t_as=σ(ϱ)(T_s−T_p) ──► P_ap 의 적분 구간 결정 ──┘

∂J/∂q, ∂J/∂T : MINCO 표준 역전파(GCOPTER와 동일 골격)
∂J/∂ϱ        : ∂J/∂t_as · dt_as/dρ · dρ/dϱ
             = (P_ap 적분구간 경계 민감도) · (T_s−T_p) · ρ(1−ρ)

dρ/dϱ = ρ(1−ρ)가 항상 유한하고 경계(ρ→0,1)에서 0으로 부드럽게 수렴하므로, 시작시간 변수가 폭주하거나 제약 경계에 들러붙는 문제 없이 q·T와 동시에 한 최적화 루프에서 갱신된다. 이것이 "시작시간을 변수화"하면서도 수치 안정성을 유지하는 비결이다.

부록 J. perception-aware planning 계보 안에서의 위치

시선/지각 계획의 진화 (ZJU FAST Lab 및 관련 계보)
  RAPTOR(2020)   : yaw를 risk-aware 하게 계획(미관측 위험 최소화)
  FUEL(2021)     : frontier 기반 빠른 탐사(시선=정보 획득)
  Bubble(2021)   : 안전 회랑(corridor) 기반 고속 비행
  EGO-Planner    : ESDF-free 경량 로컬 플래너
  SUPER(2025)    : 안전 보장 고속 비행(좁은 FOV엔 취약)
  ────────────────────────────────────────────────
  FLAP(2026)     : FOV 기하를 "센서프레임 미분가능 제약"으로 명시화
                 + "언제부터 볼지(시작시간)"를 변수화
                 + 속도-트리거로 효율-안전 자기조정

위 계보에서 FLAP의 독창성은 두 가지로 압축된다. 첫째, 지각의 "공간"(어디를 보는가, FOV)뿐 아니라 "시간"(언제부터 보는가, t_as)까지 동시에 최적화 변수로 끌어올린 점이다. RAPTOR류가 "위험을 덜 만드는 yaw"를 계획했다면, FLAP은 "위험을 만나기 전에, 정지 가능성이 위협받는 그 순간부터, 그 방향을 FOV에 담는" 것을 하나의 매끄러운 최적화로 형식화했다. 둘째, 센서 기하의 추상화로 LiDAR·카메라를 같은 백엔드로 흡수해, perception-aware planning이 그동안 안고 있던 "센서 의존적 휴리스틱" 문제를 구조적으로 해소했다.

이로써 FLAP은 단순한 점진적 개선이 아니라, "perception-aware planning을 센서-불가지(sensor-agnostic)·시공간 통합 미분가능 최적화로 재정식화"하는 방향 제시로 읽을 수 있다. 후속 연구가 ReliaDiffNav류의 지각 신뢰도나 동적 장애물 예측을 같은 페널티 틀에 더하면, "보이고·믿을 수 있고·미래에도 안전한" 능동 지각으로 자연스럽게 확장된다.
