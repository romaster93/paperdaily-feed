1.2 연구 목표 (Research Objective)

LP-NavOA는 전역 지도도, 외부 플래너도 없이, 오직 고유수용감각(proprioception)과 단거리(4m) 국소 거리 센싱만으로 휴머노이드 로봇(Unitree G1)이 어수선한 환경을 국소 내비게이션·장애물 회피하며 목표에 도달하는 문제를 해결한다. 핵심 연구 질문은:

"장거리 LiDAR·전역 지도·별도 경로 플래너 없이, 부분 관측(partially observable)·희소 목표(sparse-goal) 조건에서, 어떻게 장애물 회피 · 목표 복원(goal recovery) · 안정적 전신 보행을 하나의 학습 정책으로 통합할 것인가?"

기존 휴머노이드 내비게이션은 보통 계층 분리 구조를 쓴다: 상위 전역 플래너(지도 기반 A*/RRT)가 경로를 만들고, 하위 보행 컨트롤러가 추종한다. 그러나 이 구조는:

계층 분리 구조의 문제:
  1. 전역 지도 의존 → 미지·동적 환경에서 지도 구축 비용·지연
  2. 장거리 센서(3D LiDAR) 가정 → 저가/경량 플랫폼에 부담
  3. 플래너-컨트롤러 인터페이스 불일치 → 컨트롤러가 추종 못하는 경로 생성 가능
  4. 희소 목표가 장애물에 가려지면(occluded) 상위 플래너가 마비

LP-NavOA는 이를 2단계 학습(PPO 보행 백본 + 증류된 GRU 로컬 플래너) 으로 통합한다. 핵심 발상은:

  • 하위(보행) 백본을 "원형 목표 명령(circular goal command)"으로 먼저 강건하게 학습시키고(3.0 m/s까지),
  • 그 위에 순환신경망(GRU) 기반 경량 조향(steering) 플래너를 행동 복제(behavior cloning)로 증류하여,
  • 추론 시에는 외부 플래너 없이(planner-free) GRU가 헤딩 명령만 갱신해 백본을 조종한다.

즉 "무거운 전역 계획을 추론 시점에서 완전히 제거하고, 단거리 센싱만으로 동작하는 재귀적 조향 모듈로 대체"하는 것이 본 논문의 정체성이다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 제한된 인식 (Limited Perception)

LP-NavOA는 의도적으로 단거리(4m)·저해상도(8×8) 레이캐스트 3개(전/좌/우) 만 사용한다. 이는 VL53L8CX 같은 저가 ToF 센서를 모사한 설정으로, 3D LiDAR(SCAN-Planner의 Livox Mid-360 등) 대비 정보량이 극히 적다.

인식 제약:
  • 거리 센서   : 8×8 레이캐스트 × 3 (전/좌/우), FOV 45°, 최대 4m, 12Hz
  • 전역 정보   : 없음 (지도 없음)
  • 목표 정보   : 신체 좌표계 목표 오프셋 + 베어링 (희소, 가려질 수 있음)

이 빈약한 관측만으로 장애물을 회피하면서 목표를 찾아가야 한다 — "근시안적(myopic) 센싱 하의 내비게이션"이 핵심 난제다.

B. 부분 관측·희소 목표 (Partial Observability & Sparse Goal)

목표가 장애물 뒤에 가려지면, 순간 관측만으로는 어느 방향으로 우회할지 결정할 수 없다. "벽을 만나면 좌/우 중 어디로 돌아야 목표에 더 빨리 도달하는가"는 과거 관측의 시간적 통합(temporal integration) 을 요구한다. 이것이 LP-NavOA가 순수 MLP가 아니라 GRU(순환 메모리) 를 쓰는 이유다.

C. 회피와 전신 안정성의 결합 (Avoidance ⊗ Whole-Body Stability)

휴머노이드는 이족 보행이라 본질적으로 불안정하다. 급격한 회피 기동(큰 헤딩 변화)은 균형 붕괴(낙상)를 유발한다. 따라서 "장애물 회피를 위한 조향 명령"과 "안정적 전신 보행"을 동시에 만족해야 한다 — 둘을 분리해 학습하면 인터페이스 불일치가 생긴다.

2.2 핵심 해결책

난제 A (제한 인식) ─→ 단거리 레이캐스트만으로 동작하는 경량 정책 설계
난제 B (부분관측)  ─→ GRU 순환 메모리로 과거 관측 통합, 우회 방향 결정
난제 C (회피+안정) ─→ 보행 백본 선학습(circular cmd) 후 조향만 증류,
                      백본은 동결(frozen) → 안정성 보존

핵심 통찰 두 가지:

  1. "원형 목표 명령"으로 보행을 먼저 학습하면, 임의 방향·속도 추종이 가능한 강건한 백본을 빠르게(3.0 m/s) 얻는다. 흩어진 고정 웨이포인트 시퀀스로 학습하는 것보다 압도적으로 우수(§5.3 Table I).
  2. 조향 플래너를 백본 위에 증류하면, 백본의 안정성을 해치지 않으면서 "어디로 돌아갈지"만 학습할 수 있다. 추론 시 외부 플래너가 불필요해진다.

3. 핵심 방법론 (Core Methods)

3.1 PPO 보행 백본 (Locomotion Backbone)

1단계는 강화학습(PPO)으로 인식-행동 정책 π_θ를 학습한다.

목적:
    θ* = argmax_θ  E_{π_θ} [ Σ_t γ^t · r_t^ll ]

  r_t^ll : 저수준(low-level) 보행 보상
  γ      : 할인율 (0.99)

관측 공간(세 요소 결합):

  고유수용감각 : 몸체 각속도, 중력 벡터, 관절 오프셋/속도, 이전 행동, 보행 위상(gait phase)
  국소 거리센싱: 정규화 레이캐스트 3그리드(전/좌/우), 8×8, 0~4m
  명령 입력    : c_t = [Δψ_t, v_t*]   (헤딩 오차, 목표 속도)

원형 목표 명령(Circular Goal Command) — 본 논문의 첫 핵심 트릭(Eq. 3):

    θ_t^{w,cmd} = wrap_{[-π,π]}( ψ_t + U(-θ_max, θ_max) )
    p_t^{w,goal} = p_t^w + R · [ cos θ_t^{w,cmd}, sin θ_t^{w,cmd} ]

  ψ_t        : 현재 몸체 요(yaw)
  U(·)       : 균등 분포 샘플 (목표 방향 무작위 섭동)
  R          : 목표 반경
  → 매 에피소드 로봇 주변 "원" 위에 목표를 무작위 배치

해석: 고정된 흩어진 목표 시퀀스 대신, 로봇 중심 원 위에 목표를 두고 임의 방향·속도를 추종하게 하면, 정책이 "모든 방향으로 안정적으로 걷는" 능력을 균일하게 학습한다. 이것이 3.0 m/s 고속에서도 99.51% 완주율을 내는 비결이다(§5.3).

보상 설계(Table V):

  track_ang_vel_cmd   +1.3~1.8   요-레이트 추종
  track_goal_velocity +2.0       전진 속도 추종
  flat_orientation_l2 −5.0       직립 자세 유지
  is_terminated       −200       낙상 페널티 (지배적)
  joint_pos_limits    −10        관절 한계 회피
  action_rate_l2      −0.05      행동 평활성
  foot_slip           −0.25      미끄럼 억제
  body_collision      −1.0       접촉 페널티
  in_place_turn_bonus +1.0       제자리 큰 회전 보너스

낙상 페널티(−200)가 압도적으로 커, 백본은 "무엇보다 넘어지지 않는다"를 최우선으로 학습한다 — 이후 증류 단계에서 조향이 더해져도 안정성이 유지되는 토대다.

3단계 학습 커리큘럼:

  Stage 1 : 평지 원형목표 보행 (3.0 m/s 백본 확보)
  Stage 2 : A* 시각 일반화 (장애물 웨이포인트 추가)
  Stage 3 : (선택) 거친 지형 적응

3.2 증류된 순환 로컬 플래너 (Distilled Recurrent Local Planner)

2단계는 동결된 백본 위에 행동 복제로 GRU 조향 플래너 f_φ를 학습한다.

목적:
    φ* = argmin_φ  E_{D_{π_θ}} [ ℓ( f_φ , y_t ) ]

  D_{π_θ} : 동결 백본 롤아웃으로 수집한 데이터셋
  y_t     : 교사(teacher)가 제공한 헤딩 타깃

플래너 관측(Eq. 4):

    o_t^lp = [ η_t, ν_t, ρ_t^f, ρ_t^ℓ, ρ_t^r, ξ_t ]

  η_t = [cos ψ_t, sin ψ_t]                          요 인코딩
  ν_t = 관절속도(dead reckoning) 또는 몸체속도(odometry)
  ρ^{f,ℓ,r} = 전/좌/우 레이캐스트 3그룹
  ξ_t = [ d^x_b/10, d^y_b/10, cos β_t, sin β_t ]     신체좌표 목표 오프셋 + 베어링

아키텍처(Eq. 5) — 본 논문의 두 번째 핵심:

    z_t^s = E_ρ( ρ_t^s ),   s ∈ {f, ℓ, r}            그룹별 CNN 인코더 (32-D)
    h_t   = GRUCell( φ([η_t, ν_t, z_t^f, z_t^ℓ, z_t^r, ξ_t]), h_{t-1} )   GRU(48-D)
    Δψ̂_t = Δψ_max · tanh( W_ψ · h_t )                헤딩 명령 (tanh 유계)

구성:
  • 레이캐스트 그룹별 CNN 인코더 (각 32-D 출력)
  • 융합 MLP φ
  • GRU 순환 유닛 (은닉 h_t ∈ R^48)  ← 부분관측 하 시간 통합의 핵심
  • tanh 유계 헤딩 출력 (급격한 명령 방지 → 안정성)

GRU의 48차원 은닉 상태가 "벽을 따라 어느 쪽으로 돌고 있었는지"의 시간적 맥락을 유지하여, 순간 관측만으로는 불가능한 일관된 우회를 가능하게 한다.

3.3 경로 형성 교사 제어 (Route-Shaping Teacher Control)

증류의 품질은 교사 신호 품질에 달려 있다. LP-NavOA는 웨이포인트 추종과 목표 직진을 동적으로 혼합하는 교사를 설계한다(Eq. 6):

    Δψ_t* = α_t · Δψ_t^key + (1 − α_t) · Δψ_t^wp

  Δψ^key : 목표(key-goal) 직진 헤딩
  Δψ^wp  : 웨이포인트(우회) 헤딩
  α_t    : 게이팅 가중 (1=직진, 0=우회)

게이팅 메커니즘(Eq. 7) — 전방 여유 공간에 따라 직진/우회 전환:

    α̃_t = σ( k_α · (d_t^f − d_turn) )                전방 여유 기반 로지스틱

    α_t^raw = { 0,    if d_t^gs < d_block             목표측이 막히면 강제 우회
              { α̃_t,  otherwise

  비대칭 EMA 평활:
    α_t = α_{t-1} + μ_t · (α_t^raw − α_{t-1})
    μ_t = μ_up   if α_t^raw > α_{t-1}  (직진으로 빠르게 복귀)
        = μ_down otherwise            (우회로 천천히 진입)

파라미터:
  d_max = 4m            센서 범위 상한
  d_t^f = d_max·min ρ^f 전방 여유 거리
  d_t^gs               목표측 좌/우 최소 여유
  k_α                  전환 급격함
  d_turn               우회 해제 여유 임계
  d_block              목표측 차단 임계

설계 의도: 전방이 열려 있으면(d^f > d_turn) α→1로 목표 직진, 목표측이 막히면(d^gs < d_block) α→0으로 강제 우회한다. 비대칭 EMA는 "우회는 신중히 진입, 직진 복귀는 신속히"라는 비대칭 정책을 구현하여, 장애물을 충분히 지난 뒤에야 목표로 복귀하게 한다. 이 동적 경로 형성이 단순 웨이포인트 추종 대비 결정적 성능 차이를 만든다(§5.3 Table III: Full 85.3% vs Waypoint-only 72.6% vs Key-goal-only 33.9%).

교사 활성 데이터 수집(Teacher-active): 교사의 경로 형성 타깃을 동결 백본 롤아웃에 주입하여, 학생이 학습할 상태 분포를 "회피 상황이 풍부한" 쪽으로 조건화한다. 이를 제거하면 85.3%→67.9%로 급락(§5.3) — DAgger류 분포 정합의 중요성을 보여준다.

3.4 PPO/GAE 학습 동역학 (Backbone Optimization Dynamics)

백본 π_θ는 PPO의 클리핑 대리목적(clipped surrogate)으로 최적화된다(논문 하이퍼파라미터 기반 재구성).

PPO 클리핑 목적:
    L^CLIP(θ) = E_t[ min( r_t(θ)·Â_t , clip(r_t(θ), 1−ε, 1+ε)·Â_t ) ]

  r_t(θ) = π_θ(a_t|s_t) / π_{θ_old}(a_t|s_t)   확률비
  ε      = 0.2                                  클립 범위
  Â_t    = GAE 이득 추정 (γ=0.99, λ=0.95)

GAE(Generalized Advantage Estimation):
    Â_t = Σ_{l≥0} (γλ)^l · δ_{t+l}
    δ_t = r_t + γ·V(s_{t+1}) − V(s_t)            TD 잔차

왜 이 설정이 휴머노이드에 중요한가:

  γ = 0.99   → 유효 지평 ~100 스텝. 낙상(−200) 페널티가 먼 미래까지
               역전파되어 "지금의 불안정 자세"가 미래 낙상으로 처벌됨
  λ = 0.95   → 이득 추정의 편향-분산 균형. 휴머노이드의 고분산 보상
               (낙상 sparse + 추종 dense)에서 안정적 학습
  ε = 0.2    → 정책 갱신 폭 제한 → 이미 학습한 균형 능력을 급격히
               망가뜨리지 않음 (보수적 갱신)
  8192 envs  → 대규모 병렬로 낙상/회복의 희귀 상태를 충분히 표집

엔트로피 계수 0.01은 탐험을 약하게 유지하여, 백본이 다양한 헤딩·속도 명령에 노출되도록 한다 — 원형 목표 명령(§3.1)과 결합되어 "모든 방향 강건 보행"을 형성한다. entropy가 과하면 균형 붕괴, 과소하면 명령 범위 미탐험이 되므로 0.01은 균형점이다.

3.5 GRU 신용 할당과 비대칭 게이트 안정성

왜 MLP가 아니라 GRU인가 — 시간적 신용 할당 관점:

  순간 관측 o_t만으로는 "벽을 좌/우 어느 쪽으로 돌고 있었나"가 미관측.
  GRU 은닉 h_t가 "직전까지의 우회 방향"을 보존 →
    h_t = (1−u_t)⊙h_{t-1} + u_t⊙h̃_t     (GRU 갱신 게이트 u_t)
  → 벽을 따라 도는 동안 일관된 헤딩 부호 유지 (진동/되돌이 방지)

만약 메모리가 없으면(MLP), 로봇이 벽 중앙 부근에서 좌우 관측이 대칭일 때 헤딩이 진동(chatter)하여 벽에 갇힌다. GRU의 48-D 상태가 이 대칭을 깨는 "이력(hysteresis)"을 제공한다. 이는 §5.3 Key-goal-only(메모리 활용 없는 직진 교사)가 33.9%로 붕괴하는 것과 대조적이다.

비대칭 EMA 게이트의 안정성 분석(Eq. 7):

  μ_up > μ_down  (직진 복귀 빠름, 우회 진입 느림)

  의미: α(직진 가중)가 올라갈 때(=장애물 벗어남)는 빠르게 목표 복귀,
        내려갈 때(=장애물 접근)는 천천히 우회 진입.
  효과: 장애물을 "충분히" 지난 뒤에만 목표로 꺾어, 모서리에서
        다시 부딪히는 "코너 클리핑"을 방지.
  안정성: 비대칭 시정수가 일종의 디바운싱(debouncing)으로 작동,
          d^f가 d_turn 근처에서 진동해도 α가 채터링하지 않음.

이 비대칭성은 제어 이론의 슈미트 트리거(Schmitt trigger)와 유사한 히스테리시스를 구현하여, 경계 근처에서의 모드 진동을 억제한다 — 휴머노이드처럼 급변 명령에 취약한 플랫폼에 특히 중요한 설계다.

4. 시스템 아키텍처 (System Architecture)

[ 학습 단계 ]
  Stage 1 (PPO):
     관측(고유수용+레이캐스트+[Δψ,v*]) → π_θ → 정규화 관절 행동
     원형목표 명령으로 전방향 보행 학습 (3.0 m/s)

  Stage 2 (증류):
     π_θ 동결 → A*/웨이포인트 교사 하에 롤아웃 수집
     교사가 경로형성 게이트 α_t로 웨이포인트·목표 타깃 혼합
     동결 π_θ가 지도된 [Δψ*, v*]를 전신 보행으로 변환

  GRU 플래너 f_φ ← 동결백본 롤아웃에 행동복제
     입력: 국소 관측 + 순환 메모리 → 출력: 유계 헤딩 Δψ̂_t

[ 추론 단계 — Planner-Free ]
  고유수용감각 + 국소 레이캐스트 + 목표 방향
        │
        ▼
  ┌──────────────────────┐
  │  GRU 플래너 f_φ       │  ← 순환 조향 모듈(외부 플래너 없음)
  └──────────┬───────────┘
        헤딩 명령 Δψ̂_t (원형 명령을 덮어씀)
             ▼
  ┌──────────────────────┐
  │  안전 필터            │  ← 레이캐스트 기반 속도/요 감쇠
  └──────────┬───────────┘
             ▼
  ┌──────────────────────┐
  │  동결 백본 π_θ        │  ← 전신 보행 생성
  └──────────┬───────────┘
             ▼
       관절 타깃 → PD 제어 → G1 구동

데이터 흐름의 핵심: 추론 시 GRU 플래너가 내놓는 헤딩 명령 Δψ̂_t가 원형 명령을 덮어쓰고(overwrite), 안전 필터를 거쳐, 동결 백본이 이를 전신 보행으로 실현한다. 외부 전역 플래너·지도가 전혀 개입하지 않는 완전 planner-free 추론 인터페이스가 본 아키텍처의 정체성이다.

5.5 단일 에피소드 동작 추적 (Episode Walkthrough)

Open-wall 시나리오에서 한 에피소드가 어떻게 전개되는지, 게이트 α_t와 GRU 헤딩의 상호작용을 단계별로 추적하면 다음과 같다(설계 기반 재구성).

t=0  목표가 전방, 벽 아직 멀리(d^f > d_turn)
     → α≈1 (직진 모드)
     → GRU 헤딩 Δψ̂≈0, 목표 향해 직진

t=k1 벽 접근(d^f ↓ → d_turn 근처)
     → α̃ = σ(k_α(d^f − d_turn)) 가 0.5 부근으로 하강
     → 비대칭 EMA μ_down으로 "천천히" 우회 진입
     → GRU가 좌/우 레이캐스트 비대칭(ρ^ℓ vs ρ^r) 감지,
       여유 큰 쪽으로 Δψ̂ 부호 결정 + h_t에 그 방향 기억

t=k2 목표측이 막힘(d^gs < d_block)
     → α_raw = 0 강제 (완전 우회)
     → GRU 헤딩이 벽을 따라 일관되게 한 방향 유지
       (h_t의 이력 덕에 좌우 진동 없음)

t=k3 벽 끝을 충분히 지남(d^f 다시 ↑)
     → α̃ 상승, μ_up으로 "빠르게" 직진 복귀
     → 단, d^gs가 충분히 열릴 때까지 코너 클리핑 방지
     → 목표 베어링 ξ_t를 향해 헤딩 복원

t=T  목표 도달 (on-time 예산 ~25s 내)

이 추적은 세 메커니즘(게이트 α, 비대칭 EMA, GRU 메모리)이 어떻게 협력하는지를 압축적으로 보여준다: 게이트가 "언제" 우회할지, GRU가 "어느 쪽으로" 우회할지, 비대칭 EMA가 "얼마나 신중히" 전환할지를 각각 담당한다. R1 백본(직진만, 38%)이 벽에 부딪혀 brush 70%를 기록하는 것과 달리, 이 협력 구조가 brush를 24%로 낮추고 성공률을 85%로 끌어올린다.

6. 핵심 기여점 (Key Contributions)

  1. 통합 학습 기반 로컬 내비게이션: 전역 지도·외부 플래너·장거리 LiDAR 없이, 단거리 레이캐스트만으로 장애물 회피·목표 복원·전신 보행을 하나의 정책으로 통합. 추론 시 완전 planner-free.

  2. 원형 목표 명령(Circular Goal Command): 임의 방향·속도를 균일하게 추종하는 강건 백본을 빠르게 학습. 고정 시퀀스 대비 추종속도 3.0 vs 1.44 m/s, 완주율 99.51 vs 40%.

  3. 증류 + GRU 순환 플래너: 동결 백본 위에 48-D GRU 조향 모듈을 행동복제로 증류. 부분관측 하 시간적 통합으로 일관된 우회 결정. 백본 안정성 보존.

  4. 동적 경로 형성 교사(Route-Shaping Gate): 전방 여유 기반 로지스틱 게이트 + 비대칭 EMA로 직진/우회 동적 혼합. 단순 웨이포인트 대비 85.3% vs 72.6%.

  5. 실로봇 검증: Unitree G1에서 다양한 벽 장벽 구성을 0.281m 여유까지 우회-복원 조향으로 통과(정성적). 시뮬 성공률 3840%→8597% 도약.

  • 동적 환경 확장      : 이동 보행자·동적 장애물 처리 (SCAN-Planner가 일부 다룸)
  • 정량 실로봇 평가    : 반복 시행 + 성공률/충돌률 통계 보고
  • 장거리 센싱 융합    : 단거리 레이캐스트 + 희소 LiDAR 결합으로 계획 지평 확대
  • 더 긴 시간 메모리   : GRU → Transformer/SSM으로 장기 부분관측 통합
  • 코드 공개           : 현재 Coming Soon — 재현성 확보의 핵심 다음 단계

8.3 설계 철학 분석 — "계획을 학습으로 내재화"

LP-NavOA의 본질은 "전통적으로 명시적 모듈(전역 플래너)이 하던 일을 순환 신경망의 은닉 상태로 내재화" 하는 것이다. 이는 NeuPAN의 "E2E 모델 기반 학습"과 철학을 공유하나, LP-NavOA는 특히 휴머노이드의 안정성 제약을 백본 동결로 분리 보존한다는 점이 다르다. 즉 "안정성은 RL로 한 번 확실히 학습해 얼리고(freeze), 그 위에 조향 지능만 증류"하는 2단계 분리가 핵심 엔지니어링 결정이다. 이 분리 덕에 조향 학습이 보행 안정성을 망가뜨리지 않는다 — 단일 정책 E2E 학습이 흔히 겪는 "안정성-기동성 trade-off 충돌"을 회피하는 영리한 구조다.

8.4 안전 필터의 이중 역할

흥미로운 관찰: 안전 필터를 끄면 시뮬 성공률이 오히려 약간 오른다(85.3→87.0%). 이는 필터가 시뮬에서는 "지나치게 보수적"임을 뜻한다. 그럼에도 저자가 필터를 유지하는 이유는 실로봇 배포 안전 때문이다. 시뮬-실 격차를 고려한 현실적 설계 결정으로, "시뮬 지표 최대화"가 아니라 "실배포 안전"을 우선한 점은 평가할 만하다.

8.5 추론 비용과 온보드 실행 가능성 (Inference Cost)

추론 경로 연산량(대략):
  • CNN 인코더 × 3 그룹  : 각 8×8 입력 → 32-D, 매우 경량(수 μs급)
  • 융합 MLP φ           : 소형 (입력 ~수십 차원)
  • GRUCell (48-D)       : O(48²) ≈ 2.3K MAC/스텝, 무시 가능
  • 백본 MLP (512,256,128): 주 연산 (~200K MAC/스텝)
  • 안전 필터            : 레이캐스트 기반 단순 임계 연산

전체 추론은 작은 MLP+GRU 수준으로, GPU 없이 G1 온보드 CPU에서 실시간(12Hz 센서 주기 이상)으로 충분히 실행 가능하다. 학습은 8192 병렬 환경 × 1600 iteration의 대규모 GPU 작업이지만, 배포는 극히 가볍다 — "학습은 무겁게, 추론은 가볍게"라는 증류의 전형적 이점이다. 이것이 LP-NavOA가 저가 휴머노이드 플랫폼을 표적으로 삼을 수 있는 실질적 근거다.

8.6 시뮬-실 전이(Sim-to-Real) 격차 분석

전이 시 잠재 격차 요인:
  1. 레이캐스트 모사 vs 실 ToF 노이즈 : 실센서의 다중경로·결측이
                                       관측 분포를 흔들 수 있음
  2. dead-reckoning 드리프트          : 관절속도 적분 목표 추종은
                                       장거리에서 누적 오차 → odometry 변형이 더 강건
  3. 접촉 동역학(MuJoCo vs 실제)      : 발-지면 마찰·미끄럼 차이
  4. 안전 필터 보수성                 : 격차 흡수 버퍼로 의도적 유지

저자가 dead-reckoning(DR)과 odometry(Odom) 두 변형을 모두 제시한 것은 이 격차 인식의 산물이다. 실로봇에서 odometry가 더 신뢰되는 환경이라면 Odom 변형(시뮬 96.6%)이, 추가 센서가 없다면 DR 변형(88.0%)이 선택지가 된다 — 배포 유연성을 확보한 설계다.

9. 비교 분석 (Comparative Analysis)

같은 Planner 트랙에서 학습 기반 로컬 내비게이션 / 장애물 회피 / 실로봇 주제로 가장 인접한 선행 리뷰 세 편과 비교한다:

  • NeuPAN: Direct Point Robot Navigation with End-to-End Model-based Learning (RA-L, E2E 모델 기반 map-free)

  • IRRL: Incremental Residual Reinforcement Learning Toward Real-World Learning for Social Navigation (arXiv 2026, 잔차 RL 소셜 내비)

9.2 장단점 분석

LP-NavOA의 강점:
  + 휴머노이드 특화 — 백본 동결로 보행 안정성과 조향 지능을 깔끔히 분리
  + 극도로 제한된 인식(4m 레이캐스트)만으로 동작 → 저가 플랫폼 친화
  + GRU 순환으로 부분관측·희소목표 우회를 일관되게 처리
  + 강력한 절제 실험(원형명령/경로형성/교사강제) — 각 설계 결정의 근거 명확
  + 실 G1 배포로 시뮬-실 전이 가능성 입증

LP-NavOA의 약점:
  − 실로봇 정량 지표 부재 (SCAN-Planner의 Go2 정량 주행거리와 대비)
  − 코드 미공개(Coming Soon) → 즉시 재현 불가
  − 정적·단순 장애물(벽 2종)에 국한, 동적 환경 미처리
  − 4m 단거리 한계 — 더 먼 전역 계획 불가(순수 로컬)
  − 교사(웨이포인트/A*) 품질에 학생 성능 상한 종속

9.3 실적용 가능성 평가

적용 적합:
  ✓ 저가 ToF 센서만 장착한 휴머노이드의 실내 국소 내비게이션
  ✓ 지도 구축이 어려운 미지 실내에서 단순 장애물 우회
  ✓ 연속 조이스틱 없이 자율 우회-복원이 필요한 휴머노이드 데모

적용 부적합 / 주의:
  ✗ 동적·혼잡 환경(보행자) — IRRL/SCAN-Planner의 동적 처리 권장
  ✗ 장거리 전역 계획 필요 임무 (4m 로컬 한계)
  ✗ 안전 인증·정량 신뢰성 요구 (실로봇 통계 미보고)
  ✗ 즉시 재현·배포 (코드 Coming Soon)

NeuPAN이 "비휴머노이드 E2E 학습"의 성숙한 사례라면, LP-NavOA는 휴머노이드라는 불안정 플랫폼에 그 철학을 이식하면서 "백본 동결"이라는 안정성 보존 장치를 추가한 점이 차별적이다. SCAN-Planner가 기하학적 정밀 로컬 플래닝(정량 실로봇)으로 강하다면, LP-NavOA는 학습 기반 경량성·저센싱 친화성으로 강점이 있으나 실로봇 정량성에서 뒤진다.

트랙 분류 근거: LP-NavOA는 휴머노이드 로코모션(PPO 보행)을 포함하지만, 논문의 핵심 기여와 평가 지표가 "로컬 내비게이션 · 장애물 회피 · 목표 도달" 에 집중되어 있다(Table II/III의 모든 지표가 도달율·brush·충돌). 이는 본 코퍼스 Planner 트랙의 정의("경로 생성, 장애물 회피, 탐색 전략")에 정확히 부합한다. 보행 백본은 회피 조향을 실현하는 하위 수단일 뿐, 논문의 신규성은 조향 플래너(GRU)와 경로 형성 교사에 있다. 따라서 매니퓰레이션·로코모션 학습 그 자체가 목적인 논문(트랙 외)과 달리, 본 논문은 Planner 트랙으로 분류함이 타당하다. (NeuPAN·IRRL·SCAN-Planner 등 학습 기반 로컬 내비 선례가 이미 코퍼스 Planner 트랙에 등재되어 있어 일관적이다.)

9.5 종합 위치 평가

  검증 성숙도 :  NeuPAN ≈ SCAN-Planner > LP-NavOA > (코드 미공개 다수)
  아이디어 신선도: LP-NavOA(휴머노이드 분리 레시피) > NeuPAN(성숙) ≈ SCAN(기하)
  센싱 경제성  :  LP-NavOA(4m 레이캐스트) > NeuPAN > SCAN(3D LiDAR)
  플랫폼 난이도:  LP-NavOA(이족 휴머노이드) > SCAN(사족) > NeuPAN(차량/점로봇)

요컨대 LP-NavOA는 "가장 어려운 플랫폼(이족)에서, 가장 빈약한 센싱(4m)으로, 영리한 분리 학습 레시피" 를 보였다는 점에서 가치가 높으나, 검증 성숙도(정량 실로봇·코드)에서 선례들에 뒤처진다. 코드 공개와 정량 실로봇 평가가 이루어지면 휴머노이드 로컬 내비게이션의 유력한 레퍼런스가 될 것이다.

9.4 연구 방향성 평가

LP-NavOA의 기술적 참신성은 "원형 목표 명령으로 보행을 균일 학습 → 동결 → GRU 조향 증류" 라는 2단계 분리 레시피에 있다. 개별 요소(PPO 보행, GRU 플래너, DAgger류 교사 강제)는 각각 알려진 기법이지만, 이를 휴머노이드 안정성 보존이라는 제약 하에 조합하고 원형 명령이라는 백본 학습 트릭으로 고속 강건성을 확보한 통합이 기여다. 순수하게 새로운 알고리즘이라기보다 "잘 동작하는 시스템 통합 + 영리한 명령 설계" 에 가깝다. 향후 동적 환경·장기 메모리(Transformer/SSM)·정량 실로봇으로 확장하면 휴머노이드 로컬 내비게이션의 실용 표준이 될 잠재력이 있다.

11. 결론 (Conclusion)

LP-NavOA는 "전역 지도도 외부 플래너도 장거리 LiDAR도 없이, 단거리 레이캐스트만으로 휴머노이드가 장애물을 우회하며 목표에 도달한다" 는 도전적 목표를, 2단계 학습(PPO 보행 백본 + GRU 증류 조향 플래너)으로 달성한 시스템이다. 원형 목표 명령으로 3.0 m/s 강건 백본을 확보하고(완주율 99.51%), 이를 동결한 뒤 48-D GRU 조향 모듈을 동적 경로 형성 교사로 증류하여, 추론 시 완전 planner-free로 동작한다. 그 결과 시뮬레이션 목표 도달 성공률이 백본만의 3840%에서 8597%로 도약했고, 실 Unitree G1에서 0.281m 여유까지 우회-복원 조향을 정성적으로 시연했다.

혁신성: "안정성은 RL로 한 번 확실히 학습해 동결, 그 위에 조향 지능만 증류"하는 분리 레시피와, 전방향 강건 보행을 빠르게 얻는 원형 목표 명령 설계가 핵심 신규성이다. 부분관측·희소목표를 GRU 순환 메모리로 통합한 점도 휴머노이드 로컬 내비에 적절하다.

실용적 의의: 저가 단거리 센서만으로 동작하는 경량성은 비용에 민감한 휴머노이드 배포에 직접적 가치가 있다. 다만 실로봇 정량 지표 부재, 코드 미공개(Coming Soon), 정적·단순 장애물 한정, 4m 단거리 한계는 실용화의 분명한 장벽이다. SCAN-Planner(정량 실로봇)나 NeuPAN(공개·성숙)과 비교하면, LP-NavOA는 "휴머노이드 특화 통합 아이디어"는 신선하나 "검증·재현 성숙도"는 아직 낮다.

향후 연구: 동적 환경 확장, 정량 실로봇 평가(반복 시행·통계), 장기 메모리(Transformer/SSM) 도입, 그리고 무엇보다 코드 공개가 LP-NavOA를 데모에서 실용 표준으로 전환시킬 핵심 다음 단계다. "백본 동결 + 조향 증류"라는 분리 레시피는 다른 레그드 로봇(사족·이족)의 로컬 내비게이션에도 일반화될 잠재력이 충분하다.
