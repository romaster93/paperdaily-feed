1.2 연구 목표 (Research Objective)

NavWM은 목표 이미지 조건부 시각 내비게이션(image-goal visual navigation) 문제를, "세계 모델(world model)"을 단순한 미래 예측기가 아니라 폐루프 플래너(closed-loop planner) 로 작동시켜 해결하려 한다. 기존 시각 내비게이션 정책은 (a) 결정론적 단일 행동 출력에 의존해 근시안적(myopic) 의사결정과 모드 붕괴(mode collapse) 에 빠지고, (b) 세계 모델 계열은 지각(perception)·생성(generation)·제어(control)를 분리된 모듈로 다뤄 이들이 공유하는 시공간 동역학(spatio-temporal dynamics)을 포착하지 못한다.

NavWM의 핵심 주장은 다음과 같다: "잠재 세계 추론(latent world reasoning) + 멀티모달 행동 예측(multimodal action prediction) + 제어 가능한 시각 생성(controllable visual generation)을 하나의 통합 모델 안에서 결합하면, 생성형 세계 모델이 다양한 후보 경로를 가상으로 시뮬레이션(visual foresight)하여 목표에 가장 잘 정렬되는 경로를 선택하는 강건한 폐루프 플래너로 동작할 수 있다." 즉 NavWM은 후보 궤적의 다양성(diversity)을 명시적으로 확보한 뒤, 세계 모델이 그 다양성을 "평가·선별"하는 데 쓰이도록 설계되었다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

목표 이미지 조건부 시각 내비게이션은 다음과 같은 근본 난제를 안고 있다.

  1. 근시안성(myopia)과 모드 붕괴: 결정론적 정책(예: GNM, ViNT)은 분기점(intersection)에서 좌/우 두 경로가 모두 타당할 때 그 평균(직진)을 출력하는 평균화 문제를 겪는다. 멀티모달 분포를 단일 모드로 붕괴시키면 복잡 환경에서 비현실적 궤적이 나온다.
  2. 세계 모델 플래닝의 계산 비용: NWM(Navigation World Model)류는 미래를 예측(rollout)하고 그 위에서 비용을 최소화하는 CEM(Cross-Entropy Method) 플래닝을 쓴다. 그러나 매 스텝 수백~수천 행동 후보마다 비싼 비디오 디퓨전 rollout을 수행해 계산량이 폭발한다(동일 코퍼스의 NavWAM 측정 기준 NWM CEM은 행동 1회당 ≈14,521 TFLOPs).
  3. 지각·생성·제어의 분절(isolation): 깊이·의미 등 구조적 prior를 추출하는 모듈, 미래 영상을 합성하는 생성 모듈, 행동을 내는 제어 모듈이 따로 학습되면, 서로의 표현이 정합되지 않아 "그럴듯하지만 기하학적으로 근거 없는" 미래/궤적이 생긴다.
  4. 노출 편향(exposure bias): 세계 모델을 교사 강제(teacher forcing)로만 학습하면, 추론 시 자신이 예측한(불완전한) 궤적을 조건으로 받을 때 분포 이동(distribution shift)이 발생해 생성 품질이 급락한다.

2.2 핵심 해결책

NavWM은 네 가지 설계로 위 난제에 대응한다.

  • (C1→) 잠재 세계 추론(World Reasoning, WR): 학습 가능한 "Latent World Tokens"를 Bidirectional Mamba 백본에 prepend하고, CNN 디코더로 업샘플해 깊이/의미 맵을 예측·감독(Depth Anything V2 + SAM)하여 구조적 prior를 내재화.
  • (C1→) 앵커 기반 멀티모달 궤적 예측(Action Proposal, AP): K-Means + Farthest Point Sampling으로 만든 앵커 코드북에서 K개(≈7) 다양한 후보 목표·궤적을 생성해 모드 붕괴를 회피.
  • (C2→) 시각 예지 플래닝(Visual Foresight, World Model WM): Flow Matching 기반 Conditional Diffusion Transformer(CDiT)로 각 후보 행동에 대응하는 미래 관찰을 합성하고, 목표 정렬도로 최적 경로를 선택 — 세계 모델이 "고수준 감독 플래너"로 동작.
  • (C4→) 2단계 학습(teacher forcing → exposure bias correction): 1단계 공동 학습 후, 2단계에서 백본·궤적 헤드를 동결하고 예측 분포에서 샘플링한 궤적으로 CDiT를 미세조정해 노출 편향을 교정.

3. 핵심 방법론 (Core Methods)

NavWM은 단일 1.5B 파라미터 통합 모델로, 다음 식으로 추상화된다.

(1)   (T, O) ~ F_θ(· | O_c, o_t, o_g)
        O_c : 과거 4프레임 컨텍스트 (context window = 4)
        o_t : 현재 관찰
        o_g : 목표 이미지(goal image)
        T   : 예측 궤적(waypoint 시퀀스)
        O   : 예측 미래 관찰(future frames, horizon N = 4)

즉 하나의 분포 F_θ가 (행동 궤적 T)와 (미래 영상 O)를 공동(jointly) 생성한다. 아래 3개 모듈이 이 분포를 구성한다.

3.1 잠재 세계 추론 (Latent World Reasoning, WR)

Bidirectional Mamba(SSM) 백본이 VAE 인코딩된 과거 프레임·현재 관찰·목표 이미지를 입력받고, 그 앞에 학습 가능한 Latent World Tokens를 prepend한다. 이 토큰들은 CNN 디코더로 공간 업샘플되어 깊이(depth) 와 의미(semantic) 맵을 예측하며, 파운데이션 모델의 출력으로 감독된다.

Latent World Tokens ──prepend──► [VAE(O_c), VAE(o_t), VAE(o_g)]
        │                                  │
        │                          Bidirectional Mamba (SSM)
        │                                  │
   CNN Decoder ◄──── upsample ──── world feature H
        │
   ┌────┴────┐
   D̂(depth)  Ŝ(semantic)
   │           │
 supervise   supervise
 (Depth      (SAM)
  Anything
  V2)

깊이는 스케일 불변(scale-invariant) 손실, 의미는 MSE로 감독한다.

(2)   L_si  = (1/P) Σ_p g_p²  -  (λ/P²) (Σ_p g_p)²
              g_p = log D̂_p - log D_gt,p   (픽셀 p의 로그 깊이 잔차)
(3)   L_reason = λ_depth · L_si(D_gt, D̂)  +  λ_sem · L_mse(S_gt, Ŝ)

핵심 의도: 깊이/의미를 명시적 보조 과제(auxiliary task) 로 강제함으로써, 잠재 토큰이 단순 픽셀 재현이 아니라 기하·의미 구조를 압축한 표현을 학습하게 만든다. 이는 뒤따르는 행동 예측과 미래 생성 모두가 공유하는 "구조적 prior" 역할을 한다.

3.2 앵커 기반 멀티모달 궤적 예측 (Anchor-Based Multimodal Trajectory Forecasting, AP)

모드 붕괴를 막기 위해, NavWM은 자율주행 모션 예측에서 검증된 앵커(anchor) 기반 2단계 예측을 내비게이션에 도입한다.

오프라인 앵커 코드북 구축:

A ∈ ℝ^(K×2)   ← K-Means( ground-truth target 좌표 ) → Farthest Point Sampling
              (K개의 대표 목표점 = "어디로 갈 수 있는가"의 사전(prior))

Stage 1 — 앵커 정제(Intent + Control 헤드):

(4)   π̂  = Softmax( MLP_intent([H ∥ A]) )       # 각 앵커 채택 확률 ∈ ℝ^K
      ΔÂ = MLP_control([H ∥ A])                  # 앵커별 공간 오프셋 ∈ ℝ^(K×2)
      Ã  = A + ΔÂ                                 # 정제된 후보 목표 K개

여기서 H는 3.1의 세계 특징. Intent 헤드는 "어느 앵커가 그럴듯한가"를 분류하고, Control 헤드는 이산 앵커를 연속 좌표로 보정한다(분류+회귀 분리 = anchor-based regression의 표준 레시피).

Stage 2 — 목표 조건부 궤적 회귀:

      T̂_k = MLP_traj( H, Ã_k )    # 각 후보 목표 Ã_k에 대응하는 waypoint 시퀀스
      (타임스텝 간 조건부 독립 가정으로 한 번에 회귀)

손실(승자 앵커 k*만 회귀 감독 — winner-takes-all):

(5)   L_anchor = -log(π̂_{k*})                                  # 정답에 가장 가까운 앵커 분류
                 + L_huber(Δx̂_{k*}, Δx_gt) + L_huber(Δŷ_{k*}, Δy_gt)   # 오프셋 회귀
(6)   L_traj   = L_huber(T̂_{k*}, T_gt)                          # 궤적 회귀(Huber)
(7)   L_action = L_anchor + λ_traj · L_traj

이 설계의 효과는 정량적으로 확인된다(Table 4): GMM·Diffusion·Anchor 세 가지 멀티모달 헤드를 비교했을 때, Anchor 방식의 APD(Average Pairwise Distance, 궤적 다양성 지표)가 1.49 로 Diffusion(0.59)·GMM(0.31)을 압도하면서도, 동시에 항법 정확도(ATE 0.36)도 가장 낮다. 즉 "다양성과 정확도의 동시 달성"이 앵커 방식의 핵심 우위다.

3.3 Flow Matching 시각 예지 세계 모델 (Visual Foresight World Model, WM)

각 후보 궤적이 "실제로 어떤 미래를 낳는가"를 합성하기 위해, NavWM은 Conditional Diffusion Transformer(CDiT) 블록을 연속시간 Flow Matching으로 학습한다.

행동 궤적 T̂_k ──► dense optical flow field F  (행동을 광류장으로 변환)
                                │
                  adaLN(adaptive layer norm)으로 CDiT를 변조(modulate)
                                │
        latent 보간:  ẑ_τ = τ·z₁ + (1-τ)·z₀,   τ ∈ [0,1]
        네트워크는 벡터장 u_τ = z₁ - z₀ 를 회귀

시각 생성 손실(flow matching vector-field regression):

(8)   L_visual = E_τ [ || v_θ(z_τ, τ, F, H) - (z₁ - z₀) ||²₂ ]
        z₀ : 노이즈(또는 현재 잠재),  z₁ : 목표(미래) 잠재
        F  : 행동에서 유도된 광류 조건,  H : 세계 특징

행동을 광류(optical flow) 로 사상해 조건으로 주입하는 것이 핵심 트릭이다. 이는 "행동(저차원 제어)"과 "미래 영상(고차원 픽셀)" 사이의 추상화 간극을, 픽셀 이동량이라는 기하학적으로 근거 있는 중간 표현으로 메운다.

멀티태스크 가중(uncertainty weighting): 세 손실(추론·행동·생성)을 학습 가능한 과제 분산으로 자동 균형한다.

(9)   L = Σ_k [ ½·exp(-s_k)·L_k + ½·s_k ]    (s_k = log σ_k², 학습 파라미터)

이는 Kendall et al.의 동형 불확실성(homoscedastic uncertainty) 가중을 그대로 채택한 것으로, λ_depth·λ_sem·λ_traj를 수동 튜닝하지 않고 데이터가 자동 조정하게 한다.

3.4 폐루프 예지 플래닝 (Closed-Loop Foresight Planning)

추론 시 세계 모델은 "고수준 감독 플래너"로 동작한다.

   현재 o_t, 목표 o_g
        │
   ┌────▼─────────────────────────────────────────┐
   │ AP: K≈7개 후보 궤적 {T̂_1, …, T̂_K} 생성        │
   └────┬─────────────────────────────────────────┘
        │  각 후보마다 ↓
   ┌────▼─────────────────────────────────────────┐
   │ WM: T̂_k → flow F_k → CDiT → 미래 관찰 Ô_k 합성 │ ← "multiverse" 시뮬레이션
   └────┬─────────────────────────────────────────┘
        │
   ┌────▼─────────────────────────────────────────┐
   │ 목표 정렬도 평가: align(Ô_k, o_g) 최대 후보 선택  │
   └────┬─────────────────────────────────────────┘
        │
     최적 궤적 T̂_{k*} 실행 → 다음 스텝 재계획(폐루프)

NavWM은 "가능성들의 시뮬레이션된 멀티버스(simulated multiverse) 안에서 목표 정렬도를 평가해 최적 경로를 필터링한다"고 기술한다. 무작위 샘플링 대비 세계 모델 플래닝의 이득은 Table 2의 핵심 수치로 드러난다: 무작위 샘플링 0.63 SR(seen) → 세계 모델 플래너 사용 시 0.74 SR(seen), 0.44 SR(unseen). 즉 "다양한 후보를 만든 뒤 예지로 고른다"는 파이프라인이 실제 성공률을 끌어올린다.

3.5 2단계 학습으로 노출 편향 교정

[Stage 1] 100,000 step — 전 모듈 공동 최적화(teacher forcing)
          CDiT에 ground-truth 궤적을 조건으로 제공 → 안정적 수렴
                         │
                         ▼
[Stage 2]  50,000 step — SSM 백본 + 궤적 제안 헤드 동결(freeze)
          예측 분포에서 "샘플링된 궤적"으로 CDiT만 미세조정
          → 추론 시 자기 예측을 조건으로 받는 상황에 적응(exposure bias 해소)

Figure 4는 2단계 미세조정이 SSIM/PSNR/LPIPS 전반의 영상 재구성 품질을 유의하게 끌어올림을 보인다. 이는 시퀀스 생성 모델의 고전 문제(teacher forcing↔free running 간극)를 내비게이션 세계 모델에 맞춰 푼 실용적 처방이다.

3.6 왜 Bidirectional Mamba(SSM)인가 — 백본 선택의 함의

NavWM이 Transformer가 아닌 양방향 상태공간모델(SSM, Mamba) 을 공유 백본으로 택한 것은 단순한 유행 추종이 아니라 과제 구조와 맞물린 선택이다.

표준 self-attention:   O(L²)  토큰 길이 L에 제곱   (멀티프레임×멀티스트림이면 L 폭증)
Mamba(SSM) 스캔:       O(L)   선형 — 선택적 상태 전이로 장기 의존 압축

NavWM의 입력은 (과거 4프레임 + 현재 + 목표) × (VAE 패치 토큰) + Latent World Tokens로, 시퀀스 길이 L이 쉽게 커진다. SSM의 선형 복잡도는 이 멀티스트림 잠재열을 감당하는 데 유리하다. 또한 양방향(bidirectional) 스캔은, 항법 세계 모델이 "과거→현재"의 인과 흐름뿐 아니라 "목표 이미지 ↔ 현재 관찰"의 비인과적 정합(목표가 과거/현재 어디에 대응하는가)을 양방향으로 융합해야 하기에 자연스럽다. 즉 목표 토큰이 과거 컨텍스트 전체에 양방향으로 메시지를 전달하며 H를 형성한다. 다만 이로 인해 NavWM은 NavWAM(Cosmos DiT, 사전학습 비디오 prior 이식)과 달리 대규모 비디오 사전학습 가중치의 직접 이식 이점을 포기한다 — 백본을 내비게이션 데이터로 사실상 처음부터 정렬해야 하므로, 데이터 효율 면에서 NavWAM의 "2B 비디오 백본 + 커리큘럼" 노선과 상반된 베팅이다.

3.7 Flow Matching vs. DDPM — 왜 연속시간 벡터장 회귀인가

NavWM의 생성 모듈이 표준 DDPM(이산 노이즈 스케줄)이 아니라 Flow Matching(연속시간 벡터장 회귀) 을 택한 점도 분석할 가치가 있다.

DDPM:           ε_θ(x_t, t)로 노이즈 ε를 예측, 다단계 역확산(수십~수백 스텝)
Flow Matching:  직선 보간 ẑ_τ = τz₁+(1-τ)z₀ 위에서 벡터장 u_τ=z₁-z₀ 를 회귀
                → 직선 경로(rectified flow류)이므로 적은 적분 스텝으로 샘플링 가능

핵심 이점은 추론 가속이다. NavWM은 추론 시 K개 후보 각각에 대해 미래를 rollout해야 하므로(K배 생성 비용), 생성 1회의 적분 스텝 수를 줄이는 것이 전체 실시간성에 직결된다. 직선 보간 기반 flow matching은 동일 품질에서 DDPM보다 적은 스텝으로 샘플링되어, K-후보 예지 플래닝의 비용을 구조적으로 낮춘다. 또한 행동→광류 F→adaLN 변조라는 조건 주입 방식은, 광류가 "픽셀이 어디로 이동하는가"라는 결정론적 기하 신호이므로, 생성 모델이 자유롭게 미래를 환각하지 않고 행동에 인과적으로 종속된 미래만 그리도록 강하게 구속한다. 이는 WorldMAP이 지적한 "기하학적으로 근거 없는 미래" 문제를 NavWM이 조건 설계 수준에서 완화하는 장치다.

5.6 지표 해석 및 결과의 함의 (Metric Interpretation)

NavWM의 결과표는 항법 정확도(ATE/RPE/AOE)와 생성 품질(PSNR/SSIM/LPIPS/DreamSim)을 한 모델로 동시에 보고한다는 점에서 해석상 주의가 필요하다.

  • ATE↓와 PSNR↑의 동반 개선이 왜 비자명한가: 보통 생성 모델을 더 "그럴듯하게" 만들면(높은 PSNR), 모델이 관찰에 과적합해 행동 다양성이 줄고 분기점 성능이 떨어지는 경향이 있다. NavWM이 PSNR을 14.17→17.34로 올리면서 ATE를 0.302→0.207로 함께 낮춘 것은, 공유 특징 H가 "잘 그리는 능력"과 "잘 가는 능력"을 동시에 떠받친다는 통합 가설의 직접 증거다. Table 3에서 WM 단독(✓ on WR)이 PSNR을 16.627까지 올리지만 ATE는 AP 결합 시에만 0.254로 내려가는 패턴은, 생성 품질과 항법 정확도가 서로 다른 모듈에서 주로 기여하되 H를 통해 상승작용함을 보여준다.
  • Unseen 격차의 의미: NavWM의 Unseen SR 0.44는 절대값으로는 여전히 절반 이하다. image-goal 항법에서 미지 환경 일반화가 본질적으로 어렵다는 점(UniWM 0.36, NWM 0.23)을 감안하면 상대 개선은 크지만, 실배치 신뢰성 관점에서는 아직 부족하다. 이는 §8.2의 "실로봇 검증 부재"와 맞물려, NavWM이 벤치마크 SOTA와 실용 신뢰성 사이의 전형적 간극에 놓여 있음을 시사한다.
  • APD의 위상: APD(1.49)는 "다양성" 지표지만, 다양성 자체가 목적이 아니라 예지 평가가 고를 좋은 후보가 후보군에 존재할 확률을 높이는 수단이다. Table 4에서 APD가 낮은 GMM(0.31)이 WM 플래닝을 붙여도 ATE 0.79에 그친 것은, "평가기가 아무리 좋아도 후보 풀이 빈약하면 한계"라는 점 — 즉 생성(다양성)과 평가(예지)가 둘 다 필요함을 정량적으로 못박는다.

6. 핵심 기여점 (Key Contributions)

  1. 통합 내비게이션 세계 모델: 잠재 세계 추론·멀티모달 행동 예측·제어 가능 시각 생성을 단일 Mamba 백본의 공유 특징 H 위에서 결합. 지각·생성·제어의 분절을 하나의 표현으로 해소.
  2. 앵커 기반 멀티모달 궤적 예측의 내비게이션 이식: 자율주행 모션 예측의 anchor regression을 image-goal 항법에 도입, APD 1.49로 다양성을 확보하면서 정확도까지 최고를 달성(다양성-정확도 동시 최적화).
  3. Flow Matching CDiT 예지 플래너: 행동을 광류장으로 사상해 조건 주입, 연속시간 flow matching으로 고품질 미래(+3.17dB PSNR)를 합성하고 이를 폐루프 경로 선별에 활용.
  4. 노출 편향 교정 2단계 학습: teacher forcing(100k) → 예측 분포 샘플 미세조정(50k)으로 세계 모델 생성 품질을 안정화.
  5. SOTA 달성: 오프라인 ATE 0.207, image-goal SR seen 0.72 / unseen 0.44로 NWM·UniWM 등 최신 세계 모델 플래너를 전 지표에서 능가(ECCV 2026).

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

1.5B 규모는 동일 코퍼스 NavWAM(Cosmos 2B)과 비슷한 체급이지만, NavWM은 추론 시 K개 후보 각각에 CDiT rollout을 돌려 평가하므로, 추론 비용이 K에 선형 비례한다(K≈7). 이는 NWM의 CEM(수백~수천 후보)보다는 훨씬 싸지만, NavWAM처럼 행동을 직접 디퓨전하는 "플래너 제거" 노선(≈4.45 TFLOPs/행동, ~5Hz)보다는 무겁다. 즉 NavWM은 "소수의 다양한 후보 + 예지 평가"라는 중간 지점을 택했다.

8.2 한계점 (Limitations)

  • 실로봇 온라인 검증 부재: 오프라인 데이터셋 롤아웃만 — 실제 동역학·지연·센서 노이즈 하 폐루프 안정성 미검증.
  • 코드 미공개: 재현성 낮음. 앵커 코드북·flow 조건·2단계 스케줄 등 디테일이 많아 재현 난이도 높음.
  • 앵커 분포 의존성: 코드북이 학습 데이터 목표 분포에서 유도 → 분포가 크게 다른 환경에서 후보 다양성이 저하될 수 있음.
  • 언어 미지원: image-goal 전용. 자연어 지시 기반 VLN 과제(예: R2R)에는 직접 적용 불가(목표를 이미지로 줘야 함).
  • K개 rollout의 지연: 후보별 비디오 생성은 여전히 디퓨전 비용 — 온보드 실시간성은 미입증.

8.3 복잡도 분석 (Complexity)

추론 1스텝 비용 ≈ (Mamba 인코딩 1회) + (AP 헤드 1회) + (CDiT rollout × K). CDiT가 지배항이며 flow matching의 적분 스텝 수 × K에 비례. NavWM은 K≈7로 후보 수를 묶어 NWM(CEM)의 폭발적 비용을 회피하지만, NavWAM(플래너 자체 제거) 대비로는 K배의 생성 비용이 남는다. 이 "다양성↔실시간성" 트레이드오프가 본 설계의 핵심 위치.

8.5 실패 모드 추론 (Failure Modes)

논문이 실패 사례를 상세히 다루지 않으므로, 설계로부터 예상되는 실패 모드를 정리한다.

  • 앵커 커버리지 공백: 학습 분포에 없던 위상(예: 처음 보는 분기 구조)에서는 앵커 코드북이 유효 목표를 못 덮어, K 후보 전부가 차선책이 될 수 있다. APD가 높아도 "정답 모드"가 후보군에 없으면 예지 평가가 무의미하다.
  • 예지-실제 간극(foresight gap): CDiT가 합성한 미래 Ô_k가 실제 동역학과 어긋나면, "가장 목표 정렬된 후보"가 실제로는 충돌·이탈 경로일 수 있다. 오프라인 평가만으로는 이 간극이 드러나지 않으며, 실로봇 폐루프에서 누적될 위험이 크다(§5.4 한계와 직결).
  • 목표 정렬도 메트릭의 모호성: 논문은 선택 기준을 "목표 정렬도 평가" 이상으로 명시하지 않는다. 정렬도가 픽셀 유사도 기반이면, 시각적으로 비슷하나 위상적으로 다른 위치(예: 동일 복도의 반대편)를 혼동할 수 있다.
  • 노출 편향 잔존: 2단계 미세조정이 완화하나, 장기 지평(N=4 초과로 누적 rollout) 시 자기 예측 오차가 복리로 쌓일 수 있다.

8.4 향후 방향 (Future Directions)

  • 언어 조건 결합: 목표 이미지 대신/병행해 자연어 지시를 받아 진정한 VLN으로 확장(앵커 intent를 언어 그라운딩과 결합).
  • 온보드 증류: NavWAM식 distillation으로 K-후보 예지 플래닝을 단일 정책으로 증류해 실시간 실로봇 배치.
  • 적응적 K: 분기 복잡도에 따라 후보 수를 동적으로 조절(개활지 K↓, 분기점 K↑)해 비용-성능 균형.

9.2 장단점 분석

NavWM의 강점:

  • 다양성과 정확도의 동시 달성: 앵커 헤드가 APD 1.49로 Diffusion/GMM을 압도하면서 ATE도 최저 — "모드 붕괴 회피"를 정량으로 입증한 드문 사례.
  • 생성-항법 동반 향상: PSNR +3.17dB와 ATE −31%를 동시에 — 통합 표현 H 공유의 실익.
  • 예지 평가의 일반화 효과: Unseen SR에서 NWM 대비 +21%p로 미지 환경 강건성이 두드러짐.

NavWM의 약점(상대적):

  • 실로봇 부재: NavWAM이 실 Jetson에서 79.2%를 보인 것과 대비해, NavWM은 오프라인 롤아웃에 머문다 — "플래너로서의 세계 모델"이 실제 폐루프 동역학에서도 통하는지는 미검증.
  • 추론 비용: NavWAM의 플래너 제거(≈4.45 TFLOPs/행동) 노선보다 K배 무거움. WorldMAP의 경량 학생(단일 추론)보다도 무겁다.
  • 언어 미지원: WMNav·WorldMAP이 언어/지시를 다루는 반면 NavWM은 image-goal 전용.

9.3 실적용 가능성 평가

현재로서는 연구 프로토타입 단계다. NavWAM이 "플래너를 정책으로 증류해 임베디드 실시간"을 이미 달성한 점을 고려하면, NavWM의 K-후보 예지 플래닝은 실로봇 적용 전 증류·가속이 선결 과제다. 다만 NavWM의 앵커 멀티모달 + 예지 선별 구조는, NavWAM의 "value 모드 후보 재정렬"과 결합하면(다양한 앵커 후보를 값으로 빠르게 재정렬) 상호 보완적일 수 있다. WorldMAP식 교사-학생 증류를 NavWM의 K-후보 평가 결과에 적용하면, 온라인 rollout 없이도 "예지가 고른 경로"를 학생에 이식하는 길이 열린다.

9.4 연구 방향성 평가 (트랙 분류 근거 포함)

트랙 분류: NavWM은 자연어 지시를 받지 않는 image-goal 시각 내비게이션이지만, 본 코퍼스의 VLN 트랙은 이미 NavWAM(image-goal), NavDP(image/point-goal), WMNav(object-goal) 등 언어 비의존 시각 내비게이션을 포함하는 광의의 "Navigation" 트랙으로 운용되고 있다. 따라서 NavWM도 VLN 트랙에 배치하여 NavWAM·WorldMAP·WMNav와 직접 비교하는 것이 코퍼스 정합성과 비교 유용성 측면에서 타당하다.

방향성: 세계 모델을 "플래너"로 쓰는 NavWM과 "플래너를 없애는" NavWAM은 정반대 설계 철학을 보여준다. NavWM은 다양성·해석가능성(어떤 후보를 왜 골랐는지 예지로 설명 가능)에서, NavWAM은 효율·실시간성에서 우위다. 두 노선의 수렴점(다양한 후보를 싸게 평가)이 차세대 내비게이션 세계 모델의 핵심 연구 축이 될 것이다.

9.5 NavDP와의 위치 비교 및 베이스라인 계보 분석

NavDP(ICRA 2026, 동일 코퍼스) 는 diffusion 기반 궤적 생성 + critic 함수를 결합해 시뮬에서 학습 후 다양한 로봇 플랫폼으로 zero-shot 전이하는 E2E 항법 정책이다. NavDP는 "critic으로 궤적을 채점"하는 반면, NavWM은 "세계 모델 rollout으로 궤적을 채점"한다. 둘 다 "후보 생성 + 평가"라는 공통 골격이지만, 평가 신호가 학습된 스칼라 critic(NavDP, 싸고 빠름)이냐 생성된 미래 영상(NavWM, 비싸지만 해석 가능)이냐가 갈린다. NavDP가 zero-shot 크로스-플랫폼 전이를 핵심 강점으로 내세운 것과 달리, NavWM은 플랫폼 전이보다 환경 일반화(seen→unseen) 와 생성 품질을 전면에 둔다.

베이스라인 계보: NavWM이 비교한 베이스라인은 세 계보로 정리된다.

(a) 순수 정책 계열:   GNM → ViNT → NoMaD   (결정론/diffusion 정책, 세계모델 없음)
(b) 세계 모델 계열:   NWM → UniWM          (미래 예측 + 그 위 플래닝)
(c) 통합 생성 계열:   Anole-7B, Diamond    (대형 생성/멀티모달)

NavWM의 직접 경쟁자는 (b)다. NWM(CEM 플래닝, 비쌈)과 UniWM(통합 세계 모델)을 전 지표에서 앞선 것이, NavWM이 "세계 모델을 플래너로 쓰는" 계보 안에서의 SOTA임을 뒷받침한다. 특히 UniWM 대비 PSNR +3.17dB·Unseen SR +8%p는 "앵커 멀티모달 + flow matching"이라는 두 축의 기여를 분리해 보여준다(Table 4가 이를 절제로 확증). 반대로 (a)의 NoMaD(diffusion 정책)가 ATE 1.070에 머문 것은, "세계 모델 없는 다양성"만으로는 부족하고 예지 평가가 결합되어야 정확도가 따라옴을 방증한다.

11. 결론 (Conclusion)

NavWM은 "세계 모델은 미래를 예측만 하는가, 아니면 직접 길을 고르는가?"라는 질문에 "고른다" 로 답한 작업이다. 핵심 혁신은 (1) 앵커 기반 멀티모달 궤적 예측으로 모드 붕괴를 정량적으로 회피(APD 1.49)하고, (2) Flow Matching CDiT로 각 후보의 미래를 고품질로 합성(+3.17dB)하여, (3) 이 "시뮬레이션된 멀티버스"에서 목표 정렬도로 최적 경로를 폐루프 선별한 데 있다. 그 결과 오프라인 ATE 0.207·image-goal SR seen 0.72/unseen 0.44로 NWM·UniWM 등 최신 세계 모델 플래너를 전 지표에서 앞섰다.

실용적 의의는 분명하되 경계가 있다: NavWM은 다양성·해석가능성·미지 환경 강건성에서 강점을 보이지만, 실로봇 온라인 검증과 코드 공개 부재, 그리고 K-후보 rollout의 추론 비용이 실적용의 관문이다. 동일 코퍼스의 NavWAM이 "플래너를 정책으로 증류해 실시간 실로봇"을 이미 입증한 만큼, NavWM의 다음 과제는 명확하다 — 예지 플래닝의 증류·가속과 언어 조건 확장. 두 방향이 결합되면, "다양한 후보를 싸게 시뮬레이션해 고르는" 진정한 실시간 내비게이션 세계 모델에 한층 가까워질 것이다.
