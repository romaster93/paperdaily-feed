1.2 연구 목표 (Research Objective)

이 논문은 "포토리얼리스틱하지만 무거운 3D Gaussian Splatting(3DGS) 장면을, 자원 제약이 심한 온보드 하드웨어에서 증명 가능하게 안전한(provably safe) 실시간 경로 계획에 쓸 수 있는 가벼운 표현으로 바꿀 수 있는가" 라는 문제를 푼다.

3DGS·NeRF 같은 radiance field는 장면을 고충실도로 복원하지만, 수백만 개의 가우시안 타원체(ellipsoid)로 이루어져 있어 메모리·연산이 모두 과중하다. 마이크로컨트롤러급 드론(예: Crazyflie)에서 이 표현을 직접 충돌 회피에 쓰는 것은 비현실적이다. 한편 안전 계획에서는 장애물을 보수적으로(conservatively) 과대근사(over-approximate) 해야 충돌이 없음을 보장할 수 있는데, 원본 3DGS를 그대로 줄이면 이 과대근사 성질이 깨질 수 있다.

PolyMerge의 핵심 아이디어는 "3DGS 장애물을, 그 합집합이 원본의 모든 장애물을 증명 가능하게 포함(over-approximate) 하는 소수의 볼록 다면체(convex polytope) 집합으로 압축한다" 는 것이다. 구체적으로:

  1. 복셀화 + 가중 집합 덮개(greedy weighted set cover): 3DGS를 복셀 점유로 환산하고, 점유 복셀을 덮는 볼록 다면체를 탐욕적으로 선택.
  2. 병합 이력 재생(merge-history replay): 응집 군집화(agglomerative clustering)로 다면체를 병합하되 전체 병합 이력을 저장 → 재압축 없이 임의의 다면체 개수로 장면을 즉시 재구성(보수성↔연산 비용 trade-off 튜닝).
  3. CBF 안전 필터: 각 다면체를 제어 장벽 함수(Control Barrier Function, CBF)로 인코딩하여, 단일 적분기(single-integrator) 에이전트가 CLF로 목표를 향하면서 CBF로 충돌을 형식적으로 회피.

결과적으로 mip-NeRF360 9개 장면에서 SaferSplat 대비 메모리를 최대 10×(473.6–718.7MB → 8.5–67.3MB) 줄이고 시뮬 런타임을 ~100× 가속하며, 실제 Crazyflie 드론에서 실시간(125–500Hz) 안전 비행을 달성한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

C1. radiance field의 자원 과중. 3DGS는 장면을 100만~160만 개 타원체로 표현(473.6–718.7MB). 마이크로컨트롤러급 온보드에서 이를 매 제어 주기마다 충돌 질의에 쓰는 것은 메모리·연산 모두 불가능.

C2. 과대근사(보수성) 보장의 필요성. 안전 계획에서는 장애물을 빠짐없이 덮어야(under-approximation 금지) 충돌-없음을 보장한다. 단순히 가우시안 수를 줄이면 빈틈이 생겨 "안전 보장"이 무너진다. 압축하면서도 합집합이 원본 장애물을 포함함을 증명해야 한다.

C3. 보수성 ↔ 연산 비용의 trade-off. 다면체를 적게 쓰면 가볍지만 과대근사가 커져(불필요하게 공간을 막아) 경로가 막히고, 많이 쓰면 정밀하지만 무겁다. 이 trade-off를 배포 시점에 유연하게 조절할 수 있어야 한다(매번 재압축은 비현실적).

C4. 미분가능·실시간 안전 질의. 온보드 제어 루프(수백 Hz)에서 장애물까지의 안전 여유를 미분가능하게(그래디언트 기반 QP) 평가해야 한다. 임의 형상이면 이 질의가 느리다.

C5. 형식적 안전 보장(provable safety). 휴리스틱 회피가 아니라, 전방 불변성(forward invariance)으로 충돌하지 않음을 수학적으로 보장해야 한다.

2.2 핵심 해결책

  • C1 → 3DGS를 수백~수천 개 볼록 다면체로 압축(최대 10× 메모리 절감, ~100× 런타임 가속).
  • C2 → 가중 집합 덮개의 weight가 과대근사 부피(wasted volume) 를 측정하고, 합집합이 모든 점유 복셀을 덮도록 제약 → 합집합이 원본 장애물을 증명 가능하게 over-approximate.
  • C3 → 병합 이력을 저장해 재압축 없이 임의 다면체 개수 n으로 즉시 재구성.
  • C4 → 다면체용 장벽 함수 ψ(p)=min_k max_l n_kl^T(p−w_kl)는 폐형(closed-form)·미분가능 → QP 안전 필터에 직결.
  • C5 → CBF 전방 불변성으로 충돌-없음을 형식적으로 보장.

3. 핵심 방법론 (Core Methods)

표기 (Notation)
  𝒢            : 원본 3DGS 모델(가우시안 타원체 집합)
  𝒳_unsafe^GS  : 3DGS가 정의하는 장애물(불안전) 영역
  ℋ = {H_k}    : 선택된 볼록 다면체 집합 (각 H_k = 반공간 교집합)
  𝒞_v          : 한 복셀 그룹/클러스터(다면체 후보의 정점 집합)
  ψ(p)         : 다면체 장애물 장벽 함수 (양수=안전)
  B            : 다면체 예산(개수 상한)
  n            : 배포 시 사용하는 다면체 개수(병합 이력에서 선택)

3.1 3DGS → 복셀 점유 → 가중 집합 덮개 (Compression)

1) 복셀화(voxelization). 3DGS .ply를 복셀 격자(기본 grid_size = 0.1 m)로 이산화한다. 복셀의 점유 판정은 겹치는 가우시안 수 ≥ k(기본 k = 2)일 때 occupied. (k로 노이즈성 단일 가우시안 floater를 걸러내 견고성 확보.)

2) 탐욕적 가중 집합 덮개(greedy weighted set cover, Eq. 11). 점유 복셀 전체를 덮는 볼록 다면체들을 탐욕적으로 선택한다. 각 후보 다면체의 가중치는 과대근사 부피(wasted volume) 를 측정:

W(𝒞_v) = Vol( Hull(𝒞_v) \ {occupied voxels} )      # (Eq. 11)
         = 다면체가 "장애물 아닌 공간"까지 덮어버린 부피

즉 적은 다면체로, 빈틈 없이(coverage), 헛되이 막는 공간은 최소로 덮는 것이 목표다. 이는 NP-hard 집합 덮개의 표준 탐욕 근사로 푼다.

3) 과대근사 최적화 문제(over-approximation guarantee). 전체 목표는 보수성(헛부피)을 최소화하되 모든 장애물을 덮고 예산 B를 지키는 것:

min_ℋ   L(ℋ) = Vol( (∪_{H_k∈ℋ} H_k) \ 𝒳_unsafe^GS )   # 헛부피(보수성)
s.t.    𝒳_unsafe^GS ⊆ ∪_{H_k∈ℋ} H_k                     # 커버리지(과대근사 보장)
        |ℋ| ≤ B                                          # 다면체 예산

핵심: 커버리지 제약이 합집합 ⊇ 원본 장애물을 강제하므로, 압축 후에도 "장애물을 빠뜨리지 않는다"는 안전 성질이 증명 가능하게 보존된다(C2 해소). 목적함수는 그 보장을 지키면서 헛부피만 줄인다.

3.2 응집 군집화 + 병합 이력 재생 (Merge-History Replay)

집합 덮개로 얻은 다면체들을 응집 군집화(agglomerative clustering) 로 점진 병합한다. 핵심 설계는:

"The full merge history is saved, so the scene can be reconstructed
 at any polytope count without recompressing."

즉 매 병합 단계(다면체 개수 N → N−1)를 이력으로 저장해 두면, 배포 시 원하는 개수 n을 골라 재압축 없이 즉시 그 해상도의 장면을 복원할 수 있다. 이로써 C3(보수성↔비용 trade-off)를 온라인 튜닝 파라미터 하나(n)로 환원한다. 적은 n = 가벼움·보수적, 많은 n = 정밀·무거움.

   다면체 개수      특성                     드론 제어 주파수(실측)
   n=10            가장 가벼움/보수적        500 Hz
   n=30~50         균형                      250 Hz
   n=100           정밀                      167 Hz
   n=150           가장 정밀/무거움          125 Hz

3.3 다면체 장벽 함수 + CLF-CBF 항법 (Safe Navigation)

다면체 장벽 함수(Eq. 3). 각 볼록 다면체 H_k는 반공간들의 교집합 H_k = {p : n_kl^T(p−w_kl) ≤ 0, ∀l∈Λ_k} 이다. 점 p가 모든 장애물 다면체 밖에 있으면 안전. 이를 하나의 폐형 장벽으로:

ψ(p) = min_{k∈K} max_{l∈Λ_k} n_kl^T (p − w_kl)        # (Eq. 3)
  • 안쪽(한 다면체 내부)이면 그 다면체의 모든 면 값 ≤0 → max ≤0 → 위험.
  • 밖이면 적어도 한 면이 양수 → max>0; 모든 다면체에 대해 min>0 → ψ(p)>0 ⟺ 안전.
  • max/min은 코드에서 CBF_KAPPA=100의 softmax/softmin으로 평활화(미분가능, C4 해소).

제어 리아푸노프 함수(CLF, Eq. 16) — 목표 도달. 단일 적분기 ẋ = u에 대해 V(x) = ½‖x − x_goal‖². 명목 제어는:

u_nom = argmin ½‖u‖²   s.t.   L_f V + L_g V·u ≤ −c·V(x)      # (Eq. 16)

(코드: CLF_GAMMA = 1.5가 수렴률 c.)

제어 장벽 함수(CBF, Eq. 17) — 안전 필터. 명목 제어를 최소 수정해 안전 제약을 강제:

u* = argmin ½‖u − u_nom‖²   s.t.   L_f ψ_r + L_g ψ_r·u ≥ −β·ψ_r(x)   # (Eq. 17)

이는 집합 {x : ψ_r(x) ≥ 0}의 전방 불변성을 보장 — 즉 안전 영역에서 출발하면 영원히 안전(C5 해소). (코드: CBF_ALPHA=2.0이 β, CBF_B=10 바이어스, 에이전트 반경 CBF_RADIUS=0.05 m, DELTA_T=0.01.)

전체 항법은 매 스텝 위 QP 두 개(CLF로 목표 방향 → CBF로 안전 투영)를 푸는 CLF-CBF-QP 구조다.

4. 시스템 아키텍처 (System Architecture)

                        PolyMerge 전체 파이프라인
┌──────────────────────────── 오프라인 (압축) ────────────────────────────┐
│  3DGS .ply (100만~160만 타원체, 473~719MB)                                 │
│        │ 복셀화 (grid 0.1m, k≥2 점유)                                      │
│        ▼                                                                   │
│  점유 복셀 격자                                                            │
│        │ 탐욕적 가중 집합 덮개  W(𝒞_v)=Vol(Hull\occupied)  (Eq.11)         │
│        ▼                                                                   │
│  볼록 다면체 집합 ℋ  (합집합 ⊇ 장애물, 과대근사 보장)                       │
│        │ 응집 군집화 + 병합 이력 전체 저장                                  │
│        ▼                                                                   │
│  병합 이력 (N, N-1, ..., 1 모든 해상도)  ─── compressed.pkl                │
└───────────────────────────────────────────────────────────────────────────┘
                                  │  배포 시 n 선택 (재압축 불요)
                                  ▼
┌──────────────────────────── 온라인 (항법, 온보드) ───────────────────────┐
│  n개 다면체 로드 (예: Crazyflie)                                           │
│  매 스텝 (dt=0.01):                                                        │
│    ψ(p)=min_k max_l n_kl^T(p−w_kl)  (Eq.3, KAPPA=100 평활)                  │
│    CLF-QP:  u_nom ← min ½‖u‖²  s.t. L_fV+L_gV u ≤ −cV   (목표, GAMMA=1.5)   │
│    CBF-QP:  u*   ← min ½‖u−u_nom‖² s.t. L_fψ+L_gψ u ≥ −βψ (안전, ALPHA=2)   │
│    x ← x + u*·dt                                                           │
│  → 실시간 충돌-없는 궤적 (125~500 Hz, n에 따라)                            │
└───────────────────────────────────────────────────────────────────────────┘

데이터 흐름 요약: 무거운 3DGS → (오프라인) 가벼운 다면체 + 병합 이력 → (온라인) n 선택 → CLF-CBF-QP 실시간 안전 항법. 안전 보장(과대근사)은 압축 단계의 커버리지 제약에서, 실시간성은 다면체의 폐형 장벽에서 나온다.

  • 시뮬레이션: mip-NeRF360 9개 장면 — 실외 5개(Bicycle, Flowers, Garden, Stump, Treehill) + 실내 4개(Room, Counter, Kitchen, Bonsai).

  • 최소 여유(Min. Clearance, m) — 궤적의 다면체 장면까지 최소 부호거리.

5.4 리얼월드 실험 (Real-world Experiments)

본 논문은 실제 Crazyflie 2.1+ 마이크로 드론 비행을 포함한다(코퍼스 1순위 가치 충족).

  • 후프·장애물 실내 환경에서 PolyMerge 다면체로 실시간 CLF-CBF-QP 항법.
  • 극심한 온보드 연산 제약 하에서도 n을 낮춰(예: n=10, 500Hz) 실시간 안전 비행을 달성하며, 속도에서 베이스라인을 능가하면서 안전을 보장.
  • 다면체 개수 n을 바꿔가며(10~150) 보수성-실시간성 trade-off를 실기에서 직접 검증.

5.5 비교/어블레이션 요약 (Comparison Highlights)

  • vs SaferSplat: SaferSplat은 full 3DGS 타원체에 직접 CBF를 거므로 정밀하지만 무거움(473~719MB). PolyMerge는 동일 안전 보장을 유지하면서 10× 가볍고 ~100× 빠름.
  • vs SuGaR+CoACD: 메시 추출 후 볼록 분해는 PolyMerge와 메모리대는 비슷하나(1.8~13.5MB), 과대근사(안전 over-approximation) 보장이 없고 메시 품질에 민감. PolyMerge는 커버리지 제약으로 안전을 형식 보장.
  • n 스윕(ablation): n↑ → 여유↓(덜 보수적)·주파수↓(무거움), n↓ → 보수적·고속. 병합 이력 덕에 이 스윕이 재압축 없이 가능.

6. 핵심 기여점 (Key Contributions)

  1. 3DGS의 안전-보존 압축(safety-preserving compression). radiance field를, 합집합이 원본 장애물을 증명 가능하게 과대근사하는 소수의 볼록 다면체로 줄이는 최초의 정식 프레임워크. 가중 집합 덮개의 weight가 헛부피(보수성)를 직접 측정하고, 커버리지 제약이 안전 보장을 강제한다. → 압축과 안전이 분리되지 않고 한 최적화로 결합.

  2. 병합 이력 재생(merge-history replay)으로 trade-off의 온라인 튜닝. 응집 군집화의 전체 병합 이력을 저장해, 배포 시 다면체 개수 n을 골라 재압축 없이 보수성↔연산비용을 조절. 동일 장면을 다양한 하드웨어 예산에 즉시 맞춤. 이는 단순 "압축률 하나 고정"을 넘어선 실용적 기여.

  3. 다면체 폐형 장벽 + CLF-CBF-QP 실시간 안전 항법. ψ(p)=min_k max_l n_kl^T(p−w_kl) 폐형·미분가능 장벽을 CBF 안전 필터에 직결하여, 전방 불변성으로 충돌-없음을 형식 보장하면서 마이크로 드론에서 125–500Hz 실시간 달성.

  4. 자원 제약 하드웨어에서의 실증. mip-NeRF360 9장면 시뮬 + 실제 Crazyflie 2.1+ 비행. 메모리 최대 10× 절감, 시뮬 ~100× 가속, 전 장면 최고 성공률. radiance-field 안전 계획이 실제 마이크로 드론에서 돈다는 것을 보였다.

  5. 오픈소스 구현. github.com/trustworthyrobotics/PolyMerge에 압축(compress.py)·CBF(cbf.py)·롤아웃(rollout.py)·벤치마크 스크립트를 Python으로 공개 → 재현성 확보.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

  • 장면 규모: mip-NeRF360 실외 대형 장면까지 압축(4543,296 다면체). 다면체 수는 장면 복잡도에 따라 선형 증가, 메모리는 8.567.3MB로 온보드 친화적.
  • 하드웨어 이식성: 병합 이력 덕분에 동일 압축 산출물을 다양한 컴퓨트 예산(고성능 GPU~마이크로컨트롤러)에 n만 바꿔 배포. 재압축 비용 0.
  • 차원/동역학: 단일 적분기 3D에서 검증. 고차 동역학(쿼드로터 완전 동역학, 가속도 입력)으로의 확장은 CBF의 상대차수(relative degree) 처리(HOCBF)가 필요 — 향후 과제.

8.2 한계점 (Limitations)

  1. 정적 장면 가정. 3DGS는 정적 복원이므로 동적 장애물(움직이는 사람/물체)은 직접 다루지 않는다. 실시간 3DGS 갱신·동적 CBF 결합이 미해결.
  2. 단일 적분기 동역학. 항법 검증이 1차 적분기 기반 — 실제 쿼드로터의 비선형·언더액추에이티드 동역학을 완전히 반영하진 않음(추적 제어와의 분리).
  3. 과대근사의 보수성. 안전 보장의 대가로 다면체 합집합이 자유공간을 일부 막아, 좁은 통로에서 경로가 막힐 수 있음. n↑로 완화되나 연산 비용 증가.
  4. 압축 오프라인. 집합 덮개·군집화는 오프라인 단계 — 온라인 SLAM처럼 장면을 실시간 구축하며 압축하는 시나리오는 미지원.
  5. 3DGS 품질 의존. 입력 3DGS에 floater/노이즈가 많으면(k 임계로 일부 완화되나) 헛부피가 커져 보수성↑.

8.3 향후 방향 (Future Directions)

  • 동적 환경: 시간가변 다면체 + HOCBF로 이동 장애물 회피.
  • 완전 동역학: 쿼드로터 비선형 동역학에 직접 CBF(상대차수 보정) 적용.
  • 온라인 압축: 탐사 중 3DGS를 증분 구축하며 병합 이력 갱신.
  • 멀티에이전트: 다면체 장면 공유 + 분산 CBF로 군집 비행 안전.

9.2 장단점 분석

PolyMerge의 강점.

  • 압축 + 형식 안전의 결합: SafeNavNeRF는 NeRF로부터 안전 기하를 뽑되 표현이 무겁고 시뮬만, PolyMerge는 가벼우면서도 CBF로 형식 보장하고 실기 검증.
  • 배포 유연성: 병합 이력 재생은 선행 연구 어디에도 없는 차별점 — 같은 산출물을 하드웨어별로 즉시 맞춤.
  • 탑티어 + 오픈소스 + 하드웨어: 코퍼스 1·2·3순위 기준(코드·실로봇·탑티어)을 모두 충족하는 드문 사례.

약점/상대적 한계.

  • 정적·단일적분기: AgiPIX는 실제 UAV 완전 동역학으로 비행하지만 PolyMerge 항법 검증은 단일 적분기. ReliaDiffNav는 지각 신뢰성(유리·거울 등 센서 실패)을 1급으로 다루나 PolyMerge는 3DGS가 정확하다고 가정.
  • 보수성 비용: SafeNavNeRF의 도달집합도 보수적이듯, PolyMerge 과대근사도 좁은 공간을 막을 수 있음.

9.3 실적용 가능성 평가

  • 온보드 적합성 최상: 8.567.3MB·125500Hz는 마이크로 드론에서 실제로 돌아가는 수치(코퍼스 내 radiance-field 계열 중 가장 경량). SafeNavNeRF(NeRF 질의)·SaferSplat(타원체 직접)는 이 급에서 비현실적.
  • 파이프라인 호환: 입력이 표준 3DGS .ply라 기존 3DGS 복원 파이프라인에 바로 접속. ReliaDiffNav처럼 별도 신뢰도 증류 학습이 불필요.
  • 즉시 사용 가능한 코드: 압축~벤치마크 스크립트 공개로 재현·확장 용이.

9.4 연구 방향성 평가

  • 기술적 참신성: "radiance field → 안전-보존 볼록 덮개 + 병합이력 튜닝"은 SafeNavNeRF의 "NeRF→도달집합" 계열과 구별되는 새 접근(중복 아이디어 아님). 집합 덮개의 weight를 과대근사 부피로 정의해 압축과 안전을 한 목적함수에 융합한 점이 핵심 신규성.
  • 상보성: ReliaDiffNav의 지각 신뢰성(센서 실패 영역 가상 장애물화)과 PolyMerge의 안전-보존 압축을 결합하면 "신뢰 불가 영역까지 보수적으로 덮는 경량 다면체 장면" 같은 후속이 자연스럽다.

11. 결론 (Conclusion)

PolyMerge는 "포토리얼리스틱 3DGS를, 마이크로 드론에서 형식적으로 안전하게 쓸 수 있는 가벼운 볼록 다면체로 압축" 하는 문제에 대해, 압축(가중 집합 덮개)·안전(과대근사 커버리지 제약)·배포 유연성(병합 이력 재생)·실시간 항법(다면체 폐형 CBF)을 한 파이프라인으로 묶은 완결적 시스템이다.

혁신성. 집합 덮개의 가중치를 과대근사 부피로 정의해 "압축률"과 "안전 보장"을 분리된 두 목표가 아닌 하나의 최적화로 융합한 점, 그리고 병합 이력으로 보수성↔연산비용 trade-off를 배포 시점 파라미터 n 으로 환원한 점이 핵심 신규 기여다. 이는 NeRF→도달집합(SafeNavNeRF) 계열과 명확히 구별된다.

실용적 의의. 메모리 최대 10×·시뮬 ~100× 절감으로 radiance-field 기반 안전 계획을 실제 Crazyflie 마이크로 드론에서 125–500Hz로 구동했다. 표준 3DGS .ply 입력 + 오픈소스 구현 + RA-L 탑티어로, 코퍼스의 코드·실로봇·탑티어 기준을 모두 충족하는 즉시 활용 가능한 연구다.

향후 연구. (1) 동적 장애물(시간가변 다면체 + HOCBF), (2) 쿼드로터 완전 비선형 동역학 직접 CBF, (3) 탐사 중 온라인 증분 압축, (4) 멀티에이전트 분산 CBF. ReliaDiffNav의 지각 신뢰성과 결합한 "신뢰 불가 영역까지 보수적으로 덮는 경량 안전 장면" 방향도 유망하다.

부록 A. 심화 분석 — 가중 집합 덮개가 보장하는 것

왜 과대근사가 안전을 보장하는가. 충돌-없음은 "에이전트가 자유공간 𝒳_free에 머문다"는 것이다. 만약 압축 표현이 장애물을 과소근사하면(빈틈), 실제 장애물이 자유공간으로 잘못 분류되어 CBF가 통과를 허용 → 충돌. PolyMerge는 커버리지 제약

𝒳_unsafe^GS ⊆ ∪_k H_k

로 압축된 장애물(다면체 합집합)이 원본 장애물을 포함함을 강제한다. 따라서 ψ(p)>0(모든 다면체 밖)이면 p ∉ ∪H_k ⊇ 𝒳_unsafe → p는 실제로도 안전. 이 포함관계가 압축 후에도 충돌-없음 보장을 보존하는 수학적 근거다. 목적함수 L(ℋ)는 이 보장을 깨지 않으면서 헛부피만 줄이므로, "안전을 지키되 덜 보수적으로"가 정확히 구현된다.

탐욕 근사의 타당성. 가중 집합 덮개는 NP-hard지만, 탐욕 알고리즘은 최적 대비 O(log n) 근사를 보장(고전 결과). 여기서 "원소"는 점유 복셀, "집합"은 후보 다면체가 덮는 복셀, "비용"은 헛부피 W(𝒞_v)다. 매 단계 비용 대비 새로 덮는 복셀 수가 최대인 다면체를 선택 → 커버리지를 채우면서 헛부피를 억제.

부록 B. CLF-CBF-QP 한 스텝 의사코드

def step(x, x_goal, polytopes, radius=0.05, dt=0.01,
         gamma=1.5, alpha=2.0, kappa=100.0):
    # --- CLF: 목표 도달 명목 제어 ---
    V   = 0.5 * norm(x - x_goal)**2
    LgV = (x - x_goal)            # ẋ=u 이므로 L_gV = ∇V
    # min ½‖u‖²  s.t.  LgV·u ≤ −gamma·V   →  폐형: 제약 활성 시 투영
    u_nom = solve_qp(H=I, f=0, A=LgV, b=-gamma*V)

    # --- 다면체 장벽 ψ (Eq.3, softmin/softmax 평활) ---
    # ψ(p)=min_k max_l n_klᵀ(p−w_kl) − radius
    psi, grad_psi = barrier(x, polytopes, kappa=kappa, radius=radius)

    # --- CBF: 안전 필터 (명목 제어 최소 수정) ---
    # min ½‖u−u_nom‖²  s.t.  grad_psiᵀ·u ≥ −alpha·psi
    u = solve_qp(H=I, f=-u_nom, A=-grad_psi, b=alpha*psi)

    return x + u*dt            # 전방 불변성 → 안전 유지

부록 D. 다면체 장벽 함수 ψ의 수학적 유도와 평활화

D.1 볼록 다면체의 반공간 표현

하나의 볼록 다면체 H_k는 유한 개의 반공간 교집합으로 표현된다:

H_k = { p ∈ ℝ³ :  n_kl^T (p − w_kl) ≤ 0,  l = 1,…,L_k }

여기서 n_kl은 l번째 면(face)의 외향(outward) 법선, w_kl은 그 면 위의 한 점이다. 즉 p가 면의 안쪽이면 n_kl^T(p−w_kl) ≤ 0.

D.2 단일 다면체에 대한 부호거리형 함수

점 p가 H_k 밖에 있는지를 한 스칼라로 판정하려면, 가장 많이 위반된(=가장 양수인) 면을 보면 된다:

g_k(p) = max_{l=1..L_k}  n_kl^T (p − w_kl)
  • p ∈ H_k(내부) ⟺ 모든 면 ≤0 ⟺ g_k(p) ≤ 0.
  • p ∉ H_k(외부) ⟺ 적어도 한 면 >0 ⟺ g_k(p) > 0. 즉 g_k는 "이 다면체를 피하고 있는가"의 부호 지표(양수=안전)다.

D.3 다(多) 다면체로의 결합

장면 전체(K개 다면체)에 대해 안전하려면 모든 다면체 밖에 있어야 한다. "모든 H_k에 대해 g_k(p)>0" ⟺ 최솟값이 양수:

ψ(p) = min_{k=1..K}  g_k(p) = min_k max_l  n_kl^T (p − w_kl)      # (Eq.3)

이것이 본문 식 (3)이다. ψ(p) > 0 ⟺ p가 모든 장애물 다면체 밖 ⟺ 안전. 0-상위집합 {p : ψ(p)≥0}이 안전집합이고, CBF는 이 집합의 전방 불변성을 강제한다.

D.4 미분가능 평활화 (softmin/softmax, KAPPA)

min/max는 비매끄러워 QP 그래디언트가 불안정하다. 코드는 CBF_KAPPA=100(=κ)으로 로그-합-지수(LSE) 평활을 쓴다:

softmax_κ(a) = (1/κ) log Σ_l exp(κ·a_l)        →  max_l a_l  (κ→∞)
softmin_κ(b) = −(1/κ) log Σ_k exp(−κ·b_k)      →  min_k b_k  (κ→∞)

ψ̃(p) = softmin_κ ( softmax_κ ( n_kl^T(p − w_kl) ) ) − radius
  • κ가 클수록 진짜 min/max에 근접(보수성↑, 그러나 그래디언트 sharp).
  • κ=100은 "충분히 정확하면서도 미분 안정"의 경험적 절충.
  • 끝에 radius(=0.05m, 에이전트 반경)를 빼서 유한 크기 드론의 충돌-없음을 보장(점→구 팽창의 거리 보정).

ψ̃의 그래디언트 ∇ψ̃는 평활화된 가중치를 통해 폐형으로 구해지며, 이것이 부록 B의 CBF-QP 제약 ∇ψ̃^T u ≥ −α·ψ̃에 들어간다.

D.5 CBF 전방 불변성이 주는 보장

클래스-K 함수 α(·)에 대해 제약 ψ̇ ≥ −α(ψ)를 매 순간 만족시키면(Nagumo/CBF 정리), 초기 상태가 ψ≥0이면 이후 모든 시간에 ψ≥0이 유지된다(전방 불변). 단일 적분기 ẋ=u에서 ψ̇=∇ψ^T u 이므로 제약은 선형:

∇ψ̃(x)^T u ≥ −α·ψ̃(x),   α = CBF_ALPHA = 2.0

이 선형 제약 하에서 명목 제어 u_nom(CLF)과의 거리를 최소화하는 u가 한 번의 QP로 구해진다. 결과적으로 "목표를 향하되, 안전을 깨지 않는 최소 수정"이 매 스텝 보장된다.

부록 G. 정량 결과 심화 해석 (mip-NeRF360 9장면)

G.1 메모리 절감의 출처

SaferSplat의 473.6–718.7MB는 장면당 100만~160만 가우시안 타원체를 각각 평균·공분산·불투명도로 저장하기 때문이다. PolyMerge는 이를 454–3,296개 볼록껍질(다면체)로 환원한다. 다면체 하나는 면 법선·오프셋의 작은 집합이므로, 개체 수가 ~10³배 줄고 개체당 저장도 가벼워 8.5–67.3MB로 떨어진다(최대 10× 절감). 실외 대형 장면(Bicycle/Garden 등)일수록 다면체 수가 많아 67MB 쪽, 실내 소형(Bonsai/Counter 등)은 8.5MB 쪽으로 분포한다.

G.2 ~100× 런타임 가속의 이유

타원체 기반 안전 질의는 점-타원체 거리를 수백만 개에 대해 평가해야 하지만(또는 가속 자료구조에도 불구하고 무거움), 다면체 기반 ψ(Eq.3)는 K개 다면체×면 수의 작은 연산이다. RTX A6000에서 이 차이가 시뮬 롤아웃 ~100× 가속으로 나타나며, 이것이 마이크로컨트롤러 온보드 실행을 가능케 하는 결정적 요인이다.

G.3 성공률·여유의 트레이드오프 읽기

  • 성공률: 시뮬 100궤적에서 PolyMerge가 전 장면 최고. 이는 과대근사(빈틈 없음)로 거짓 안전 통과가 없으면서도, 헛부피 최소화로 불필요한 막힘도 적기 때문이다 — 두 베이스라인의 약점(SaferSplat: 무거움/실시간성, SuGaR+CoACD: 보장 부재)을 동시에 회피.
  • 최소 여유 0.097–0.268m: n이 작을수록(보수적) 여유가 크고, n이 클수록(정밀) 여유가 줄어든다. 후프 통과 같은 타이트한 기동에서는 큰 n으로 여유를 좁혀 통과, 넓은 공간에서는 작은 n으로 고속·저메모리를 택하는 식의 상황별 n 선택이 합리적이다.
  • 하드웨어 성공률 0.7–1.0: 10개 start-goal·5개 n 설정 전반에서 안정적. 일부 어려운 쌍에서 0.7로 떨어지나, 형식 안전(CBF) 덕에 실패=목표 미도달이지 실패=충돌이 아니라는 점이 중요하다(안전은 보장, 가용성은 보수성에 따라 변동).
