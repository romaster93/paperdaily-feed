1.2 연구 목표 (Research Objective)

다중 로봇 궤적 계획(multi-robot trajectory planning)은 비볼록(nonconvex)·다봉(multimodal)·고차원(high-dimensional) 이라는 삼중고 때문에 계산적으로 매우 어렵다. N대의 로봇이 각자 지평(horizon) T 스텝의 제어 시퀀스를 갖는다면 결합 최적화 변수는 O(N·T·|u|) 차원이며, 로봇 간 충돌 회피 제약이 변수들을 강하게 결합(couple)시켜 문제를 비볼록하게 만든다. 게다가 서로 다른 로봇이 "누가 먼저 지나가는가"를 정하는 이산적 통행 순서(passing order)마다 별개의 국소 최적해가 존재하므로 해 공간은 다봉이다.

전통적 수치 최적화(numerical optimization; SQP, 내부점법 등)는 그래디언트에 의존하므로 비볼록·다봉 지형에서 쉽게 나쁜 국소해에 갇히고, 제약이 많은 결합 문제에서 수렴이 느리다. 반면 학습 기반 확산 정책(diffusion policy)은 대량의 시연 데이터와 학습 비용이 필요하고, 학습 분포 밖(out-of-distribution) 시나리오에서 일반화가 불확실하다.

D4orm의 핵심 목표는 학습 요소가 전혀 없는(no learning component) 샘플링 기반 최적화로 이 문제를 정면 돌파하는 것이다. 필요한 재료는 단 두 가지 — (1) 롤아웃(rollout)으로 동역학적으로 실현 가능한 궤적을 얻기 위한 로봇 동역학 모델, (2) 디노이징을 유도하는 적합도 함수(fitness function) 이다. 이 둘만으로 모델 기반 확산(Model-Based Diffusion, MBD) 의 역디노이징(reverse denoising) 과정을 통해 노이즈 궤적을 점진적으로 정제하여 고품질·동역학 실현 가능·무충돌 궤적을 발견한다.

본 T-RO 판본은 원형 D4orm(단일 배치 오프라인 플래너)을 빌딩 블록으로 삼아 세 가지 운용 요건에 맞춘 플래너 아키텍처 계열(family of planning architectures) 로 확장한다: (a) 확장성을 위한 분리형(decoupled) 플래너, (b) 피드백 제어를 결합한 온라인 후퇴 지평(online receding-horizon) 플래너, (c) 자원 제약 환경을 위한 분산(distributed) 플래너.

트랙 판정 (in-scope Planner): 본 논문은 로봇 플랫폼으로 쿼드로터·차동구동/홀로노믹 지상로봇을 쓰지만 기여의 본질은 결합 구성공간에서의 다중 로봇 모션/궤적 계획 알고리즘이다. 매니퓰레이션·그래스핑·VLA가 아니며, 언어 지시가 없는 순수 경로/궤적 생성이다. 선례 — Model-Based Diffusion OC Multi-Robot(#106), MR.POP(#303, GPU 다중로봇 a.s.a.o. 계획), STL-Diffusion(#251, 다중에이전트 확산 계획), Anytime GTMP, PAAMP — 에 따라 Planner 트랙 in-scope로 확정.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

(C1) 비볼록·다봉·고차원 결합 최적화. N대 로봇의 결합 궤적 최적화는 변수 차원이 로봇 수에 선형, 지평 길이에 선형으로 커진다. 충돌 회피 제약은 로봇 쌍마다 비볼록 영역(서로의 몸체를 배제)을 만들어 실현가능 영역이 비연결(disconnected)이 되고, 통행 순서 조합마다 국소 최적해가 갈라진다. 그래디언트 기반 solver는 초기값에 극도로 민감하다.

(C2) 동역학 실현가능성(kinodynamic feasibility). 단순히 무충돌 기하 경로를 그리는 것으로는 부족하다. 차동구동 로봇은 비홀로노믹 제약(옆으로 못 감), 쿼드로터는 관성·추력 한계를 지닌다. 계획된 궤적이 실제 로봇에서 재현(zero-shot deploy) 가능하려면 동역학 모델을 만족하는 제어 시퀀스여야 한다.

(C3) 실시간성과 anytime 요구. 온라인 재계획(receding-horizon)에서는 매 제어 주기 안에 개선된 궤적을 내놓아야 한다. 계산 시간이 지평·로봇 수에 따라 폭발하면 실기체에 못 올린다. "시간이 허락하는 만큼만 정제(anytime refinement)"할 수 있어야 한다.

(C4) 확장성 vs 최적성 절충. 결합(coupled) 계획은 최적성은 좋지만 로봇 수에 지수적으로 느려지고, 완전 분리(decoupled) 계획은 빠르지만 충돌·교착에 취약하다. 100대 규모 디컨플릭션(deconfliction)과 6대 온보드 분산 운용을 같은 프레임워크로 다루려면 절충을 조절 가능해야 한다.

(C5) 학습 기반 방법의 데이터·일반화 부담. 확산 정책류는 대규모 시연 데이터로 학습해야 하고, 로봇 수·환경이 바뀌면 재학습이 필요하며, 학습 분포 밖 상황에서 안전 보장이 약하다.

2.2 핵심 해결책

D4orm은 모델 기반 확산(MBD) 을 다중 로봇 궤적에 적용한다. 핵심 통찰은 "고품질 궤적은 어떤 분포에서 샘플링한 노이즈 궤적을 디노이징하는 것만으로 발견될 수 있다" 이다. 학습된 스코어 네트워크 대신, 동역학 모델 롤아웃 + 적합도 함수 + 몬테카를로 그래디언트 근사로 역확산의 스코어를 해석적으로 추정한다. 매 디노이징 스텝은 이전 궤적에 대한 변형(deformation) 을 최적화하며, 이는 (i) anytime 정제를 지원하고 (ii) 임의 동역학을 수용하며 (iii) 대량 병렬 샘플링으로 GPU 가속의 이득을 극대화한다.

이 오프라인 단일 배치 코어를 세 방향으로 확장하여 운용 요건별 플래너 계열을 구성한다.

3. 핵심 방법론 (Core Methods)

3.1 문제 정식화 (Coupled Multi-Robot Trajectory Optimization)

N대 로봇 i∈{1..N}, 상태 x_i∈ℝ^{d_x}, 제어 u_i∈ℝ^{d_u}, 이산 동역학:

  x_i[k+1] = f_i( x_i[k], u_i[k] ),   k = 0, ..., T-1

각 로봇의 제어 시퀀스를 U_i = (u_i[0], ..., u_i[T-1]) 로 두고, 결합 제어를 U = (U_1, ..., U_N) 로 둔다. 궤적은 동역학 롤아웃으로 결정론적으로 얻어진다:

  X_i = rollout( x_i[0], U_i )    # 초기상태 + 제어 → 상태 시퀀스

목표는 다음 적합도(비용) J(U) 를 최소화하는 결합 제어 U 를 찾는 것:

  J(U) = Σ_i  w_goal · c_goal(X_i, x_i^goal)      # 목표 도달
       + Σ_{i<j} w_col · c_col(X_i, X_j)          # 로봇-로봇 충돌
       + Σ_i  w_obs · c_obs(X_i, O)               # 로봇-장애물 충돌
       + Σ_i  w_ctrl · c_ctrl(U_i)                # 제어 노력/평활

여기서 c_col 은 두 로봇 궤적이 매 시점 안전 반경보다 가까우면 벌점(예: 힌지 형태 max(0, r_safe - ‖p_i[k]-p_j[k]‖)^2 의 시간 합), c_obs 는 장애물 집합 O 와의 거리 벌점이다. 동역학 실현가능성은 제약이 아니라 롤아웃으로 by-construction 보장 된다 — U 를 어떻게 정하든 rollout(f_i, U_i) 는 항상 실현 가능한 궤적을 낸다. 이 점이 D4orm이 무제약(unconstrained) 최적화처럼 J(U) 를 다룰 수 있게 하는 핵심 설계다.

3.2 모델 기반 확산 (Model-Based Diffusion, MBD) — 역디노이징 스코어의 해석적 추정

학습형 확산 모델은 데이터로 스코어 함수 ∇_U log p(U) 를 학습한다. MBD는 이 스코어를 데이터 없이 동역학 모델과 적합도 함수만으로 몬테카를로 추정한다. 목표 분포를 적합도에 대한 볼츠만 분포로 둔다:

  p*(U) ∝ exp( - J(U) / λ )        # λ = 온도(temperature)

확산 전방(forward) 과정은 U 에 점진적으로 가우시안 노이즈를 더해 U_τ (τ = 노이즈 레벨) 를 만든다:

  U_τ = √(ᾱ_τ) · U_0 + √(1 - ᾱ_τ) · ε,   ε ~ N(0, I)

역방향(reverse) 과정은 순수 노이즈 U_{τ=T_diff} 에서 시작해 τ 를 낮춰가며 디노이징한다. 각 스텝에서 필요한 것은 조건부 평균 E[U_0 | U_τ] 이며, MBD는 이를 현재 노이즈 궤적 U_τ 주변에서 대량 샘플을 뿌리고 적합도로 가중 평균 하여 근사한다:

  # 몬테카를로 스코어(가중 평균) 근사 — D4orm 코어
  U_τ 주변 M개 샘플:  U^(m) = U_τ + σ_τ · ξ^(m),   ξ^(m) ~ N(0, I)
  적합도 가중치:        w^(m) = exp( - J( U^(m) ) / λ )  /  Σ_m exp( - J(U^(m)) / λ )
  디노이징 추정:        Û_0(U_τ) = Σ_m  w^(m) · U^(m)
  다음 레벨로 스텝:      U_{τ-1} = √(ᾱ_{τ-1}) · Û_0 + √(1 - ᾱ_{τ-1}) · (U_τ - √(ᾱ_τ)·Û_0)/√(1-ᾱ_τ)

이 가중 평균은 곧 비용이 낮은(적합도가 높은) 후보 방향으로 궤적을 끌어당기는 스코어 상승 스텝과 동치다. λ→0 이면 최소 비용 샘플로 수렴(탐욕적), λ 가 크면 다수 후보를 완만히 혼합(탐색적)한다. M개 샘플의 롤아웃·비용 평가는 로봇·샘플에 대해 완전 병렬이므로 GPU/JAX에서 벡터화되어 대량 병렬 샘플링의 이득을 그대로 받는다.

코드(github.com/proroklab/d4orm) 기본 하이퍼파라미터로 확인된 값:

  --num-samples 1024     # M: 디노이징 스텝당 몬테카를로 샘플 수
  --horizon 100          # T: 궤적 지평 길이
  --num-steps 100        # 역디노이징 스텝 수 (τ 레벨 개수)
  --dt 0.1               # 이산화 시간 간격 (s)
  --direct-path-init     # 초기화: 직선 경로에서 시작
  --seed 0

3.3 변형 기반 반복 정제 (Deformation-based Iterative Refinement) — anytime 구조

원형 D4orm의 이름(...Denoised Deformations)이 가리키듯, 핵심은 매 디노이징 라운드가 이전 궤적에 대한 "변형(deformation)" 을 최적화 한다는 점이다. 완전히 새 궤적을 매번 처음부터 만드는 대신, 직전 최적해 U^{prev} 를 기준으로 삼아 그 위의 증분 변형 ΔU 를 확산-디노이징으로 찾는다:

  U^{new} = U^{prev} ⊕ deform(ΔU)     # ⊕: 제어 시퀀스에 변형 적용

이 구조가 주는 이점:

  • Anytime 정제: 라운드를 더 돌릴수록 해가 단조 개선되며, 시간이 부족하면 현재 최선을 즉시 반환한다. 온라인 재계획에 필수적이다.
  • 웜스타트(warm-start): 후퇴 지평에서 직전 주기의 해가 다음 주기의 초기 변형 기준이 되어 수렴이 빠르다.
  • 동역학 무관성: deform 은 제어 공간에서 이루어지므로 f_i 가 무엇이든(차동구동·홀로노믹·쿼드로터) 동일 코드로 처리된다.
   초기 U (직선/이전해)
        │
        ▼
   ┌─────────────────────────────────────────────┐
   │  역디노이징 라운드 (num-steps 회 반복)         │
   │   τ = T_diff → 0                              │
   │   ┌───────────────────────────────────────┐  │
   │   │ 1024개 변형 샘플 뿌리기 (GPU 병렬)      │  │
   │   │ 각 샘플 롤아웃 → 궤적 X^(m)             │  │
   │   │ 적합도 J(U^(m)) 평가 (충돌/목표/제어)   │  │
   │   │ 볼츠만 가중 평균 → Û_0                  │  │
   │   │ 다음 노이즈 레벨로 스텝 U_{τ-1}        │  │
   │   └───────────────────────────────────────┘  │
   │   (시간 남으면 계속, 없으면 현재 최선 반환)     │
   └─────────────────────────────────────────────┘
        │
        ▼
   무충돌·동역학 실현가능 결합 궤적 U*

3.4 확장 1 — 분리형 플래너 (Decoupled Planner, "D4orm-D") : 확장성

결합(coupled) D4orm은 J(U) 안에 모든 로봇 쌍의 충돌 항 Σ_{i<j} 를 두므로 로봇 수 N 에 대해 비용 평가가 O(N^2), 결합 차원이 O(N·T·d_u) 로 커진다. 대규모(수십~100대)에서는 이 결합이 병목이다.

분리형 플래너는 로봇(또는 로봇 부분집합)마다 부분 문제로 나누어 병렬 디노이징하되, 이웃 로봇의 현재 궤적을 동결된 장애물(frozen obstacle) 처럼 적합도에 주입하여 충돌 회피를 유지한다. 일종의 우선순위/반복형 디컨플릭션으로, 결합 최적성은 약간 희생하지만 확장성이 크게 향상되어 100대 시뮬레이션 디컨플릭션을 가능하게 한다. 코드의 multi2dholo_random, multi2dholo_obsX 환경이 이 대규모/장애물 시나리오에 대응한다.

3.5 확장 2 — 온라인 후퇴 지평 플래너 (Online Receding-Horizon + Feedback)

오프라인 코어를 매 제어 주기마다 짧은 지평으로 재실행하는 후퇴 지평(receding-horizon) 구조다. 3.3의 anytime·웜스타트 성질 덕분에 매 주기 직전 해를 이어받아 짧은 시간 예산 안에 개선된 궤적을 낸다. 여기에 피드백 제어(feedback control) 를 결합하여, 계획된 궤적을 실기체가 추종할 때의 모델 오차·외란을 보정한다(계획은 D4orm, 추종은 피드백 컨트롤러의 2계층). 이 구조가 10대 실제 쿼드로터 + 장애물 환경 zero-shot 배치를 지지한다.

3.6 확장 3 — 분산 플래너 (Distributed Planner) : 온보드·자원 제약

중앙 GPU 없이 각 로봇의 온보드 컴퓨트에서 도는 분산(distributed) 변형이다. 각 로봇이 자신의 부분 문제를 디노이징하고, 이웃과 현재 궤적 의도를 통신·교환하여 국소적으로 충돌을 해소한다(분산 MBD 계열, 베이스라인 DMBD와 같은 계보). 자원 제약 때문에 샘플 수·지평이 작아지지만, anytime 성질로 "가능한 만큼" 정제한다. 이 구조가 6대 지상로봇 완전 온보드 분산 'lifelong'(지속) 운용을 가능하게 한다 — 목표가 계속 갱신되는 무한 지평 임무에서 각 로봇이 스스로 계획을 이어간다.

3.7 워크드 예제 — 한 디노이징 스텝의 내부 (Worked Example)

MBD 코어가 실제로 어떻게 "충돌하는 초기 궤적"을 "무충돌 해"로 밀어내는지 4대 로봇 antipodal swap의 단순화 예로 추적한다. 편의상 2D 홀로노믹, T=100, dt=0.1, 안전반경 r_safe=0.5m 로 둔다.

초기화(--direct-path-init): 각 로봇 i의 제어 U_i 를 시작→목표 직선을 그리도록 설정. 4대가 중앙에서 정면충돌하는 궤적이 나온다. 이때 적합도:

  J(U^init) = 목표항(≈0, 직선이라 목표엔 잘 감)
            + 충돌항(매우 큼, 중앙에서 4쌍 모두 r_safe 위반)
            + 제어항(작음)
          ⇒ J 지배항 = 로봇-로봇 충돌

디노이징 스텝 τ (예: τ=50, num-steps의 중간):

  1) 1024개 변형 샘플:  U^(m) = U_τ + σ_τ·ξ^(m)   (ξ^(m)~N(0,I))
     → 어떤 샘플은 우회(중앙 비켜감), 어떤 샘플은 여전히 충돌
  2) 각 샘플 롤아웃 → 궤적 X^(m), 비용 J(U^(m)) 평가:
        우회 샘플:   충돌항 작음 → J 작음 → w^(m) 큼
        충돌 샘플:   충돌항 큼   → J 큼   → w^(m)≈0
  3) 볼츠만 가중 평균:  Û_0 = Σ_m w^(m)·U^(m)
     → 우회 샘플들이 지배 → Û_0 는 "중앙을 비켜 회전하며 지나가는" 궤적
  4) 다음 레벨:  U_{τ-1} = √(ᾱ_{τ-1})·Û_0 + (잔여 노이즈)

핵심은 적합도가 낮은(무충돌) 샘플이 가중 평균을 지배하면서, 노이즈 레벨이 낮아질수록(τ↓) Û_0 가 점점 확정적인 무충돌 회전 패턴으로 수렴한다는 점이다. antipodal swap의 전형적 해 — 4대가 같은 방향으로 원을 그리며(rotational symmetry breaking) 중앙을 회피 — 가 자연스럽게 창발한다. 이 "회전 방향 선택"이 곧 다봉성의 한 봉우리이며, MBD는 초기 노이즈에 따라 시계/반시계 중 하나로 대칭을 깬다.

3.8 온도 스케줄과 탐색-탐욕 절충 (Temperature Annealing)

볼츠만 가중치 w^(m) ∝ exp(-J(U^(m))/λ) 에서 온도 λ 와 노이즈 스케일 σ_τ 가 탐색-탐욕 균형을 지배한다.

  λ 큼   → 가중치 평탄 → 많은 샘플 혼합 → 탐색적(넓게 봄, 봉우리 놓칠 위험 적음)
  λ 작음 → 최소비용 샘플로 첨예 → 탐욕적(빠른 수렴, 나쁜 국소해 위험)

  σ_τ (노이즈 레벨, τ에 따라 감소):
    τ 큼(초기) → σ_τ 큼 → 넓은 변형 탐색 → 전역 구조(회전 방향) 결정
    τ 작음(후기) → σ_τ 작음 → 미세 변형 → 국소 정제(안전여유 미세조정)

이 coarse-to-fine 구조가 확산 최적화의 핵심 이점이다. 초기 큰 노이즈에서 통행 순서·회전 방향 같은 이산적 결정을 탐색하고, 후기 작은 노이즈에서 연속적 궤적을 매끄럽게 다듬는다. num-steps=100 스텝에 걸친 σ_τ 감소 스케줄이 이 전이를 담당한다. 그래디언트 기반 solver가 초기값의 국소 분지에 갇히는 것과 대조적으로, MBD는 초기 고노이즈 단계에서 여러 분지를 동시에 탐색해 다봉성을 자연스럽게 다룬다.

3.9 왜 롤아웃이 제약을 무제약으로 바꾸는가

D4orm 설계의 미묘하지만 결정적인 점은 동역학을 제약이 아닌 파라미터화로 흡수한 것이다. 전통적 궤적 최적화는:

  min_{X,U}  J(X)   s.t.  x[k+1] = f(x[k],u[k])   (동역학 등식제약)
                          충돌회피, 제어한계 (부등식제약)

처럼 상태 X와 제어 U를 모두 변수로 두고 동역학을 등식제약으로 강제한다(direct collocation). 이는 변수·제약 수가 크고 solver가 무겁다. D4orm은:

  min_U  J( rollout(x0, U) )     (무제약! 동역학은 rollout 안에 흡수)

처럼 제어 U만 변수로 두고, 상태는 롤아웃으로 결정론적으로 유도한다(direct shooting). 이렇게 하면 어떤 U를 뽑아도 동역학 실현가능하므로 MBD의 무제약 샘플링이 그대로 적용된다. 대가는 롤아웃의 순차 의존성(긴 지평에서 shooting의 수치 민감도)이지만, 확산의 증분 변형과 anytime 정제가 이를 완화한다. 이 선택이 임의 동역학(차동구동·홀로노믹·쿼드로터)을 동일 코드로 다루는 유연성의 근원이다.

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 / 시나리오 (Scenarios)

학습 데이터셋이 없는(zero-learning) 방법이므로 벤치마크는 합성 다중 로봇 조율 시나리오로 구성된다. 코드 저장소가 노출하는 환경 구성:

환경 키 설명
multi2dholo 2D 홀로노믹 팀 (기본)
multi2d 2D 차동구동(비홀로노믹) 팀
multi2dholo_heter 2D 홀로노믹 이종(heterogeneous) 팀
multi3dholo 3D 홀로노믹 팀 (쿼드로터형)
multi2dholo_random 무작위 시작/목표 대규모
multi2dholo_obsX 장애물 포함 시나리오

대표 시나리오는 원형 배치에서 대각 반대편으로 목표 교환(circular goal-swapping / antipodal swap) 으로, 모든 로봇이 중앙을 지나며 최악의 결합 충돌을 유발하는 다중 로봇 계획의 표준 스트레스 테스트다.

5.2 평가 지표 (Evaluation Metrics)

  • 성공률(success rate): 무충돌·목표 도달·데드라인 내 완료 비율
  • 런타임(runtime): 해를 찾기까지의 벽시계 시간 (GPU 가속 포함)
  • 메이크스팬(makespan): 전체 팀이 임무를 마치는 시각
  • 실현가능성(feasibility): 데드라인 안에 동역학 실현가능 무충돌 해 확보 여부

5.3 정량적 결과 (Quantitative Results)

검증된(abstract·프로젝트·웹) 핵심 결과:

항목 결과
2D 홀로노믹 16대, MPPI 대비 속도 약 2배 빠름 (원형 D4orm 핵심 수치)
16대 2D 홀로노믹, 5초 데드라인 항상 실현가능 해 확보, 런타임 ~2초 수준

5.4 리얼월드 실험 (Real-world Experiments)

D4orm의 가장 강한 실증 축은 광범위한 실기체 배치다:

  • 10대 실제 쿼드로터 + 장애물 환경 zero-shot 배치: 계획된 궤적을 재학습·튜닝 없이 그대로 실기체에 올려 무충돌 비행. 온라인 후퇴 지평 + 피드백 제어 구조가 모델 오차를 흡수. (원형 판본은 8대 멀티로터였고 T-RO에서 10대 + 장애물로 확장.)
  • 6대 지상로봇 완전 온보드 분산 lifelong 운용: 중앙 서버 없이 각 로봇 온보드에서 분산 플래너가 돌며, 목표가 계속 바뀌는 무한 지평 임무를 지속 수행.
  • 100대 시뮬 대규모 디컨플릭션: 분리형 플래너의 확장성 실증.

이 세 축은 각각 세 플래너 변형(온라인·분산·분리형)에 대응하여, "하나의 MBD 코어 → 운용 요건별 아키텍처"라는 논문의 주장을 실기체로 뒷받침한다.

5.5 sim-to-real 갭 흡수 메커니즘

무학습 플래너가 zero-shot으로 실기체에 올라가는 것은 자명하지 않다. 계획-실행 간 모델 오차(공기역학·지연·마찰)가 오픈루프 궤적을 발산시킬 수 있기 때문이다. D4orm이 이를 흡수하는 두 축:

  (1) 온라인 후퇴 지평 재계획:
      매 주기 실측 상태에서 다시 정제 → 누적 오차 리셋
  (2) 피드백 제어(§3.5):
      계획 궤적을 레퍼런스로, 저수준 컨트롤러가 추종 오차 보정

즉 D4orm은 "완벽한 오픈루프 계획"이 아니라 "빠르게 반복되는 폐루프 재계획"으로 실기체 견고성을 얻는다. 이는 오프라인 최적성만 추구하는 계획기와 근본적으로 다른 배치 철학이며, 10대 쿼드로터 실증의 신뢰성 근거다.

6. 핵심 기여점 (Key Contributions)

  1. 학습 없는 다중 로봇 궤적 최적화의 MBD 정식화. 동역학 모델 롤아웃 + 적합도 함수 + 몬테카를로 그래디언트 근사만으로 역디노이징 스코어를 해석적으로 추정하여, 대규모 시연 데이터·재학습 없이 비볼록·다봉·고차원 결합 문제를 푼다.

  2. 변형 기반 반복 정제(deformation-based refinement)로 anytime·웜스타트 달성. 매 라운드가 이전 궤적 위의 증분 변형을 최적화하므로, 시간 예산에 맞춰 단조 개선하고 후퇴 지평에서 직전 해를 이어받는다.

  3. 단일 코어에서 파생한 플래너 아키텍처 계열. 분리형(확장성)·온라인 후퇴지평(실시간+피드백)·분산(온보드/자원제약)의 세 변형으로 다양한 운용 요건을 하나의 원리로 커버.

  4. GPU/JAX 대량 병렬 샘플링. 디노이징 스텝당 1024 샘플의 롤아웃·비용 평가가 로봇·샘플에 대해 완전 병렬화되어, MPPI·CEM 대비 속도·신뢰성 우위(16대 2D 홀로노믹 ~2배).

  5. 광범위 실기체 실증. 10대 쿼드로터(장애물, zero-shot)·6대 지상로봇(완전 온보드 분산 lifelong)·100대 시뮬 디컨플릭션으로 세 변형을 모두 검증.

  6. 완전 공개 코드(Apache-2.0). github.com/proroklab/d4orm 에 학습 불필요·재현 가능한 구현(JAX) 공개.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

결합 D4orm의 충돌 항은 O(N^2) 쌍이지만 GPU 병렬로 상수배 흡수된다. 그럼에도 100대 규모에서는 결합 차원이 부담이므로 분리형이 필수다. 분리형은 최적성-확장성 절충을 조절 가능한 knob로 제공한다. 향후 방향은 이웃 그래프 기반 부분집합 결합(cluster-coupled)으로 절충 곡선을 개선하는 것.

8.2 한계점 (Limitations)

  • 전역 최적성 보장 부재: MBD는 볼츠만 분포 샘플링 기반이라 확률적 근사이며, λ·샘플 수·스텝 수에 성능이 민감하다. MR.POP(#303)류의 점근 최적성(a.s.a.o.) 이론 보장과 달리 형식적 최적성 정리는 약하다.
  • 적합도 함수 설계 의존성: 충돌·목표·제어 가중치 튜닝이 성능을 좌우한다. 잘못된 가중은 교착·진동을 유발할 수 있다.
  • 학습형 대비 특정 구간 속도 열위: DMBD 같은 학습형 diffusion이 학습 분포 내 시나리오에서 ~10배 빠른 구간이 있다(학습 이득). D4orm은 일반화·무학습이 강점이지 절대 속도 챔피언은 아니다.
  • 분산 변형의 통신·수렴: 온보드 분산에서 이웃 궤적 의도 교환의 통신 지연·부분 관측이 국소 교착을 만들 수 있다.

8.3 향후 방향 (Future Directions)

  • 이종 동역학(공중+지상 혼합 팀) 결합 계획의 정식 벤치마크.
  • 적합도 함수 자동 튜닝(예: STL 명세 → 가중치 유도, STL-Diffusion #251 계보와 결합).
  • 학습형 스코어와 MBD 몬테카를로 스코어의 하이브리드(웜스타트는 학습, 정제는 MBD)로 속도·일반화 동시 확보.
  • 안전 인증(reachability/CBF)과의 결합으로 확률적 근사에 결정론적 안전 보장 부여.

8.4 anytime 특성의 실무적 함의 (Anytime Properties)

변형 기반 정제(§3.3)는 D4orm에 anytime 성질을 부여한다 — 언제 중단해도 그 시점까지의 최선 궤적을 반환한다. 이는 온라인 후퇴 지평(§3.5) 배치에서 결정적이다:

  계산 예산 vs 해 품질:
    스텝 20 중단 → 대략적 무충돌(안전여유 빠듯) → 저지연 재계획에 적합
    스텝 100 완주 → 매끄럽고 여유있는 궤적 → 오프라인 고품질

  후퇴 지평 루프(온라인):
    while running:
      obs = sense()                    # 이웃/장애물 상태
      U = MBD_refine(U_prev, budget=Δt) # 이전 해를 웜스타트로 정제
      apply(U[0])                       # 첫 제어만 실행
      U_prev = shift(U)                 # 지평 시프트

이전 해를 웜스타트로 쓰는 증분 정제가 매 주기 처음부터 다시 푸는 비용을 없앤다. 실제 10대 쿼드로터 실험에서 이 웜스타트가 실시간성을 담보한 핵심이다.

8.5 GPU/JAX 병렬화의 역할

MBD의 몬테카를로 스코어 추정은 1024개 샘플의 독립 롤아웃 + 비용 평가로, 임베러싱하게 병렬적이다. JAX의 vmap/jit이 이를 단일 GPU 커널로 융합한다:

  batched_rollout = vmap(rollout, in_axes=(None, 0))  # 1024 샘플 병렬
  costs = vmap(cost_fn)(trajectories)                  # 병렬 비용
  weights = softmax(-costs / λ)                        # 볼츠만 가중

이 병렬성이 "학습 없이도 실시간"을 가능케 한 물리적 근거다. 그래디언트 solver의 순차 반복과 달리, MBD는 샘플 축을 GPU 코어에 펼쳐 상수 시간에 스코어를 얻는다. N^2 충돌 항도 동일하게 배치 텐서 연산으로 흡수된다.

9.2 장단점 분석

vs Model-Based Diffusion OC Multi-Robot (#106): 둘 다 다중 로봇에 MBD를 적용하는 같은 계보다. #106이 확산 최적제어의 다중로봇 확장을 시뮬 중심으로 제시했다면, D4orm은 (a) 변형 기반 anytime 정제, (b) 분리/온라인/분산 3변형 아키텍처, (c) 10대 쿼드로터+6대 지상 lifelong 실기체라는 배치 폭에서 뚜렷이 앞선다. D4orm은 #106의 아이디어를 실기체·확장성·운용 요건으로 성숙시킨 판본으로 볼 수 있다.

vs MR.POP (#303): 두 논문 모두 GPU 병렬 다중 로봇 계획이지만 철학이 상보적이다. MR.POP은 dRRT+AO-x의 점근 최적성 이론 보장과 결합공간 탐색이 강점이고, D4orm은 무학습 확산 최적화의 유연성(임의 동역학·anytime·분산) 이 강점이다. MR.POP은 매니퓰레이터(이중팔) 실기체, D4orm은 쿼드로터/지상로봇 이동체 — 플랫폼도 갈린다. 이론적 최적성이 중요하면 MR.POP, 운용 유연성·이기종 이동 팀이면 D4orm.

vs STL-Diffusion (#251): STL-Diffusion은 시간논리 명세를 확산 계획에 조건화하는 데 초점(무엇을 만족할지), D4orm은 명세 없는 순수 무충돌·동역학 실현가능 궤적 생성에 초점(어떻게 빠르고 실기체 가능하게). 두 축은 직교하며, D4orm의 적합도 J 에 STL 유도 항을 넣는 결합이 유망한 후속이다.

vs DMBD(분산 학습형 확산, 베이스라인): D4orm은 무학습이라 일반화·재현이 강하지만, DMBD가 학습 분포 내에서 특정 구간 ~10배 속도 우위를 보인다. 즉 D4orm의 가치는 "챔피언 속도"가 아니라 학습 없이도 경쟁력 있는 속도 + 임의 시나리오 일반화 + 실기체 zero-shot이다.

9.3 실적용 가능성 평가

매우 높음. (1) 무학습이라 새 로봇·환경에 즉시 적용(동역학 모델·적합도만 정의), (2) Apache-2.0 공개 코드+JAX로 재현·확장 용이, (3) 온라인 후퇴지평+피드백으로 실기체 zero-shot 검증 완료, (4) 분산 변형으로 중앙 서버 없는 온보드 운용 가능. 드론 군집·창고 AGV·다중 지상로봇 조율에 직접 적용 가능한 성숙도.

9.4 연구 방향성 평가

"학습형 확산 정책" 흐름에 대한 강력한 무학습 반례로서 가치가 크다. 확산의 이점(다봉 탐색·병렬 샘플링·anytime)을 학습 없이 취한다는 점에서 샘플링 기반 최적화(MPPI/CEM) 계보와 확산 정책 계보를 잇는 교량이다. 향후 학습형 웜스타트 + MBD 정제 하이브리드, 안전 인증 결합, STL 명세 유도 적합도 등으로 확장 여지가 넓다.

9.5 확산-계획 계보에서의 위치

로봇 계획에서 "확산(diffusion)"은 세 갈래로 발전해 왔으며, D4orm의 좌표를 정리하면:

  (A) 학습형 확산 정책 (Diffusion Policy 계열):
      대규모 시연 데이터로 스코어 네트워크 학습 → 재학습 부담·분포밖 취약
      예: DMBD(분산 학습형), Diffuser류
  (B) 명세 조건 확산 (STL-Diffusion #251):
      시간논리 명세를 조건으로 궤적 분포 학습 → "무엇을" 강조
  (C) 모델 기반 확산 (MBD, 본 논문·#106):
      학습 없이 롤아웃+적합도+몬테카를로 스코어 → "어떻게 빠르고 실기체 가능하게"

D4orm은 (C) 계보의 다중 로봇·실기체 성숙판이다. (A)의 데이터 부담을 지지 않으면서 확산의 다봉 탐색·병렬성을 취하고, (B)의 명세 조건화는 향후 적합도 항으로 흡수 가능(직교 결합). 즉 D4orm은 세 갈래의 교차점에서 무학습·유연·실기체라는 좌표를 점유하며, 이는 샘플링 기반 MPC(MPPI/CEM)와 확산 정책 양쪽 커뮤니티가 모두 참조할 실용적 기준점이 된다.

또한 원형 D4orm(2503.12204)에서 T-RO 판본(2609.35651)으로의 확장은 "단일 알고리즘 논문 → 운용 아키텍처 계열 논문" 의 전형적 성숙 경로를 보여준다: 코어 MBD는 그대로 두고, 분리형(확장성)·온라인(실시간)·분산(온보드)의 세 배치 변형을 추가해 저널 깊이를 확보했다. 이는 AnytimeGTMP·PAAMP 등 최근 Planner 논문들이 코어 + 다변형 + 실기체로 저널화하는 흐름과 궤를 같이한다.

11. 결론 (Conclusion)

D4orm은 학습 요소 없이 모델 기반 확산(MBD)만으로 다중 로봇 궤적을 최적화하는 프레임워크를 제시하고, 이를 빌딩 블록으로 삼아 분리형·온라인 후퇴지평·분산의 세 플래너 아키텍처 계열로 확장했다. 핵심 혁신은 (i) 동역학 롤아웃 + 적합도 + 몬테카를로 그래디언트로 역디노이징 스코어를 해석적으로 추정하고, (ii) 매 라운드 이전 궤적의 변형을 최적화하여 anytime·웜스타트를 얻으며, (iii) GPU/JAX 대량 병렬로 MPPI·CEM 대비 속도·신뢰성 우위(16대 2D 홀로노믹 ~2배)를 확보한 데 있다.

실용적 의의는 광범위한 실기체 실증에 있다 — 10대 쿼드로터(장애물, zero-shot), 6대 지상로봇(완전 온보드 분산 lifelong), 100대 시뮬 디컨플릭션. 이는 "하나의 무학습 코어 → 운용 요건별 아키텍처"라는 주장을 설득력 있게 뒷받침한다. 한계는 형식적 전역 최적성 보장의 부재와 적합도 튜닝 의존성이며, 향후 학습형 웜스타트와의 하이브리드·안전 인증 결합·STL 명세 유도가 유망하다. 무학습·공개코드·실기체라는 삼박자로, D4orm은 다중 로봇 궤적 계획의 실전 적용 가능한 강력한 기준선(baseline)이 될 것이다.
