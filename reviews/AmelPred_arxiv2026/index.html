1.2 연구 목표 (Research Objective)

이 논문은 자율 UAV(무인 항공기)가 사전 좌표 없이 목표 객체를 탐색(Object-Goal Navigation, OGN)하는 문제를 강화 학습(RL)과 자기 예측 표현 학습(Self-Predictive Representation Learning, SRL)의 결합으로 해결한다.

핵심 연구 질문: 강화학습 기반 UAV 탐색에서 샘플 효율성과 실세계 전이 능력을 동시에 향상시키는 표현 학습 방법은 무엇인가?

기존 방법론의 한계:

  1. 샘플 비효율성: 모델-프리 RL은 좋은 정책을 학습하기까지 수백만 번의 상호작용이 필요
  2. 목표 좌표 의존성: 대부분의 OGN 방법은 목표 위치를 명시적으로 제공받아야 함
  3. 이미지 기반 SPR의 벡터 관찰 미지원: 기존 자기 예측 표현(SPR)은 이미지 입력 전제
  4. 시뮬레이션-현실 전이 어려움: 시뮬레이터에서 학습한 정책이 실제 드론에서 성능 저하

AmelPred의 핵심 아이디어:

기존 SPR (이미지 기반):
  인코더(CNN) → 잠재 표현 z_t → 전이 모델 → z^{t+k} 예측
  손실: InfoNCE (이미지 패치 간 대조 학습)

AmelPred (벡터 상태 기반):
  인코더(MLP) → 잠재 표현 z_t → 전이 모델 → z_{t+1} 예측
  손실: InfoNCE (결정론적) 또는 KL Divergence (확률론적)
  특이점: 상태 벡터에서 확률 분포 학습 → UAV 관찰 불확실성 포착

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 3D 공간에서의 UAV 객체 목표 탐색

UAV가 3D 공간을 자유롭게 비행하면서 목표 객체를 찾아가는 문제는 다음과 같은 독특한 어려움을 가진다:

UAV OGN의 특수성:

지상 로봇 탐색:
  - 2D 평면 이동 (일반적)
  - 휠 마찰로 인한 자연적 안정성
  - 중력에 의한 자세 제한

UAV 탐색:
  - 6-DOF 3D 자유 운동
  - 기체 역학: φ(롤), θ(피치), ψ(요) 동시 제어
  - 항공 역학적 불안정성
  - 실시간 자세 제어 + 탐색 정책 동시 요구

관찰 공간:
  - 위치: [x, y, z] (3차원)
  - 속도: [ẋ, ẏ, ż] (3차원)
  - 자세: [φ, θ, ψ] (오일러 각 3개)
  - 각속도: [φ̇, θ̇, ψ̇] (3차원)
  - (선택) 목표 좌표: [T_x, T_y, T_z, η] (4차원)
  - (선택) 가상 근접 센서: 6차원
  총: 12~22차원 연속 벡터

B. 강화학습의 샘플 비효율성

강화학습에서 좋은 정책을 학습하려면 환경과의 많은 상호작용이 필요하다:

샘플 효율성 문제:

기본 TD3 학습 곡선 (450K 스텝):
  Episode 0-10:   탐색, 보상 매우 낮음 (IQM ≈ 0.1)
  Episode 10-30:  점진적 향상 (IQM ≈ 0.3-0.5)
  Episode 30-50:  수렴 (IQM ≈ 0.5)
  → 의미있는 성능(IQM > 0.6) 달성까지 약 300K+ 스텝

AmelPredSto + TD3:
  Episode 0-10:   빠른 초기 학습 (IQM ≈ 0.7)
  Episode 10+:    안정적 유지 (IQM ≈ 0.8)
  → 200K 스텝 이내에 IQM 0.8 달성

이유: 표현 학습이 상태 공간의 유용한 구조를 미리 파악하여
     RL 에이전트의 학습 방향 제공

C. 벡터 관찰에서의 자기 예측 학습

원래 SPR(Self-Predictive Representations, Schwarzer et al. 2021)은 이미지 기반 Atari 게임을 위해 설계되었다:

이미지 기반 SPR의 특징:
  - CNN 인코더: 이미지 → 잠재 표현
  - 시간적 예측: 현재 z_t + 행동 a_t → 미래 z_{t+1} 예측
  - InfoNCE 손실로 대조적 자기 지도 학습

벡터 기반 적용의 도전:
  - CNN 대신 MLP 인코더 필요 (구조 완전 재설계)
  - 이미지 패치 간 대조학습 → 상태 벡터 간 비교로 전환
  - 연속 상태 공간에서의 분포 모델링 필요
  - UAV의 동역학적 불확실성: IMU 노이즈, 공기역학적 교란

이 논문의 기여:
  - AmelPredDet: InfoNCE 손실로 결정론적 매핑
  - AmelPredSto: KL 발산으로 확률론적 분포 매핑
  → UAV 동역학의 내재적 불확실성을 확률 분포로 포착

UAV 제어에서 시뮬레이션과 현실의 차이는 특히 크다:

Sim-to-Real 갭 주요 원인:

3. 핵심 방법론 (Core Methods)

3.1 MDP 공식화 (Problem Formalization)

UAV OGN을 마르코프 결정 과정(MDP)으로 형식화한다:

상태 공간 S:

관찰 공간 O는 두 가지 변형:

O_TC (목표 좌표 포함):
  o = [x, y, z,          ← UAV 3D 위치
       ẋ, ẏ, ż,          ← 선속도
       φ, θ, ψ,          ← 오일러 각 (롤, 피치, 요)
       φ̇, θ̇, ψ̇,         ← 각속도
       T_x, T_y, T_z,    ← 목표 객체 좌표
       η]                 ← 북 기준 방향
  차원: 16

O_TS (가상 근접 센서):
  o = [x, y, z, ẋ, ẏ, ż, φ, θ, ψ, φ̇, θ̇, ψ̇]  ← 기본 12차원
    + [s_1, ..., s_6]      ← 6개 가상 센서 (목표 방향 감지)
  차원: 18

가상 센서 s_i 정의:
  s_i = {1, if 목표가 i번째 방향 섹터에 위치
         0, otherwise}
  6개 섹터: 전방, 후방, 좌, 우, 위, 아래

행동 공간 A (연속):

a = [ẋ_cmd, ẏ_cmd, ż_cmd, ψ̇_cmd]

ẋ, ẏ, ż ∈ [-0.5, 0.5] m/s   ← 속도 명령
ψ̇ ∈ [-72, 72] deg/s          ← 요 회전 속도

보상 함수 R (다요소 보상):

거리 보상 (r_dist):
  r_dist = -(1 - D_T_t / D_g)^2 * sign(D_T_t - D_g)

  여기서:
  D_T_t = 현재 UAV와 목표 사이 거리
  D_g = 목표 반경 = D_risk + D_thr/2

방향 보상 (r_ori):
  r_ori = -|UAV_heading - T_direction| / π
  → 목표를 정면으로 향할수록 높은 보상

고도 보상 (r_elev):
  r_elev = -|arctan(Δx,y, Δz)| / (π/2)
  → 목표와 동일 고도에 있을수록 높은 보상

자세 결합 보상:
  r_pose = r_dist + r_ori + r_elev

속도 보상 (r_vel):
  r_vel = (d_t - d_{t+1}) / Δt
  → 목표를 향해 접근 속도가 빠를수록 보상

패널티:
  r_penalty = -2, if (경계 초과 OR 장애물 충돌)
            = -1, if (장애물 근접)
            = 0, otherwise

성공 보너스:
  r_success = 10, if (1 + r_dist)(1 + r_ori)(1 + r_elev) > 0.95
  → 목표에 모든 조건이 충족될 때만 달성

총 보상:
  r_total = r_vel + 0.1 × r_pose + r_penalty + r_success

감가율 γ = 0.99 (장기 보상 중시)

3.2 AmelPred: 자기 예측 표현 학습

자기 예측 표현(Self-Predictive Representation, SPR)의 기본 원리:

핵심 아이디어: 미래 상태를 정확히 예측할 수 있는 표현은
              환경의 동역학을 잘 포착한다.

시간적 예측 구조:
  현재: o_t → z_t = f_enc(o_t)
  행동: a_t
  미래 예측: ẑ_{t+1} = g(z_t, a_t)
  실제 미래: z_{t+1} = f̄_enc(o_{t+1})

목표: ẑ_{t+1} ≈ z_{t+1}

인코더 구조 (MLP 기반):

class Encoder(nn.Module):
    def __init__(self, obs_dim, hidden_dim=256, latent_dim=128):
        # 결정론적 버전 (AmelPredDet)
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim),
            nn.LeakyReLU(0.2),
            nn.LayerNorm(hidden_dim),
            nn.Linear(hidden_dim, hidden_dim),
            nn.LeakyReLU(0.2),
            nn.LayerNorm(hidden_dim),
            nn.Linear(hidden_dim, latent_dim),
            nn.Tanh()  # 출력 범위: [-1, 1]
        )
    
    def forward(self, obs):
        return self.net(obs)

class StochasticEncoder(nn.Module):
    def __init__(self, obs_dim, hidden_dim=256, latent_dim=128):
        # 확률론적 버전 (AmelPredSto)
        self.backbone = ...  # 위와 동일
        self.mu_head = nn.Linear(hidden_dim, latent_dim)
        self.log_sigma_head = nn.Linear(hidden_dim, latent_dim)
    
    def forward(self, obs):

전이 모델 (Transition Model):

class TransitionModel(nn.Module):
    def __init__(self, latent_dim, action_dim, hidden_dim=256):
        self.net = nn.Sequential(
            nn.Linear(latent_dim + action_dim, hidden_dim),
            nn.LayerNorm(hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, latent_dim),
            nn.Tanh()  # 잠재 공간 [-1, 1] 유지
        )
    
    def forward(self, z_t, a_t):
        x = torch.cat([z_t, a_t], dim=-1)
        return self.net(x)  # ẑ_{t+1}

투영 헤드 (Projection Head):

class ProjectionHead(nn.Module):
    # z_{t+1} → 투영 공간으로 변환 (비교를 위한 공간)
    def __init__(self, latent_dim, proj_dim=64):
        self.net = nn.Sequential(
            nn.Linear(latent_dim, latent_dim // 2),
            nn.Tanh(),
            nn.Linear(latent_dim // 2, proj_dim),
            nn.Tanh()  # AmelPredDet만 사용
        )

3.3 AmelPredDet: 결정론적 표현 손실 (InfoNCE)

InfoNCE(Noise Contrastive Estimation) 손실:

목적: 같은 궤적에서 연속된 (z_t, z_{t+1}) 쌍을 가깝게,
     다른 궤적의 z는 멀게 학습

수식:
  L_InfoNCE = -E[log( f_k(z_{t+1}, c_t) / Σ_{j∈Batch} f_k(z_j, c_t) )]

  여기서:
  c_t = 컨텍스트 표현 = h(ẑ_{t+1})  (투영 헤드 통과 후)
  z_{t+1} = 타겟 인코더가 생성한 실제 다음 상태 표현
  f_k(x, c) = exp(x · c / τ)        (온도 조절 내적)
  τ = 온도 파라미터 (기본 0.1)

직관적 해석:
  배치 내의 N개 샘플 중 실제 다음 상태를 맞추는 분류 문제
  → 미래를 잘 예측하는 표현 구조 학습

타겟 인코더 (Target Encoder) - Polyak 평균화:

타겟 인코더의 파라미터 θ̄는 학습 인코더 θ의 지수 이동 평균:

θ̄ ← τ_ema · θ̄ + (1 - τ_ema) · θ

τ_ema = 0.999  (느린 이동)
→ 타겟은 안정적으로 유지되어 학습을 안정화

3.4 AmelPredSto: 확률론적 표현 손실 (KL Divergence)

KL 발산 손실:

확률론적 버전은 인코더가 가우시안 분포를 출력:
  f_enc(o_t) → (μ_t, σ_t)
  z_t ~ N(μ_t, diag(σ_t²))

예측 분포와 실제 분포 간의 KL 발산:
  L_KL = D_KL( P(z_{t+1}) || Q(ẑ_{t+1}) )
       = Σ_x P(x) log(P(x) / Q(x))

  여기서:
  P = 타겟 인코더로부터의 실제 z_{t+1} 분포
  Q = 전이 모델로부터의 예측 ẑ_{t+1} 분포

두 가우시안 분포 간의 분석적 KL:
  D_KL( N(μ_1, Σ_1) || N(μ_2, Σ_2) )
  = 0.5 × [tr(Σ_2⁻¹ Σ_1) + (μ_2-μ_1)^T Σ_2⁻¹ (μ_2-μ_1) - d + log(|Σ_2|/|Σ_1|)]

장점:
  불확실성 정보가 분포로 인코딩됨
  → UAV 동역학의 공기역학적 노이즈를 모델링 가능

3.5 통합 학습 목표

최종 학습 목표 (AmelPredSto + TD3 예시):

총 손실:
  L_total = L_RL + α · L_SPR

L_RL = TD3 Actor-Critic 손실:
  Critic: L_critic = MSE(Q(s,a), y)
    y = r + γ × min(Q₁'(s',ã'), Q₂'(s',ã'))  (클리핑)
    ã' ~ π(s') + ε, ε ~ clip(N(0,σ), -c, c)  (정책 노이즈)
  Actor: L_actor = -E[Q(s, π(s))]
  
L_SPR = α_SPR × (L_KL 또는 L_InfoNCE)

역전파 경로:
  파란색 (RL 경로): L_RL → 인코더 + Q네트워크
  초록색 (표현 경로): L_SPR → 인코더 + 전이 모델 + 투영 헤드

중요: 타겟 인코더는 역전파에서 제외 (stop-gradient)
     → 이는 Polyak 평균화로만 업데이트됨

5.2 평가 지표 (Evaluation Metrics)

1. IQM (Interquartile Mean) 보상:
   - 상위/하위 25% 제외한 중간값 평균
   - 이상값에 강인한 성능 측정

2. SPL (Success weighted Path Length):
   SPL = (1/N) Σᵢ Sᵢ × (L*ᵢ / max(p_i, L*ᵢ))
   - Sᵢ: i번째 에피소드 성공 여부 (0/1)
   - L*ᵢ: 최적 경로 길이
   - p_i: 실제 이동 경로 길이
   → 성공률과 경로 효율성 동시 평가

3. DTS (Distance to Success):
   DTS = 마지막 관찰 시점에서 목표까지의 거리
   → 성공하지 못했을 때 얼마나 가까이 갔는지

4. FLOPs:
   평가 시 1 스텝당 부동소수점 연산 횟수

8. 고급 주제 (Advanced Topics)

8.1 정보 병목 관점에서의 분석

AmelPredSto의 KL 발산 손실은 정보 병목(Information Bottleneck) 원리와 연결된다:

전통적 정보 병목:
  min I(Z; X) s.t. I(Z; Y) ≥ I_Y
  → 입력 X에 대한 정보를 최소화하면서 타겟 Y에 대한 정보 유지

AmelPredSto의 암묵적 병목:
  L_KL = D_KL(P_target || Q_predicted)
  → 현재 상태만 알고 미래를 예측 → 불필요한 정보 압축
  → 상태 전환에 관련된 정보만 잠재 공간에 보존

효과: 
  불필요한 관찰 변동성(센서 노이즈)은 압축
  동역학적으로 중요한 패턴은 보존
  → 더 일반화 가능한 정책 학습

8.2 Sim-to-Real 전이 분석

전이 성능 저하 분석 (91% → 65.9% SPL):

주요 원인:
1. 비동기 통신 지연 (8~10ms)
   시뮬레이션: 동기적, 일정한 간격
   실세계: 비동기 패킷, 지연 편차 있음

2. 공기역학 차이
   시뮬레이션: 간단한 로터 추력 모델
   실세계: 지면 효과, 기류 변동, 배터리 전압 강하

3. 위치 추정 노이즈
   시뮬레이션: 완벽한 상태 정보
   실세계: OptiTrack → 소량의 지연 및 노이즈

개선 방향:
  도메인 무작위화 (Domain Randomization)
  시뮬레이터 동적 파라미터 노이즈 추가
  실세계 데이터로 표현 파인튜닝
  시스템 식별(System Identification) 통합

8.3 한계점 (Limitations)

현재 한계:

1. 목표 좌표 의존성
   O_TC 변형: 목표 좌표(T_x, T_y, T_z) 명시적 제공 필요
   실제 운용: 목표 탐지/위치 추정 시스템 별도 필요

2. 소규모 환경
   비행 공간: 2.3×2.3×2.0m (실내, 소형)
   대규모 또는 외부 환경으로의 확장 미검증

3. 단일 장애물 없는 환경
   현재 벤치마크에는 동적 장애물 없음
   실제 환경의 복잡한 장애물 처리 미검증

4. 단일 목표 객체
   여러 유사 객체 중 특정 하나를 찾는 문제 미다룸
   시각적 인식 모듈 통합 필요

9.2 장단점 분석

AmelPred의 장점:

1. 샘플 효율성
   → 표준 RL보다 2배 빠른 수렴
   → 제한된 환경 상호작용으로도 좋은 성능

2. 경량성
   → TD3-AmelPredSto: 기본 TD3보다 FLOPs 30% 절감
   → nano-UAV (Crazyflie, 27g)에서 실행 가능

3. 온보드 실행 가능성
   → SANDO의 MIQP 최적화 대비 훨씬 낮은 계산량
   → 엣지 디바이스에서 실시간 추론 가능

4. Sim-to-Real 전이
   → 제로샷으로 66.66% 달성
   → 도메인 무작위화 없이도 상당한 전이 능력

AmelPred의 단점:

1. 안전 보장 부재
   → SANDO와 달리 수학적 충돌 회피 보장 없음
   → RL 보상 패널티에만 의존

2. 목표 인식 미통합
   → AgiPIX처럼 완전한 검사 파이프라인 없음
   → 목표 좌표 또는 방향 정보 명시적 제공 필요

3. 제한된 환경 복잡성
   → 소규모 장애물 없는 환경에서만 검증
   → ViLiNT처럼 복잡한 실내 환경 미검증

4. 실세계 신뢰도
   → 66.66% 성공률은 안전-비판적 응용에 부족
   → SANDO의 안전 보장 수준에 못 미침

9.3 실적용 가능성 평가

AmelPred 실적용 시나리오:

✅ 적합한 응용:
   - 제어된 실내 환경에서의 소형 드론 탐색

⚠️ 개선 필요:
   - 야외 또는 대규모 실내 환경 (확장성 미검증)
   - 다중 장애물 환경 (안전 보장 부재)
   - GPS 없는 자율 위치 추정 통합 필요

❌ 현재 적합하지 않음:
   - 안전-비판적 환경 (의료, 산업 점검)

9.4 연구 방향성 평가

기존 방법 대비 기여:

SANDO (최적화 기반 안전 계획) 대비:
  - 학습 기반의 적응적 정책 vs 계획 기반의 안전 보장
  - AmelPred: 불확실성 있는 목표 탐색에 강점
  - SANDO: 명확한 웨이포인트와 안전 보장이 필요한 경우 우월

AgiPIX (전통적 계획 + 오픈소스) 대비:
  - RL로 학습된 적응적 행동 vs ESDF 기반 반응적 계획
  - AmelPred: 다양한 목표에 유연하게 대응
  - AgiPIX: 구조화된 검사 임무에 더 적합

기술적 트렌드:
  학습 기반 표현 + 모델-프리 RL의 결합은 현재 로봇 내비게이션의 핵심 트렌드
  자기 예측 표현의 벡터 상태 적용은 드론 분야에서의 새로운 기여
  확률론적 표현은 불확실한 환경에서의 강인성 향상 가능성 시사

11. 결론 (Conclusion)

11.1 혁신성 평가

AmelPred는 자기 예측 표현 학습을 처음으로 UAV의 연속 상태 벡터에 체계적으로 적용한 논문이다. 특히 확률론적 변형인 AmelPredSto는 UAV 동역학의 내재적 불확실성을 분포로 포착함으로써 기존 결정론적 표현보다 더 풍부한 잠재 공간을 형성한다.

혁신성 측면:
  기존: 이미지 기반 SPR → 게임 AI 한정
  이 논문: 벡터 기반 AmelPred → UAV 물리 환경으로 확장
  
  기존: 결정론적 잠재 표현
  이 논문: 확률론적 잠재 표현으로 불확실성 모델링
  
  기존: 표현 학습 + RL은 이미지 도메인에서만 효과적
  이 논문: 연속 상태 벡터에서도 유효함을 실증

11.2 실용적 의의

  • nano-UAV에서의 작동 가능성: 27g Crazyflie에서 제로샷 전이로 66.66% 성공률은 실용적 가능성을 보여줌
  • FLOPs 절감: TD3-AmelPredSto가 기본 TD3보다 30% 계산량 절감 → 온보드 처리에 유리
  • 오픈소스 환경: gym-webots-drone 공개로 재현성 및 후속 연구 용이

11.3 향후 연구 방향

단기 개선:
  1. 비주얼 목표 인식 통합 (객체 탐지 → 좌표 자동 추정)
  2. 장애물 회피 강화 (안전 제약 추가)
  3. 도메인 무작위화로 Sim-to-Real 갭 감소

중기 확장:
  1. 더 복잡한 환경 (창고, 건물 내부) 적용
  2. 다중 UAV 협력 탐색
  3. 외부 환경 + GPS 대체 위치 추정 통합

장기 비전:
  1. 완전 자율 드론 배송 (제로샷 목표 탐색)
  2. 재난 현장 수색/구조 (목표: 생존자 탐색)
  3. 대규모 환경 매핑과 탐색의 통합

종합 평가: AmelPred는 표현 학습과 RL의 결합을 통해 샘플 효율적이고 경량인 UAV 탐색 정책을 학습한다. 기존 계획 기반 방법(SANDO, AgiPIX)보다 적응적이며, 제로샷 Sim-to-Real 전이 능력을 실증했다. 그러나 안전 보장의 부재와 66.66%의 실세계 성공률은 추가 개선이 필요함을 시사한다. T-RO에 게재될 경우, 학습 기반 UAV 탐색의 새로운 기준선으로 자리잡을 가능성이 있다.

부록: 관련 방법론 심화 분석

A. 자기 예측 표현 학습 계보

AmelPred가 속하는 자기 예측 표현 학습의 발전 계보:

표현 학습 방법론 계보:

1. 자동 인코더 (Autoencoder, 2006):
   인코더 f(x) → z, 디코더 g(z) → x̂
   손실: ||x - x̂||²
   한계: 재구성 중심, 정책 학습에 간접적

2. 변분 자동 인코더 (VAE, 2013):
   인코더 → (μ, σ), 잠재 변수 z ~ N(μ, σ²)
   손실: 재구성 + KL 발산
   RL 적용: 드림러너(Dreamer), World Models 등

3. 대조 학습 (Contrastive Learning, 2018-2020):
   SimCLR, MoCo: 유사 샘플 가깝게, 비유사 멀게
   CURL (2020): RL에 대조 학습 적용 (이미지 기반)
   강점: 재구성 없이 구조적 표현 학습

4. 자기 예측 표현 (SPR, Schwarzer et al. 2021):
   이미지 Atari: CNN + 미래 상태 예측
   InfoNCE 손실로 time-contrastive 학습
   샘플 효율성 크게 향상

5. AmelPred (본 논문, 2026):
   벡터 상태로 SPR 적용
   확률론적 변형 (KL Div) 추가
   UAV 3D 내비게이션 도메인 검증

B. Crazyflie 드론의 기술적 특성

Crazyflie 2.0 플랫폼 상세:

하드웨어:
  무게: 27g
  크기: 92×92mm (모터 중심 기준)
  배터리: 240mAh LiPo (약 7분 비행)
  통신: Crazyradio PA USB 동글 (2.4GHz)

모터:
  6mm × 15mm 소형 코어리스 DC 모터
  7mm polypropylene 프로펠러
  최대 추력: 60mN/모터 (4개 = 240mN)

센서:
  MPU-9250 IMU (가속도계 + 자이로 + 자력계)
  LPS22H 기압 센서 (고도 보조)
  PMW3901 광학 유동 센서 (선택)

제어 아키텍처:
  온보드 PID 제어기 (펌웨어 기반)
  외부 위치 명령 수신 → PID로 추적
  통신 지연: 약 5~10ms

실험적 한계:
  비행 지속 시간 짧음 (배터리 제약)
  작은 페이로드 (추가 센서 제한적)
  빠른 동역학 (소형 드론 특성 - 불안정)

C. 강화학습 알고리즘 상세 비교

DQN vs TD3 vs SAC 핵심 차이:

DQN (Deep Q-Network):
  액션 공간: 이산 (연속 불가)
  정책: ε-탐욕 (탐색-활용 균형)
  주요 기법: 리플레이 버퍼, 타겟 네트워크
  → 이산 제어(4방향)에 적합
  → 연속 제어에 직접 적용 어렵 (이산화 필요)

TD3 (Twin Delayed Deep Deterministic):
  액션 공간: 연속
  정책: 결정론적 (DDPG 계열)
  주요 기법: 이중 Q, 정책 지연, 노이즈 정책
  → 연속 제어에 직접 적합
  → AmelPredSto와 조합 시 최고 성능

SAC (Soft Actor-Critic):
  액션 공간: 연속
  정책: 확률론적 (엔트로피 최대화)
  주요 기법: 이중 Q, 자동 온도 조정
  → 엔트로피 보너스로 탐색 장려
  → AmelPredSto와 조합 시 TD3 다음 성능

AmelPredSto와의 궁합:
  확률론적 표현 + 확률론적 정책(SAC):
    → 두 층의 불확실성이 서로 보완적
  확률론적 표현 + 결정론적 정책(TD3):
    → 표현의 불확실성이 탐색에 암묵적 기여
    → 가장 좋은 성능 달성
  결정론적 표현 + 가치 기반(DQN):
    → 상당한 FLOPs 증가 (5.7×) 대비 성능 향상 없음
    → 이산 Q값과 연속 잠재 표현의 미스매치

D. 객체 목표 탐색(OGN)과 비전-언어 탐색(VLN)의 관계

OGN vs VLN 비교:

객체 목표 탐색 (Object-Goal Navigation):
  목표: 특정 객체 카테고리 탐색
  입력: 목표 카테고리 이름 또는 좌표
  평가: 성공률, SPL, DTS
  AmelPred: 목표 좌표 또는 방향 센서 사용

비전-언어 탐색 (Vision-Language Navigation):
  목표: 자연어 지시 따르기
  입력: "빨간 소파 오른쪽으로 가서 문을 통과하시오"
  평가: SR, SPL, NE (Navigation Error)
  차이: 훨씬 복잡한 의미적 이해 필요

AmelPred의 위치:
  OGN의 일종이지만 언어 지시 없음
  "빨간 배럴 찾기"라는 단순화된 목표
  VLN의 기반 능력(탐색 효율)을 강화할 수 있는 표현 학습
  향후 언어 인코더와 통합 시 VLN으로 확장 가능

학습 커리큘럼:
  단계 1: AmelPred로 기본 탐색 정책 사전 학습
  단계 2: 언어 인코더 추가 파인튜닝
  → VLN 성능 향상 가능성 (미검증)
