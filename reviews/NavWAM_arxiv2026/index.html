1.2 연구 목표 (Research Objective)

NavWAM은 목표 조건부 시각 내비게이션(goal-conditioned visual navigation) 문제를 단일 생성 모델 안에서 통합적으로 푸는 것을 목표로 한다. 구체적으로, 로봇이 현재 RGB 관찰과 "목표 이미지(goal image)"를 입력받아, 목표 위치로 도달하는 행동열(action chunk)을 생성하는 image-goal navigation 과제를 다룬다.

기존 내비게이션 연구는 크게 두 갈래로 나뉘어 있었다.

  1. 정책(policy) 계열 — 관찰을 행동으로 직접 매핑하는 종단간(end-to-end) 정책. 빠르지만 "이 행동을 취하면 미래가 어떻게 될지"에 대한 명시적 예측을 갖지 않는다.
  2. 세계 모델(world model) 계열 — 미래 관찰을 예측(rollout)하고, 그 예측 위에서 비용/가치를 평가해 행동을 탐색(planning)한다. 예측은 풍부하지만, 행동 후보를 샘플링하고 매번 rollout을 돌려 평가하는 CEM류 플래닝은 계산량이 폭발적이다 (대표적으로 NWM의 CEM 플래닝).

NavWAM의 핵심 통찰은 "미래 관찰 예측 + 가치(목표 도달 진행도) 추정 + 행동 생성을 하나의 디퓨전 캔버스(latent canvas)에서 공동(jointly) 생성"하는 것이다. 즉 세계 모델의 예측 능력과 정책의 즉답성을 한 모델 안에 융합하여, 별도의 외부 플래너(CEM) 없이도 세계 모델의 이점을 누리되 추론 비용을 정책 수준으로 낮춘다.

연구의 실용적 목표는 명확하다:

  • (a) 사전학습된 대규모 비디오 생성 백본(Cosmos Predict2 2B)의 시각적 예측 능력을 내비게이션에 이식하고,
  • (b) 행동·가치·미래관찰을 한 텐서로 묶어 공동 디노이징함으로써 세 가지를 일관되게(coherently) 생성하며,
  • (c) 실제 로봇(real-world)에서 기존 7B급 정책(OmniVLA-7B)이나 세계 모델 플래너(NWM)를 능가하는 성공률을 2B 규모로 달성하는 것이다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

목표 조건부 시각 내비게이션, 특히 image-goal navigation은 다음과 같은 근본 난제를 안고 있다.

(C1) 정책의 근시안성(myopia)과 분포 이동(distribution shift) 종단간 정책은 현재 관찰 → 행동의 반응적(reactive) 매핑이다. 미래를 명시적으로 시뮬레이션하지 않으므로, 학습 분포를 벗어난 장면이나 목표가 멀리 있을 때 누적 오차(compounding error)에 취약하다. 행동의 결과를 "상상"하지 못해 막다른 길에 갇히거나 목표를 지나치는 실패가 흔하다.

(C2) 세계 모델 플래닝의 계산 폭발 세계 모델(예: NWM)은 미래를 예측하고 그 위에서 비용을 최소화하는 행동을 찾는다. 그러나 CEM(Cross-Entropy Method)류 샘플링 플래너는 매 스텝마다 수백~수천 개의 행동 후보를 샘플링하고, 각 후보에 대해 비싼 비디오 디퓨전 rollout을 수행한다. 본 논문 측정에 따르면 NWM의 CEM 플래닝은 행동 1회당 약 14,521 TFLOPs에 달해 실시간(real-time) 로봇 제어에 부적합하다.

(C3) 예측·가치·행동의 불일치(incoherence) 세계 모델이 미래를 그럴듯하게 예측하더라도, 그 예측과 실제 취할 행동, 그리고 목표까지의 진행도(value) 추정이 서로 따로 학습/추론되면 일관성이 깨진다. "내가 예측한 미래"와 "내가 취할 행동"과 "그 행동이 목표에 얼마나 가까워지는지"가 정합되지 않으면, 예측의 풍부함이 행동 품질로 이어지지 못한다.

(C4) 도메인 격차(domain gap)와 데이터 부족 내비게이션 전용 대규모 데이터는 매니퓰레이션이나 일반 비디오에 비해 적다. 대규모 비디오 생성 모델의 시공간 사전지식(spatiotemporal prior)을 내비게이션으로 전이하면서도, 로봇 구체화(embodiment)와 행동 조건부성을 주입하는 것이 어렵다.

(C5) 가치 함수의 부재 또는 비용 정책 계열은 보통 가치(목표 도달 진행도)를 명시적으로 추정하지 않는다. 세계 모델 계열은 가치를 외부 비용 함수로 두지만, 이는 별도 모듈/플래너를 요구한다. 가치를 "생성 대상"으로 모델 내부에 통합하는 접근은 드물었다.

2.2 핵심 해결책

NavWAM은 위 다섯 난제에 대해 "하나의 latent canvas에서 미래 관찰·가치·행동을 공동 디퓨전 생성"하는 단일 아키텍처로 응답한다.

  • (C1 대응) 행동을 미래 관찰과 함께 생성하므로, 정책은 암묵적으로 "이 행동을 취하면 미래가 이렇게 된다"는 세계 모델적 사전지식을 공유한다 → 근시안성 완화.
  • (C2 대응) 외부 CEM 플래너를 제거하고, 행동을 디퓨전으로 직접 샘플링한다. 행동 1회당 약 4.45 TFLOPs로 NWM 대비 약 3,000배 이상 저렴해 ~5Hz 실시간 동작.
  • (C3 대응) 미래 관찰·가치·행동을 하나의 텐서(latent canvas)로 묶어 공동 디노이징하므로 세 출력이 구조적으로 일관된다.
  • (C4 대응) Cosmos Predict2 2B 비디오 생성 백본을 사전학습 가중치로 활용하여 시공간 prior를 이식하고, 3단계 커리큘럼으로 내비게이션 도메인과 행동 조건부성을 점진적으로 주입.
  • (C5 대응) "목표 도달 진행도(goal-progress value)"를 latent canvas의 한 슬롯으로 두어 생성 대상으로 학습. 추론 시 가치 채널만 디노이징해 별도 critic 없이 가치 추정이 가능.

요컨대 NavWAM의 정체성은 Navigation World Action Model — 세계 모델(World), 행동 모델(Action), 가치 추정을 한 디퓨전 트랜스포머가 동시에 수행하는 통합 모델이다.

3. 핵심 방법론 (Core Methods)

3.1 Latent Canvas — 미래 관찰·가치·행동의 공동 표현

NavWAM의 심장은 latent canvas라 부르는 통합 텐서 표현이다. 9개 프레임 슬롯으로 구성된 이 캔버스는 이질적인 세 종류의 정보를 하나의 디퓨전 대상 안에 배치한다.

        Latent Canvas (9 프레임 슬롯)
 ┌──────────────────────────────────────────────────────────┐
 │  [현재/조건]      [미래 관찰 예측]        [목표/가치/행동]   │
 │                                                            │
 │  o_t (관찰)  →  ô_{t+1} ... ô_{t+k}  →  g(goal img)        │
 │                                          v (goal-progress) │
 │                                          a_{t:t+H} (action)│
 └──────────────────────────────────────────────────────────┘
   조건부(clean)      디노이징 대상          디노이징 대상
  • 미래 관찰(future observations) ô: 백본의 비디오 생성 능력으로 행동을 따랐을 때의 미래 RGB 프레임을 예측한다. 이것이 "World" 부분이다.
  • 목표 진행도 가치(goal-progress value) v: 현재가 목표에 얼마나 가까운지를 나타내는 스칼라적 신호를 latent 슬롯으로 인코딩한다. 이것이 "Value" 부분이다.
  • 행동 청크(action chunk) a: 향후 H 스텝의 행동열(예: 속도/방향 또는 waypoint)을 latent로 임베딩한다. 이것이 "Action" 부분이다.

세 정보는 동일한 디퓨전 프로세스에서 공동으로(jointly) 디노이징된다. 핵심은 이들이 동일한 어텐션 컨텍스트를 공유한다는 점이다. 즉 행동 토큰은 미래 관찰 토큰과 목표 토큰을 어텐션으로 참조하면서 생성되므로, "목표에 도달하는 일관된 미래 + 그 미래를 만드는 행동 + 그 진행도"가 하나의 정합된 출력으로 나온다.

공동 디노이징 (joint denoising) 개념도:

   noise ──► [DiT blocks] ──► clean latent canvas
              ▲   ▲   ▲
              │   │   └─ goal image (조건, clean으로 고정)
              │   └───── 현재 관찰 o_t (조건, clean으로 고정)
              └───────── 나머지 슬롯(미래관찰·가치·행동)은 디노이징

여기서 조건(현재 관찰 o_t, 목표 이미지 g)은 노이즈를 주지 않고 clean 상태로 고정(inpainting-style conditioning)하고, 나머지 슬롯만 디노이징한다. 이로써 단일 모델이 조건부 생성기처럼 동작하면서, 어떤 슬롯을 비우고(노이즈) 어떤 슬롯을 고정하느냐에 따라 여러 동작 모드(아래 3.4)를 같은 가중치로 구현한다.

3.2 Cosmos Predict2 2B 백본과 행동 조건부성 주입

NavWAM은 NVIDIA의 Cosmos Predict2 2B 비디오 생성 모델을 백본으로 채택한다. 이는 대규모 비디오로 사전학습된 디퓨전 트랜스포머(DiT)로, 풍부한 시공간 prior(물체 영속성, 카메라 모션, 장면 기하 등)를 내장한다.

핵심 설계는 이 일반 비디오 생성기를 행동 조건부 내비게이션 생성기로 개조하는 것이다.

Cosmos Predict2 2B (일반 비디오 DiT)
        │
        │  (1) latent canvas 슬롯 재배치: 미래관찰 + 가치 + 행동 슬롯 추가
        │  (2) action / value 임베딩용 경량 토크나이저·헤드 추가
        │  (3) 내비게이션 데이터로 3단계 커리큘럼 파인튜닝
        ▼
   NavWAM (Navigation World Action Model)

행동과 가치는 RGB 프레임과 모달리티가 다르므로, 이들을 latent 공간에 임베딩하는 경량 인코더/디코더(헤드)를 추가한다. 행동 슬롯은 RGB 프레임 슬롯과 같은 시퀀스 차원에 배치되어 트랜스포머의 자기어텐션을 통해 시각 토큰과 상호작용한다.

행동 업웨이트(action upweighting), λ=5. 순수하게 비디오 재구성 손실로 학습하면, 픽셀 수가 압도적으로 많은 RGB 관찰 슬롯이 손실을 지배하여 행동 슬롯의 학습 신호가 묻힌다. NavWAM은 행동(및 가치) 슬롯의 손실에 가중치 λ=5를 부여해 행동 디노이징이 충분한 그래디언트를 받도록 한다.

# 개념적 손실 구성 (실제 코드 미공개 — 논문 서술 기반 재구성)
# x: latent canvas, eps: 주입 노이즈, eps_hat: 모델 예측 노이즈
loss_obs    = mse(eps_hat[obs_slots],    eps[obs_slots])     # 미래 관찰
loss_value  = mse(eps_hat[value_slot],   eps[value_slot])    # 목표 진행도
loss_action = mse(eps_hat[action_slots], eps[action_slots])  # 행동 청크

LAMBDA = 5.0  # 행동/가치 슬롯 업웨이트
loss = loss_obs + LAMBDA * (loss_action + loss_value)

주: 위 코드는 논문 본문의 손실 설계 서술을 바탕으로 한 개념적 재구성이다. 공식 구현은 Coming Soon 상태로 미공개이므로, 실제 슬롯 인덱싱·노이즈 스케줄·가중치 적용 위치는 공개 시 검증이 필요하다.

3.3 가치(Goal-Progress Value) 슬롯 — 생성형 critic

전통적 세계 모델 플래너는 외부 비용 함수(예: 목표 이미지와 예측 관찰 간 거리)를 두고 CEM으로 최소화한다. NavWAM은 이 비용/가치를 모델이 생성하는 출력으로 내재화한다.

  • goal-progress value v: 현재 상태가 목표에 얼마나 가까운지(혹은 남은 진행도)를 나타내는 신호. latent canvas의 전용 슬롯으로 인코딩되어, 디노이징 시 미래 관찰·행동과 함께 출력된다.
  • 효과: (a) 별도 critic 네트워크/플래너 불필요, (b) 가치가 미래 관찰·행동과 같은 어텐션 컨텍스트에서 나오므로 정합된 가치 추정, (c) 추론 시 가치 슬롯만 디노이징하는 "value 모드"로 후보 평가·재정렬에 활용 가능.

이 설계는 NavDP의 "diffusion으로 궤적 생성 + critic으로 평가"를 하나의 디퓨전 통합 생성으로 진화시킨 것으로 볼 수 있다(9장 비교 참조).

3.4 단일 가중치, 다중 동작 모드 (Policy / World-Model / Value)

NavWAM의 우아함은 같은 가중치를 어떤 슬롯을 마스킹/조건화하느냐에 따라 세 가지 모드로 운용한다는 점이다.

┌────────────────────────────────────────────────────────────────┐
│ 모드        조건(clean 고정)        디노이징(생성)        용도     │
├────────────────────────────────────────────────────────────────┤
│ Policy      o_t, goal             action (+미래관찰·가치)  주행 행동│
│ World-Model o_t, action           미래 관찰 ô            미래 예측 │
│ Value       o_t, goal(,미래)       value v               진행도평가│
└────────────────────────────────────────────────────────────────┘

학습 시 모드 혼합 비율: Policy 50% / World-Model 25% / Value 25%. 학습 배치마다 어떤 슬롯을 조건으로 고정하고 어떤 슬롯을 디노이징할지를 위 비율로 샘플링한다. 이 멀티태스크 학습이 단일 모델로 정책·예측·가치 능력을 동시에 습득하게 하며, 세 능력이 같은 표현을 공유하므로 상호 보강된다.

추론 시: 기본 주행은 Policy 모드로 행동을 직접 디노이징해 받아 즉시 실행(외부 플래너 없음). 필요 시 World-Model 모드로 미래를 시각화하거나, Value 모드로 후보를 평가/재정렬할 수 있다.

3.5 디퓨전 학습 목표와 인페인팅식 조건화

NavWAM의 학습은 표준 디퓨전(노이즈 예측) 목표를 latent canvas 위에서 수행하되, 어떤 슬롯을 조건(clean)으로 둘지를 마스크로 제어하는 인페인팅(inpainting) 방식이라는 점이 핵심이다.

디퓨전 한 스텝(개념):
  1) 깨끗한 캔버스 x0 구성 = [o_t | ô(미래) | g | v | a]
  2) 모드 마스크 m 샘플링 (Policy/WM/Value 비율 50/25/25)
       - m=1 슬롯: 조건(노이즈 미주입, clean 유지)
       - m=0 슬롯: 디노이징 대상
  3) 비조건 슬롯에만 노이즈 주입: x_τ = √ᾱ_τ·x0 + √(1−ᾱ_τ)·ε   (m=0 영역)
  4) 모델이 ε̂ = f_θ(x_τ, τ, m) 예측
  5) 손실: 슬롯별 가중 MSE  (행동·가치 슬롯 ×λ=5)

이 설계의 함의는 세 가지다.

  • 단일 목적함수로 멀티모드 통합: 마스크 m만 바꾸면 같은 손실식이 정책 학습(행동 디노이징), 세계 모델 학습(미래 관찰 디노이징), 가치 학습(가치 디노이징)을 모두 표현한다. 별도 헤드/별도 학습 루프가 필요 없다.
  • 조건 일관성: 조건 슬롯이 clean으로 어텐션 컨텍스트에 항상 노출되므로, 생성 슬롯은 "현재 관찰과 목표가 주어졌을 때"라는 조건을 강하게 따른다(classifier-free 류 별도 가이던스 없이도 강한 조건성).
  • 추론 유연성: 추론 시 마스크만 바꿔 동일 가중치로 모드를 전환한다(3.4). 즉 학습/추론이 같은 마스킹 추상화를 공유한다.

주: 정확한 노이즈 스케줄(ᾱ_τ), 샘플러(예: 소수 스텝 ODE/flow 샘플러 여부), 가이던스 사용 여부는 본문 서술만으로 단정하기 어렵다 — 코드 공개 시 검증 항목.

3.6 Receding-Horizon 실행과 실시간성

NavWAM은 한 번의 디노이징으로 길이 H의 행동 청크를 생성하고, receding-horizon(후퇴 지평선) 방식으로 앞쪽 일부 행동만 실행한 뒤 새 관찰로 다시 생성한다(MPC-스타일).

t=0:  관찰 o_0 → [디노이징] → a_{0:H} → 앞 일부 실행
t=Δ:  새 관찰 o_Δ → [디노이징] → a_{Δ:Δ+H} → 앞 일부 실행
...
주기: 약 5Hz (Jetson AGX Orin 온보드)

행동 1회당 약 4.45 TFLOPs라는 경량 추론 덕에 임베디드 GPU에서 ~5Hz 폐루프 제어가 가능하다. 이는 NWM CEM(≈14,521 TFLOPs/행동) 대비 3,000배 이상 저렴하며, 세계 모델의 이점을 정책 수준의 비용으로 누린다는 본 논문의 핵심 주장을 뒷받침한다.

4.2 데이터 흐름 설명

  1. 입력 인코딩: 현재 RGB 관찰 o_t와 목표 이미지 g를 사전학습 VAE로 latent 토큰화한다.
  2. 캔버스 조립: o_t와 g는 clean(조건)으로 고정, 미래 관찰·가치·행동 슬롯은 노이즈로 초기화하여 9-프레임 latent canvas를 만든다.
  3. 공동 디노이징: Cosmos Predict2 2B DiT가 캔버스를 디노이징한다. 자기어텐션을 통해 행동 토큰이 목표·미래관찰 토큰을 참조하므로 세 출력이 정합된다.
  4. 행동 디코딩 & 실행: 행동 슬롯을 디코딩해 행동 청크를 얻고, receding-horizon으로 앞쪽 일부를 실행한다.
  5. 폐루프 반복: 새 관찰로 2~4를 ~5Hz로 반복한다.
  6. (선택) 예측/평가 활용: World-Model 모드로 미래를 시각화하거나, Value 모드로 후보 평가에 사용.

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 (Datasets)

NavWAM은 공개 내비게이션 데이터로 학습/평가된다. 핵심 벤치마크는 다음과 같다.

  • GO STANFORD (GS): 실내 image-goal 내비게이션 궤적 데이터셋. 미래 관찰 예측 품질(ATE, 시각 일관성)과 image-goal 주행 평가에 사용.
  • SIT (Social/Indoor Trajectory 계열 벤치마크): image-goal 내비게이션 성공률 비교에 사용. OmniVLA-7B 등 정책 베이스라인과 대비.
  • 실제 로봇(real-world): 자체 로봇 플랫폼으로 수행한 24개 에피소드 폐루프 주행.

학습은 3단계 커리큘럼(아래 7장)으로, 비디오 사전학습 prior → 내비게이션 도메인 적응 → 행동/가치 조건부 미세조정의 순서를 따른다.

5.2 평가 지표 (Evaluation Metrics)

  • ATE (Absolute Trajectory Error): 예측/실행 궤적과 정답 궤적 간 절대 오차. 낮을수록 좋음.
  • Subject Consistency: 생성된 미래 관찰 비디오에서 장면/주체의 시간적 일관성. 높을수록 좋음(세계 모델 예측 품질).
  • Success Rate (성공률): image-goal 도달 성공 비율(시뮬/실제).
  • 추론 비용(TFLOPs/action): 행동 1회 생성당 부동소수 연산량. 실시간성 지표.

5.4 리얼월드 실험 (Real-world Experiments)

NavWAM은 시뮬레이션 수치에 그치지 않고 실제 로봇 폐루프 주행으로 검증된다.

로봇 플랫폼

  • 베이스: Direct Drive Technology Diablo (휠-레그 하이브리드 이동 로봇)
  • 카메라: Intel RealSense D455 (RGB-D)
  • LiDAR: Livox Mid-360 (상태추정/안전, 주: NavWAM 정책 입력은 RGB 중심)
  • 온보드 컴퓨트: NVIDIA Jetson AGX Orin (~5Hz 추론)

결과 (24개 에피소드)

모델 실제 성공률 ↑
NWM (CEM) 16.7% (4/24)
OmniVLA 58.3% (14/24)
NavWAM 79.2% (19/24)
  • NavWAM 79.2%는 OmniVLA(58.3%)와 NWM(16.7%)를 큰 폭으로 능가한다.
  • 특히 세계 모델 플래너 NWM이 실제에서 16.7%로 급락하는 것과 대조적으로, NavWAM은 세계 모델의 예측 이점을 유지하면서도 정책의 즉응성/강건성을 확보했음을 보인다.
  • 온보드 Jetson에서 ~5Hz로 동작 → 외부 서버 없이 임베디드 실시간 배치 실현.

주의: 실제 평가는 24 에피소드로 표본이 작고(8장 한계), 정적(static) 장면 위주다. 성공률의 절대 우위는 분명하나, 통계적 신뢰구간/동적 환경 일반화는 후속 검증 대상이다.

5.5 분해(Ablation) 및 실패 모드 분석

핵심 설계요소의 기여 (정성/정량 종합)

  • 파인튜닝(FT)의 효과: GO STANFORD ATE가 no-FT 0.324 → FT 0.192로 약 41% 개선. 비디오 백본 prior만으로도 NWM(0.453)을 이기지만, 내비게이션 도메인 파인튜닝이 궤적 정확도에 결정적임을 보인다.
  • 행동 업웨이트(λ=5): 업웨이트가 없으면 픽셀 다수의 관찰 슬롯이 손실을 지배해 행동 슬롯 학습이 약화된다. λ=5는 행동/가치 신호가 충분한 그래디언트를 받게 하는 안정장치로, 통합 모델이 "그림만 잘 그리고 행동은 못 하는" 실패를 방지한다.
  • 모드 혼합(50/25/25): 세 모드 공동 학습이 정책·예측·가치 표현을 공유시켜 상호 보강한다. 정책 단독 학습 대비 미래 예측·가치 추정이 행동 품질을 끌어올리는 정합 효과가 기대된다.
  • 백본 규모 효율: 2B로 OmniVLA-7B와 경쟁 — 통합 모델링이 단순 스케일업보다 파라미터 효율적임을 시사하는 간접 ablation.

관찰된/예상되는 실패 모드

  1. 목표 모호성(visual aliasing): image-goal이 시각적으로 유사한 여러 위치와 매칭될 때(복도 끝, 반복 구조) 잘못된 위치로 수렴할 수 있다. 가치 슬롯이 진행도를 단조 증가로 잘못 추정하면 막다른 길 고착 가능.
  2. 장거리 드리프트: receding-horizon 재계획에도 불구하고 장거리에서는 누적 위치 오차가 커질 수 있다(단·중거리 위주 검증).
  3. 동적 객체: 정적 장면 학습 분포를 벗어난 보행자/이동 물체에서 미래 관찰 예측이 부정확해져 행동 품질 저하 가능.
  4. 분포 밖 조명/장면: 비디오 백본 prior가 강하더라도 실내 학습 분포와 크게 다른 환경(야외, 극단 조명)에선 예측 신뢰도 저하.

이들 실패 모드는 8.2의 한계(소표본·정적·단중거리·image-goal 한정)와 직접 연결되며, 향후 동적 예측 강화·언어 조건·장거리 메모리(8.3)로 완화될 수 있는 지점이다.

6. 핵심 기여점 (Key Contributions)

  1. Navigation World Action Model (통합 정식화): 미래 관찰 예측(World) · 행동 생성(Action) · 목표 진행도 가치(Value)를 하나의 디퓨전 latent canvas에서 공동 생성하는 최초급의 통합 모델을 제안. 세계 모델과 정책의 이분법을 단일 생성 프로세스로 해소한다.

  2. 외부 플래너 제거를 통한 실시간 세계 모델 내비게이션: 행동을 직접 디노이징해 CEM류 샘플링 플래닝을 없앰으로써, 세계 모델적 예측 이점을 누리면서 추론 비용을 행동당 ≈4.45 TFLOPs로 낮춰 임베디드 ~5Hz 폐루프를 달성(NWM 대비 3,000배↓).

  3. 대규모 비디오 생성 prior의 내비게이션 이식: Cosmos Predict2 2B를 백본으로 채택하고, 행동/가치 슬롯 추가 + λ=5 업웨이트 + 3단계 커리큘럼으로 일반 비디오 생성기를 행동 조건부 내비게이션 모델로 변환하는 레시피를 제시.

  4. 단일 가중치, 다중 모드 운용: 같은 모델을 Policy / World-Model / Value 모드로(학습 비율 50/25/25) 운용하는 마스킹 기반 멀티태스크 설계로, 정책·예측·가치 능력을 상호 보강한다.

  5. 강한 실증 결과 (시뮬 + 실제): GO STANFORD ATE 0.453→0.192, subject consistency 0.524→0.668, 실제 성공률 79.2%(vs OmniVLA 58.3%, NWM 16.7%), 2B로 OmniVLA-7B와 경쟁 — 정확도·일관성·실세계 성공률·효율을 동시에 입증.

7. 구현 상세 (Implementation Details)

7.1 백본 및 표현

  • 백본: Cosmos Predict2 2B (비디오 디퓨전 트랜스포머, 사전학습 가중치 초기화)
  • 표현: 9-프레임 latent canvas (미래 관찰 + 가치 + 행동 슬롯). 이미지 슬롯은 VAE latent, 행동/가치는 전용 임베딩.
  • 조건화: 현재 관찰 o_t와 목표 이미지 g를 clean으로 고정(inpainting-style), 나머지 슬롯 디노이징.

7.2 학습 설정

  • 행동 업웨이트: λ = 5 (행동/가치 슬롯 손실 가중).
  • 모드 혼합 비율: Policy 50% / World-Model 25% / Value 25% (배치별 마스킹 샘플링).
  • 3단계 커리큘럼 (curriculum):
    1. Phase 1 — 시각/비디오 prior 유지·적응: 백본의 비디오 생성 능력을 내비게이션 관찰 분포로 도메인 적응.
    2. Phase 2 — 행동 조건부성 주입: 행동 슬롯을 도입해 행동↔미래관찰 결합을 학습(world-model/policy 모드 강화).
    3. Phase 3 — 가치·정책 미세조정: goal-progress value와 정책 모드를 정교화하여 목표 도달 행동 품질을 끌어올림.
  • 하드웨어(학습): 고성능 데이터센터 GPU(논문 서술상 RTX PRO 6000 급) 사용.

7.3 추론/실행 설정

  • 실행 방식: receding-horizon(MPC 스타일), 행동 청크 생성 후 앞쪽 일부만 실행 후 재계획.
  • 추론 비용: ≈ 4.45 TFLOPs / action.
  • 온보드 주기: ~5Hz (Jetson AGX Orin).
  • 추론 모드: 기본 Policy 모드(행동 직접 생성), 필요 시 World-Model/Value 모드 전환.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

  • 파라미터 효율: 2B로 7B급 정책과 경쟁 → 통합 세계-행동 모델링이 파라미터 효율적. 더 큰 백본(Cosmos 더 큰 변형)으로 스케일 시 추가 이득 기대.
  • 모달리티 확장 여지: latent canvas는 슬롯 추가에 유연. 향후 언어 지시(language-goal) 슬롯, 깊이/세그멘테이션 슬롯 등을 같은 프레임워크로 통합할 잠재력.

8.2 한계점 (Limitations)

  1. Image-goal 한정: 목표가 "이미지"로 주어진다. 자연어 지시(language-conditioned VLN)나 객체 카테고리 목표(ObjectNav)는 직접 다루지 않는다. (→ 9장 비교에서 WMNav의 언어/객체 목표와 대비.)
  2. 소표본 실제 평가: 실제 24 에피소드로 표본이 작아 통계적 신뢰성에 제약. 다양한 장소/조명/군중 일반화 미검증.
  3. 정적 장면 위주: 동적 장애물(보행자, 움직이는 물체)·혼잡 환경에서의 강건성 미검증.
  4. 단·중거리 위주: 장거리/대규모 환경(층간 이동, 광역 매핑)에서의 누적 오차·드리프트는 추가 검증 필요.
  5. 코드 미공개: 프로젝트 페이지가 Coming Soon 상태 — 재현성은 공개 시점에 평가 가능. (현 시점 예정.)
  6. LiDAR 보조 의존 정도 불명확: 플랫폼에 Mid-360 LiDAR가 있으나 정책 입력에서의 역할/필요성(안전정지 vs 상태추정)의 경계가 본문상 명료하지 않음.

8.3 향후 방향 (Future Directions)

  • 언어 조건 통합: goal 슬롯을 이미지→언어 임베딩으로 확장해 VLN(자연어 지시) 과제로 일반화.
  • 동적 환경 대응: 동적 객체 예측을 미래 관찰 슬롯에 명시적으로 강화(소셜 내비게이션).
  • 장거리 메모리: 외부 메모리/맵 슬롯을 캔버스에 결합해 장거리 일관성 확보.
  • 가치 모드의 능동 활용: Value 모드를 후보 재정렬·안전 검증에 적극 사용하는 하이브리드(빠른 Policy + 선택적 Value 검증) 추론.

9. 비교 분석 (Comparative Analysis)

비교 대상은 동일 트랙(VLN)에서 토픽이 가장 가까운 선행 리뷰 2편을 선정했다(바운드된 읽기 프로토콜 준수):

  • WMNav: Integrating Vision-Language Models into World Models for Object Goal Navigation (IROS 2025) — 세계 모델 + VLM 기반 ObjectNav.
  • NavDP: Learning Sim-to-Real Navigation Diffusion Policy with Privileged Information Guidance (ICRA 2026) — 디퓨전 정책 + critic 기반 맵리스 내비게이션.

NavWAM은 두 흐름의 교집합에 정확히 위치한다: WMNav의 "세계 모델적 예측" + NavDP의 "디퓨전 정책 + 가치(critic)"를 단일 디퓨전 생성으로 융합한다.

9.2 장단점 분석

WMNav 대비

  • 장점: WMNav는 클라우드 VLM API에 의존해 오프라인 배치가 불가능하고 호출 지연·비용이 있다. NavWAM은 온보드 2B 모델로 오프라인 ~5Hz 실시간이 가능하고, 미래를 점수맵이 아닌 실제 비디오로 명시 예측해 일관성이 높다.
  • 단점: WMNav는 학습이 필요 없는 zero-shot이며 객체/언어 목표를 다룬다. NavWAM은 학습(대규모 커리큘럼)이 필수이고 이미지 목표에 한정되어, "새 객체를 말로 찾아가라"는 과제엔 WMNav가 더 직접적이다.

NavDP 대비

  • 장점: NavDP는 디퓨전으로 궤적을 생성하고 별도 critic으로 평가하는 2모듈 구조다. NavWAM은 가치를 같은 디퓨전 캔버스에서 생성해 정책·예측·가치가 구조적으로 정합되며, 명시적 미래 관찰 예측이라는 세계 모델 능력을 추가로 갖는다. 또 NavWAM은 실제 로봇 성공률(79.2%)을 구체적으로 제시해 실증이 강하다(NavDP 리뷰의 약점으로 지적된 "실세계 수치 부족"을 보완하는 방향).
  • 단점: NavDP는 시뮬만으로 sim-to-real을 달성하는 데이터 효율 철학과 3,000 장면 대규모 일반화가 강점이다. NavWAM은 비디오 백본 사전학습 + 커리큘럼 의존도가 높고, 실세계 표본(24ep)이 작아 일반화 폭 측면에선 NavDP의 스케일 검증이 더 광범위하다.

공통적으로 NavWAM의 차별점

  • 세 모델 중 NavWAM만이 예측·행동·가치를 한 생성 프로세스로 통합하고, 세계 모델 플래너(NWM)를 실세계에서 실제로 능가(79.2% vs 16.7%)하며 그 비용을 3,000배 낮췄다 — "세계 모델의 이점 + 정책의 효율"이라는 두 토끼를 동시에 잡은 점이 핵심 신규성이다.

9.3 실적용 가능성 평가

  • 임베디드 실시간성: Jetson AGX Orin ~5Hz, 오프라인 동작 → 현장 배치 친화적(클라우드 VLM 의존 WMNav 대비 우위).
  • 하드웨어 현실성: RGB(+RealSense, 보조 LiDAR)와 흔한 이동 플랫폼(Diablo)로 구성 → 재현 가능한 표준 스택.
  • 걸림돌: (1) 코드 미공개로 즉시 재현 불가(예정), (2) image-goal 한정으로 "사진으로 목표 지정"이 가능한 응용에 적합(임의 자연어 명령 응용엔 추가 확장 필요), (3) 동적·장거리 환경 미검증.
  • 종합: 사진 기반 목표 지정이 가능한 실내 배달/순찰/안내 같은 응용에 단기 적용 잠재력이 높으나, 코드 공개와 동적 환경 검증이 채택의 선결 조건.

9.4 연구 방향성 평가

  • 기술적 참신성: 높음. "미래관찰+가치+행동의 공동 디퓨전"은 NavDP(정책+critic 분리)·WMNav(VLM 점수맵)·NWM(세계모델+CEM)의 약점을 동시에 겨냥한 새로운 통합 접근이다. 단순 중복 아이디어가 아니라, 세 갈래의 장점을 한 아키텍처로 수렴시킨 점에서 방향성이 뚜렷하다.
  • 확장 잠재력: latent canvas의 슬롯 추가성 덕에 언어 목표·동적 예측·장거리 메모리로 자연스럽게 확장 가능 — VLN 본류(자연어 지시)로의 다리 역할 기대.
  • 검증 성숙도: 시뮬 정확도·실세계 성공률·효율을 고루 제시했으나, 실세계 표본 규모·동적 환경·코드 공개가 보강되면 탑티어 수용성이 크게 높아질 것.

11. 결론 (Conclusion)

NavWAM은 목표 조건부 시각 내비게이션에서 세계 모델과 정책의 이분법을 단일 디퓨전 생성으로 해소한 통합 모델이다. 미래 관찰·목표 진행도 가치·행동 청크를 9-프레임 latent canvas에서 공동 디노이징함으로써, (1) 정책의 근시안성을 세계 모델적 예측으로 보완하고, (2) CEM류 외부 플래너를 제거해 추론 비용을 행동당 ≈4.45 TFLOPs로 낮춰 임베디드 ~5Hz 폐루프를 실현하며, (3) 예측·가치·행동의 구조적 일관성을 확보했다.

혁신성: 단일 가중치를 Policy/World-Model/Value 세 모드로 운용하는 마스킹 멀티태스크 설계와, 가치(critic)를 모델이 직접 생성하도록 내재화한 점이 NavDP(정책+분리 critic)·WMNav(VLM 점수맵)·NWM(세계모델+CEM) 대비 분명한 신규성을 제공한다.

실용적 의의: 실제 로봇에서 79.2%(vs OmniVLA 58.3%, NWM 16.7%)를 2B 규모로 달성하고, 세계 모델 플래너(NWM)를 실세계에서 큰 폭으로 능가하면서 비용을 3,000배 낮춘 것은 "세계 모델의 예측 이점 + 정책의 실시간 효율"이라는 오랜 트레이드오프를 실제로 깨뜨린 결과다.

향후 연구 방향: image-goal 한정·소표본 실세계·정적 장면·코드 미공개(예정)는 분명한 한계다. latent canvas의 슬롯 확장성을 활용해 언어 조건(VLN 본류)·동적 환경·장거리 메모리로 일반화하고, 실세계 평가 규모와 재현성(코드 공개)을 보강한다면, 통합 세계-행동 모델 패러다임의 대표 사례로 자리매김할 잠재력이 크다.

본 리뷰는 arXiv:2606.13494v1 본문·부록 서술을 근거로 작성되었으며, 공식 구현이 미공개(Coming Soon, 예정) 상태이므로 슬롯 인덱싱·노이즈 스케줄·정확한 손실 적용 위치 등 세부 구현은 코드 공개 시 재검증을 권장한다.
