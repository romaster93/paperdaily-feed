1.2 연구 목표 (Research Objective)

본 연구는 사족보행 로봇(quadruped robot)이 평탄하지 않은 3D 비정형 환경(unstructured environment) — 계단, 경사로, 좁은 통로, 다층 구조, 옥외 캠퍼스 등 — 에서 지면을 따라 움직이면서도(surface-following) 충돌을 회피하는 실시간 로컬 플래닝(local planning) 문제를 다룬다.

기존의 사족보행 로컬 플래너는 크게 두 부류로 나뉜다. (1) 로봇을 2D 평면 위의 점 또는 원판(disk)으로 단순화하여 빠르게 계획하지만, 계단·경사·턱(step)과 같은 z축 지형 변화를 무시하여 실제 다리가 닿는 영역의 충돌을 제대로 모델링하지 못한다. (2) 완전한 3D 점유 격자(occupancy grid)와 3D 형상을 사용하지만, 매 계획 주기마다 막대한 충돌 질의 비용이 발생하여 온보드 컴퓨팅(Jetson Orin NX 급)에서 실시간성을 확보하기 어렵다.

SCAN-Planner의 핵심 목표는 이 둘 사이의 간극을 메우는 것이다. 즉,

  1. 사족보행 로봇의 실제 점유 형상을 단 2개의 점 질의로 근사하는 yaw-aware twin-cylinder footprint(요각 인지 쌍원기둥 풋프린트) 충돌 모델을 도입하여 3D 충돌 인지를 저비용으로 달성하고,
  2. 지면을 따라가는 투영 A*(projected A*) 전단(front-end)으로 z축을 별도 차원으로 탐색하지 않으면서도 지형을 추종하는 초기 경로를 생성하며,
  3. 로봇 중심 슬라이딩 3D 점유 맵(robot-centric sliding occupancy map) 과 경계 폴백(boundary fallback) 메커니즘으로 제한된 메모리·시야 안에서 안정적인 재계획을 보장하고,
  4. 3차 B-스플라인(cubic B-spline) 기반 후단(back-end) 궤적 최적화로 충돌·평활성·동역학 실현가능성을 동시에 만족하는 매끄러운 궤적을 산출한다.

최종적으로 시뮬레이션(MARSIM)과 실제 Unitree Go2 로봇(다층 건물 횡단, 옥외 캠퍼스 주행 포함)에서 EGO-Planner, CMU-Planner, ART-Planner 등 강력한 베이스라인을 능가하는 성공률·안전성·경로 효율을 입증하는 것을 목표로 한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

사족보행 로봇의 3D 비정형 환경 로컬 플래닝은 다음과 같은 본질적 난제를 갖는다.

(C1) 충돌 모델의 차원-비용 딜레마. 로봇을 2D 점/원판으로 보면 충돌 질의는 빠르지만, 계단·턱·경사처럼 z축으로 형상이 변하는 곳에서 다리·몸체의 실제 점유를 표현하지 못한다. 반대로 완전한 3D 볼륨(다수의 복셀/구체)로 모델링하면 충돌 질의 수가 폭증하여 최적화 반복마다 수백~수천 회의 점유 조회가 필요해 실시간성이 붕괴된다.

(C2) z축 탐색의 조합 폭발. 전단 경로 탐색에서 (x, y, z)를 모두 그래프 노드 차원으로 두면 탐색 공간이 급격히 커지고, 지면을 벗어난 비물리적 노드(공중 부양 경로)가 다수 생성된다. 사족보행 로봇은 본질적으로 지면 접촉 이동체이므로, z를 자유 차원으로 두는 것은 낭비이자 위험이다.

(C3) 제한된 시야와 메모리 안에서의 안정적 재계획. 온보드 LiDAR(Livox Mid-360 등)는 유한한 범위만 관측한다. 로봇이 빠르게 이동하면 맵 경계 밖으로 목표가 사라지거나, 아직 관측되지 않은 영역으로 경로가 향한다. 고정 크기 맵을 매 주기 재구성하면 비용이 크고, 경계 처리(미관측 영역을 점유로 볼지 자유로 볼지)에 따라 플래너가 멈추거나 위험한 경로를 내는 진동이 발생한다.

(C4) 매끄러움·동역학 실현가능성·안전 여유의 동시 만족. 이산 경로를 그대로 추종하면 급격한 가감속·요동이 생겨 사족보행 보행기(locomotion controller)의 추종 성능과 안정성을 해친다. 속도·가속도 한계를 지키면서, 장애물로부터 충분한 여유를 유지하고, 저크(jerk)를 억제한 매끄러운 궤적을 실시간으로 최적화해야 한다.

(C5) 요각(yaw)과 비대칭 형상. 사족보행 로봇의 몸체는 전후로 긴 비대칭 형상이며, 진행 방향(yaw)에 따라 점유 영역이 회전한다. 충돌 모델이 yaw를 무시하면 좁은 통로에서 보수적(통과 실패)이거나 위험한(측면 충돌) 판단을 한다.

2.2 핵심 해결책

SCAN-Planner는 위 난제들을 다음과 같이 정조준하여 해결한다.

도전과제 SCAN-Planner의 해결책
(C1) 차원-비용 딜레마 Twin-cylinder footprint: 몸체를 전·후 2개의 원기둥으로 근사 → 충돌 질의 = 단 2 점 질의
(C2) z축 조합 폭발 Projected A*: (x,y) 2D 그래프 탐색 + 지면 보간으로 z를 종속변수로 산출
(C3) 시야·메모리·재계획 Robot-centric sliding map (제로카피 중첩·순환버퍼) + boundary fallback (가상 자유층 → 경계 탈출 복셀을 폴백 목표로)
(C4) 매끄러움·실현가능성·안전 Cubic B-spline back-end: rebound 충돌항 + jerk 평활항 + 속도/가속도 feasibility, L-BFGS
(C5) 요각·비대칭 B-스플라인 접선으로 유도한 induced yaw를 풋프린트 회전에 반영

전체적으로 "3D 충돌 인지를 유지하되 비용은 2D 수준으로" 를 관통하는 설계 철학을 따른다.

3. 핵심 방법론 (Core Methods)

3.1 Yaw-Aware Twin-Cylinder Footprint (요각 인지 쌍원기둥 풋프린트)

SCAN-Planner의 가장 핵심적인 기여는 사족보행 로봇의 충돌 형상을 전·후 2개의 원기둥으로 근사하는 것이다. 이로써 한 위치에서의 충돌 검사는 단 2번의 점유 맵 질의로 환원된다.

(1) 몸체 좌표계에서의 두 원기둥 중심

로봇 몸체 좌표계(body frame)에서 두 원기둥의 중심을 전후 대칭으로 배치한다.

s_{b,1} = [ d_off, 0, 0 ]^T     # 전방 원기둥 중심
s_{b,2} = [ -d_off, 0, 0 ]^T    # 후방 원기둥 중심

여기서 d_off는 몸체 중심에서 각 원기둥까지의 전후 오프셋이다. 몸체의 길쭉한 형상을 두 원기둥의 합집합(capsule 유사)으로 덮음으로써, 단일 원기둥보다 측면-전후 비대칭을 잘 표현하면서도 충돌 질의 비용은 2배에 그친다.

각 원기둥은 다음 여유(clearance) 파라미터로 정의된다.

d_xy    : 수평(반경) 방향 여유   — 측면 충돌 마진
d_up    : 상방 여유             — 머리 위 천장/턱 클리어런스
d_down  : 하방 여유             — 다리가 닿는 지면 아래 허용 깊이
        = nominal_height - d_step

d_down을 nominal_height - d_step으로 정의한 점이 중요하다. 즉 로봇의 공칭 보행 높이(nominal_height)에서 한 스텝으로 오르내릴 수 있는 턱 높이(d_step)만큼을 뺀 값을 하방 허용으로 두어, 계단/턱을 "충돌"이 아니라 "넘을 수 있는 지형"으로 분류한다. 이 한 줄의 정의가 surface-following의 본질을 충돌 모델 안에 내장한다.

(2) B-스플라인 접선으로부터의 유도 요각(induced yaw)

사족보행 로봇은 보통 진행 방향을 바라보므로, 별도의 yaw 자유도를 최적화하지 않고 궤적의 접선 방향에서 yaw를 유도한다. B-스플라인 제어점 Q에 대해 i번째 점의 yaw는 전후 제어점의 차분 벡터로부터 계산한다.

ψ_i = atan2( e_y^T (Q_{i+1} - Q_{i-1}),
             e_x^T (Q_{i+1} - Q_{i-1}) )

여기서 e_x, e_y는 수평면의 단위 기저 벡터다. 이렇게 하면 yaw는 위치 제어점의 함수가 되어, 위치 최적화만으로도 풋프린트 회전이 자동 갱신된다.

(3) 세계 좌표계로의 변환과 충돌 지표

i(또는 k)번째 경로점에서 두 원기둥의 세계 좌표 중심은 yaw 회전 후 평행이동으로 얻는다.

s_{k,j} = R_z(ψ_k) · s_{b,j} + Q_k ,   j ∈ {1, 2}

R_z(ψ_k)는 z축 회전행렬이다. 점유 맵 조회 함수 χ(·)(점이 점유면 1, 자유면 0에 해당하는 비용/지표)를 이용해, k번째 점의 충돌 지표는 두 원기둥 중 더 위험한 쪽으로 정의한다.

H_k(Q_k, ψ_k) = max_{ j ∈ {1,2} } χ( s_{k,j} )

H_k = 0이면 충돌 없음(collision-free), H_k > 0이면 충돌 위험이다. 핵심은 한 경로점당 점유 질의가 정확히 2회라는 점 — 이것이 전체 파이프라인이 온보드에서 실시간으로 도는 비결이다.

        진행방향 (yaw ψ)
            ▲
   ┌────────┼────────┐
   │   ◯ 전방 원기둥   │  s_{k,1} = R_z(ψ)·[+d_off,0,0]^T + Q
   │  (d_xy, d_up,   │
   │       d_down)   │
   │        ●  Q_k   │  ← 경로 제어점(몸체 중심)
   │   ◯ 후방 원기둥   │  s_{k,2} = R_z(ψ)·[-d_off,0,0]^T + Q
   └─────────────────┘
   충돌검사 = max( χ(전방), χ(후방) )  →  단 2회 점유 질의

이 모델은 (C1) 차원-비용 딜레마와 (C5) 요각·비대칭을 동시에 해결한다. 완전 3D 볼륨 대비 질의 수를 수백 분의 일로 줄이면서도, yaw 회전과 상/하방 여유로 3D 지형(턱·천장)을 인지한다.

3.2 Projected A* (지면 추종 투영 A*)

전단 경로 탐색은 z를 자유 차원으로 두지 않고, (x, y) 2D 격자에서 A*를 수행하되 각 노드의 z를 관측된 지면으로 보간하여 종속적으로 결정한다. 이를 "투영(projected) A*"라 부른다.

(1) 지면 보간(ground interpolation)

수평 위치 x_xy에서의 지면 높이 z(x_xy)는, 관측된 진입점 x_in(높이 z_in)과 진출점 x_out(높이 z_out) 사이를 선형 보간한 비율 β로 구한다.

                 (x_xy - x_in)^T (x_out - x_in)
β(x_xy) = Π_[0,1]( ----------------------------- )
                      || x_out - x_in ||^2

z(x_xy) = z_in + β · ( z_out - z_in )

Π_[0,1](·)는 [0,1] 구간으로의 클리핑(projection)으로, 보간 비율이 선분을 벗어나지 않도록 한다. 이렇게 하면 각 2D 노드는 자동으로 그 지점의 추정 지면 높이를 부여받아, 경로가 지면을 따라 흐르게(surface-following) 된다.

(2) 이웃 노드의 요각과 충돌 검사

A* 확장에서 현재 노드에서 이웃 노드로의 이동 방향이 곧 그 구간의 yaw가 된다.

ψ_Δ = atan2( Δy, Δx )      # 이웃으로의 진행 방향 = yaw

이 yaw로 §3.1의 twin-cylinder를 회전시켜 충돌 지표를 계산하고, 충돌 지표가 0인 노드만 확장 후보로 수용한다.

노드 n 수용 조건:  H(Q_n, ψ_Δ) == 0   (collision-free)

(3) z-그래디언트 억제(z-gradient suppression)

지면 보간만으로는 급경사·낭떠러지·점프가 필요한 비물리적 전이가 생길 수 있다. 이를 막기 위해 인접 노드 간 z 변화율(높이 그래디언트)이 사족보행 로봇이 안전하게 오르내릴 수 있는 한계를 넘으면 해당 전이의 비용을 크게 키우거나 금지한다(z-gradient suppression). 즉 턱은 넘되 절벽은 피하는 필터다.

if  |z(n') - z(n)| / ||xy(n') - xy(n)||  >  γ_max :
        해당 간선 비용 ↑↑  (사실상 차단)

   투영 A* 개념도 (측면도)
   z
   │            ___                 ← 절벽/급경사: z-gradient suppression 으로 차단
   │      _____/   \____
   │   __/  ▲    ▲    ▲ \___        ← 노드의 z = 지면 보간값 (surface-following)
   │  /     │    │    │      \
   │_/      ●────●────●       \_    ← 2D (x,y) A* 경로를 지면에 투영
   └──────────────────────────► x
   각 노드: (x,y)는 그래프 차원, z는 보간 종속변수, 충돌검사는 twin-cylinder@ψ_Δ

이 설계는 (C2) z축 조합 폭발을 근본적으로 회피한다 — 탐색 차원은 2D이지만 결과 경로는 3D 지면을 추종한다.

3.3 Robot-Centric Sliding Occupancy Map (로봇 중심 슬라이딩 점유 맵)

실시간 재계획을 위해 SCAN-Planner는 고정 크기의 로봇 중심 3D 점유 격자를 유지하고, 로봇이 이동하면 맵을 전체 재할당하지 않고 제로카피 중첩(zero-copy overlap) 과 순환 버퍼(circular buffer) 로 갱신한다.

(1) 제로카피 중첩 갱신

로봇이 한 격자 이동하면, 이전 맵과 새 맵은 대부분 겹친다(영역 B). 겹치는 부분은 복사하지 않고 그대로 두고, 빠져나가는 영역(A)의 메모리를 새로 들어오는 영역(C)에 재사용(circular buffer reuse) 한다.

   이동 전:  [ A | ===== B ===== ]
   이동 후:        [ ===== B ===== | C ]
                    └ 그대로 유지 ┘  └ A의 메모리 재사용
   → B는 복사 0회 (zero-copy), A 슬롯을 순환적으로 C로 인덱스 재매핑

이로써 매 주기 맵 갱신 비용이 O(맵 전체)에서 O(새로 들어온 얇은 층)으로 줄어든다.

(2) 로그-오즈(log-odds) 점유 융합과 클램핑

각 복셀은 로그-오즈 확률로 점유를 누적하며, 과도한 확신을 막기 위해 상·하한으로 클램핑한다.

L(v) ← clamp( L(v) + Δl_hit/miss ,  p_min ,  p_max )
점유 판정:  occupied  if  L(v) > L_thresh

(3) 증분 인플레이션(incremental inflation)

장애물 주변에 안전 여유를 두기 위해 점유 복셀을 팽창(inflation)시키되, 매번 전체를 다시 팽창하지 않고 새로 점유/해제된 복셀 주변만 증분 갱신한다.

(4) 경계 폴백(boundary fallback)

목표가 맵 밖에 있거나, 경로가 미관측 영역(맵 경계)으로 향할 때 플래너가 멈추지 않도록 하는 메커니즘이다.

  1. 맵 경계에 가상의 1-복셀 자유층(virtual one-voxel free layer) 을 부여하여, 가설 경로(hypothesis path)가 경계를 "탈출"할 수 있게 한다.
  2. 그 가설 경로가 맵을 빠져나가는 경계 탈출 복셀(boundary exit voxel) 을 폴백 목표(fallback target) 로 설정한다.
  3. 이 폴백 목표까지의 유계 복구 궤적(bounded recovery trajectory) 을 생성하여, 로봇이 관측 범위 안에서 안전하게 전진하다가 새 관측이 들어오면 다시 정상 목표로 재계획한다.
   ┌─────────── sliding map ───────────┐
   │  ●로봇                              │
   │     ╲                              │
   │      ╲ 가설경로                     │
   │       ╲                            ★ 진짜 목표 (맵 밖)
   │        ◇ ← boundary exit voxel = fallback target
   │ (virtual free layer) ░░░░░░░░░░░░░░│
   └────────────────────────────────────┘
   → 경계로 향하는 경로도 멈추지 않고 "경계 탈출 복셀"까지 유계 전진

이 설계는 (C3)을 해결한다 — 제한된 시야·메모리에서도 진동 없이 부드럽게 전진하며, 미관측 영역으로의 보수성과 진취성 사이 균형을 맞춘다.

3.4 Cubic B-Spline Back-End Trajectory Optimization (3차 B-스플라인 후단 최적화)

전단 투영 A*가 낸 이산 경로를 초기값으로 하여, 후단에서 균일 3차 B-스플라인(uniform cubic B-spline, 차수 p_b = 3) 궤적을 최적화한다.

(1) B-스플라인 파라미터화

차수            p_b = 3 (cubic)
제어점          Q_1, ..., Q_{N_c}
노드 간격        Δt (uniform knot span)
총 시간          T = (N_c - p_b) · Δt
최적화 대상      내부 제어점 (양끝 p_b개씩 경계조건 고정) → N_c - 2·p_b 개

균일 3차 B-스플라인은 볼록 껍질 성질(convex hull property) 과 미분의 닫힌 형식(속도·가속도·저크가 제어점 차분으로 표현됨) 덕분에 충돌·동역학 제약을 제어점에 대한 비용으로 깔끔하게 쓸 수 있다.

(2) 목적 함수

J = λ_c · J_c  +  λ_s · J_s  +  λ_f · J_f
        충돌        평활성       실현가능성

(3) 충돌 항 (rebound penalty)

EGO-Planner 계열의 rebound(되튕김) 아이디어를 사용한다. 충돌하는 제어점 Q_i에 대해, 장애물 표면 위의 기준점 a_ij와 그 지점에서 자유공간을 향하는 방향 벡터 v_ij를 정의하고, 침투 깊이를 페널티화한다.

d_ij = (Q_i - a_ij)^T v_ij          # v_ij 방향 부호거리(자유공간 향)
c_ij = s_f - d_ij                    # s_f: 요구 안전여유, c_ij>0 이면 위반

J_c  = Σ_i Σ_j  ρ( c_ij )            # ρ: 위반에 대한 (구간별) 페널티
∂J_c/∂Q_i = - Σ_j  ρ'(c_ij) · v_ij  # 자유공간 방향으로 제어점을 밀어냄

기울기가 v_ij 방향(자유공간 쪽)을 향하므로, 최적화는 충돌 제어점을 장애물 밖으로 "되튕겨" 낸다. 여기서 충돌 검사 d_ij 평가는 §3.1 twin-cylinder를 통해 이루어져 점유 질의 비용이 낮게 유지된다.

(4) 평활성 항 (smoothness, jerk 최소화)

제어점 차분으로 표현된 저크(3계도함수) 대용량을 최소화한다.

J_s = Σ_k || J_k ||^2          # J_k: k 구간의 저크(또는 그 이산 근사)

균일 B-스플라인에서 저크는 연속한 4개 제어점의 선형결합으로 닫힌 형식으로 주어지므로, ∂J_s/∂Q도 해석적으로 계산된다.

(5) 실현가능성 항 (feasibility, 속도·가속도 한계)

F(c, c_m) = max( c - c_m , 0 )^2     # 한계 초과분만 이차 페널티

J_f = Σ_k F( ||V_k|| , v_m )         # 속도 한계 v_m
    + Σ_k F( ||A_k|| , a_m )         # 가속도 한계 a_m

V_k, A_k는 제어점 차분으로 얻는 속도·가속도다. 한계 이내면 0, 초과 시에만 이차로 벌점을 부과해 매끄럽고 미분 가능한 제약을 만든다.

(6) 솔버

전체 목적 함수 J는 미분 가능하므로 L-BFGS(준-뉴턴, quasi-Newton) 무제약 최적화로 내부 제어점을 푼다. 해석적 그래디언트와 저비용 twin-cylinder 충돌 질의 덕분에 온보드에서 수 ms~수십 ms 수준의 재계획이 가능하다.

   후단 최적화 루프
   ┌─────────────────────────────────────────────┐
   │ 초기 제어점 ← 투영 A* 경로 적합               │
   │ repeat (L-BFGS):                              │
   │   J_c: twin-cylinder 충돌 → rebound 그래디언트 │
   │   J_s: jerk 평활                               │
   │   J_f: 속도/가속도 feasibility                  │
   │   Q ← Q - α·∇J  (L-BFGS 갱신)                  │
   │ until 수렴                                     │
   └─────────────────────────────────────────────┘

이 항들의 조합이 (C4)를 해결한다 — 충돌 안전·매끄러움·동역학 실현가능성을 단일 미분가능 목적으로 통합한다.

4. 시스템 아키텍처 (System Architecture)

SCAN-Planner의 전체 파이프라인은 (센서 → 슬라이딩 맵 → 투영 A* 전단 → B-스플라인 후단 → 보행 제어기) 의 흐름을 갖는다.

┌──────────────────────────────────────────────────────────────────────┐
│                        SCAN-Planner 파이프라인                          │
└──────────────────────────────────────────────────────────────────────┘

  [LiDAR: Livox Mid-360]        [상태추정: FAST-LIO2]
          │ 점군                        │ odom (pose, twist)
          ▼                            ▼
  ┌───────────────────────────────────────────────┐
  │  Robot-Centric Sliding Occupancy Map (§3.3)    │
  │  • zero-copy overlap / circular buffer         │
  │  • log-odds 융합 + clamping                     │
  │  • 증분 inflation                               │
  │  • boundary fallback (가상 자유층/탈출 복셀)    │
  └───────────────────────────────────────────────┘
          │ 3D 점유 맵 χ(·)
          ▼
  ┌───────────────────────────────────────────────┐
  │  Front-End: Projected A* (§3.2)                │
  │  • (x,y) 2D 그래프 탐색                          │
  │  • z = 지면 보간 (surface-following)            │
  │  • ψ_Δ = atan2(Δy,Δx) 로 twin-cylinder 충돌검사 │
  │  • z-gradient suppression                       │
  └───────────────────────────────────────────────┘
          │ 충돌없는 이산 지면추종 경로
          ▼
  ┌───────────────────────────────────────────────┐
  │  Back-End: Cubic B-Spline Optimization (§3.4)  │
  │  J = λ_c J_c(rebound) + λ_s J_s(jerk)          │
  │      + λ_f J_f(vel/acc)                         │
  │  • induced yaw ψ_i = atan2(...) (§3.1)          │
  │  • twin-cylinder 2-점 충돌질의                   │
  │  • L-BFGS                                        │
  └───────────────────────────────────────────────┘
          │ 매끄럽고 실현가능한 3D 궤적
          ▼
  [Quadruped Locomotion Controller (Unitree Go2)]
          │ 관절/보행 명령
          ▼
  [실제 보행 — 계단/경사/좁은통로/다층/옥외]

데이터 흐름 요약. LiDAR 점군과 FAST-LIO2의 상태 추정이 슬라이딩 맵을 갱신하면, 투영 A*가 지면을 따라가는 충돌 없는 초기 경로를 빠르게 찾고, B-스플라인 후단이 이를 매끄럽고 동역학적으로 실현 가능한 궤적으로 다듬는다. 모든 충돌 질의는 twin-cylinder의 2-점 조회로 통일되어, 전단·후단 양쪽에서 일관되고 저렴하게 평가된다. 목표가 시야 밖이면 boundary fallback이 유계 전진을 보장한다.

5. 실험 결과 및 성능 (Experimental Results)

5.1 데이터셋 / 시뮬레이션 환경 (Datasets / Simulation)

시뮬레이터: MARSIM (LiDAR 기반 경량 시뮬레이터). 다음 시나리오에서 평가.

  • Forest (숲): 40 m × 20 m 공간에 100500개의 장애물(폭 0.20.5 m)을 밀도별로 배치 (Sparse / Medium / Dense).
  • Desk (책상 밑): 낮은 천장·다리 구조의 3D 통과 시나리오 → twin-cylinder의 상/하방 여유 검증.
  • Stair (계단): 연속 턱 지형 → surface-following과 z-gradient suppression 검증.

각 시나리오에서 50회 시행(trials), 시작/목표 무작위. 동역학 한계 v_max = 1.5 m/s, a_max = 1.0 m/s², 시행 타임아웃 120 s. 시뮬레이션 컴퓨팅은 데스크톱(Intel i9-14900K)에서 수행.

5.2 평가 지표 (Evaluation Metrics)

  • SR (Success Rate): 충돌·타임아웃 없이 목표 도달 비율.
  • Coll (Collision Rate): 충돌로 실패한 비율.
  • SPL (Success weighted by Path Length): 성공을 경로 효율로 가중 — 최단경로 대비 실제경로 길이 효율. 1.0에 가까울수록 짧고 효율적.

5.3 정량적 결과 (Quantitative Results)

Dense Obstacles(고밀도 장애물) 시나리오 — 핵심 비교표:

플래너 SR ↑ Coll ↓ SPL ↑
SCAN-Planner (본 논문) 1.00 0.00 0.95
EGO-Planner-2D 0.96 0.04 0.88
EGO-Planner-3D 0.76 0.24 0.75
CMU-Planner 0.92 0.08 0.86
ART-Planner 0.44 0.56 0.31

해석.

  • SCAN-Planner는 고밀도에서 SR 1.00 / 충돌 0.00으로 완전 무충돌 성공을 달성, SPL 0.95로 경로 효율도 최고.
  • EGO-Planner-2D는 빠르지만(2D 단순화) 3D 지형에서 충돌이 발생(0.04). EGO-Planner-3D는 완전 3D 모델링의 비용·민감도로 오히려 SR이 0.76으로 떨어지고 충돌 0.24 — (C1) 차원-비용 딜레마를 그대로 드러내는 대조군이다.
  • CMU-Planner는 견실하나(SR 0.92) SCAN에 미치지 못함.
  • ART-Planner는 고밀도에서 SR 0.44 / Coll 0.56으로 크게 무너짐 — 밀집 3D 비정형에 취약.

이 결과의 메시지는 명확하다: twin-cylinder(2-점 질의)는 2D의 속도와 3D의 안전성을 동시에 취한다. EGO-2D의 속도는 얻되 그 충돌(0.04)을 0.00으로, EGO-3D의 3D 인지는 얻되 그 SR 저하(0.76)를 1.00으로 뒤집었다.

5.4 리얼월드 실험 (Real-world Experiments)

플랫폼. Unitree Go2 사족보행 로봇 + Livox Mid-360 LiDAR + FAST-LIO2 상태 추정 + NVIDIA Jetson Orin NX 온보드 컴퓨팅. 실제 주행 동역학 한계는 보수적으로 v_m = 1.0 m/s, a_m = 0.25 m/s².

실험 시나리오:

  1. Cluttered room (어수선한 실내): 의자·박스 등 밀집 장애물 회피.
  2. S-bend (S자 좁은 통로): yaw-aware twin-cylinder가 좁은 굴곡 통로를 비충돌 통과 — 요각 인지의 직접 검증.
  3. 3D unstructured (3D 비정형): 높이 변화·턱·경사가 섞인 비정형 지형에서 surface-following 검증.
  4. Dynamic human avoidance (동적 보행자 회피): 움직이는 사람을 슬라이딩 맵 갱신 + 재계획으로 회피.
  5. Cross-floor (다층 횡단): 3층 건물을 계단으로 가로지름. 작업공간 약 [45 × 15 × 15] m³, 약 251 s 동안 149 m 주행 — 계단 지형에서 z-gradient suppression과 d_step 기반 d_down의 실효성 입증.
  6. Campus outdoor (옥외 캠퍼스): 대규모 옥외 환경 [278 × 48 × 5] m³, 약 367 m / 589 s 주행 — 장거리·옥외 일반화와 boundary fallback의 실효성 입증.

시사점. 실제 Go2에서 다층 건물 횡단과 수백 미터 옥외 주행을 온보드 컴퓨팅만으로 완수했다는 점은, 본 방법이 시뮬레이션 과적합이 아닌 실배치 가능한 로컬 플래너임을 강하게 뒷받침한다. 특히 cross-floor(계단 다층)와 dynamic human avoidance는 각각 surface-following과 실시간 재계획의 결정적 실증이다.

6. 핵심 기여점 (Key Contributions)

  1. Yaw-aware twin-cylinder footprint (2-점 충돌 모델). 사족보행 로봇의 비대칭 3D 형상을 전·후 2개의 원기둥으로 근사하여, 충돌 검사를 단 2회 점유 질의로 환원했다. d_down = nominal_height - d_step 정의로 "넘을 수 있는 턱"을 충돌 모델 내부에 내장하고, B-스플라인 접선 유도 yaw로 회전 비대칭을 반영한다. → 3D 안전성 + 2D 비용.

  2. Projected A* 지면추종 전단. z를 그래프 차원에서 배제하고 (x,y) 2D 탐색 + 지면 선형보간으로 z를 종속 결정. z-gradient suppression으로 절벽/급경사를 차단하여, 탐색 비용을 2D로 유지하면서 3D 지면을 추종하는 충돌 없는 초기 경로를 생성.

  3. Robot-centric sliding occupancy map + boundary fallback. 제로카피 중첩·순환버퍼로 맵 갱신 비용을 얇은 신규층 수준으로 절감, 로그-오즈 클램핑·증분 인플레이션으로 견실한 점유 추정. 가상 자유층/경계 탈출 복셀 기반 폴백으로 시야 밖 목표에서도 유계·무진동 전진 보장.

  4. Cubic B-spline 후단 통합 최적화. rebound 충돌항 + jerk 평활항 + 속도/가속도 feasibility를 단일 미분가능 목적으로 통합, 해석적 그래디언트 + L-BFGS로 온보드 실시간 최적화. 모든 충돌 질의가 twin-cylinder로 통일.

  5. 광범위한 실증. MARSIM에서 EGO-2D/3D·CMU·ART를 능가(Dense: SR 1.00/Coll 0.00/SPL 0.95), 실제 Go2에서 다층 횡단(3층, 149 m)과 옥외 캠퍼스(367 m) 주행을 온보드로 완수.

7. 구현 상세 (Implementation Details)

아래 값들은 논문 본문에 명시된 설정을 정리한 것이다. (코드 미공개 — 정확한 기본 하이퍼파라미터의 코드 검증은 향후 공개 시 가능.)

충돌 모델 (twin-cylinder)

d_off    : 전후 원기둥 오프셋 (몸체 길이의 ~절반 수준)
d_xy     : 수평 여유(반경 마진)
d_up     : 상방(천장) 여유
d_down   = nominal_height - d_step    # 턱 통과 허용

전단 (Projected A*)

탐색 차원 : (x, y) 2D 격자
z         : 지면 선형보간 (β ∈ [0,1])
yaw       : ψ_Δ = atan2(Δy, Δx)
수용조건  : H(Q, ψ_Δ) == 0
z-gradient: |Δz|/Δxy > γ_max → 간선 차단

후단 (Cubic B-spline)

차수 p_b   = 3 (cubic, uniform knots)
제어점     N_c (양끝 p_b개 경계 고정, 내부 N_c - 2·p_b 최적화)
총시간 T   = (N_c - p_b)·Δt
목적함수   J = λ_c·J_c + λ_s·J_s + λ_f·J_f
충돌(rebound): c_ij = s_f - d_ij,  d_ij = (Q_i - a_ij)^T v_ij
평활(jerk) : J_s = Σ_k ||J_k||^2
feasibility: F(c,c_m) = max(c - c_m, 0)^2  (속도 v_m, 가속도 a_m)
솔버       : L-BFGS (해석적 그래디언트)

시뮬레이션 동역학: v_max = 1.5 m/s, a_max = 1.0 m/s², 타임아웃 120 s, 50 trials, i9-14900K. 실제 로봇 동역학: v_m = 1.0 m/s, a_m = 0.25 m/s², Go2 + Livox Mid-360 + FAST-LIO2 + Jetson Orin NX. 맵: 로봇 중심 고정 크기 3D 격자, log-odds (p_min/p_max 클램핑), 증분 inflation, zero-copy/circular buffer.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

twin-cylinder의 2-점 질의는 제어점 수 N_c에 선형이므로, 더 긴 시계(horizon)나 고해상도 맵으로 확장해도 충돌 질의 비용 증가가 완만하다. 슬라이딩 맵의 제로카피 갱신은 고속 주행(맵이 빨리 이동)에서도 갱신 비용을 신규층에 한정해 확장성을 유지한다. 옥외 [278×48×5] m³ 주행이 이를 실증한다.

8.2 한계점 (Limitations)

  1. 형상 근사의 보수성/과소표현. 두 원기둥은 캡슐 유사 형상을 잘 덮지만, 다리가 크게 벌어지는 자세나 매우 좁은 비정형 틈에서는 과소(측면 충돌) 또는 과대(통과 실패) 근사 가능. 자세 적응(posture-adaptive) 형상은 미고려 — 이는 HiPAN과의 대비점(§9).
  2. 지면 보간의 단순성. 진입/진출 두 점 선형보간은 복잡한 비단조 지형(다중 턱, 굴곡 경사)에서 실제 지면과 오차가 생길 수 있음. 더 풍부한 지면 표면 추정(평면 피팅/메시)이 향후 방향.
  3. 요각의 종속성. yaw를 궤적 접선에서 유도하므로, 제자리 회전·게걸음(crab walk)·후진 등 비전진 기동은 표현 못 함.
  4. 동적 장애물의 명시적 예측 부재. 동적 회피는 빠른 재계획에 의존하며 보행자 의도/속도의 명시적 예측 모델은 없음.
  5. 코드 미공개. 재현성 측면에서 현재 placeholder 상태(Coming Soon)로, 정량 재현은 공개 시점까지 제한됨.

8.3 향후 방향 (Future Directions)

  • 자세 적응형 풋프린트(가변 d_off/원기둥 수)로 좁은 3D 틈 통과 강화.
  • 학습 기반 지면/통과가능성(traversability) 추정과의 결합.
  • 동적 장애물 예측을 후단 비용에 통합(시간 차원 B-스플라인).
  • 비전진 기동(회전/후진)을 위한 yaw 자유도 분리 최적화.

9.2 장단점 분석

HiPAN 대비. HiPAN은 계층적 강화학습으로 자세 적응(posture-adaptive) 을 학습하여, 몸을 낮추거나 자세를 바꿔 높이가 제한된 3D 통로를 통과한다. SCAN-Planner는 자세를 바꾸지 않는 고정 형상(twin-cylinder) + 명시적 최적화 접근이다.

  • SCAN 장점: 학습 불필요(training-free), 해석가능·튜닝가능한 명시적 비용, 시뮬-실세계 갭(sim-to-real) 부담이 작음, 새 환경 일반화가 정책 일반화에 의존하지 않음.
  • SCAN 단점: 몸을 낮추는 등 능동적 자세 변형이 필요한 극단적 높이제약 통로는 HiPAN이 유리. SCAN의 d_down/d_up은 "넘기/통과 여부"를 판정할 뿐 자세를 바꾸지는 않음.
  • 종합: 명시적·검증가능 안전(SCAN) vs 유연한 자세적응(HiPAN) 의 트레이드오프. 산업 배치에서 안전 검증이 중요하면 SCAN, 극한 지형 민첩성이 중요하면 HiPAN.

FRGraph 대비. FRGraph는 방향-인지 볼록 자유영역(convex free-region) 을 생성해 좁은 복도·군중을 통과하며, Go2와 UAV 모두에서 실증한 점이 SCAN과 가장 가까운 실배치 사례다.

  • 공통점: 둘 다 Go2 실로봇, 좁은 통로(SCAN의 S-bend / FRGraph의 narrow corridor) 강조, 기하·최적화 기반.
  • 차이: FRGraph는 주로 수평 통과(자유영역의 통과 보장) 에 강점, 명시적 안전영역으로 통과가능성을 보증. SCAN은 수직(지면추종·계단·다층) 에 강점 — cross-floor 3층 횡단이 차별화 포인트. SCAN의 twin-cylinder는 통과 보증(certificate)은 없지만 충돌 질의가 극도로 저렴(2-점).
  • 종합: 수평 좁은통로 통과보장(FRGraph) vs 수직 지면추종·다층(SCAN). 둘은 상호보완적이며, FRGraph의 자유영역 통과보장 + SCAN의 surface-following twin-cylinder를 결합하면 강력할 것.

FLAP 대비. FLAP은 시야(FOV) 제약 하 능동 지각으로 사전지도 없이 3D 비행 항법을 수행하는 UAV 최적화 플래너(MINCO 계열). 방법 패러다임(최적화 기반 로컬 플래닝)은 SCAN과 동류지만 플랫폼·차원 사용이 다르다.

  • 공통점: 둘 다 사전지도 없이 온보드 슬라이딩/국소 인지로 실시간 최적화. 매끄러운 미분가능 궤적 표현(FLAP=MINCO, SCAN=B-spline).
  • 차이: FLAP은 3D 자유 비행(지면 무관, 시야 확보가 핵심 과제)인 반면 SCAN은 지면 접촉 이동체라 z를 자유 차원에서 배제(투영 A*)하는 것이 오히려 강점이 된다. FLAP의 능동지각(어디를 볼지)은 SCAN에는 없는 축이며, 반대로 SCAN의 twin-cylinder 지면추종은 비행체엔 불필요.
  • 종합: 같은 "최적화 기반" 가문이지만 비행체의 능동지각(FLAP) vs 지면체의 저비용 3D 충돌+지면추종(SCAN) 으로 문제 구조가 갈린다.

9.3 실적용 가능성 평가

  • 온보드 실시간성: twin-cylinder 2-점 질의 + 제로카피 슬라이딩 맵 + L-BFGS는 Jetson Orin NX에서 실배치를 실증 → 산업/서비스 사족보행 로봇에 즉시 이식 가능성 높음.
  • 다층·옥외 일반화: 3층 건물 횡단(149 m)·옥외 캠퍼스(367 m)는 순찰·점검·배송 등 실제 임무 시나리오에 부합.
  • 재현성 리스크: 코드가 현재 placeholder(Coming Soon) → 즉시 재현·이식은 공개 시점까지 보류. 동급 선행(FRGraph/FLAP) 대비 이 점이 단기 약점.
  • 검증가능 안전: 명시적 비용·여유 파라미터(d_xy/d_up/d_down/s_f)는 안전 인증·튜닝에 유리(학습 정책 대비 해석가능).

9.4 연구 방향성 평가

SCAN-Planner는 "3D 인지를 2D 비용으로"라는 명확한 한 줄 통찰을 footprint·전단·후단 전반에 일관되게 관철한 점에서 기술적 응집도가 높다. 향후 가치가 큰 방향:

  1. FRGraph식 통과보장 + SCAN twin-cylinder 결합 — 저비용 충돌질의에 자유영역 certificate를 더해 좁은통로 안전 보증.
  2. HiPAN식 자세적응의 선택적 결합 — 평시엔 SCAN(명시·저비용), 극한 높이제약에선 자세적응 모듈로 전환하는 하이브리드.
  3. 동적 환경의 시간축 B-스플라인 — 보행자 예측을 후단 비용에 통합.
  4. 학습 기반 traversability와의 융합 — z-gradient suppression의 휴리스틱 임계를 학습된 통과가능성으로 대체.

11. 결론 (Conclusion)

혁신성. SCAN-Planner의 핵심 혁신은 사족보행 로봇의 3D 충돌 인지를 단 2개의 점 질의(yaw-aware twin-cylinder) 로 압축한 것이다. 이 한 가지 설계가 전단(투영 A*의 충돌 검사)·후단(B-스플라인 rebound 충돌항) 전반에 일관되게 흐르며, "3D의 안전성과 2D의 비용"이라는 오랜 딜레마(C1)를 정면으로 해소한다. 여기에 z를 종속변수로 두는 투영 A*(C2), 제로카피 슬라이딩 맵 + 경계 폴백(C3), 단일 미분가능 목적의 B-스플라인 최적화(C4)가 결합되어, 비정형 3D 환경을 위한 응집력 있는 로컬 플래닝 스택을 이룬다.

실용적 의의. MARSIM 고밀도에서 SR 1.00 / Coll 0.00 / SPL 0.95로 EGO-2D/3D·CMU·ART를 모두 능가했고, 무엇보다 실제 Go2에서 3층 건물 횡단(149 m) 과 옥외 캠퍼스(367 m) 주행을 Jetson Orin NX 온보드로 완수했다. 이는 본 방법이 시뮬레이션 결과에 머물지 않고 실제 사족보행 로봇 배치에 곧장 쓰일 수 있는 성숙도를 가졌음을 보여준다. 다만 현재 코드가 placeholder(Coming Soon) 상태라 즉시 재현성은 공개 시점까지 제한된다.

향후 연구 방향. FRGraph식 자유영역 통과보장과의 결합, HiPAN식 자세적응의 선택적 하이브리드, 동적 장애물 예측을 위한 시간축 B-스플라인, 학습 기반 traversability와의 융합이 유망하다. 종합적으로 SCAN-Planner는 사족보행 3D 비정형 로컬 플래닝에서 저비용·해석가능·실배치 가능이라는 세 마리 토끼를 균형 있게 잡은, 실용 지향의 견고한 기여다.
