1.2 연구 목표 (Research Objective)

HEIGHT는 밀집된 동적 군중(crowd)과 복도·가구 같은 정적 제약(constraint)이 공존하는 실내 환경에서, 로봇이 충돌 없이 안전하고 효율적으로 목표점까지 이동하는 군중 내비게이션(crowd navigation) 문제를 다룬다. 이는 자연어 지시가 없는 점-목표(point-goal) 내비게이션이며, 본 코퍼스 분류상 Planner 트랙(로컬 모션 플래닝/장애물 회피·탐색 전략) 에 해당한다.

핵심 통찰은 한 문장으로 요약된다: "군중 내비게이션에서 발생하는 상호작용은 동질적(homogeneous)이지 않다 — 로봇-인간(RH), 인간-인간(HH), 장애물-에이전트(OA) 상호작용은 물리적 성질이 근본적으로 다르며, 로봇의 의사결정에 미치는 영향도 다르다." 따라서 이들을 하나의 동질 그래프(homogeneous graph)로 뭉뚱그리거나 동일한 attention 가중치로 처리하는 기존 방식은 표현 능력에 손실을 낳는다.

기존 심층강화학습(DRL) 기반 군중 내비게이션 연구의 한계는 다음과 같다:

  • 인간과 장애물을 모두 동일한 원판(disk)/원 집합(set of circles) 으로 추상화하여 정적/동적의 본질 차이를 버린다.
  • 인간-인간(HH) 상호작용을 무시하거나, RH와 HH를 공유된 단일 attention으로 처리하여 각 상호작용 타입의 특수성을 잃는다.
  • 정적 장애물(OA)과의 상호작용을 명시적으로 모델링하지 않아, 복도·코너 같은 제약 공간에서 비효율적·비안전한 경로를 만든다.

HEIGHT는 이 간극을 메우기 위해 이질적 시공간 상호작용 그래프(heterogeneous spatio-temporal interaction graph) 를 정의하고, 그래프 구조에서 직접 유도된 네트워크 아키텍처(HH self-attention + RH cross-attention + OA MLP/CNN + GRU 시간 모델)를 PPO로 학습한다.

연구가 답하려는 핵심 질문은 세 가지다:

  1. 상호작용을 타입별로 분리(heterogeneous) 하여 모델링하면, 동질 그래프(HomoGAT)나 RH-only(DS-RNN) 대비 성공률·효율·안전성이 실제로 개선되는가?
  2. 저충실도(low-fidelity) 시뮬레이터 로 학습한 정책이, 픽셀이 아닌 구조화된 그래프 표현 덕분에 도메인 갭을 넘어 실세계로 추가 학습 없이(zero-shot) 전이되는가?
  3. 훈련 분포(5–9명)와 다른 인간/장애물 밀도(0–4명, 10–14명)에서 out-of-distribution 일반화가 되는가?

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

(C1) 상호작용의 이질성(heterogeneity)을 잃는 동질 표현. 군중 내비게이션에서 일어나는 상호작용은 적어도 세 종류이며 그 물리적 성질이 다르다.

  • RH(로봇-인간): 로봇이 직접 제어 가능한 양방향 상호작용. 로봇의 행동이 인간 반응을 유도하고, 그 반응이 다시 로봇의 다음 행동에 피드백된다.
  • HH(인간-인간): 로봇이 직접 제어할 수 없으나 간접적으로 로봇에 영향을 주는 양방향 상호작용. 인간 A가 인간 B를 피해 방향을 틀면 로봇도 대응해야 한다.
  • OA(장애물-에이전트): 정적 장애물이 동적 에이전트(로봇·인간)에 일방향으로 영향을 주는 비대칭 상호작용. 벽은 움직이지 않으므로 영향은 한 방향뿐이다.

이 셋을 동일한 원판으로 추상화하거나 동일 attention으로 처리하면, "직접/간접/일방향"이라는 본질 차이가 소거되어 정책이 제약 공간에서 적절히 행동하지 못한다.

(C2) 정적/동적 분리 없는 장면 표현. 인간(동적, 상호작용 발생)과 장애물(정적, 일방향 영향)을 하나의 표현 채널에 뒤섞으면, 정책은 "이 객체가 나에게 반응할 수 있는 존재인가"를 구별할 정보를 잃는다. 인간은 로봇을 피해줄 수 있으나 벽은 그렇지 않다 — 이 구별이 행동 결정에 핵심적이다.

(C3) 부분 관측(partial observability)과 가변 에이전트 수. 실세계에서 로봇은 센서 범위·가림 때문에 모든 인간을 항상 보지 못한다. 또한 인간 수 n은 시간에 따라 변한다(시야 진입/이탈). 고정 차원 네트워크는 이 가변성을 다루지 못하며, 보이지 않는 인간에 대한 attention은 잘못된 신호를 준다.

(C4) 시뮬레이션-실세계 도메인 갭(sim-to-real gap). End-to-end RGB/point cloud 정책은 정확도는 높지만 픽셀 분포 차이에 극도로 취약하고, 고충실도 시뮬레이터(LiDAR 정밀 시뮬 포함)를 요구해 학습 비용이 크다. 저충실도 시뮬레이터로 학습하면서도 실세계로 전이되는 추상화 수준의 표현이 필요하다.

(C5) 효율과 안전의 동시 달성, 그리고 freezing problem. ORCA·Social Force 같은 모델 기반 방법은 하이퍼파라미터에 민감하고, 좁은 통로·U자형 장애물에서 freezing robot problem(과보수적 정지)이나 비효율 경로를 낳는다. DWA 같은 단순 반발력 기반은 인간 간 상호작용을 전혀 고려하지 못한다.

2.2 핵심 해결책

HEIGHT의 해법은 "이질적 시공간 그래프 + 그래프-유도 이질적 네트워크" 의 결합이다:

                ┌──────────────────────────────────────────────────────┐
  인간 노드 ───▶│ HH self-attention (인간 간 상호작용, visibility mask)  │──┐
  (h_1..h_n)    └──────────────────────────────────────────────────────┘  │
                ┌──────────────────────────────────────────────────────┐  │
  장애물 노드 ─▶│ OA encoder: 1D-CNN(point cloud) → FC                  │──┤
  (o^t)         └──────────────────────────────────────────────────────┘  ├─▶ GRU(시간) ─▶ FC ─▶ V(s), π(a|s)
                ┌──────────────────────────────────────────────────────┐  │        ↑                  │
  로봇 노드 ───▶│ RH cross-attention (로봇이 query, HH가중 인간이 key/val)│──┘    h^{t-1}            PPO 학습
  (w^t)         └──────────────────────────────────────────────────────┘
  • 이질적 그래프(C1·C2 해결): RH/HH/OA를 서로 다른 함수로 모델링. 같은 edge type은 파라미터를 공유(parameter sharing)하여 가변 n에 확장 가능. 인간(독립 상태 벡터)과 장애물(통합 point cloud)을 분리 표현.
  • 이질적 attention(C1 해결): HH는 인간들 간 self-attention, RH는 로봇 관점의 cross-attention. 두 attention을 분리하여 직접/간접 상호작용의 특수성을 각각 학습.
  • Visibility mask(C3 해결): 감지되지 않은 인간을 -∞로 마스킹 → softmax 후 0 → 부분 관측을 자연스럽게 처리.
  • 구조화된 저차원 표현(C4 해결): 픽셀이 아닌 (위치·속도·point cloud) 그래프 표현이므로 저충실도 PyBullet 시뮬에서 학습해도 TurtleBot 2i로 zero-shot 전이.
  • DRL + 적절한 보상(C5 해결): PPO로 효율(시간 페널티)·안전(충돌/근접 페널티)·자연스러움(회전 페널티)을 균형.

3. 핵심 방법론 (Core Methods)

3.1 이질적 시공간 상호작용 그래프 (Heterogeneous Spatio-Temporal Graph)

HEIGHT의 출발점은 매 timestep t의 장면을 그래프 𝒢^t = (𝒱^t, ℰ^t) 로 정식화하는 것이다.

노드 정의 (Nodes)

  • 로봇 노드 w^t = (p_x, p_y, u_x, u_y, g_x, g_y, θ) — 위치, 속도, 목표, 헤딩각 (1개)
  • 인간 노드 h_i^t — 각 감지된 인간의 상대 위치(+속도). (가변 n개, ID 추적 없음, L2 거리순 정렬)
    • 시뮬: (p_x^i − p_x, p_y^i − p_y, u_x^i, u_y^i) (속도 포함)
    • 실세계: (p_x^i − p_x, p_y^i − p_y) (속도 추정 어려워 위치만)
  • 장애물 노드 o^t — 모든 정적 장애물을 통합한 2D point cloud (1개)

엣지 정의 (Edges) — 세 가지 이질적 타입

엣지 노드 쌍 방향성 물리적 의미 네트워크 처리
HH (파랑) 인간↔인간 양방향 인간 A가 B를 피하면 로봇도 대응 (간접 효과) self-attention
RH (빨강) 로봇↔인간 양방향 로봇이 직접 제어 가능 (직접 효과) cross-attention
OA (주황) 장애물→에이전트 일방향 정적 장애물은 수동, 로봇/인간만 이동 1D-CNN + FC

여기에 시간 함수(temporal edge, 보라) 가 인접 timestep의 같은 그래프를 연결하여 과거 상태를 추적한다(GRU로 구현).

Parameter sharing의 의미: 동일 edge type은 동일 가중치를 공유한다. 따라서 인간이 5명이든 14명이든 HH/RH attention의 파라미터 수는 일정하다. 이 설계가 훈련(5–9명)과 다른 밀도(0–14명)로의 일반화를 수학적으로 가능케 한다 — 네트워크는 "인간 한 명을 어떻게 처리할지"를 배우고 그것을 임의 수에 반복 적용한다.

장면 표현의 핵심 — 인간/장애물 분리

각 인간:  독립적 상태 벡터  (동적, 양방향 상호작용)  → attention으로 처리
모든 장애물:  통합 point cloud  (정적, 일방향 영향)   → CNN으로 처리

장애물 point cloud o^t 의 생성에는 두 가지 변종이 있다:

  1. Real-time point cloud: 센서(LiDAR)로 실시간 생성. 즉각적이나 LiDAR 시뮬레이션 정밀도가 필요해 sim-to-real 갭이 커진다.
  2. Artificial point cloud: 사전 구축된 지도 + 로봇 위치 기반 raycasting으로 생성. 맵·localization이 필요하지만 센서 노이즈·occlusion에 강건하고 sim-to-real 갭이 작다. 본 논문이 채택한 방식으로, 저충실도 시뮬레이터 학습과 실배치를 모두 지원한다.

3.2 HH Attention — 인간 간 상호작용 (Self-Attention)

인간들 간 상호작용을 self-attention으로 모델링한다. 인간 노드 행렬 [h_1^t, …, h_n^t]^T 로부터 Query/Key/Value를 투영:

Q_HH^t = [h_1^t, ..., h_n^t]^T · W_HH^Q   ∈ ℝ^{n×d}
K_HH^t = [h_1^t, ..., h_n^t]^T · W_HH^K   ∈ ℝ^{n×d}
V_HH^t = [h_1^t, ..., h_n^t]^T · W_HH^V   ∈ ℝ^{n×d}

가중 인간 특징 v_HH^t 는 scaled dot-product attention에 visibility mask M^t 를 더해 계산:

v_HH^t = softmax( (Q_HH^t (K_HH^t)^T + M^t) / √d ) · V_HH^t

Visibility Mask M^t ∈ ℝ^{n×n}

M^t[i,j] = -∞   if  j번째 인간이 시각 t에 감지되지 않음 (occluded / out-of-range)
            0    otherwise

-∞ 항은 softmax를 거치며 exp(-∞)=0 으로 변환되어 해당 인간으로의 attention 가중치를 정확히 0 으로 만든다. 이로써 부분 관측(C3)을 gradient 불편향(unbiased) 하게 처리한다 — 보이지 않는 인간은 손실 함수에 기여하지 않으나, 보이는 인간에 대한 학습은 정상적으로 진행된다.

물리적 의미: HH attention은 각 인간의 "사회적 영향도(social influence)"를 계산한다. 군중 한가운데 있어 여러 인간의 흐름에 영향받는 인간은 높은 가중치를, 외곽의 고립된 인간은 낮은 가중치를 받는다. 이 가중 표현이 다음 단계 RH attention의 입력이 된다.

3.3 RH Attention — 로봇-인간 상호작용 (Cross-Attention)

RH attention은 로봇 관점에서 각 (HH-가중) 인간의 중요도를 학습한다. 핵심은 Query/Key/Value의 출처가 비대칭이라는 점이다:

Q_RH^t = v_HH^t · W_RH^Q   ∈ ℝ^{n×d}   (query: HH로 가중된 인간 특징)
K_RH^t = w^t    · W_RH^K   ∈ ℝ^{1×d}   (key:   로봇 상태)
V_RH^t = v_HH^t · W_RH^V   ∈ ℝ^{n×d}   (value: HH로 가중된 인간 특징)

가중 RH 특징:

v_RH^t = softmax( (Q_RH^t (K_RH^t)^T + M^t) / √d ) · V_RH^t

왜 HH 먼저, RH 나중인가? 이 순차 구조는 "인간들 사이의 사회적 동역학을 먼저 파악(HH)한 뒤, 그 사회적 맥락 위에서 로봇에게 무엇이 중요한지 결정(RH)" 하는 2단계 추론을 인코딩한다. 인간 A가 인간 B 때문에 곧 로봇 경로로 들어올 것이라면, HH가 A의 영향도를 높이고 RH가 이를 로봇 관점에서 "주의해야 할 인간"으로 재가중한다.

3.4 OA Encoder — 장애물-에이전트 상호작용

장애물은 attention 없이 1D-CNN + FC로 처리한다:

v_O^t = f_CNN(o^t)     (장애물 point cloud 임베딩)
v_R^t = f_R(w^t)       (로봇 상태 임베딩)

왜 attention이 아니라 CNN/MLP인가? 논문의 논거(Footnote)는: 에이전트는 각 timestep에서 전체 장애물 집합 중 작은 부분집합과만 상호작용한다(가까운 벽/모서리). 따라서 모든 장애물에 대한 비싼 attention 계산이 불필요하며, point cloud를 CNN으로 임베딩하는 단순 처리로 충분하다. 또한 장애물은 정적이고 일방향이므로(OA edge), 인간처럼 "서로 반응하는" 동역학을 모델링할 필요가 없다.

이것이 이질성(heterogeneity)의 핵심 구현이다 — RH/HH는 attention, OA는 CNN. 상호작용 타입의 성질에 맞춰 서로 다른 연산을 배치한다.

3.5 GRU — 시간적 상호작용 (Temporal Modeling)

공간 추론(HH/RH/OA)의 출력을 시간 축으로 통합한다:

h^t = GRU( h^{t-1}, [v_RH^t, v_R^t, v_O^t] )

GRU는 과거 hidden state h^{t-1} 를 기억하며 현재 공간 임베딩을 누적한다. 이로써 인간의 이동 경향(다가오는지/멀어지는지)과 로봇 자신의 과거 행동을 시간적으로 일관되게 추적한다. 최종 hidden state로부터 가치 함수와 정책을 출력:

V(s^t)        = f_V(h^t)      (가치 헤드)
π(a^t | s^t)  = f_π(h^t)      (정책 헤드)

3.6 보상 함수 (Reward Function)

보상은 세 부분으로 구성된다.

주 보상 r_main(s^t, a^t)

r_main = +20                        if  목표 도달 (d_goal ≤ ρ_robot)
       = -20                        if  충돌      (d_min ≤ 0)
       = d_min - 0.25               if  근접 위험 (0 < d_min < 0.25 m)
       = 4 · (d_goal^{t-1} - d_goal^t)   otherwise  (potential-based shaping)
  • 목표 도달 +20, 충돌 -20 의 강한 단말 보상.
  • 근접 위험 구간(0 < d_min < 0.25 m)에서 d_min − 0.25 로 부드러운 패널티 → 인간/장애물에 너무 붙으면 음의 보상.
  • 4(d_goal^{t-1} − d_goal^t) 는 목표에 가까워질수록 양의 보상을 주는 potential-based shaping 으로, 희소 보상 문제를 완화하고 학습을 가속한다.

회전 페널티 r_spin

r_spin = -0.05 · ‖ω^t‖_2^2

고속 회전을 억제하여 자연스럽고 매끄러운 경로를 유도. 지그재그·과회전을 막는다.

시간 페널티 r_time

r_time = -0.025   (매 timestep)

에피소드 단축을 유도해 효율성(navigation time 단축) 을 촉진.

전체 보상

r(s^t, a^t) = r_main + r_spin + r_time

이 세 항의 균형이 C5(효율·안전·자연스러움 동시 달성)를 직접 다룬다 — r_main이 안전·완수를, r_time이 효율을, r_spin이 자연스러움을 담당한다.

3.7 상태/행동 공간과 PPO 학습

상태 공간

s^t = [w^t, o^t, h_1^t, ..., h_n^t]     (n 가변, ID 추적 없이 L2 거리순 정렬)

행동 공간 (이산, discrete)

병진 가속도:  {-0.05, 0, +0.05} m/s²
회전 가속도:  {-0.1,  0, +0.1 } rad/s²
속도 클리핑:  병진 ∈ [-0.5, 0.5] m/s,  회전 ∈ [-1, 1] rad/s

가속도를 행동으로 두고 속도를 적분·클리핑하는 구조라 부드러운 제어가 가능하다.

학습 — PPO

  • 알고리즘: Proximal Policy Optimization (PPO), 순수 RL(지도학습 사전훈련 없음).
  • 특권 정보(privileged information) 미사용 — 정책 입력 = 로봇이 실제 관측 가능한 상태.
  • 행동은 학습 시 π(a^t|s^t) 에서 샘플링, 테스트 시 최고 확률 행동 선택.
ASCII: HEIGHT 한 스텝 추론
  관측 → [인간 노드 | 장애물 point cloud | 로봇 노드]
            │HH self-attn (+mask)      │1D-CNN          │
            ▼                          ▼                │
         v_HH^t ──RH cross-attn(+mask)─┐  v_O^t         │ v_R^t
                            ▼          │   │            │
                         v_RH^t ───────┴───┴────────────┘
                            ▼
                   GRU(h^{t-1}, [v_RH, v_R, v_O]) → h^t
                            ▼
                   V(s^t),  π(a^t|s^t) ──샘플링──▶ 행동(가속도)

4. 시스템 아키텍처 (System Architecture)

전체 파이프라인:

[센서 입력]
  ├─ 인간 검출(off-the-shelf detector) → 상대 위치(+속도), L2 정렬 → h_1..h_n
  ├─ 장애물 → artificial point cloud(맵+raycasting) → o^t
  └─ 로봇 상태(odometry/localization) → w^t
        │
[공간 추론 — 그래프-유도 이질적 네트워크]
  ├─ HH self-attention  : 인간 간 사회적 영향도 (visibility mask)
  ├─ RH cross-attention : 로봇 관점 인간 중요도 (HH 출력을 query로)
  └─ OA encoder (1D-CNN+FC) : 장애물 영향 임베딩
        │
[시간 추론]
  └─ GRU(h^{t-1}, [v_RH, v_R, v_O]) → h^t
        │
[출력 헤드]
  ├─ V(s^t)        (PPO critic)
  └─ π(a^t|s^t)    (PPO actor) → 행동(병진/회전 가속도)
        │
[실행] 속도 적분·클리핑 → 로봇 모터

설계 미학 — "그래프 구조가 곧 네트워크 구조": HEIGHT의 핵심은 네트워크가 임의로 설계된 것이 아니라 이질적 그래프의 edge type으로부터 직접 유도됐다는 점이다. HH edge → self-attention, RH edge → cross-attention, OA edge → CNN, temporal edge → GRU. 각 컴포넌트가 그래프의 특정 상호작용 타입에 1:1 대응한다. 이 구조적 정합성이 동질 그래프(HomoGAT)와의 본질적 차이이며, 표현 능력 우위의 원천이다.

데이터 흐름의 비대칭성: 정보는 OA(일방향)에서 에이전트로, HH(양방향)에서 인간 간으로, RH(양방향)에서 로봇-인간으로 흐른다. 이 방향성이 attention의 Q/K/V 출처 배치(RH에서 로봇이 key, HH-가중 인간이 query)로 구현된다.

5.4 리얼월드 실험 (Real-world Experiments)

플랫폼: TurtleBot 2i (차동구동 지상 로봇).

핵심 — Zero-shot sim-to-real: PyBullet 저충실도 시뮬에서 학습한 정책을 추가 미세조정 없이 그대로 실로봇에 배치. 이것이 가능한 이유는 정책 입력이 픽셀이 아니라 (상대 위치·속도·artificial point cloud) 구조화된 그래프 표현이기 때문 — 시뮬과 실세계의 표현 분포가 유사해 도메인 갭이 작다.

인식: 인간은 off-the-shelf detector로 검출(ID 추적 없이 위치만), 장애물은 사전 맵 + raycasting으로 artificial point cloud 생성.

환경: 좁은 복도, 혼잡한 라운지 등 일상적 동적 실내 환경. 프로젝트 페이지는 실내·실외 배치 영상을 모두 제공하며, 실패 케이스도 투명하게 공개한다(초고밀도 가림, 자아중심 카메라 제한 FOV에서의 의도 추론 실패).

의의: 단일 환경이 아니라 다양한 실내(복도/라운지) 및 실외에서 zero-shot으로 동작했다는 것은, 그래프 표현이 특정 시뮬 설정에 과적합되지 않았음을 시사한다.

5.5 Ablation Study — 이질성의 분해

논문은 attention 구성요소를 제거하며 이질적 설계의 기여를 분해한다:

변종 구성 결과 경향
No attn HH·RH 모두 제거 최저 — 상호작용 추론 부재
RH only HH 제거(=DS-RNN 유사) 중간 — 인간 간 상호작용 손실
HH only RH 제거 중간 — 로봇 관점 중요도 손실
RH + HH (Full) 완전 HEIGHT 최고 — 두 attention 협력

해석: RH only와 HH only 각각이 No attn보다 낫지만, 둘을 함께 쓴 Full이 일관되게 최고다. 이는 HH(사회적 맥락 파악)와 RH(로봇 관점 재가중)가 상보적(complementary) 임을 보인다 — 어느 하나만으로는 "인간들의 흐름 + 로봇에게 중요한 인간"을 동시에 잡지 못한다. 3.3에서 설명한 "HH 먼저, RH 나중"의 2단계 추론이 ablation으로 정당화된다.

5.6 결과의 심층 해석 — 왜 이질성이 이기는가

세 베이스라인 군의 실패 양상은 서로 다르며, 이것이 HEIGHT 설계 철학을 역으로 증명한다:

  • DWA(반응형): 인간 간 상호작용·미래 의도를 전혀 못 봐 혼잡 환경에서 충돌·freezing.
  • DS-RNN(RH-only): 로봇-인간만 봐서, "인간 A가 B를 피해 로봇 경로로 들어오는" 간접 효과를 놓침.
  • HomoGAT(동질 그래프): 모든 상호작용을 같은 attention으로 처리 → RH(직접)와 HH(간접)의 다른 성질이 평균화되어, 특히 인간 밀도가 높을 때 표현이 무너짐.

HEIGHT의 우위는 "상호작용 타입별 전용 연산(RH/HH=attention, OA=CNN) × parameter sharing(가변 n 확장) × visibility mask(부분관측)" 의 곱으로 나온다. 어느 하나만으로는 OOD 일반화와 sim-to-real를 동시에 달성하지 못한다.

6. 핵심 기여점 (Key Contributions)

  1. 이질적 시공간 상호작용 그래프 정식화. 군중 내비게이션의 상호작용을 RH(직접·양방향)/HH(간접·양방향)/OA(일방향)로 명시적으로 구별하여 그래프로 정식화. 인간과 장애물을 분리 표현(동적 상태 벡터 vs 정적 point cloud)하여 정적/동적의 본질 차이를 보존.

  2. 그래프 구조에서 직접 유도된 이질적 네트워크. 각 edge type에 전용 연산을 1:1 대응 — HH self-attention, RH cross-attention, OA 1D-CNN, temporal GRU. Parameter sharing으로 가변 인간 수 n에 확장하고, visibility mask로 부분 관측을 gradient-불편향하게 처리.

  3. 저충실도 시뮬 → zero-shot 실세계 전이. 픽셀이 아닌 구조화된 그래프 표현 + artificial point cloud 덕분에, PyBullet 저충실도 시뮬에서 학습한 PPO 정책을 추가 학습 없이 TurtleBot 2i로 전이. 실내(복도/라운지)·실외 배치 실증.

  4. 광범위 평가 + OOD 일반화 검증. 동질 그래프(HomoGAT)·RH-only(DS-RNN)·반응형(DWA)·end-to-end(A*+CNN, DRL-VO) 대비 우위. 특히 훈련 분포(5–9명)와 다른 밀도(0–4, 10–14명)에서 일반화 입증 — 혼잡할수록 이질성의 이득 확대.

7.2 구현상의 미묘함

  • L2 거리순 정렬·ID 미추적: 인간 노드를 로봇과의 L2 거리로 정렬하고 ID는 추적하지 않는다. 이는 (i) 실세계에서 안정적 ID 추적이 어렵다는 현실, (ii) parameter sharing과 결합해 가변 n 처리를 단순화한다는 두 이점을 노린 설계다.
  • Artificial point cloud 선택: real-time(센서 직접) 대신 맵+raycasting을 택해 sim-to-real 갭을 줄임. 단 이는 사전 맵·정확한 localization을 요구하며, LiDAR 센서 노이즈·occlusion의 실제 영향을 우회하는 측면이 있다(8장 한계 L2).
  • 이중 attention의 입력 의존성: RH의 query가 HH의 출력 v_HH^t 라는 점이 중요하다. HH가 먼저 계산돼야 RH가 동작하므로 순차 의존이며, 이 순서가 "사회적 맥락 → 로봇 관점" 추론을 강제한다.
  • OA가 CNN인 이유의 코드적 함의: point cloud 크기가 가변일 수 있어 1D-CNN + FC가 고정 차원 임베딩을 만든다. point cloud 가변 길이 처리(pooling 등)는 코드 확인이 필요하다.

7.3 실배치 엔지니어링 고려사항

실로봇(TurtleBot 2i) 설정에서 드러나는 실무적 선택들:

  • 차동구동 + 10 Hz 제어: 0.1s 제어 주기는 군중 회피에 충분히 빠르나, 매우 빠른 보행자(달리는 사람)에는 반응이 늦을 수 있다.
  • off-the-shelf 인간 검출: 검출기 성능이 정책 입력 품질을 좌우. 가림이 심하면 인간 노드가 누락되고(visibility mask가 이를 흡수하지만), 검출 누락 자체가 안전 위험으로 이어질 수 있다.
  • 사전 맵 의존: artificial point cloud는 맵+localization을 요구하므로, 맵이 없는 미지 환경이나 localization 드리프트가 큰 환경에선 OA 입력 품질이 저하된다.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

Parameter sharing의 위력: 인간 수 n에 무관하게 파라미터 수가 일정하므로, 훈련(5–9명)에서 배운 "한 인간 처리 방식"을 임의 n에 적용 가능. OOD 실험(0–14명)이 이를 입증한다.

계산 복잡도의 병목: HH self-attention은 O(n²·d) 로 인간 수에 이차(quadratic) 다. 군중이 매우 밀집(n > 30)하면 실시간 10 Hz 유지가 어려워질 수 있다. 본 논문 평가 범위(최대 14명)에선 문제없으나, 초밀집 플라자·역사 같은 환경 확장에는 sparse/linear attention 같은 보완이 필요하다.

8.2 한계점 (Limitations)

  • (L1) 장애물 통합 표현의 공간 정보 손실: 모든 장애물을 하나의 point cloud 노드로 뭉치면 장애물 간 배치·관계의 세밀도가 약해진다. 복잡한 가구 배치에서 통과 가능 틈(gap)의 미세 판단이 제한될 수 있다. 개선안: 동적 장애물 그래프(각 장애물=노드) — 단 복잡도 증가.
  • (L2) Artificial point cloud가 센서 현실을 우회: 실세계 LiDAR 노이즈·occlusion을 raycasting이 가려, sim-to-real 갭을 인위적으로 작게 만들 가능성. 실제 센서 노이즈 주입 실험이 robust성 검증을 강화할 것이다.
  • (L3) O(n²) HH attention의 확장 한계: 초고밀도(n>30)에서 실시간성·메모리 부담. linear attention 미적용.
  • (L4) ORCA 기반 시뮬 인간의 행동 다양성 부족: 훈련 인간이 ORCA로 생성돼 "최적 회피" 위주. 실세계의 비합리적·예측 불가 행동(멈춤, 군집, 역주행)의 분포를 충분히 담지 못해 일반화에 한계 가능.
  • (L5) 그래프 설계 선택의 일부 미정당화: OA를 MLP/CNN으로, HH/RH를 attention으로 둔 이질적 배치의 ablation(OA-attention vs OA-CNN 비교)은 제한적이다. 이질성의 어느 부분이 결정적인지의 분해가 더 필요하다.

8.3 향후 방향

  • 동적 장애물 그래프화: 장애물을 개별 노드로 모델링해 공간 세밀도 회복(L1).
  • 시간적 attention: GRU 대신 temporal attention으로 인간 궤적 패턴(직선/불규칙)을 명시적으로 학습 — 현재 HH/RH는 현재 프레임만 보고 과거 궤적은 GRU hidden에만 암묵적으로 담긴다.
  • 인간 행동 다양화: ORCA 외에 random walk, 군집, 비합리적 행동을 시뮬에 혼합해 분포 강건성 강화(L4).
  • 확장적 attention: sparse/linear attention으로 O(n²) 완화(L3), 초밀집 환경 지원.

8.6 이론적 위치짓기 — 동질 vs 이질 그래프

HEIGHT는 그래프 신경망(GNN) 기반 군중 내비게이션 계보 안에서, "동질 그래프 → 이질 그래프(heterogeneous graph)"로의 전환을 대표한다. 초기 연구(CADRL, SARL, RGL)는 로봇-인간 상호작용만 또는 동질 attention만 모델링했다. DS-RNN은 RH attention + RNN을 도입했으나 HH를 누락했다. HomoGAT류는 그래프 attention을 쓰되 모든 edge를 동일하게 처리했다. HEIGHT의 기여는 edge type을 명시적으로 구별(heterogeneous) 하고 각 타입에 전용 연산을 배치한 것 — 이는 일반 GNN 문헌의 heterogeneous GNN(R-GCN, HAN 등) 아이디어를 군중 내비게이션의 물리적 상호작용 구조에 특화한 것으로 볼 수 있다.

8.7 더 넓은 맥락 — 의도/상호작용 인지 내비게이션의 스펙트럼

군중 내비게이션 연구는 "보행자를 얼마나 풍부하게 표현하는가"의 스펙트럼 위에 있다:

원판(disk)/점  →  위치+속도  →  상호작용 그래프(HEIGHT)  →  3D 포즈/의도(iCrowdNav)
   (정보 최소)                    (관계 명시)              (선행 운동 신호)

HEIGHT는 에이전트 간 관계(상호작용)를 명시적으로 모델링하는 축에서 강점을 가지며, iCrowdNav류는 개별 보행자의 미래 의도(3D 자세) 를 인코딩하는 축에서 강점을 가진다. 두 축은 직교하며, 결합 가능성이 자연스러운 다음 단계다(9.4 참조).

9.2 장단점 분석

HEIGHT의 강점:

  1. 상호작용 이질성의 명시적 모델링 — iCrowdNav가 개별 보행자의 미래 의도에 집중하는 반면, HEIGHT는 에이전트 간 관계(RH/HH/OA)를 명시적으로 분리한다. 인간이 많아질수록(혼잡) HH 상호작용 수가 폭증하므로, 이를 동질 attention(HomoGAT)으로 뭉개지 않는 HEIGHT의 이득이 OOD에서 확대된다(5.3, 10–14명에서 HomoGAT 대비 +6%p).
  2. 코드 완전 공개로 재현성 최상 — iCrowdNav·ReliaDiffNav가 코드 미공개인 가운데, HEIGHT는 풀스택 + 사전학습 모델 + baseline·ablation 구현까지 공개. 세 비교 논문 중 재현성 최상위.
  3. 구조화 표현으로 견고한 sim-to-real — 픽셀(iCrowdNav RGB-D)보다 추상화된 (상태+point cloud) 표현이 저충실도 시뮬 학습과 zero-shot 전이를 모두 지원. iCrowdNav도 zero-shot을 달성하나 RGB-D 도메인 갭 관리가 더 까다롭다.

HEIGHT의 약점:

  1. 개별 의도 신호의 부재 — iCrowdNav의 3D 포즈는 "그 사람이 회전 중인지/감속 중인지"라는 선행 운동 신호를 담는다. HEIGHT의 (위치+속도) 노드는 이 정보가 없어, 사회적 거리(comfort)·예측적 회피에서 iCrowdNav가 유리할 수 있다. HEIGHT는 관계는 잘 보지만 개별 미래는 GRU의 암묵적 추적에 의존한다.
  2. 장애물 통합 표현의 세밀도 손실 — LP-NavOA류 로컬 내비가 장애물을 더 정밀히 다룰 수 있는 반면, HEIGHT는 모든 장애물을 한 point cloud 노드로 통합해 미세 틈 판단이 제한된다(L1).
  3. O(n²) HH attention의 확장 한계 — 초밀집에서 실시간성 부담. iCrowdNav·diffusion 계열과의 직접적 속도 비교는 제한적이다.

9.3 실적용 가능성 평가

  • HEIGHT: 코드 공개 + zero-shot 실로봇(TurtleBot 2i) + 10 Hz 실시간 + OOD 일반화 → 즉시 실배치 후보로 강함. 특히 사전 맵이 있는 실내(병원 복도, 사무실, 라운지)에서 중밀도 군중 회피에 적합. 단 사전 맵 의존·초밀집 한계로 미지/초혼잡 환경엔 보완 필요.
  • iCrowdNav: 의도-인지로 사회적 적절성(comfort) 이 critical한 응용(서비스 로봇, 공공장소)에 우위. 단 코드 미공개로 즉시 재현은 어려움.
  • LP-NavOA: 제한된 온보드 인식만 가능한 휴머노이드 플랫폼의 로컬 회피에 특화.

9.4 연구 방향성 평가

HEIGHT는 군중 내비게이션의 무게중심을 "동질 표현 → 이질적 상호작용 그래프" 로 옮긴다. 이는 iCrowdNav의 축(개별 의도 인코딩)과 직교한다. 따라서 결합이 자연스럽다 — 예: HEIGHT의 인간 노드 특징에 iCrowdNav의 3D 포즈 의도 임베딩을 주입하면, "에이전트 간 관계(HEIGHT) + 개별 미래 의도(iCrowdNav)"를 동시에 잡는 하이브리드가 된다. 또한 HEIGHT의 OA-CNN을 LP-NavOA류의 정밀 로컬맵으로 대체하면 장애물 세밀도(L1)를 보완할 수 있다.

9.5 일반화 가능성

HEIGHT의 "이질적 그래프 + edge-type별 전용 연산 + parameter sharing"은 군중 내비게이션에 국한되지 않는다. 다종(multi-type) 에이전트가 상호작용하는 모든 의사결정 — 다중 로봇 협조, 자율주행의 차량/보행자/신호 이질 상호작용, 멀티에이전트 RL — 에 이식 가능한 일반 레시피다. 핵심 원리는 "상호작용의 물리적 타입이 다르면 같은 연산으로 처리하지 말라"이며, 이는 도메인 무관하게 유효하다.

  • 관련 기법/베이스라인: DS-RNN (Liu et al., decentralized structural-RNN), HomoGAT(동질 graph attention), DWA (Fox et al., 1997), DRL-VO, ORCA (van den Berg et al.), Social Force Model (Helbing & Molnár, 1995), PPO (Schulman et al., 2017), GRU (Cho et al., 2014), Graph Attention Networks (Veličković et al., 2018).

11. 결론 (Conclusion)

혁신성

HEIGHT의 핵심 혁신은 군중 내비게이션의 상호작용을 "동질적(homogeneous)"이라는 암묵적 가정에서 해방시킨 것이다. RH(직접·양방향)/HH(간접·양방향)/OA(일방향)를 명시적으로 구별하는 이질적 시공간 그래프를 정의하고, 각 edge type에 전용 연산(HH self-attention, RH cross-attention, OA 1D-CNN, temporal GRU)을 1:1 대응시켜 그래프 구조가 곧 네트워크 구조가 되게 했다. Parameter sharing으로 가변 인간 수에 확장하고, visibility mask(-∞)로 부분 관측을 gradient-불편향하게 처리하며, PPO로 효율·안전·자연스러움을 균형 잡는다.

실용적 의의

저충실도 PyBullet 시뮬에서 학습한 정책이 추가 미세조정 없이(zero-shot) TurtleBot 2i 실로봇으로 전이되어 실내(복도·라운지)·실외 동적 환경에서 동작했다. 이는 정책 입력이 픽셀이 아닌 구조화된 그래프 표현 + artificial point cloud이기 때문이며, 도메인 갭이 작다는 설계 철학의 직접 증거다. 코드·영상·사전학습 모델이 완전 공개(github.com/Shuijing725/CrowdNav_HEIGHT)되어 재현성이 본 코퍼스 군중 내비 논문 중 최상위다.

향후 연구 방향

한계는 (i) 장애물 통합 표현의 공간 세밀도 손실, (ii) artificial point cloud가 실센서 노이즈를 우회, (iii) O(n²) HH attention의 초밀집 확장 한계, (iv) ORCA 시뮬 인간의 행동 다양성 부족, (v) 이질적 설계 선택의 부분적 ablation 미흡에 있다. 따라서 장애물 그래프화, temporal attention 도입, 인간 행동 다양화, sparse/linear attention 확장, 개별 의도(3D 포즈) 임베딩 결합이 자연스러운 다음 단계다.

종합 평가

HEIGHT는 군중 내비게이션의 오랜 약점인 "상호작용을 동질적으로 뭉개는 표현"을, 이질적 그래프 + edge-type별 전용 연산으로 정면 돌파한다. 핵심 실험 증거는 두 가지다: (1) 혼잡도가 올라갈수록 동질 그래프(HomoGAT) 대비 이득이 확대(훈련분포 +2%p → 10–14명 OOD +6%p)되어 "이질성이 필요하다"는 주장을 직접 입증하고, (2) 저충실도 시뮬 → zero-shot 실로봇 전이가 다양한 실내·실외에서 성립하여 구조화 표현의 sim-to-real 우위를 보인다. 평가 측면에서도 동질 그래프·RH-only·반응형·end-to-end를 폭넓게 비교하고 ablation으로 HH/RH의 상보성을 분해했으며, 완전한 오픈소스로 재현성을 담보했다. 다만 개별 보행자의 미래 의도 신호(iCrowdNav의 3D 포즈가 담는)를 표현에 담지 못해 사회적 적절성(comfort) 측면에선 보완 여지가 있고, 가장 어려운 초밀집·비합리 행동 시나리오의 정량 검증이 제한적이라는 점은 후속 연구가 메울 빈칸이다. 그럼에도 "상호작용의 물리적 타입이 다르면 같은 연산으로 처리하지 말라"는 명료한 원리와 즉시 재현 가능한 풀스택 오픈소스는, 본 논문을 GNN 기반 군중 내비게이션 흐름에서 주목할 가치가 높은 T-ASE 결과로 만든다.
