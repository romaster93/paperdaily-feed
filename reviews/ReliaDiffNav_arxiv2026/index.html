1.2 연구 목표 (Research Objective)

이 논문은 "종단간(end-to-end) 생성형 UAV 궤적 플래너가 지각(perception)을 신뢰할 수 없는 영역에서도 안전하게 비행하도록 만들 수 있는가" 라는 문제를 푼다.

전통적 UAV 내비게이션은 지각 → 매핑 → 계획을 분리된 단계로 처리한다. 이 파이프라인은 (1) 단계 간 오차 전파, (2) 지연 누적, (3) 환경마다 재튜닝 필요라는 고질병을 안는다. 이를 해결하려 종단간 생성 모델(관찰 → 궤적 직접 매핑)이 등장했으나, 이들은 깨끗한 데이터로만 학습되어 "관찰이 신뢰 불가능한 순간"을 인지하지 못한다. 그 결과 유리·거울·과노출 표면 같은 지각 실패 영역을 유효한 자유공간으로 오인해 충돌한다.

저자들의 핵심 아이디어는 "신뢰도(reliability)를 1급 시민으로 만든 디퓨전 플래너" 다. 구체적으로:

  1. 신뢰도 히트맵: 비전-언어 모델(VLM)의 open-vocabulary 추론을 경량 네트워크로 증류(distill)하여, "어디를 믿으면 안 되는가"를 실시간 예산 안에서 픽셀 단위로 예측.
  2. 신뢰도 조건 디퓨전: 궤적 생성을 관찰 + 신뢰도 히트맵에 조건화.
  3. 2단계 ESDF 가이드: 디노이징 과정을, 깊이에서 온 물리적 장애물과 신뢰 불가 영역에서 온 가상 장애물을 동등하게 다루는 미분가능 ESDF 비용으로 조향.

결과적으로 실제 쿼드로터에서 장애물 위반율을 40.3%→9.6%로 낮추고, 주행 영역의 평균 신뢰도를 0.588→0.925로 끌어올린다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

C1. 모듈러 파이프라인의 구조적 취약성. 지각·매핑·계획 분리 구조는 각 모듈 경계에서 오차가 전파되고 지연이 쌓이며, 새 환경마다 수동 재튜닝이 필요하다.

C2. 생성 플래너의 "지각 과신(perceptual overconfidence)". 종단간 디퓨전/플로우 플래너는 깨끗한 학습 데이터에 적합되어, 유리·거울·반사·과노출처럼 센서가 실패하는 영역을 자유공간으로 착각한다. 깊이 센서(스테레오/ToF)는 이런 표면에서 잘못된(가까운/먼) 깊이를 반환하므로, 깊이 기반 ESDF만으로는 가상의 위험을 포착할 수 없다.

C3. 신뢰도 추론의 실시간 예산. "어디가 믿을 수 없는가"는 의미적 판단이라 VLM이 잘하지만, VLM을 매 프레임 돌리면 온보드 실시간 계획 예산(수십 ms)을 초과한다. 즉 의미적 신뢰도 판단을 경량화해야 한다.

C4. 미지 환경으로의 일반화. 학습 분포 밖의 새 환경에서 재학습 없이 작동해야 한다. 학습된 정책의 사전분포만으로는 새로운 장애물 배치에 취약하다.

C5. 안전과 목표 도달의 균형. 신뢰 불가 영역을 무조건 회피하면 경로가 막히거나 목표 도달에 실패한다(논문 ablation의 delta-path 변형이 실제로 이 함정에 빠진다 — §5.5). 안전성을 높이되 목표 도달성을 해치지 않아야 한다.

2.2 핵심 해결책

  • C1 → 종단간 디퓨전 플래너로 관찰에서 궤적을 직접 생성.
  • C2 → 신뢰도 히트맵을 디퓨전 조건 + 가이드 비용에 명시적으로 주입. 신뢰 불가 영역을 가상 장애물로 ESDF에 합류.
  • C3 → AnyTraverse(VLM 교사)를 경량 MiT-B0 학생으로 증류 → VLM 대비 최대 2× 가속.
  • C4 → 학습-불요(training-free) 가이드: 디노이징 score에 ESDF 비용 그래디언트를 더해, 학습 분포 밖에서도 기하 제약을 강제.
  • C5 → 2단계(hard/weak) 신뢰도 임계와 안전 보조손실 L_safe로 안전·도달을 절충.

3. 핵심 방법론 (Core Methods)

표기 (Notation)
  I            : RGB 관찰 이미지
  M ∈ [0,1]^HW : 신뢰도 히트맵 (낮을수록 지각 신뢰 불가)
  x_t          : 디퓨전 타임스텝 t의 (노이즈 섞인) 궤적
  ε, ε_θ       : 가우시안 노이즈 / 노이즈 예측 1D U-Net
  ᾱ_t          : DDPM 누적 노이즈 스케줄
  c            : 조건 집합 {v_0, g, F_I, F_S}
  C            : 가이드 비용 (obs + goal + perc)
  τ_h, τ_s     : hard/weak 신뢰도 임계 (0.3 / 0.6)

3.1 신뢰도 히트맵 네트워크 (Distilled Reliability)

핵심 1단계는 "어디를 믿으면 안 되는가"를 VLM에서 증류한 경량 네트워크로 예측하는 것이다.

교사-학생 증류 (teacher-student distillation).

  • 교사(teacher): AnyTraverse — VLM 기반 traversability 프레임워크. 오프라인에서 지도(supervision)를 생성.
  • 학생(student): 경량 MiT-B0 백본 + 전(全) 인코더 스케일에서의 깊이 융합(depth fusion).
  • 특징 감독(feature supervision): 고정(frozen)된 ViT-Adapter/DINOv2가 다중 스케일 특징 감독을 제공.

출력 정의.

M = 1 − AnyTraverse(I; w)        # M: 신뢰도 히트맵, 낮을수록 위험
   가중치 w:  유리(glass)=1.0, 플레어/과노출=1.0, 반사면=1.0, 광택면=1.0

즉 traversability가 높은(통행가능) 영역은 신뢰도 높음(M↑), 유리·거울·과노출 같은 영역은 신뢰도 낮음(M↓)으로 사상된다.

증류 손실(3중).

ℒ_feat : 인코더 스케일별 코사인 비유사도(feature imitation)
ℒ_task : 하드-네거티브 가중 L1 픽셀 회귀
         w_i = 1 + w_max·(1 − M_T,i),  w_max = 4
         → 신뢰 불가(M_T 낮음) 픽셀에 최대 5배 가중 (놓치면 치명적이므로)
ℒ_SSIM = 1 − SSIM(M_S, M_T)      # 안전/위험 경계 보존

ℒ_distill = w_feat·ℒ_feat + w_task·[ (1−w_ssim)·ℒ_task + w_ssim·ℒ_SSIM ]

하드-네거티브 가중(w_max=4)이 핵심이다 — 신뢰 불가 영역을 놓치는 것이 안전상 가장 위험하므로, 그 픽셀의 회귀 오차에 최대 5배(1+4) 가중을 준다. SSIM 항은 경계가 뭉개지지 않게 구조 보존.

효과: VLM의 의미적 신뢰도 판단을 MiT-B0 한 번의 순전파로 근사 → 전체 프레임워크 최대 2× 가속(C3 해소), off-board RTX 4070에서 500MB 메모리로 동작.

3.2 신뢰도 조건 디퓨전 플래너 (Conditional Diffusion Planner)

2단계는 표준 DDPM 으로 3D 궤적을 생성하되, 신뢰도를 조건으로 받는다.

디퓨전 정식화.

순방향:  x_t = √ᾱ_t · x_0 + √(1−ᾱ_t) · ε
손실:    ℒ_diff = E[ ‖ ε − ε_θ(x_t, t, c) ‖² ]
백본:    1D U-Net ε_θ

조건 집합 c = {v_0, g, F_I, F_S}.

  • v_0 (초기 속도): FiLM으로 주입.
  • g (목표 위치): FiLM으로 주입.
  • F_I (이미지 특징): 학생 인코더(또는 VLM 인코더)에서 추출.
  • F_S (신뢰도 맵 패치 토큰): 히트맵 M을 패치 토큰화.
  • 공간 구조 입력(F_I, F_S)은 U-Net 병목(bottleneck)에서 2개의 순차 cross-attention 블록으로 주입.

상태 표현.

  • 궤적은 절대 ego-frame waypoint s_i ∈ ℝ³의 열. (절대 vs 변위 둘 다 실험 — ego-path(절대)가 우수, §5.5 delta-path 실패 참조.)

보조 손실.

ℒ = ℒ_diff + λ1·ℒ_smooth + λ2·ℒ_origin + λ3·ℒ_speed + λ4·ℒ_safe
   ℒ_safe = (1/|𝒱|) · Σ_{i∈𝒱} (1 − τ_i)    # 저신뢰 영역 통과 waypoint 패널티

L_safe는 궤적 waypoint가 통과하는 영역의 신뢰도 τ_i가 낮을수록 벌점을 주어, 학습 단계에서부터 신뢰 불가 영역을 피하도록 유도한다. L_smooth(평활), L_origin(시작점 정합), L_speed(속도 일관)는 물리적 실행가능성 보장.

3.3 2단계 미분가능 ESDF 가이드 (Two-Stage Guidance)

3단계는 학습-불요(training-free) 가이드 로, 디노이징 score에 비용 그래디언트를 더해 궤적을 안전 방향으로 조향한다.

가이드 메커니즘.

ε̃_θ(x_t, t) = ε_θ(x_t, t, c) − s · ∇_{x_t} C        # s: 가이드 스케일
C = w_obs·C_obs + w_goal·C_goal + w_perc·C_perc

핵심 — 물리 장애물과 가상 장애물의 동등 취급. 신뢰도 맵 M_S를 두 임계로 나눠 ESDF에 합류시킨다.

① Hard (M_S ≤ τ_h=0.3): "확실히 못 믿는" 영역
     → 여러 깊이로 역투영(back-project)하여 깊이 포인트클라우드에 병합
     → ESDF 구성 시 물리 장애물과 똑같이 취급 (C_obs에 포함)
② Weak (τ_h < M_S ≤ τ_s=0.6): "애매하게 못 믿는" 영역
     → 별도의 약한 CHOMP 비용(C_perc)
     → 활성화 거리 η_perc > η_obs (더 멀리서부터 부드럽게 밀어냄)

즉 유리·거울 같은 가상 위험이 깊이로는 안 보여도, 신뢰도 맵을 통해 ESDF의 장애물로 "물질화"된다. 이것이 본 논문의 가장 독창적인 지점이다 — 깊이 센서가 실패하는 바로 그 영역을, 의미적 신뢰도가 메워 안전 여유(clearance)를 만든다.

목표 비용.

C_goal = ‖ p_H − g ‖²₂        # 최종 waypoint p_H와 목표 g의 제곱거리

절대 표현에서의 가이드 스텝(clean-manifold projection).

x̂_0  = ( x_t − √(1−ᾱ_t)·ε_θ(x_t,t,c) ) / √ᾱ_t      # 깨끗한 궤적 추정
(메트릭 좌표에서 ∇C 계산 → x̂_0* 로 업데이트)
ε̂   = ( x_t − √ᾱ_t·x̂_0* ) / √(1−ᾱ_t)               # 갱신된 노이즈로 환원

노이즈 궤적을 한 번 깨끗한 궤적 x̂_0로 투영해 실제 미터 좌표계에서 비용 그래디언트를 계산한 뒤, 다시 노이즈 공간으로 환원한다. 이로써 가이드가 물리적으로 의미 있는 방향(미터 단위 거리·여유)으로 작동한다.

4.2 데이터 흐름 요약

  1. 지각: RGB(+깊이) → 신뢰도 히트맵 M(경량, ~2× 빠름).
  2. 생성: 관찰·목표·속도·신뢰도 조건으로 디퓨전이 궤적 사전분포 샘플.
  3. 가이드: 매 디노이징 스텝에서 ESDF(물리+가상 장애물) 비용 그래디언트로 궤적을 안전 방향 조향.
  4. 실행: 절대 ego-frame waypoint를 ArduPilot으로 추종.

  • 4단계 데이터 생성 파이프라인: 스테레오 깊이 재구성 → 신뢰도 맵 추정 → 기하 경로 계획 → 물리 기반 궤적 시뮬레이션.

5.2 평가 지표 (Evaluation Metrics)

  • Min. Distance to Obstacle (m): 장애물까지 최소 거리(클수록 안전).
  • Clearance (m): 평균 여유 거리.
  • Obstacle Violation (%): 장애물 침범 비율(작을수록 안전).
  • Mean Reliability: 주행 영역의 평균 신뢰도(클수록 안전한 영역 주행).
  • (ablation) Path Efficiency, Trajectory Length, Goal Error(m).

5.4 리얼월드 실험 (Real-world Experiments)

본 논문은 실제 쿼드로터 비행 실험을 포함한다(본 코퍼스 1순위 가치 중 하나).

  • 기체: 8인치 프레임 커스텀 쿼드로터.
  • 저수준 제어: ArduPilot via MAVROS.
  • 센서: Intel RealSense D455 깊이 카메라.
  • 연산: off-board 단일 NVIDIA RTX 4070 GPU, 메모리 사용 500 MB.
  • 속도: 증류 학생 덕에 전체 프레임워크 최대 2× 가속(VLM 직접 호출 대비).
  • 시뮬(Pegasus)에서 학습한 정책이 실기에서 더 안전한 궤적을 생성함을 정성·정량으로 확인.

5.5 어블레이션 및 분석 (Ablations & Analysis)

  • 신뢰도 항 제거: 평균 신뢰도 0.898 → 0.783 하락 → 신뢰도 조건/비용이 안전 영역 주행에 직접 기여.
  • delta-path 변형(변위 표현): 평균 신뢰도 0.925로 높았으나 목표 도달 실패(목표 오차 1.959 m vs ego-path 0.710 m). → 절대 ego-frame 표현이 안전·도달 균형에 필수(C5).
  • 가이드 비활성화: path efficiency 0.867(직선 경로, 장애물 회피 없음).
  • 가이드 활성화: 궤적 길이 5.027 ± 0.871 m(안전을 위한 우회 발생).

이 ablation들은 세 구성요소(신뢰도 조건, 절대 표현, ESDF 가이드)가 각각 독립적으로 안전·도달성에 기여함을 보인다.

6. 핵심 기여점 (Key Contributions)

기여 1 — 신뢰도를 1급 시민으로 만든 종단간 UAV 디퓨전 플래너. 기존 종단간 생성 플래너는 관찰을 무비판적으로 신뢰한다. 본 논문은 "지각이 실패하는 곳"을 명시적 신뢰도 신호로 모델 전 과정(조건 + 가이드 비용 + 학습 손실)에 주입한 최초 부류의 UAV 플래너다. 이는 단순한 안전 후처리가 아니라, 생성 사전분포 자체를 신뢰도에 조건화한다는 점에서 구조적이다.

기여 2 — VLM 신뢰도의 실시간 증류(distillation). open-vocabulary VLM(AnyTraverse)의 의미적 traversability 판단을 MiT-B0 경량 학생으로 증류하여, 온보드 실시간 예산(500MB, 2× 가속) 안에서 픽셀 단위 신뢰도를 산출한다. 하드-네거티브 가중(w_max=4) + SSIM 경계 보존은 "안전상 치명적인 저신뢰 영역을 절대 놓치지 않게" 설계된 증류 목적함수다.

기여 3 — 물리·가상 장애물을 동등 취급하는 2단계 ESDF 가이드. 신뢰 불가 영역(유리·거울 등)을 깊이로 역투영해 물리 장애물과 같은 ESDF에 합류시키고(hard, M≤0.3), 애매한 영역은 더 멀리서 작동하는 약한 CHOMP 비용(weak, 0.3<M≤0.6)으로 다룬다. 학습-불요(training-free) 가이드라 재학습 없이 새 환경의 기하 제약을 강제(C4 해소). clean-manifold 투영으로 미터 단위 좌표에서 그래디언트를 계산하는 점도 실용적 디테일.

기여 4 — 실제 쿼드로터 검증 + 설계 선택의 정량적 정당화. Pegasus 시뮬 학습 → RealSense D455 탑재 8인치 커스텀 쿼드로터(ArduPilot/MAVROS) 실비행. ego-path vs delta-path, 가이드 on/off, 신뢰도 항 유무를 ablation으로 분리해 각 구성요소의 기여를 입증.

7. 구현 상세 (Implementation Details)

7.1 신뢰도 네트워크

  • 교사: AnyTraverse(VLM traversability), 오프라인 지도 생성.
  • 학생: MiT-B0 + 전 인코더 스케일 깊이 융합.
  • 특징 감독: frozen ViT-Adapter / DINOv2 다중 스케일.
  • 손실 가중: 하드-네거티브 w_max = 4; M = 1 − AnyTraverse(I;w), w(glass/flare/reflective/glossy)=1.0.
  • 손실: ℒ_distill = w_feat·ℒ_feat + w_task·[(1−w_ssim)·ℒ_task + w_ssim·ℒ_SSIM].

7.2 디퓨전 플래너

  • 백본: 1D U-Net ε_θ, 표준 DDPM 스케줄 ᾱ_t.
  • 조건 주입: v_0, g → FiLM; F_I, F_S → 병목 2× 순차 cross-attention.
  • 상태: 절대 ego-frame waypoint s_i ∈ ℝ³.
  • 손실: ℒ = ℒ_diff + λ1 ℒ_smooth + λ2 ℒ_origin + λ3 ℒ_speed + λ4 ℒ_safe, ℒ_safe = (1/|𝒱|)Σ(1−τ_i).

7.3 가이드

  • 임계: τ_h = 0.3(hard, 깊이 역투영→ESDF C_obs), τ_s = 0.6(weak 상한, CHOMP C_perc).
  • 활성화 거리: η_perc > η_obs(약한 영역은 더 멀리서부터 부드럽게).
  • 비용: C = w_obs C_obs + w_goal C_goal + w_perc C_perc, C_goal = ‖p_H − g‖².
  • 가이드 스텝: ε̃_θ = ε_θ − s·∇_{x_t}C, clean-manifold 투영 x̂_0 = (x_t − √(1−ᾱ_t)ε_θ)/√ᾱ_t.

7.4 시스템

  • 시뮬: Pegasus Simulator(창고), 4단계 데이터 파이프라인.
  • 실기: 8인치 커스텀 쿼드로터, ArduPilot/MAVROS, RealSense D455, off-board RTX 4070(500MB), 2× 가속.
  • 베이스라인: NoMaD.

8. 고급 주제 (Advanced Topics)

8.1 확장성 (Scalability)

  • 개념적 확장성 우수: 신뢰도 히트맵은 RGB만 있으면 산출되므로, 지상 로봇·매니퓰레이터 등 다른 도메인에도 "센서가 못 믿는 영역을 가상 장애물화"하는 패러다임을 이식 가능. 단 본 논문은 UAV에 한정 검증.
  • 연산 확장성: 학생 증류로 온보드 예산 내 동작하지만 GPU(RTX 4070)는 여전히 off-board다. 완전 온보드(Jetson급) 동작은 향후 과제.

8.2 한계점 (Limitations)

  1. 코드·프로젝트 페이지 미공개 — 재현성 제약(본 코퍼스 1순위 기준 미충족). 임계·가중(λ, w, η, s)이 본문에서 완전히 수치화되지 않은 부분이 있어, 코드 없이는 재현 난도 높음.
  2. 소속·증류 세부 일부 미기재 — 소속이 본문에 없고(추정만 가능), 일부 손실 가중 수치가 부분적.
  3. 단일 베이스라인(NoMaD) 비교 — 강력하긴 하나, 최신 플로우 매칭/안전-인지 플래너(예: DreamFlow, SafeNavNeRF)와의 직접 비교 부재.
  4. off-board 연산 의존 — RTX 4070 off-board는 실배치 시 통신 지연·연결 끊김 리스크.
  5. 시뮬→실기 도메인 갭 — Pegasus 창고 한정 학습. 야외·동적 장애물 일반화는 미검증.
  6. 신뢰도 교사 의존성 — AnyTraverse(VLM)의 편향이 학생에 그대로 증류됨. 교사가 못 잡는 실패 모드(예: 비전형적 반사)는 그대로 사각지대.

8.3 향후 방향 (Future Directions)

  • 완전 온보드 추론(경량화·양자화), 동적 장애물·야외 일반화, 다중 베이스라인 벤치마크, 신뢰도 교사 앙상블/온라인 보정, 다른 로봇 도메인(지상/매니퓰레이션)으로의 이식.

9. 비교 분석 (Comparative Analysis)

본 절은 5단계 바운드 읽기 프로토콜에 따라, 같은 Planner 트랙에서 토픽이 가장 가까운 선행 리뷰 — DreamFlow(생성형 로컬 내비, 실로봇), SobolevDiffusion(디퓨전 기반 궤적최적화 가속), SafeNavNeRF(지각 신뢰성/안전 인지 내비) — 와 비교한다.

9.2 장단점 분석

장점.

  • 고유한 문제 설정: 위 세 선행 중 *지각 신뢰성(유리/거울/과노출)*을 플래너 1급 신호로 삼은 것은 본 논문뿐. SafeNavNeRF가 "안전"을 다루지만 그것은 기하/도달성 안전이지 센서 신뢰성 안전이 아니다. 본 논문은 "깊이로는 안 보이는 가상 위험"이라는 직교 축을 연다.
  • training-free 가이드의 일반화: SobolevDiffusion이 학습 단계에서 그래디언트 사전을 주입하는 반면, 본 논문은 추론 시 ESDF 그래디언트를 더해 재학습 없이 새 기하에 적응. DreamFlow의 순수 학습 정책 대비 분포 밖 강건성에 유리.
  • 실로봇 검증: DreamFlow와 더불어 실제 하드웨어 검증을 갖춰, 시뮬 한정 SafeNavNeRF보다 실적용 신뢰도가 높다.

단점.

  • 재현성: DreamFlow/SobolevDiffusion 대비 코드 미공개 + 일부 하이퍼파라미터 미기재로 재현 난도 최상.
  • 비교 빈약: 베이스라인이 NoMaD 단일. DreamFlow는 다수 베이스라인·환경 난이도(Maze Hard 83.1%/Hallway 89.8%)로 폭넓게 검증.
  • off-board 의존: DreamFlow가 4족 온보드 지향인 데 비해 본 논문은 off-board RTX 4070 필요.

9.3 실적용 가능성 평가

  • 즉시성: 실비행 검증은 강점이나, off-board GPU + 코드 미공개로 현 시점 즉시 재현·배치는 어려움. SobolevDiffusion(워밍스타트 가속, 모듈식 삽입 용이)이 단기 실용성은 더 높을 수 있다.
  • 차별적 가치: "유리·거울 많은 실내(쇼핑몰·공항·전시장) UAV 점검"처럼 지각 실패가 빈번한 환경에서 본 논문의 가치가 독보적. 이 틈새에서는 DreamFlow/SafeNavNeRF가 대체 불가.

9.4 연구 방향성 평가

  • 본 논문은 "생성 플래너 + 의미적 신뢰도"라는 새로운 결합을 개척했다. 향후 (a) 신뢰도 교사를 NeRF 불확실성(SafeNavNeRF)과 융합, (b) SobolevDiffusion식 그래디언트 사전으로 가이드를 가속, (c) DreamFlow식 다환경·온보드 검증으로 확장하면, 세 선행의 강점을 흡수하는 통합 안전-인지 생성 플래너로 발전 가능하다.

혁신성. 이 논문의 핵심 통찰은 단순하면서 강력하다 — "깊이 센서가 못 보는 위험(유리·거울·과노출)을, 의미적 신뢰도로 메워 ESDF의 가상 장애물로 물질화한다." 종단간 디퓨전 플래너에 지각 신뢰성을 1급 시민으로 통합하고, 그 신뢰도를 VLM에서 실시간 예산으로 증류했으며, training-free 2단계 가이드로 물리·가상 장애물을 동등 취급한다. 이는 본 Planner 코퍼스에서 "안전"을 기하적 도달성이 아니라 센서 신뢰성의 축으로 재정의한 첫 사례다.

실용적 의의. 실제 쿼드로터에서 장애물 위반율 40.3→9.6%, 주행 신뢰도 0.588→0.925라는 실측은, 유리·반사면이 많은 실내 점검 UAV처럼 지각 실패가 잦은 환경에서 직접적 가치를 갖는다. ego-path/가이드/신뢰도 항을 분리한 ablation은 각 설계 선택을 정량적으로 정당화한다.

향후 연구 방향. (1) 완전 온보드 추론을 위한 경량화, (2) 단일 NoMaD를 넘어선 다중 베이스라인·다환경 벤치마크, (3) 동적 장애물·야외 일반화, (4) 신뢰도 교사 앙상블·온라인 보정으로 사각지대 축소, (5) 코드·하이퍼파라미터 공개를 통한 재현성 확보. 무엇보다 코드 공개가 이 우수한 아이디어의 영향력을 좌우할 것이다.

부록 A. 심화 분석 (In-depth Analysis)

A.1 왜 "신뢰도 = 1 − traversability" 인가 — 의미론적 정당화

전통적 비용맵은 *기하적 점유(occupancy)*를 인코딩한다. 그러나 유리벽은 깊이상 "비어 있음"으로 보이면서 물리적으로는 "막힘"이다 — 기하 점유와 물리 통행가능성이 어긋나는 영역이다. AnyTraverse 같은 VLM은 "이것은 유리다 → 통행 불가/위험"을 의미적으로 판정한다. 따라서 M = 1 − traversability는 기하로는 안 보이지만 의미로는 막힌 영역을 정확히 집어낸다. 본 논문의 가상-장애물 ESDF 합류는 이 의미적 판정을 다시 기하적 비용으로 환원해, 디퓨전 가이드가 사용할 수 있는 형태로 만든다. 즉 의미 → 기하 변환 브리지가 이 방법의 본질이다.

A.2 2단계 임계(hard/weak)의 정보이론적 해석

신뢰도는 연속값 M∈[0,1]이지만, 이를 그대로 단일 비용으로 쓰면 (a) 임계 근처에서 가이드가 불안정하고, (b) "확실히 위험"과 "애매"가 같은 강도로 작동한다. 2단계 분할은 신뢰도를 세 구간으로 양자화한다:

M ≤ 0.3        : 확실한 위험 → 깊이 역투영, 물리 장애물과 동급(강한 회피)
0.3 < M ≤ 0.6  : 애매한 위험 → 약한 CHOMP, 먼 거리부터 부드럽게(η_perc>η_obs)
M > 0.6        : 신뢰 → 비용 없음(자유 비행)

hard 영역에 강한 ESDF, weak 영역에 멀리서 작동하는 약한 비용을 두는 것은, 확신 정도에 비례해 회피 강도를 조절하는 위험-민감(risk-sensitive) 설계다. 이는 단일 임계로는 표현 못 하는 "조심하되 막지는 않는" 중간 거동(C5의 안전-도달 균형)을 만든다.

A.3 ego-path(절대) vs delta-path(변위) — ablation의 심층 의미

delta-path 변형이 신뢰도 0.925로 가장 안전했으나 목표 오차 1.959m로 도달 실패한 현상은 시사적이다. 변위(델타) 표현은 매 스텝 상대 이동을 예측하므로 오차가 누적되어, 안전 영역으로는 잘 가지만 목표라는 절대 좌표에는 표류한다. 절대 ego-frame은 각 waypoint를 ego 원점 기준 절대 위치로 고정해 C_goal = ‖p_H − g‖² 가이드가 일관되게 작동한다. 이는 디퓨전 궤적 표현 설계에서 "가이드 비용이 정의된 좌표계와 상태 표현 좌표계를 일치"시켜야 한다는 일반 교훈을 준다.

A.4 training-free 가이드의 분포 밖 강건성

학습된 정책(DreamFlow류)은 학습 분포 내에서 강하나 새 장애물 배치에 취약하다. 본 논문의 가이드 ε̃_θ = ε_θ − s·∇C는 추론 시점에 현재 관찰에서 즉석 구성한 ESDF의 그래디언트를 더하므로, 사전분포가 못 본 기하라도 비용이 즉시 반영된다. 디퓨전 사전분포(자연스러운 비행 패턴) + 추론 시 기하 제약(안전)의 역할 분담이 핵심이다 — 사전분포는 "어떻게 나는가"를, 가이드는 "어디를 피하는가"를 담당한다.

부록 B. 디퓨전 가이드 메커니즘 의사코드 (Pseudocode)

B.1 학습 (Training)

입력: 시뮬 궤적 데이터셋 D = {(I, depth, v_0, g, x_0)}
신뢰도 교사 AnyTraverse 고정, 학생 S_θ, 디퓨전 ε_θ

# 단계 1: 신뢰도 학생 증류
for (I, depth) in D:
    M_T = 1 − AnyTraverse(I; w)            # 교사 라벨
    M_S = S_θ(I, depth)                    # 학생 예측
    w_i = 1 + 4·(1 − M_T,i)                # 하드-네거티브 가중
    ℒ_task = Σ w_i·|M_S,i − M_T,i|
    ℒ_feat = Σ_scale (1 − cos(f_S, f_T))   # DINOv2/ViT-Adapter 감독
    ℒ_SSIM = 1 − SSIM(M_S, M_T)
    ℒ_distill = w_feat·ℒ_feat + w_task·[(1−w_ssim)ℒ_task + w_ssim·ℒ_SSIM]
    update(θ_S, ∇ℒ_distill)

# 단계 2: 조건 디퓨전 학습
for (I, v_0, g, x_0) in D:
    M = S_θ(I); F_I = enc(I); F_S = patch_tokens(M)
    c = {v_0, g, F_I, F_S}
    t ~ U(1,T);  ε ~ N(0,I)
    x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε
    ℒ = ‖ε − ε_θ(x_t,t,c)‖² + λ1 ℒ_smooth + λ2 ℒ_origin + λ3 ℒ_speed + λ4 ℒ_safe
    update(θ_ε, ∇ℒ)

B.2 추론 + 2단계 가이드 (Inference with Guidance)

입력: 관찰 I, depth, 속도 v_0, 목표 g
M = S_θ(I, depth)                                   # 신뢰도 히트맵
# 가상 장애물을 ESDF에 합류
pcd = depth_to_pointcloud(depth)
hard = backproject(M ≤ 0.3, 여러 깊이)               # 확실한 위험
pcd_aug = merge(pcd, hard)
ESDF = build_esdf(pcd_aug)                           # C_obs용
weak = (0.3 < M ≤ 0.6)                               # 애매한 위험 → C_perc(CHOMP)

c = {v_0, g, enc(I), patch_tokens(M)}
x_T ~ N(0, I)
for t = T..1:
    ε = ε_θ(x_t, t, c)
    x̂_0 = (x_t − √(1−ᾱ_t)·ε) / √ᾱ_t                 # clean-manifold 투영(미터좌표)
    C = w_obs·C_obs(x̂_0; ESDF) + w_goal·‖p_H−g‖² + w_perc·C_perc(x̂_0; weak, η_perc)

    x_{t-1} = DDPM_step(x_t, ε̂, t)
return x_0   # 절대 ego-frame waypoints → ArduPilot/MAVROS 실행

부록 C. 수식 유도 및 정량 심화 (Derivations & Quantitative Deep-Dive)

C.1 DDPM 기반 — 순방향/역방향과 본 논문의 조건화 위치

표준 DDPM의 순방향 과정은 다음 마르코프 연쇄다.

q(x_t | x_{t-1}) = N(x_t; √(1−β_t)·x_{t-1}, β_t·I)
누적:  ᾱ_t = Π_{s=1}^{t}(1−β_s)
닫힌형:  q(x_t | x_0) = N(x_t; √ᾱ_t·x_0, (1−ᾱ_t)·I)
        ⇒  x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε,   ε ~ N(0,I)

역방향(생성)은 p_θ(x_{t-1}|x_t) = N(μ_θ(x_t,t), Σ_t) 를 학습한다. ε-parametrization에서

μ_θ(x_t,t) = (1/√(1−β_t))·( x_t − (β_t/√(1−ᾱ_t))·ε_θ(x_t,t,c) )

본 논문은 ε_θ를 조건 c={v_0,g,F_I,F_S}에 의존시키는 표준 조건 디퓨전이며, 신규성은 ε_θ 자체가 아니라 (a) 조건에 신뢰도 토큰 F_S가 들어간다는 점과 (b) 디노이징 평균 μ_θ를 ESDF 비용 그래디언트로 추가 조향한다는 점에 있다.

C.2 가이드 항이 사후분포에 대응함 (classifier-guidance 관점)

score-based 관점에서 ε_θ ≈ −√(1−ᾱ_t)·∇_{x_t} log p(x_t|c). 비용 C를 에너지로 보면 안전 사전 p_safe(x_t) ∝ exp(−s·C(x_t)). 두 분포의 곱(사후)에 대한 score는

∇ log [ p(x_t|c)·p_safe(x_t) ] = ∇ log p(x_t|c) − s·∇C
⇒ ε̃_θ = ε_θ + √(1−ᾱ_t)·s·∇C    (부호 규약에 따라)  ≈ ε_θ − s·∇_{x_t}C

즉 본 논문의 ε̃_θ = ε_θ − s·∇_{x_t}C는 "학습된 자연스러운 비행 사전 × 안전 에너지 사전"의 곱 분포에서 샘플링하는 것과 등가다. 이것이 training-free 가이드가 이론적으로 정당한 이유다 — 별도 분류기 학습 없이, 미분가능 비용 C만 있으면 사후분포 score를 구성한다.

C.3 clean-manifold 투영이 필요한 이유

비용 C(ESDF 거리, 목표 거리)는 미터 단위 깨끗한 궤적 x_0에서 정의된다. 그러나 디노이징 중 다루는 x_t는 노이즈가 섞여 스케일이 다르다. Tweedie 추정으로 깨끗한 궤적을 복원:

x̂_0 = E[x_0 | x_t] = (x_t − √(1−ᾱ_t)·ε_θ(x_t,t,c)) / √ᾱ_t

x̂_0(미터 좌표)에서 ∇C를 계산해야 ESDF 거리·목표 거리가 물리적으로 올바른 방향을 가리킨다. 갱신 후 다시 노이즈 좌표로 환원(ε̂ = (x_t − √ᾱ_t·x̂_0*)/√(1−ᾱ_t))하여 DDPM 스텝을 잇는다. 만약 x_t에서 직접 ∇C를 계산하면 노이즈 스케일 √ᾱ_t 만큼 왜곡된 그래디언트가 되어 가이드가 부정확해진다.
