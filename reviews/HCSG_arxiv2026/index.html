1.2 연구 목표 (Research Objective)

HCSG는 동적 인간-로봇 공존 환경에서의 Vision-Language Navigation(VLN) 문제를 해결한다. 기존 VLN 연구가 정적 환경을 가정하는 것과 달리, 실세계 실내 환경에서는 이동하는 보행자가 필연적으로 존재하며, 이는 단순한 장애물 회피 이상의 문제다.

핵심 연구 질문:

"로봇이 자연어 지시에 따라 내비게이션할 때, 동적 보행자를 단순한 이동 장애물이 아닌 의도와 행동을 가진 사회적 행위자로 이해하고, 이에 따른 사회적으로 지능적인 내비게이션을 수행할 수 있는가?"

본 논문의 핵심 주장:

[HCSG의 핵심 패러다임 전환]

기존 접근:
  인간 = 이동하는 장애물
  처리: 충돌 회피만 (암묵적 시각 단서 기반)
  결과: 사회적 규범 무시, 높은 충돌률

HCSG 접근:
  인간 = 의도와 행동을 가진 사회적 행위자
  처리: 자세 예측 + 궤적 예측 + 의미론적 행동 이해
  결과: 사회적으로 지능적인 내비게이션
  
패러다임 전환:
  수동적 충돌 회피 → 능동적 인간 행동 이해
  (Passive Collision Avoidance → Active Human Behavior Understanding)

결과적으로 HA-VLNCE 벤치마크에서 SR 0.24 (기존 최고 0.21 대비 +14.3% 향상), CR 0.36 (기존 0.55 대비 -34.5% 충돌률 감소), 실세계 배포에서 82% SR (vs BEVBert 38%)를 달성한다.

2. 문제 정의 (Problem Definition)

2.1 도전과제 (Challenges)

A. 정적 환경 가정의 현실적 한계

기존 VLN 연구의 가장 큰 가정: 환경이 정적이다.

[정적 환경 가정의 붕괴]

시뮬레이션 환경 (R2R, RxR, ...):
  - HM3D, Matterport3D: 스캔된 정적 씬
  - 사람 없음, 물체 이동 없음
  - 에이전트가 유일한 동적 요소

실세계 환경:
  - 복도를 걷는 사람들 (지속적 교란)
  - 방 출입구를 막는 사람 (경로 차단)
  - 반대편에서 오는 보행자 (방향 결정 필요)
  - 카트나 청소 로봇 등 이동 물체

격차 측정 (HA-VLNCE 기준):
  ETPNav (정적 환경 학습):  SR 0.17, CR 0.58
  BEVBert (정적 환경 학습): SR 0.21, CR 0.55
  
  이 방법들의 CR (충돌률) 0.55-0.77은 
  실세계 배포 시 실용 불가능한 수준

B. 기존 인간-인식 접근법의 한계

동적 환경을 다루려는 이전 시도들:

[기존 인간-인식 VLN의 문제점]

접근법 A: 점유 예측 (Occupancy Prediction)
  방법: 미래 점유 그리드 예측 → 경로 계획
  한계:
    - 사람의 의도 무시 (방향만 예측)
    - 단기 예측만 가능 (1-2 스텝)
    - 신호가 없는 길에서 대기 vs 진행 판단 불가

접근법 B: 소셜 포스 모델 (Social Force Model)
  방법: 물리적 인력/척력으로 회피 경로 생성
  한계:
    - 의미론적 이해 없음 ("이 사람은 전화 중이라 집중 않함")
    - 그룹 행동 처리 미흡
    - 사회적 규범 (앞지르기 방향, 개인 공간) 미구현

접근법 C: 암묵적 시각 단서 기반
  방법: 사람 이미지를 직접 VLN 모델에 입력
  한계:
    - 블랙박스: 인간 동작의 명시적 이해 없음
    - 일반화 제한: 보이지 않는 인간 행동에 취약
    - 설명 불가: 왜 특정 경로를 선택했는지 알 수 없음

HCSG의 해결책:
  → 기하학적 예측 (자세 + 궤적) + 의미론적 이해 (VLM 행동 해석)의 통합
  → "이 사람이 왼쪽으로 이동할 것 같고, 손을 들고 있어서 대화 중인 것 같다"
     → 오른쪽으로 돌아 접근하여 사회적 규범 준수

C. HA-VLNCE 벤치마크의 도전 요소

[HA-VLNCE 데이터셋 분석]

데이터셋 구성:
  - 86개 HM3D 씬 기반
  - 910개 동적 인간 인스턴스 배치
  - 486 SMPL 인간 모션 모델 (다양한 동작)
  - 172가지 활동 카테고리 (걷기, 서있기, 청소, 대화 등)
  - 16,844개 지시: 10,819 train / 778 val-seen / 1,839 val-unseen

인간 동작 분포:
  ┌────────────────────────────────────┐
  │ 활동 카테고리       비율            │
  │────────────────────────────────────│
  │ 걷기/이동          35.2%           │
  │ 서있기/대기        22.1%           │
  │ 앉아있기           15.4%           │
  │ 특정 작업 수행      18.7%           │
  │ 대화/상호작용       8.6%            │
  └────────────────────────────────────┘

평가 지표:
  - SR (Success Rate): 3m 이내 목표 도달
  - CR (Collision Rate): 에피소드당 평균 충돌 횟수
  
  현재 SOTA:
  CR 0.55 (BEVBert) → 에피소드당 0.55회 충돌
  SR 0.21 (BEVBert) → 21%만 성공

  실용 기준:
  CR < 0.5 → 수용 가능 (자주 사용되지 않는 경우)
  CR < 0.2 → 실용적 배포 가능
  HCSG: CR 0.36 → 개선되었으나 추가 연구 필요

2.2 핵심 해결책

[HCSG의 3요소 해결책]

요소 1: 기하학적 예측 (Geometric Reasoning Module)
  - 자세(Pose) 예측: LSTM으로 17 키포인트 × 3미래 프레임
  - 궤적(Trajectory) 예측: 에이전트 중심 좌표에서 미래 이동 경로
  → 인간의 미래 위치를 수치적으로 예측하여 경로 계획에 통합

요소 2: 의미론적 해석 (Semantic Reasoning Module)
  - Qwen3-VL-2B-Instruct로 인간 행동 자연어 서술 생성
  - "사람이 오른쪽으로 몸을 돌리고 있어 곧 전진할 것 같음"
  → 텍스트로 인코딩된 행동 의미 → VLN 행동 결정에 통합

요소 3: 사회적 거리 손실 (Social Distance Loss)
  - 충돌 페널티 + 근접도 페널티로 사회적 공간 학습
  - 인간 방향(전면 가중치 높음)에 따른 비대칭 근접 페널티
  → 학습 단계에서 사회적 규범 명시적 강화

3. 핵심 방법론 (Core Methods)

3.1 기하학적 추론 모듈 (Geometric Reasoning Module)

기하학적 추론 모듈은 인간의 자세 예측과 궤적 예측 두 부분으로 구성된다.

3.1.1 자세 예측 (Pose Prediction)

[LSTM 기반 인간 자세 예측]

입력 단계:
  1. YOLO-Pose로 현재 프레임에서 인간 감지
  2. 6 프레임 시간 윈도우 수집 (웨이포인트 전환 일시 정지 중)
  3. 각 프레임에서 17 키포인트 추출 (COCO 포맷)
     키포인트: 코, 좌/우 눈, 귀, 어깨, 팔꿈치, 손목, 
              엉덩이, 무릎, 발목

입력 시퀀스:
  X_hist = {(k_{t-5}, ..., k_{t-1}, k_t)}
  k_t ∈ R^{17 × 3}  (x, y, 신뢰도)

LSTM 인코더:
  h_t = LSTM_enc(k_t, h_{t-1})
  h_enc ∈ R^{d_h}  (히든 상태)

LSTM 디코더 (3 미래 프레임 예측):
  k_{t+1} = LSTM_dec(h_enc, k_t)  ← 자기회귀 예측
  k_{t+2} = LSTM_dec(h_enc, k_{t+1})
  k_{t+3} = LSTM_dec(h_enc, k_{t+2})

예측 출력:
  K_pred = {k_{t+1}, k_{t+2}, k_{t+3}}
  K_pred ∈ R^{3 × 17 × 3}  (3미래 × 17키포인트 × (x,y,conf))

손실 함수:
  L_pose = (1/N) Σ_i [ ||k_i^pred - k_i^gt||² + γ₁(c_i^pred - c_i^gt)² ]
  
  여기서:
  N: 총 키포인트 수 (3 × 17 = 51)
  γ₁ = 0.5: 신뢰도 손실 가중치
  
  위치 손실: L2 거리 (픽셀 좌표)
  신뢰도 손실: 신뢰도 점수 MSE

LSTM 아키텍처:
  인코더: 2 레이어, 256 히든 유닛
  디코더: 2 레이어, 256 히든 유닛
  입력 차원: 17×3 = 51 → 임베딩 레이어 → 128차원
  출력 차원: 51 (디인임베딩)
  드롭아웃: 0.2 (학습 시)

왜 "미래 지향 히든 상태(Future-Oriented Hidden States)"를 사용하는가?

[Future-Oriented Hidden States의 중요성]

일반적 접근: 역사적 히든 상태 사용
  h_enc → Feature_hist (과거 패턴 인코딩)
  
문제: 
  과거에 어떻게 움직였는지 알지만
  미래에 어떻게 움직일지는 다른 문제
  
  [예시]
  사람이 3초간 왼쪽으로 걷다가 멈춤 → h_enc = "왼쪽 이동 패턴"
  하지만 다음 순간 오른쪽으로 방향 전환 가능

HCSG의 해결책: Future-Oriented Hidden States
  h_future = LSTM_dec(h_enc, ...) 의 디코더 히든 상태
  h_future ∈ R^{3 × d_h}  (3 미래 스텝)
  
  F_geo^{t,k,j} = Concat(h_future)  ← 기하학적 특징으로 사용
  
  의의:
  - 디코더가 미래를 예측하는 과정에서 형성된 내부 표현
  - "앞으로 어떻게 움직일 것인가"에 특화된 특징
  - 방향 전환, 가속/감속 의도 인코딩 포함

실험 검증 (ablation):
  역사적 히든 상태 사용: CR 0.44 / SR 0.22
  미래 지향 히든 상태 사용: CR 0.36 / SR 0.24  ← 개선
  → 미래 지향이 더 적은 충돌, 더 높은 성공률

3.1.2 궤적 예측 (Trajectory Prediction)

[핀홀 역투영 + LSTM 궤적 예측]

단계 1: 2D 감지 → 3D 위치 변환 (핀홀 역투영)
  
  깊이 센서 기반 3D 위치:
  [X, Y, Z] = Z · K^{-1} · [u, v, 1]^T
  
  여기서:
  Z: 깊이 센서에서의 깊이 값 (해당 픽셀)
  K: 카메라 내재 파라미터 행렬
  [u, v]: 인간 중심 픽셀 좌표 (YOLO 바운딩 박스 중심)
  
  에이전트 중심 좌표로 변환:
  P_agent = R_cam_to_agent · P_cam  (에이전트 상대 좌표)
  
  [좌표 변환 예시]
  카메라 좌표: [1.2, 0.8, 3.5] m
  에이전트 중심: [3.5 (전방), -1.2 (우방), 0.8 (상방)] m

단계 2: LSTM 궤적 예측
  
  입력: p_hist = {p_{t-T}, ..., p_t}  (T=6 프레임)
  p_t ∈ R^3: 에이전트 중심 3D 위치
  
  속도 인코딩:
  v_t = (p_t - p_{t-1}) / Δt  ← 스텝별 속도 계산
  
  LSTM 입력: concat(p_t, v_t) ∈ R^6
  
  예측 출력:
  {p_{t+1}, p_{t+2}, ..., p_{t+T_f}}: T_f=3 미래 위치
  {v_{t+1}, v_{t+2}, ..., v_{t+T_f}}: T_f=3 미래 속도
  
  손실 함수:
  L_traj = (1/T_f) Σ_t [ ||p_t^pred - p_t^gt||² + γ₂||v_t^pred - v_t^gt||² ]
  
  여기서:
  γ₂ = 0.3: 속도 손실 가중치
  
  의의: 속도를 함께 예측함으로써 가속/감속 패턴 포착

궤적 특징 사용:
  F_traj^{t,k,j} = Concat(p_pred^{1:T_f}, v_pred^{1:T_f})
  → 토폴로지 맵 노드 특징으로 통합

3.2 의미론적 추론 모듈 (Semantic Reasoning Module)

[VLM 기반 인간 행동 의미 해석]

목적: "이 사람은 무엇을 하고 있는가?"를 자연어로 표현
도구: Qwen3-VL-2B-Instruct

처리 파이프라인:

단계 1: 크롭 이미지 추출
  파노라마 360° 뷰에서 감지된 인간 주변 크롭
  바운딩 박스 확장: bbox + 50px 패딩 (맥락 포함)
  크롭 해상도: 224×224 (VLM 입력 최적화)

단계 2: VLM 프롬프트 구성
  프롬프트 템플릿:
  "Describe the action and intention of the person in the image. 
   Focus on: (1) current activity, (2) movement direction/tendency, 
   (3) potential interaction with nearby space.
   Keep the response under 2 sentences."

단계 3: VLM 추론
  Qwen3-VL-2B (경량 VLM, 2B 파라미터)
  
  출력 예시:
  - "A person is walking briskly towards the left, 
     likely heading to the adjacent room."
  - "A person is standing still near the doorway, 
     possibly waiting for someone."
  - "A person is reaching for items on the shelf, 
     occupying the central corridor area."

단계 4: 텍스트 특징 인코딩
  F_sem^{t,k,j} = CLIP_TextEncoder(description)
  F_sem ∈ R^{d_clip}  (d_clip = 512 for CLIP-ViT-B/32)
  
  CLIP 텍스트 인코더 선택 이유:
  - VLN 에이전트의 지시 인코더와 동일한 임베딩 공간
  - 의미론적 정렬 자연스럽게 달성
  - 경량화: CLIP 텍스트 인코더 ~63M 파라미터

단계 5: 기하 + 의미 특징 통합
  F_human^{t,k,j} = F_geo^{t,k,j} + F_sem^{t,k,j}
  (간단한 덧셈 융합 — 동일 차원으로 프로젝션 후)

[의미론적 추론의 실제 기여]

행동 기반 의사결정 예시:

시나리오 1: 서있는 사람이 문 앞 차단
  기하학적 정보: 위치 (1.2, 0, 2.5), 속도 ≈ 0
  의미론적 정보: "A person is standing still near the door, 
                  looking at their phone."
  의사결정: 5초 대기 후 우회 경로 선택
            (서있는 경우 곧 이동할 수 있음을 학습)

  기하학적 정보: 위치 (-0.8, 0, 4.2), 속도 (0, 0, -0.5) m/s
  의미론적 정보: "A person is walking directly towards the robot 
                  at a steady pace."
  의사결정: 오른쪽으로 이동하여 양보 (사회적 규범)

3.3 사회적 거리 손실 (Social Distance Loss)

HCSG의 핵심 학습 신호 중 하나는 사회적 규범을 명시적으로 강화하는 손실 함수다.

[Social Distance Loss 설계]

전체 손실:
  L_total = L_nav + L_pose + L_traj + L_coll + L_prox

여기서:
  L_nav: 표준 VLN 내비게이션 손실 (목표 도달)
  L_pose: 자세 예측 손실 (위에서 정의)
  L_traj: 궤적 예측 손실 (위에서 정의)
  L_coll: 충돌 패널티 손실
  L_prox: 근접도 패널티 손실

---

[충돌 손실 L_coll]

정의: 실제 충돌 발생 시 이진 패널티
수식: L_coll = λ_c · Σ_{i∈C} δ_i

여기서:
  C: 에피소드 중 충돌 인덱스 집합
  δ_i = 3.0: 충돌당 패널티 값
  λ_c = 0.5: 충돌 손실 가중치

충돌 정의: 에이전트와 인간의 바운딩 박스 겹침
  또는 에이전트-인간 거리 < 0.5m

---

[근접도 손실 L_prox]

목적: 충돌하지 않더라도 너무 가까이 접근하는 것을 방지
      사회적 개인 공간(Personal Space) 학습

수식:
  L_prox = λ_p · Σ_j ϕ(θ_j) / max(||d_j||², ε_p)

여기서:
  d_j: 에이전트-인간 j 간 2D 거리 벡터
  ||d_j||: 거리 크기 [m]
  ε_p = 0.0625 = (0.25m)²: 최소 거리 클리핑 (0 나눗셈 방지)
  λ_p = 0.3: 근접도 손실 가중치
  r_s = 1.0m: 사회적 안전 거리 (이 이상에서는 패널티 없음)

방향 가중치 ϕ(θ_j):
  θ_j: 에이전트 전진 방향 기준 인간까지의 각도
  
  ϕ(θ_j) = 1.0   if |θ_j| < 45°   (정면 접근 — 가장 위험)
           = 0.75  if |θ_j| < 90°   (측면 접근 — 중간 위험)
           = 0.5   if |θ_j| < 135°  (뒤 45° — 낮은 위험)
           = 0.25  if |θ_j| < 180°  (후방 접근 — 최소 위험)
  
  [방향 가중치 시각화]
  
             ϕ=1.0
          ┌────────┐
  ϕ=0.75  │ (로봇) │  ϕ=0.75
   ◄──────┤   ↑    ├──────►
  ϕ=0.5   │        │  ϕ=0.5
          └────────┘
             ϕ=0.25
             (후방)

  설계 근거: 인간은 전면에서 접근하는 물체를 더 위협적으로 인식
           사회적 규범: 측면/후방 접근이 정면보다 덜 불편

거리-손실 관계:
  ||d_j|| = 0.5m:  패널티 = ϕ · 4.0  (매우 높음)
  ||d_j|| = 1.0m:  패널티 = ϕ · 1.0  (중간)
  ||d_j|| = 2.0m:  패널티 = ϕ · 0.25 (낮음)
  ||d_j|| > r_s:   패널티 = 0         (안전 거리 이상)
  
  → 1/r² 감쇠: 가까울수록 급격히 증가하는 패널티

4.2 토폴로지 맵 기반 계획

[HCSG의 토폴로지 맵 구조]

노드 (Waypoint):
  위치: 3D 좌표 (에이전트 좌표계)
  특징: F^fused_v = MLP(F^static_v, H_human_v)
  
  여기서:
  F^static_v: 노드 v에서의 정적 시각 특징
  H_human_v = 1/J Σ_j (F_geo^j + F_sem^j): 
              해당 웨이포인트 근처 J명의 인간 특징 평균
  
엣지 (이동 가능성):
  가중치: 거리 × 사회적 안전성
  사회적 안전성 = 1 - normalized(L_prox(edge_path))

행동 결정:
  탐색 웨이포인트 선택:
  a_t = argmax_v [ Score_nav(v, h_I) + λ_safe · Score_safe(v) ]
  
  여기서:
  Score_nav(v, h_I): 지시-목표 정렬 점수
  Score_safe(v): 사회적 안전 점수
  λ_safe = 0.3: 안전 점수 가중치 (ablation으로 결정)

6. 핵심 기여점 (Key Contributions)

[HCSG의 4가지 핵심 기여]

기여 1: 인간 중심 VLN 프레임워크 최초 제안
  기존: 인간을 이동 장애물로 처리
  HCSG: 인간을 의도/행동을 가진 사회적 행위자로 처리
  → VLN 연구에서 "동적 환경" 문제를 정면으로 다룬 최초 체계적 접근

기여 2: 통합 인간 이해 모듈 (Unified HUM)
  기하학적 예측 (자세 + 궤적) + 의미론적 이해 (VLM)의 통합
  → 수치적 예측과 의미론적 이해의 상보적 결합
  → 각각으로는 달성 불가능한 사회적 지능 구현

기여 3: 사회적 거리 손실 (SDL)
  물리적 충돌 페널티 + 근접도 페널티의 비대칭 설계
  → 충돌 이전 상황도 억제하는 예방적 학습
  → 방향 가중치로 사회적 규범(전면 vs 후면 접근)을 수학적으로 표현

기여 4: HA-VLNCE 벤치마크 활용 및 실세계 검증
  HA-VLNCE에서 SOTA: SR +14.3%, CR -34.5%
  실세계 배포: 82% vs 38% (BEVBert 대비 2.2× 향상)
  → 시뮬레이션 성능과 실세계 성능의 동반 향상 증명

8.1 Habitat 3 시뮬레이터와 실세계 간 갭

[Sim-to-Real 전이 분석]

Habitat 3 특성:
  - SMPL 기반 인간 모델 (실제 체형과 유사)
  - 물리 기반 모션 (실제 보행 패턴)
  - 충돌 감지: 정확한 메쉬 기반
  
실세계 갭:
  1. 인간 다양성: Habitat 3 < 실세계 (옷 종류, 체형 편차)
  2. 예측 불가능성: 실제 인간이 더 갑작스러운 방향 전환
  3. 멀티모달 행동: 전화+걷기, 짐+운반 등 복합 행동
  
갭 완화 전략:
  - Qwen3-VL: 오픈-도메인 비전-언어 이해 → 실세계 다양성 처리
  - 사회적 거리 손실: 예측 오차에 강건한 여유 확보
  - 미래 지향 히든 상태: 복잡한 패턴도 내부 표현으로 처리

전이 성능:
  HA-VLNCE (시뮬레이션) SR: 0.24
  실세계 SR: 0.82
  → 실세계가 더 높은 이유: 
    (a) 실세계 실험이 더 단순한 시나리오
    (b) 실세계 인간이 로봇과 협조적으로 행동
    (c) 평가 지표 차이 (엄격한 3m vs 더 유연한 실세계 판단)

8.2 의미론적 추론의 한계

[VLM 기반 의미론적 추론의 현실적 한계]

한계 1: 추론 지연 (Latency)
  Qwen3-VL-2B 추론: ~200ms per 인간 감지
  여러 인간이 동시에 있는 경우: 400ms+
  → 고속 이동 시나리오에서 지연 문제
  → 현재: 웨이포인트 전환 시에만 실행 (움직임 일시 정지)
  
한계 2: 행동 해석 오류
  비정형 행동 (예: 누군가 쓰러진 상황) → 오해석 가능
  문화적 차이 (예: 손짓의 의미) → 다국어/다문화 환경 위험
  
한계 3: 맥락 단절
  각 웨이포인트에서 독립적 해석 (연속성 없음)
  2초 후 같은 사람의 행동 변화 → 이전 해석 폐기
  → 향후: 대화 이력을 LLM에 주입하여 맥락 유지

한계 4: 복수 인간 처리
  J명 인간의 특징 단순 평균 (1/J Σ)
  그룹 상호작용 정보 손실
  → 향후: 그래프 기반 인간-인간 상호작용 모델링

8.3 확장성

[HCSG의 다양한 적용 시나리오]

적용 1: 다중 인간 밀집 환경
  현재: J=1-3명 가정 (HA-VLNCE 평균)
  확장: J=10+ 명 (쇼핑몰, 역 등)
  필요: 그룹 행동 모델링, 계층적 우선순위
  
적용 2: 다양한 로봇 플랫폼
  현재: 모바일 플랫폼 (NXROBO Leo)
  확장: 휴머노이드 (Unitree G1), 사족보행 (Go1)
  필요: 로봇별 안전 반경 설정, 모션 패턴 조정
  
적용 3: 실외 환경
  현재: 실내만 (HA-VLNCE)
  확장: 보행자가 있는 실외 보도, 공원
  필요: GPS 통합, 더 큰 사회적 안전 반경
  
적용 4: 접근성 지원 로봇
  시각 장애인 안내, 노인 보조
  장점: 인간 의도 이해 → 안전한 상호작용
  추가 필요: 촉각 피드백, 음성 통신

9.4 연구 방향성 평가

[VLN 연구 트렌드에서 HCSG의 위치]

현재 VLN 연구 방향:
  (A) 더 좋은 씬 표현 (BEV, 3D SceneGraph)
  (B) 더 강한 사전학습 (MLLM 백본)
  (C) 효율화 (캐싱, 스트리밍)
  (D) 실세계 배포 (Sim2Real, 온라인 학습)
  (E) 동적 환경 ← HCSG가 개척하는 새 방향

HCSG의 연구 방향성 평가: ★★★★☆

이유:
  1. "동적 환경" 문제는 실세계 배포의 핵심 장벽
  2. 기존 연구들이 완전히 무시한 문제를 체계적으로 접근
  3. 시맨틱-기하학 통합은 인간 이해의 올바른 방향

주의사항:
  - HA-VLNCE에서 SR 0.24는 절대적으로 낮음
  - 기본 내비게이션 능력 유지하면서 동적 환경 처리가 목표
  - StereoNav (SR 0.81)와 통합 가능성 탐색이 바람직

VLN 연구 로드맵에서의 의의:
  StereoNav: 시뮬레이션↔실세계 갭 해결 → 정적 환경 SOTA

  → StereoNav의 시각 강건성 + HCSG의 인간 인식 = 실용적 VLN

미래 영향:
  - HA-VLNCE 벤치마크 표준화 가속
  - 동적 환경 VLN 연구 커뮤니티 형성
  - 소셜 로봇공학과 VLN의 교차점 개척

11. 결론 (Conclusion)

11.1 혁신성 요약

HCSG는 VLN 연구에서 오랫동안 무시되어 온 동적 인간-로봇 공존 문제를 처음으로 체계적으로 해결한다. 이는 단순히 성능 수치 개선을 넘어, VLN 연구 패러다임의 새로운 방향을 제시하는 데 있다.

핵심 혁신:

[HCSG가 여는 새로운 연구 패러다임]

기존 VLN:
  "어떻게 지시대로 목표에 효율적으로 도달하는가?"
  (효율성, 정확도, 시뮬레이션 성능 중심)

HCSG 이후 VLN:
  "어떻게 사람들과 공존하면서 안전하고 사회적으로 지능적으로 내비게이션하는가?"
  (안전성, 사회적 지능, 실세계 적용 가능성 중심)

이 패러다임 전환은 VLN이 연구용 태스크에서 실용적 기술로 
전환하는 데 필수적인 진화다.

11.2 실용적 의의

[HCSG의 실용적 가치]

단기 (1-2년):
  - HA-VLNCE에서 표준 방법으로 자리매김 가능
  - 코드 공개 후 다른 연구자들의 기반으로 활용
  - 병원/요양원 등 고안전 환경 로봇 프로토타입

중기 (3-5년):
  - 동적 환경 VLN 표준 접근법 확립
  - StereoNav 등과 통합하여 완전한 실세계 VLN 구현
  - 실용화 수준의 충돌률 (CR < 0.1) 달성 가능

장기 (5년+):
  - 모든 상업용 서비스 로봇의 필수 모듈
  - 인간-로봇 공존의 기술적 기반
  - 소셜 로봇공학의 핵심 방법론으로 발전

11.3 향후 연구 방향

HCSG가 제기하는 중요한 미해결 과제:

  1. 고밀도 인간 처리: J=10+ 명이 동시에 존재하는 환경 (쇼핑몰, 역)
  2. 그룹 행동 이해: 개인이 아닌 그룹의 집단 동작 예측
  3. 능동적 사회 상호작용: 회피만이 아닌 협조 요청 ("실례합니다" 등)
  4. 멀티모달 의사소통: 언어, 제스처, 시선으로 의도 표현
  5. StereoNav 통합: 시각 강건성 + 인간 인식 → 완전한 실세계 VLN

HCSG는 VLN이 단순한 경로 추종을 넘어 사회적으로 지능적인 로봇 내비게이션으로 진화하는 데 핵심 이정표가 될 것이다.
